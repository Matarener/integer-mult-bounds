## B. Full-rank cyclic family with changing reader values

Let r=2,...,7, N=2r. In ordinary E8 coordinates choose
`a_g=e0-e_(g+1)`, `beta=e0+e1`, `gamma=e0-e1`, and take the two ports
`(a_g,beta),(a_g,gamma)` in each group. The scripts store doubled coordinates
and source-faithful17-bit PR606 addresses. Let U_g be the plane of that pair.
The planes share a radical line and the cyclic arc

```
F(g,k)=U_g+...+U_(g+k-1)
```

has dimension k+1. For k≤r-1 it lies in both caps of excluded target group
g+k. Helper arcs F(g,k) are nested. For fixed source group j the preceding
inclusive arcs F(j-d,d+1), d=0,...,r-2, are also nested. These facts are checked
on the actual17-bit subspaces, not inferred from real dot products alone.

The literal compensation is

```
C=(J_r-I_r) tensor (1/16)*[[-5,1],[1,-5]].
```

It includes the exceptional t=3 coefficient. Both C and the restricted
K=I-C have full rank N; their eigenvalues are checked exactly. The older
read-only cyclic word, in `cyclic_mixed.py`, gathers one pair's plus/minus
values and visits the other groups in depth order. It already changes the
one-source architecture, but leaves reader packets unchanged after loading.

The new `dynamic_cyclic.py` instead allocates two dirty readers per group,
`h_g^+=d_g^+`, `h_g^-=d_g^-`, and changes them during traversal. At depth d,
the pair g advances to F(g,d+1), and original source group g+d visits that
same frame. The reader updates are

```
h_g^+ += x_(g+d,0)+x_(g+d,1),
h_g^- += x_(g+d,0)-x_(g+d,1),   d=0,...,r-2.
```

Every original source remains unchanged and makes only its nested preceding
arc visits, then reaches FULL. Thus h_g contains all original sources except
group g-1. These are successive input reads, rather than free access to a
precomputed aggregate. There is no source reset or private compensation copy.

The excluded target pair t=g-1 reads only h_g. Its coefficients are
`-h_g^+/8-3h_g^-/16` for target0 and
`-h_g^+/8+3h_g^-/16` for target1. At ZERO first subtract exactly these
coefficients of the original dirt d_g from those targets. Run the complete
arbitrary-input K word while all targets remain ZERO. This word uses N
ordinary centres and N separate width17 private episodes on this finite
subfamily. After K, each target climbs once to F(g,r-1), receives the final
reader value and finishes its cap climb. Each reader then reaches FULL and
subtracts every original source it accumulated, restoring its arbitrary dirt.

Writing L for this all-but-excluded plus/minus accumulation and R for the
single-pair decoder, exact rational multiplication gives RL=C. The complete
ordinary map is therefore

```
(x,y,c,d) -> (x,y+(K+RL)x,c,d)=(x,y+x,c,d).
```

The same-order inverse-transpose word, including separately defined dual
private episodes, is `(x,y,c,d)->(x-y,y,c,d)`. The helper dirt need not remain
unchanged at intermediate dual cuts. Both endpoint identities include every
ordinary input column. A separate closed-block matrix product verifies the
same endpoints without parsing the event stream.

## C. Why the fresh/read-only packet integration fails

The coefficient identity is useful even though this integration does not
close. For canonical root a, signed b fibres write x^+=x(a,b)+x(a,-b) and
x^-=x(a,b)-x(a,-b). For fixed target a' and source b-line define

```
F0=sum_(a dot a' even) w(a)*x^-(a,b), w=1 except w(a')=-3,
F1=sum_(a dot a' odd) (a dot a')*x^+(a,b),
F2=sum_(a dot a' odd) x^-(a,b), P=x^+(a',b).
```

For target b'=sigma times a canonical b-line, v=b dot b', its contribution is
`sigma*v*F0/16-P/8` when v is odd, `F1/16` when v=0, and
`-3F1/16-sigma*F2/8` on the same b-line. All64 scalar cases, diagonal I
and exceptional E included, are checked in `partial_filter.py`.

The promising inventory was14400 line-loaded rank8 readers[1,7,8,1],28800
fresh rank8 packets[8,8,1], and14400 plus-input P readers[1,15,1]. With
coarse data[16] this57600-role relaxation has positive raw .002,L5 slack

Its read-only F1 broadcasts cannot retain those coarse target paths. For
fixed a', each F1(a',b) serves64 distinct target b-line caps: those orthogonal
or equal to b. With R_E8=(a_i dot a_j)^2 on the120 canonical root-lines,
their incidence matrix O is `J-R_E8+4I`. Exact root association gives

```

```

ordinary packet on a monotone path can scatter at at most one full rank16
