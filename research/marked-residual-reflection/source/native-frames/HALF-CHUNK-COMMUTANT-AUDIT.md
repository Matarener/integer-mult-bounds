# Typed half-chunk queries in the restricted bridge grammar

Scientific source: canonical `20ecf2891d80b5acf18d980b2164fb44ea7faa90`.
This independently audits the scope of the marked-residual argument. It does
not extend the argument to arbitrary ADDRESS or Pauli adapters.

Let a chunk contain f address bits. The actual operators are
`Hp_f=(Z C^-1)^tensor f`, `Hq_f=(Z C)^tensor f`, where
`C=((1+i)I+(1-i)X)/2`. In the simultaneous physical-X character basis,

    Hp_f |x>_X = (-i)^|x| |x xor 1^f>_X,
    Hq_f |x>_X = i^|x| |x xor 1^f>_X,
    Hq_f = Hp_f X_all.

These formulas follow by diagonalizing each literal C and letting Z exchange
the two X characters. They include the actual global phases.

Write `b=x_1`, `r_j=x_j xor x_1`, so `r_1=0`. Each Hp or Hq preserves r and
flips b. There are `2^(f-1)` residual labels. Choose any complex square root
`lambda_f^2=(-i)^f`; in the pair with residual r use basis multiplier
`g_0=1`, `g_1=(-i)^|r|/lambda_f`. Hp is then exactly `lambda_f X_virtual`.
This is only a basis for a rank proof. It introduces no physical scalar,
Gaussian normalization, or allowed operation. In particular the proof works
for odd f as well as even f. Hq is Hp times the actual diagonal X_all, and
has the same virtual-bit flip.

Fix L physical chunks and f>=2. Choose distinct residuals r0=0 and r1.
Let V be spanned by all character configurations having r1 at exactly one
chunk (the owner), r0 elsewhere, and arbitrary virtual bits. Then
`dim V = L*2^L`. Define C on this space by

    C |owner,b_1,...,b_L> = (-1)^b_owner |owner,b_1,...,b_L>.

Every whole-chunk permutation preserves V and commutes with C: it moves
the owner and the virtual bits by the same permutation. The above gauge
is uniform on all chunks, so this assertion has no omitted gauge phase.
Every physical ADDRESS X translation is diagonal in these characters,
with coefficient `(-1)^(a.r + b|a|)`, hence also preserves V and commutes
with C. Scalar Gaussian coefficients commute as well. Any invertible bank
matrix over the algebra generated by these operations has those properties.
There is no restriction on its word length or on the sizes of its scalar
coefficients.

A paid unary native product on a set S of r distinct chunks, using one Hp
or Hq (or inverse) on each selected chunk, has

    rank_V [C,U_S] = r*2^L.

Indeed it anticommutes on each owner block belonging to S and commutes on
the other owner blocks; every nonzero phase is invertible. Monomial
adapters from the stated commuting algebra preserve this rank. Arbitrary
monomial adapters are not included by that sentence.

On n independent data banks, the full target applying one selected Hp/Hq
on every chunk has commutator rank `n L 2^L`. Arbitrary additional dirty
banks restored literally to I contribute zero. Since

    rank[C,AB] <= rank[C,A] + rank[C,B],

every exact complete word in this grammar satisfies `sum r >= nL`, or
native rank mass at least `n L f`, the full native stock. The result is
unchanged by entrance/exit adapters within the same commuting algebra.
It holds for every f>=2, so restricting an all-size construction to odd f
does not evade it.

The claim is restricted to the displayed physical typed-query alphabet and
whole-chunk-permutation/X-translation bridges. A general bit-linear ADDRESS
map, a Pauli Z, a controlled chart not preserving V, an arbitrary monomial
native adapter, a changed datatype, or a target not equivalent through the
stated commuting algebra requires a new proof. In particular this is not a
lower bound for every native operator of the same Bruhat rank. The unpaired
reflection in `ORTHOGONAL-REFLECTION-PROOF.md` is an explicit legal operation
outside this argument.

The underlying one-chunk phases and selected-native identity are checked by
`one_chunk_phase.py` / `ONE-CHUNK-PHASE.json`; the present all-parameter
argument is a written proof, not a formal-kernel proof or a finite census.
