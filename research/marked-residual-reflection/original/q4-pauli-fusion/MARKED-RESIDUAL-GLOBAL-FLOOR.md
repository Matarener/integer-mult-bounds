# An exact stock floor for whole-plane ADDRESS and X-translation bridges

This result is about a specified operator grammar. It does not cover
arbitrary Pauli Z, arbitrary linear changes of address bits, or native
queries on unrelated symplectic axes. Those are constructive escape routes,
not consequences of the result below.

Let there be `L` ordered planes, each containing `2f` address bits, with
actual operators

```
N_i = i Hp_f(i) Hq_f(i),       N_i^2=-I.
```

Different `N_i` commute. A native query on a union `S` of whole planes is,
up to an explicitly paid Gaussian unit and ADDRESS packing, the product
`N_S=prod_(i in S) N_i`. Its recursive rank is `2f |S|`. The admitted free
coefficient algebra is generated by whole ordered-plane permutations,
all actual X translations, and Gaussian dyadic scalars. Arbitrary
invertible bank matrices over this algebra are allowed, with any number
of scalar ADDs, selectors, bank swaps and the associated paid scans.

For `n` independent banks whose exact final map is the full native
operator `E=prod_(i=0..L-1) N_i`, any word in this grammar satisfies

```
sum_native_queries |S| >= n L,
sum_native_queries rank >= 2f n L = n m,       m=2fL.       (1)
```

Arbitrary dirty helpers restored to identity do not weaken (1). The same
bound applies if the target is changed by invertible outer bank words
over the admitted free algebra. In particular, conditional bank routing
`W(Q)` with any admitted X involution is covered.

## Actual all-f embedding

On one plane choose `Q=X` on one distinguished bit. The actual `N_f`
anticommutes every single-bit X translation: each `Hp/Hq` factor contains
a Z phase and a function of X. The commuting observables

```
R_b=Q X_b,       b other than the distinguished bit,
```

commute with both `Q` and `N_f`. There are `2^(2f-1)` joint residual
labels. For each label `r`, choose a vector `|+,r>` with `Q=+1` and put

```
|-,r> = -i N_f |+,r>.
```

Then, exactly including Gaussian phases,

```
N_f = i X_virtual,       Q=Z_virtual.
```

Every physical X translation is diagonal in these virtual/residual
coordinates. This is a change of basis used in a proof; it is not a free
operation granted to a circuit.

Choose the same two distinct residual labels `u,v` on every plane. They
exist for every `f>=1`. Restrict to tensors with exactly one `v` and all
other labels `u`. The residual basis is `|owner=j>`, `0<=j<L`. This
subspace is invariant under every admitted operation, and has dimension

```
dim V = L 2^L.
```

Whole-plane ADDRESS permutations move the virtual bits and the owner
position together. No faithful-representation assumption or extrapolation
from a small `f` is required.

Define the proof witness

```
C |x,owner=j> = (-1)^x_j |x,owner=j>.
```

It is an involution. Every admitted X translation is diagonal and
commutes with `C`. Every whole-plane permutation moves `x` and `j`
together and commutes with `C`. Consequently every admitted bank bridge
commutes with the bankwise copy of `C`.

`N_S` flips precisely the virtual bits in `S` and preserves the owner.
Its commutator with `C` is nonzero precisely on owner sectors in `S`.
Each such sector contributes `2^L` independent rows and columns, so

```
rank [N_S,C] = |S| 2^L.                                   (2)
```

The full `E` flips the bit at every possible owner. Its commutator is
invertible on `V`, and its `n`-bank target rank is `n L 2^L`. Finally

```
[AB,C] = A[B,C] + [A,C]B,
rank[AB,C] <= rank[A,C]+rank[B,C]
```

for invertible `A,B`. Applying this to the complete word gives (1).
Query inverses, Gaussian units and conjugation by covered bridges have
the same query commutator rank. Neither arbitrary bank mixing nor a
longer free word evades the argument.

## Joint debt and the changed caller's terminal block

The same witness proves that a two-bank diagonal debt on disjoint native
supports `S0,S1` requires total native-plane count at least
`|S0|+|S1|`. Thus the q3 split `(1,2)` cannot use two unary native
queries, and the q4 split `(2,2)` cannot use total native-plane count
three in this grammar.

The distinct full-pair target
`diag(N0 N1,N0 N1)` has rank16 on its two-bank, two-plane marked block.
Every unary query has rank4. It requires at least four unary queries;
three cannot suffice, including arbitrary `GL2(K[Q,R,P])` bridges.

For the actual handoff family, write the terminal pivot-input block as
`H=D R J`, where `R` is a scalar bank permutation and the rows of `D`
are actual monomial native/ADDRESS factories. The required pivot
coefficient is `H^-1 N0`; public compensation columns cannot lower the
rank of this submatrix.

Right multiplying by the displayed factory ADDRESS permutations and a
bank permutation, all commuting with `C`, reduces this coefficient to

```
J^-1 diag(N0 E0,N0 E1),
```

where `E0,E1` have disjoint external native support, avoid planes0,1,2,
and have total support size `q`. On an external owner sector, `J`
commutes with `C`, so the external contribution is exactly `q 2^L`.
The three core owner sectors contribute `3 2^L`: the exact 48 by48
core matrix `J^-1 diag(N0,N0)` has rational commutator rank24, with a
displayed nonsingular 24 by24 minor in the JSON certificate. Spectator
virtual bits multiply this by `2^(L-3)`. Hence the fixed-cut tail needs

```
total native-plane count >= q+3,
native rank mass >= 2f(q+3).                               (3)
```

The current explicit tail has count `q+4`. Equation (3) is a tail bound
after the stated cut. Cross-cut cancellation has its own complete-word
invoice, while (1) applies directly to every complete word that stays
inside the same grammar.

## Exact certificate and limits

Run `python3 -B marked_residual_gate.py`, or add `-O`. The checks use
explicit integer commutator supports for the q3/q4 joint debts, the
two-bank full pair, and an exact rational RREF plus nonsingular minor
for the core matrix. They also bind the changed caller's actual factory
normal forms at q2,3,4,8 to the previously independently replayed word.

`MARKED-RESIDUAL-GLOBAL-FLOOR.json` contains the tiny matrices and scope.
An actual Pauli-Z example moves the residual label, changes the sign of
`C`, and is explicitly rejected as a commuting bridge. Thus the proof
must not be extended to that larger alphabet. All-f circuit identities
using Z, other address maps, or different native subspaces remain open.
