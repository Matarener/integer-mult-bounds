# Marked-residual stock floor and an actual reflection escape

**Scoped caller result; no new κ or selected-frontier change.**

## Result

For `L` ordered planes of `2f` bits, native products on whole
planes, whole-plane ADDRESS permutations, X translations and arbitrary
Gaussian scalar bank GL bridges, a complete word producing the full
native target on `n` independent data banks pays native rank mass at
least `n(2Lf)`, its full stock. Arbitrary dirty helpers restored to
identity contribute no escape. Outer endpoints within the same commuting
algebra do not change the bound.

The [typed half-chunk extension](source/native-frames/HALF-CHUNK-COMMUTANT-AUDIT.md)
gives the analogous stock floor for f>=2 with its explicitly stated chunk
query alphabet. It is a written argument, separate from the plane audit.

An actual bitwise orthogonal transvection `A=I+vv^T`, with four-chunk
support `{p0,q0,p1,p2}`, commutes with the old full three-plane native
source and sends a one-mark residual to a three-mark residual. This is a
concrete escape from the invariant used in the floor. Its conjugated
queries have exact arity `2f`, phases and monomial adapters. The cheap
source-factory conjugation also reduces retained source progress by the
same rank; it does not supply a favorable complete caller.

## Proof and exact coverage

The [plane proof](source/q4-pauli-fusion/MARKED-RESIDUAL-GLOBAL-FLOOR.md)
constructs the invariant residual space and prices the rank of `[C,U]`.
The independent Gaussian audit checks the literal one-bit C/Hp/Hq factors,
all characters for f=1..5, and every native support for L=1..8. The written
tensor embedding and rank subadditivity prove the stated all-parameter
result.

The joint-debt query-count corollaries apply to **single-plane**, rank-`2f`
queries. A unary query may cover several planes: `diag(N0 N1,N0 N1)`
uses two rank-`4f` queries, still paying four planes and rank mass `8f`.
The registered replay checks the complete marked-basis actions and phases
of the two-, three- and four-query realizations, plus the q3 split `(1,2)`.
These controls distinguish query count from the unchanged rank-mass floor.

The [reflection proof](source/native-frames/ORTHOGONAL-REFLECTION-PROOF.md)
and independent 64x64 matrix check retain exact physical phases and the
marked-space leakage. The incorrectly uncorrected paired reflection fails.
The registered command also replays all source-specific conjugated-query
recipes, progress-tradeoff cases and one-chunk phase controls.

## Limits

The floor excludes general bit-linear ADDRESS, arbitrary Pauli Z,
native adapters outside the commuting algebra and changed endpoints.
The reflection is outside this proof, so the two statements are
consistent. ADDRESS scans and all source/reader/cleanup work remain paid.
The reflection resource and a native-rank label are not physical supplier
admission, complete ownership, numerical precision or an exponent gain.

## Reproduce

From the repository root, on Python 3.12:

```sh
python3.12 -B scripts/research_package.py --package research/marked-residual-reflection
python3.12 -B scripts/check_research_commit.py --package research/marked-residual-reflection --check-source-history
```

The registered manifest runs `verify.py` normally and with `-O`. Its direct
portable equivalent is `python3 -B verify.py` (or `python3 -O -B verify.py`)
from this package. The direct command needs only standard-library Python,
no Git/network and no original Ross-specific directory. `--json` prints the
complete replay summary. It writes no package files.

[BINDINGS.json](BINDINGS.json) retains every consumed original source/data
byte hash and explicitly records the path-only adaptations and the query-count
scope correction. Original versions of adapted/corrected files remain under
`original/`; the old proof and checker are retained byte-for-byte in
`original/q4-pauli-fusion/`. The correction changes only the joint-debt prose
and one assertion message; historical certificate fields and arithmetic are
unchanged. Its old `full_pair_three_query_gate` field concerns single-plane
queries. Other source bytes and historical receipts remain unchanged. Those
receipts retain their old absolute provenance
paths; they are data, not required filesystem locations. The replay adapter
resolves only the explicitly retained original source inventory. Original lane
notes are archival and keep their original scope and attribution.

The source loader hashes and compiles the **same bytes**, never loads `.pyc`,
and compiles historical implementations with `optimize=0` in both parent
Python modes, preserving inherited assertions. Mathematical receipt comparison
omits only the enumerated provenance fields in `verify.py`; all such retained
input bytes are checked separately. A changed-source control rejects. Hashes
provide integrity against the trusted publication, not external authentication
or mathematical correctness. Git/source-history, export integrity, finite
replay, written proof, hosted CI and supplier admission remain separate.
