## 1. Deferred-input lemma

**Theorem 1.** Let a finite exact program have a retained input/output system `x` and an auxiliary input/output field `h`. Suppose its full endpoint is

`(x,h) ↦ (A x, B h)`,

where `B` is invertible, and its prefix before a specified cut never reads `h` into any other field. On `h` the prefix consists of invertible queries and destination-only additions of other current fields. Then `h` may be retired, its prefix omitted, and its value at the cut set by any explicit ordinary common-frame function of the other current fields. Running the old suffix gives the same retained endpoint `A x`; the retired output is erased with its positive owned cleanup cost.

**Proof.** Before the first outgoing read, all other current fields are independent of the old initial `h₀`. The old prefix sends `h₀` to `L h₀ + b(x)` at the cut, with invertible `L`. For any explicitly chosen cut value `v(x)`, there is a unique counterfactual old initial value `h₀=L⁻¹(v(x)−b(x))`. The new program does not compute this inverse or this counterfactual value: it directly writes `v(x)` in the actual common frame at the cut. The retained prefix states coincide with those of the old program for that counterfactual input, and the helper states coincide at the cut. The suffix therefore gives retained endpoint `A x`, independently of the chosen counterfactual `h₀`. The old productive `B h₀` obligation is lost and must be debited. Erasing this now-owned output is legal and paid. QED.

This is an equivalence proof for a concrete algorithm, not an unknown oracle or assumed cross-chart gadget. It remains valid for arbitrary function payloads, physical widths, spectator coordinates and dirty owned entrances: erase the retired entrance before using its slot, acquire the required header while it is zero, and make the stated common-frame copy.

Several such retirements compose in chronological first-read order. A later unbound helper has no outgoing read before its own cut, so it cannot influence an earlier binding. The corresponding old initial parameters can therefore be chosen successively. Endpoint autonomy from every retired helper then preserves every retained output. This is a causal argument; simultaneous unproved linear-system solvability is not assumed.

## 2. Rank-complement application

Suppose the retired helper's unobserved inverse prefix contains a rank-1 query from its full entrance frame to a rank-7 frame `P`, and all other prefix operations are destination-only cleanup additions. Its first outgoing read is one of three consecutive additions into a main receiver `y`, all at `P`. That block is immediately followed in inverse chronology by a rank-7 query taking `y` to the ground frame.

The three additions commute because they change only `y` and do not change their donors. Perform the other two additions first. Immediately before the retired helper's addition, copy the current whole payload of `y` into the retired helper at the same physical frame `P`. Then perform the helper addition. Characteristic two makes the whole receiver exactly zero. Omit the rank-7 query on this known whole-zero field and pay its header transition to the old output frame. The original receiver's information has been copied into the helper and is preserved by the deferred-input theorem; it has not been erased as independent input data.

For an ADD realized through a fixed whole-field alignment M, bind with its actual ordinary inverse matcher M^(-1) before retaining y += Mh. In the literal G20 ADD grammar used in the tables, the common-frame operation is pointwise, so M is identity and the binding is the stated COPY. The implementation uses that actual old pointwise matching and its whole ROW/spectator domain, rather than inferring equality of addresses from a frame number alone. Any outer alignment and inverse routing remain charged.

The helper's former unobserved prefix, including its rank-1 query, is omitted. Its later old suffix is retained exactly, with its now chosen arbitrary current value. Every old reader after the cut sees the corresponding old-program state. The old retained main outputs remain correct by endpoint autonomy. The helper's full rank-8 target is debited and its output is cleared.

Thus each row deletes paid `H₁+H₇`, loses productive `H₈`, and adds only paid finite ordinary operations: dirty entrance erasure, known-zero header acquisition, one common-frame whole-payload copy, receiver zero-header transition, and final owned clearing. It introduces no new Gaussian request or free normalization.
