# Signed late binding and block retirement for Gaussian suppliers

Dugongue, with substantial OpenAI Codex assistance. These are informal all-input operator proofs from retained local sources. They give explicit runtime constructions and sufficient complete invoices. They do not assert that a profitable first-read cohort has been found in the actual Gaussian word. No mathematical computation, replay, solver, Lean check or network search was performed.

## 1. Characteristic-independent deferred input

Let a complete finite physical program have retained input/output fields x and an auxiliary input/output cohort h. Suppose its endpoint is

    (x,h) -> (A x, B h),

with the prescribed independent auxiliary target B. Before a specified cut, assume no member of h is read into any field outside the cohort. Within h the prefix may contain invertible Gaussian queries, invertible ordinary operations and additions from the other current fields. In particular its joint prefix has the form

    h_cut = L h_entry + b(x),

with invertible L. All physical frames at the cut are declared.

**Theorem 1. Causal block retirement.** Retire the cohort's independent inputs and targets. Omit its entire unobserved prefix. At the cut give it any explicitly computable ordinary value v in its actual common physical frames, then run the old suffix and clear its now-owned outputs with paid whole-payload passes. Every retained endpoint remains exactly A x on all inputs.

**Proof.** The other cut fields are independent of h_entry because there has been no outgoing read. The unique counterfactual old entrance is L^(-1)(v-b(x)). The new runtime never computes this quantity or L^(-1). It writes the supplied ordinary v directly. At the cut the whole new physical state equals the old physical state for that counterfactual entrance. Exact suffix execution gives retained output A x, independent of this entrance. Every lost auxiliary target is debited. The h outputs are now owned and may be erased with their ordinary cost. QED.

This proof uses physical arrays, not scalar coefficient bitmaps. Copies and explicit fixed scalar operations apply to entire payloads, including all spectators. A dirty owned slot is first cleared completely, its new frame is acquired only while zero, and its current cut value is then written. No nonzero field is reheadered.

Several cohorts compose in chronological first-read order. An unbound later cohort has no outgoing influence on any earlier binding. Counterfactual entrances can therefore be chosen successively. This triangular causal argument does not assume simultaneous solvability of an unspecified global system.

## 2. Signed first-read cancellation

Suppose a retired one-field cohort first appears outside itself in the old instruction

    y += c h,

where c is an explicitly invertible fixed scalar and both payloads have the same actual physical frame. Immediately before that instruction bind

    h = -c^(-1) y.

The old instruction now makes the entire receiver y zero. Its immediately following Gaussian query may be omitted. Retain a paid zero-payload frame transition to the old output frame. If y stays without incoming writes through several queries, all those queries may be omitted; outgoing reads merely read zero and are retained.

The minus sign is essential over complex coefficients. The characteristic-two construction h=y is not the Gaussian rule. Every coefficient scan needed for -c^(-1) is an admitted paid ordinary operation. No inversion of an address operator or Gaussian query is hidden in this assignment.

The receiver may itself be a retained productive helper. The deferred-input proof preserves all retained endpoints, rather than only the main bank. However, it cannot retire an original main input merely by renaming that input a helper.

## 3. A fully priced strict-concavity sufficient construction

Assume the exact first-read hypotheses above hold for an independent H9 target. Suppose its unobserved prefix contains queries of positive ranks a_1,...,a_m, and the newly zero receiver traverses positive query ranks b_1,...,b_n before its next incoming write. Every deleted event is included in those two lists. All later old instructions are retained.

The construction deletes those paid requests, debits exactly H9, and adds only the paid ordinary binding and cleanup operations. Its precise native moment gain is

    sum_i a_i^t + sum_j b_j^t - 9^t.

In particular, if the positive ranks in the two lists sum to nine and there are at least two entries, strict subadditivity proves that this gain is positive for every 0 < t < 1. Thus any actually supplied rank-5 unobserved helper prefix followed by a zero rank-4 receiver query gives

    5^t + 4^t - 9^t > 0.

A genuinely unobserved rank-1 helper prefix followed by a zero rank-8 receiver descent gives

    1 + 8^t - 9^t > 0.

If the descent consists of several source requests whose ranks sum to eight, the actual gain is at least this quantity, and strictly larger when that eight is split. These are complete sufficient invoices: the old target is paid by its debit, every removed proper query is named, and no independent output is credited to the new owned buffer.

More generally, use the actual independent target rank k in place of nine. A full-frame output need not mean a rank-nine productive target when its original independent entrance frame was nonzero. The source's two-sided independent target matcher determines k.

## 4. A block first-read can zero several receivers

At an actual common frame suppose the first protected use of an unobserved retired k-field cohort is the explicitly supplied ordinary update

    y -> M y + N h,

with an invertible fixed scalar matrix N and a declared literal ordinary word for N^(-1). The block is uninterrupted by outside observers or queries; its complete old emitted scalar word is the stated update, so its intermediate effects are not discarded. Bind

    h = -N^(-1) M y.

Every receiver in this block is zero. The same counterfactual-prefix proof preserves all retained endpoints after the old suffix. Debit the entire original independent cohort target, count all omitted cohort queries and all proved whole-zero receiver queries, and charge the literal finite scalar inverse word, copies, clears and storage. This is a sufficient block construction; an abstract matrix rank statement without the actual ordinary inverse word does not instantiate it.

A coupled native mode bank cannot be treated as autonomous merely because its scalar output block is invertible. The retained-output part must actually be independent of the retired cohort after the supplied complete endpoint decoder. The raw coupled Gaussian provider has a main defect depending on its mode input; it does not meet this hypothesis without its charged repair.

An exact local source check prevents one tempting false instantiation. In the supplied backward word, SOURCE 124 reaches its rank-eight endpoint at record 14496. Its subsequent records 14497 and 14514 are

    helper 242 += SOURCE 124 / 2,
    helper 258 += SOURCE 124 / 2.

They read SOURCE into helpers. They do not update SOURCE. Binding a helper at these reads can zero that helper, not SOURCE 124. Adding an extra SOURCE += helper instruction would change a retained cut state and is not justified by Theorem 1. SOURCE 124's non-ground incoming write is instead its paired main-field operation at record 14137. That donor is another retained main field, not an independently discardable Gaussian target.

Likewise, field 92 in this namespace is one of the original 224 main fields. The source instruction 18 -= 92 preceding a prospective inverse H4 is not an instruction from an independent helper. It cannot support a helper retirement without an additional full main recoding theorem.

These source bindings delimit the construction precisely. No actual profitable Gaussian cohort is claimed from either of these cuts. The positive results here are the signed all-input retirement program, its block extension, and the complete strict-concavity sufficient invoices. They extend the actual BIT late-binding proof without conflating a read direction, a scalar coincidence, or a main input with a disposable helper.
