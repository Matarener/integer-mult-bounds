## Source reconstruction and native transfer

It checks the decoded original and coupled payload pins and the eight source

Each of the 641 input fields starts with its own formal column. A row is a
finite rational linear combination of those columns with free native-map

an owned zero destination. CLEAR cannot erase a persistent field. Each paid
child checks its actual entrance chart, exit chart and rank. Each zero retag

A warp prepends its signed source-map name. Only adjacent inverse names cancel.
The checker reconstructs all 72 invertible maps from their full binary columns
and checks inverse-after-map on all 512 addresses. The checked bijection also
gives the reverse inverse identity. Every one of the
240 actual warp events must send its declared source-frame span to its declared
target-frame span. This check includes reused ground-frame events.

At the native exit, every free map word cancels. No coefficient of an arbitrary
owned input remains. Every persistent chart equals the retained source exit
chart. The resulting rational transfer matrix is thus a direct consequence of
the actual word in the source convention. It is computed once and then composed
with the physical boundaries. No author-supplied provider formula is used in
place of that transfer matrix.

This matrix composition is valid for arbitrary input functions. The native
word is linear, and its guard rows are zero on all independent original and

## Exact phases and digit-column parity

A signed Clifford tableau determines its operator up to a scalar phase. The
checker also evaluates the exact zero column and retains one nonzero entry.
The tableau and that entry together determine the complete operator, including
its absolute phase. Rational Gaussian numerators and powers of two are exact.
No floating point is used.

The operator table normalizes only a real sign. If an exact product satisfies
`B A = e C`, where `e` is 1 or -1 and C is a stored operator, the prescribed
f-column evaluation satisfies

```text
B^(tensor f) A^(tensor f) = e^f C^(tensor f).
```

The checker therefore raises each extracted operator sign to the column parity.
It does not raise an exterior rational ADD or SCALE coefficient. In particular,
a scalar -1 from the native program stays -1 for every f. An i phase stays in
the stored operator key; it is not simplified into an exterior scalar.

The complete join is evaluated twice in the formal span of the stored operator
keys: once for odd f and once for even f. Both final coefficient dictionaries
must equal their independently constructed target dictionaries. Each coefficient
can depend only on `e=(-1)^f`. Equality in both classes is therefore sufficient
for every positive integer f after the prescribed tensor evaluation. Additional
linear relations between evaluated keys do not weaken this sufficient test.
No equality of sums at one column is tensor-powered in this argument. The field
index remains an exterior direct-sum label.

This argument establishes an exact field identity for that specified evaluation.
The premise that the source physical implementation realizes each columnwise
operator remains inherited. The result supplies no new implementation of the
adapters, address movement, arbitrary-width arithmetic, compiler or outer call.
The phase-only corruption control is a one-column physical rejection. It is
not a claim that an added i phase fails for every possible column count.
