# Engineering scope

Engineering-mode uses the investigation playbook. The user explicitly authorized
packaging a kept proof and executable checker. Separate Before Serializing Shared
State kept sources and results in this one owned package and cache; the common
Git and reservation transactions use OS locks. Prove It Works requires actual
committed, read-only Git-free replay before evidence-ready. Unslop applies to the
prose. No child agent or extra checkout is used.

The verifier parses pinned data and executes no retained Python source. Its
native-operation interpretation is the written selected-interface premise in
README.md. This is separate from its exact opcode/constant and tensor checks.

Power-of-ten inspection covers `verify.py`. Control flow is structured and
nonrecursive. There are two fixed orientations, 24,767 events per orientation,
five fixed retained source files, at most nine tensor terms and six coordinates.
Tensor tests have 36 basis pairs. Each input is at most 4 MB, and the compressed
input is hash-authenticated before decompression. The frozen decompressed member
is also below 4 MB. Rejection controls execute four bounded mutations. No waits,
subprocesses or network requests exist in the replay. Functions remain below
60 physical lines. All external integer contracts reject Boolean values.
ValueError checks remain active under optimization, and canonical JSON comparison
keeps Boolean/integer receipt distinctions. State is local; source pins and
paths have no write capability. No dynamic import, eval, callback or runtime
code generation is used. File reads use context-managed pathlib operations and
all return values relevant to the proof are checked.

Rule 3 managed-runtime deviation: Python and Fraction allocate during replay;
eliminating that would require a different arithmetic runtime and expand the
task. Scope is this bounded verifier. The input/event/term limits above bound
live data, no concurrent workers run inside it, and no scratch output is written.
Both normal and optimized runs exercise the complete bounded workload. A future
runtime port must preserve exact arithmetic and the same caps.

Rule 10 diagnostics use `-W error` for both registered commands and AST parsing
of the new source. Compiler-specific maximum warning settings do not exist for
this standard-library interpreted program. Native Python 3.12 and a second
existing interpreter are recorded in the cache and publication receipt. Frozen
predecessor Python is source evidence only and is neither changed nor executed.
