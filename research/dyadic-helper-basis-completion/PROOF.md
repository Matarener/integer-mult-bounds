# Complete dyadic basis construction

Let D = Z[1/2]. Let a be a row and b a column in D^n, with a b = 1.
For any index p there is an invertible R over D such that a R = e_p^T
and R e_p = b. The compiler emits R as ordinary ADDs with coefficients
in D and SCALEs by units of D. All operations use the same physical chart.
This is an application of the Euclidean algorithm, not a new theorem about
principal ideal domains. Nick Petalas used Euclidean row preparation in
[PR5115](https://github.com/CrocSwap/integer-mult-bounds/pull/5115)
for a single-hub shear. Here both the row and column are prescribed.

First clear all denominators of a by a common power of two, d. Each
column scaling is invertible over D. Apply the integer Euclidean algorithm
to coordinate p and each other coordinate. An ADD and a swap perform
one division step. The nonzero pivot becomes the gcd g of the integer
coordinates, up to sign. Because a b = 1, every odd prime divisor of g
would divide 1 in D. Thus g has no odd prime divisor. It is a unit in D.
A final unit scaling gives a P = e_p^T. Each operation used to construct
P is invertible over D. The loop terminates because each Euclidean
remainder has smaller absolute value than its divisor.

Set c = P^-1 b. Then c_p = a b = 1. The shear

```text
S = I + (c - e_p) e_p^T
```

is a product of ADDs on rows other than p. It satisfies S e_p = c and
e_p^T S = e_p^T. Set R = P S. Then

```text
a R = e_p^T,       R e_p = b.
```

Execution order is S followed by the reverse order of the right factors
of P. The compiler records this order explicitly. Its inverse uses the
reverse instruction list, with negative ADD coefficients and inverse
SCALE coefficients. No odd division, extra field, native MOVE or owned
zero is required. Scalar coefficients remain outside the tensor power.
Thus the identity holds for whole fields at every positive tensor width.

The pinned PR5602 constructor requires some a_i to be a dyadic unit.
That condition is sufficient but unnecessary. For example,

```text
a = (3, 5),       b = (2, -1)^T,
R = [[2, 5], [-1, -3]],       det(R) = -1.
```

Both identities hold. Neither entry of a is a unit. More generally,
completeness depends on the ideal generated by the row, not on any one
entry. The supplied b proves that this ideal is D. A rational pair whose
coefficients have odd denominators is outside this arithmetic contract.

## Exact caller boundary and limits

The two uses in PR5602 are the input/output helper basis and the common
cut basis. Its handoff proof needs only the two displayed identities,
invertibility and common charts. This compiler supplies those algebraic
requirements for all dyadic dual pairs. It does not find the prefix/suffix
kernels, prove that a cut exists, change a frame or add a productive target.
The source's nine witnesses supply 18 concrete interfaces. The verifier
checks all 18 with a separate dense matrix interpreter.

An emitted ADD with a large coefficient is not free. A consumer must
check the source's coefficient bound, total scalar allowance, prefix growth,
operation count and fixed-tape costs before installation. This package does
not replace the source constructor or rerun its physical caller, native
phases, compiler or outer proof. It does not increase complete kappa or
change the selected frontier. The five inherited assumptions stay open.

The finite tests corroborate the algorithm and find implementation errors.
The argument above establishes the all-input statement. Neither the tests
nor this paper proof are proof-assistant or independent human acceptance.
