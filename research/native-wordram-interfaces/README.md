# Executable native and Word RAM interfaces

This package applies the prior counted Word RAM kernel's sharing and ownership discipline to the actual native producer. Its main new implementation computes **eight shared inverse-code quotients instead of 448 repeated quotients**, with identical rounded outputs, a uniform local error theorem and literal instruction counts. It also supplies a concrete source-ABI native-unit serializer, a completion-free three-query terminal decoder and sufficient recovery bounds.

**No new multiplication κ is established.** The selected conditional value remains 0.003027288235 at the pinned main. The open p19 claims are not accepted here as completed physical callers. The four components close specific implementation interfaces; their ordinary bills and recursive paid profiles must not be confused.

| Component | Positive result | Precise boundary |
| --- | --- | --- |
| [Inverse recoding](precision/RECODING-PROOF.txt) | Actual 112-by-8 code; eight divisions; 1,329 static instructions in place versus 18,929 in the stated same-output control; error ≤ 2h | One scalar coordinate; wrapper movement and complete caller precision/tariffs remain separate |
| [Native unit](native/REPORT.txt) | Actual 28,047-event producer exports in both directions, all 632 arbitrary input rows, all 19 axis embeddings, dirty owned entry and cleared exit | Source ABI preserved; not the complete p19 controller compiler |
| [Terminal decoder](decoder/TERMINAL-PROOF.txt) | Three actual helper queries with adaptive feedback and an ordinary terminal decoder; independent outputs restored | Gaussian paid profile unchanged; caller use must remove a real request to improve κ |
| [Recovery](precision/REPORT.txt) | Width-uniform weighted contraction certificate and an all-size sufficient fixed-point FFT error bound | Actual selected consumer and all-size arithmetic cost are not supplied |

## Reproduce

Python 3.12 or newer, standard library only, on Windows or Linux:

```sh
python -I -B research/native-wordram-interfaces/verify.py
python -I -O -B research/native-wordram-interfaces/verify.py
```

These commands authenticate every package byte and run the relevant source-bound checks without Git, network, Lean or GPU dependencies. The decoder's retained assertions require a non-optimized child interpreter; the launcher enforces this even when its own `-O` mode is used. Optimized mode independently reruns the native, recoding and recovery checks. Each child uses a fresh, non-writing bytecode namespace, so package-local cached bytecode is not a source substitute. A scientific replay is not Lean kernel verification or maintainer acceptance.

The static count improvement is against the explicitly implemented duplicate-quotient control, not every optimized compiler. At k = 4, the input-preserving variant is 1,441 versus 19,041 instructions. General saving: exactly 440(4k + 24) static instructions, for 1 ≤ k ≤ 56. Setup, constants, scratch clearing, signed branches and halting are charged. This implementation uses nearest ties to even; sign symmetry is required by the stated signed-sharing argument.

## Open next questions

1. **Attach the inverse recoding to a complete caller.** Begin with the actual `/52` coded producer in `native/vendor`, allocate its uniform error through every use, and price monomial movement and coordinate traversal. The selected #5413 provider has no odd-denominator packet, so it is not a direct replacement target.
2. **Complete a D-based p19 caller.** Use the serialized native B endpoint, prove every bridge/gauge and target rank, and emit the complete owned/frame chronology. The naive R-to-D substitution fails; a one-column four-term Gaussian expansion does not extend at constant cost to arbitrary widths.
3. **Consume a real early observation.** Use the three-query interface to remove a named existing caller request and compare the full paid/target profile plus the added ordinary bill. Moving a query without removing one leaves κ unchanged.
4. **Bind the recovery certificate to actual residuals.** Extract all physical transfer blocks and decoder boundaries, obtain rational positive weights and verify the complete recovery margin. A selected grid bound alone is not an operator-error theorem.
