A concrete centre-free native producer leaf, with global address embeddings

Positive deliverable
compile_unit.py serializes the actual centre-free native source, preserving its
full retained entrance/exit chart ABI, into named field operations with explicit
153-axis frame bases and native address-map columns. It supplies every source
record, not a CENTER_FREE_FULL placeholder. The exported UNIT0-forward.json.gz
and UNIT0-backward.json.gz contain those literal event arrays. Both orientations
have 28,047 records: the source's 28,045 plus explicit owned entry and exit clears.
This is a sufficient source-ABI leaf. It is not a compiler for the complete p19
controller and does not assert a new multiplication kappa.

Exact resulting contracts
For arbitrary independent data in all 632 persistent source fields, the forward
logical endpoint is (X,Y,H)->(X,Y+A X,H), and its actual raw dual is
(X-A^T Y,Y,H). There are 112 X fields, 112 Y fields, 408 independent productive
helper fields and one owned centre. The owned centre accepts arbitrary dirty
entry data and is explicitly zero on exit. No helper is borrowed or erased.
The original entrance and exit frame lists are supplied explicitly in each export.
The code A is the retained real symmetric 112-by-112 invertible matrix with
spectrum 1 (104 times), -13 (8 times), and inverse I+(A-I)/13.

The exact paid profile is {1:2201,2:412,3:510,4:127,5:40}; there is no rank-8 centre
job. The exact productive helper profile is {4:28,7:7,8:47,9:326}. The source and
serialized traces both verify all persistent frames and every paid rank. Every forward/inverse native-map event also checks the image of its entire source frame span against its declared target span, including reused ground-to-ground instances. Direct
free-group row replay rederives the endpoint for all 632 arbitrary input rows,
including every helper, in both directions. This is the actual centre-free
28,045-record source, not the older 21,449-record predecessor with eight H8 jobs.

The scalar primitive tariffs, including the two extra clears, are 223,444 forward
and 223,492 backward. These differ from the predecessor's 158,120/158,168 tariffs.
They are scalar-record tariffs; native address movement, monomial adapters,
precision and every caller-level resource must still be charged under the source
physical model. We do not describe them as complete TM or Word RAM running times.

Universal relocation and spectator proof
For unit u in {0,...,18}, map local binary address axis 0 to global axis 0, and
local axes j=1,...,8 to 1+8u+(j-1). The explicit vector map is
 e_u(v)=(v mod 2) XOR ((v div 2) shifted left by 1+8u).
Its nine basis images are distinct standard basis vectors. It is therefore
linear and injective. Consequently it preserves sums, intersections, independence
and dimension of every source frame; every paid rank difference is unchanged.
The 72 retained native binary address maps are supplied by complete columns,
with inverse columns checked on all 512 local addresses, and extended by identity
on all spectator axes. All original field operands are renamed injectively into
MAIN, HELPER and OWNED_CENTER namespaces. Hence no owned field collides with an
independent productive field. Source adapter records are retained and bound to
the same explicit field and axis names; their inherited physical implementation
is not replaced by an assumed new primitive.

For one digit column the embedding identifies the local active tensor factor
with the nine selected axes. For every positive column count f, use the source's
columnwise lift on those axes and identity on every spectator coordinate. The
field index is a direct-sum role label and is not tensor-powered. Composition and
addition of the fixed source field program commute with this linear evaluation,
so its exact free-group endpoint and autonomous helpers are preserved for every
f. In particular no assertion that tensor powers preserve matrix sums is used.
The compiler's explicit clearing at entry kills any initial owned-centre value;
its exit clear returns the centre to the zero value in ground frame. Every other
field has exactly the source's arbitrary-data endpoint and is never cleared.

Actual uncoded leaf
The verifier also serializes and replays the retained uncoded source in both
orientations. All 632 arbitrary-input rows agree with the genuine identity
cross-transfer (X,Y)->(X,Y+X), respectively raw dual (X-Y,Y). Its paid profile is
{1:2201,2:412,3:510,4:127,5:40,8:8}; its 408 helper targets are unchanged. Thus
there really is an actual C=I producer; removing its eight H8 jobs without the
owned-helper target debits or changed code would be an invalid invoice.
The centre-free source changes the transfer to A, which is why the two payloads
cannot be interchanged solely because their other rank counts agree.

Actual checks
The verifier checks all 19 unit embeddings and both orientations. It independently
reconstructs the source error kernel, centre-free arbitrary-input endpoint,
serialized frame trace, complete paid profile and all 408 productive helper
ranks. A changed paid-rank record is rejected. Both committed compressed literal exports are required and compared as decoded JSON against regeneration. Every one of the 12,544 actual CODE.json entries is matched to the rederived arbitrary-input defect. Every consumed source is checked
against its content hash before use. The exports are generated from the literal
source events and explicit map tables, not from a substitute mathematical word.
The default run compares the retained RESULT.json and writes no output. Use
--write --emit explicitly to regenerate the receipt and two literal exports.

  python -B compile_unit.py

Python 3.10+ and its standard library suffice. No network, installed Lean, Git,
Windows-specific executable or private path is required. Upstream source is
SOURCE_ONLY here; no fresh Lean kernel or transitive-axiom audit is claimed.

Precise remaining p19 boundary
The normalized physical full call in the retained PHYSICAL.md includes a common
D on both outputs. The existing p19 FORWARD/REVERSE replay specifies pure query
shears instead. Its 20 FORWARD records are thin queries, while only its 19 thick
units may consume the above producer. Replacing all 39 records by this source
would both change the operator and double-charge the intended local profile.
Changing the prototype LETTER from R to D is not enough: with the actual C/C^-1
gauges, the p1 control then differs in 57,344 entries, whereas the R control agrees.
The same controls at p2/p3 have 99,233/141,124 differences for D and zero for R.
A fresh D-based caller can still be researched; these controls only refute that
literal substitution, not every new caller.

The PHYSICAL full-call gauge G(B)=diag(B,Q^-1 B Q) identifies the next exact
interface. Q is an f-column Gaussian. Although Q=aI+bX has a four-term ordinary
conjugation expansion at f=1, tensoring that expression has exponentially many
terms in f. It is therefore not an all-width cheap recoding theorem. We do not
use this invalid shortcut to assert the p19 compiler is complete. The source
normalizer theorem supplies normalized full F/B calls, not unpaid pure shears.
