# P104 translated progress: symplectic width and an adapter-sensitive boundary

**Result:** matched Clifford translations cannot raise the persistent progress
of the unchanged **intrinsic** P104 endpoints above 2312. The proof uses the
actual native width `phi(M)=rank_F2(B)` of a Clifford symplectic matrix and a
conjugacy-invariant upper bound from `rank(M-I)`. It applies to role-local
charts and common-chart scalar additions, with the same translation at both
ends. It does not assume that translations retain the paid native profile.

The source convention matters. At actual X0, translating the **bare canonical**
endpoint changes its native width from 8 to 9. Its previously rank-zero source
adapter then costs width 2. Including the intrinsic adapter restores width 8.
This is a concrete missing-hypothesis control, not a supplier improvement.
The 208 rank-zero intrinsic adapters are distinct from the later 208 rank-one
side-correction transports.

The theorem is reusable after a real endpoint change. If every Y ends at F9
instead of F9*Cq^-1, the corresponding sharp progress cap becomes **2416**.
The old 2312 must not be applied to that changed contract. Any such new word
still needs its actual logical return, complete bill and global caller proof.

[PROOF.md](PROOF.md) contains the general matrix proof, nonorthogonal and
alternating residual treatment, exact source binding, counterexample and
scope limits. [RESULT.json](RESULT.json) contains the finite receipt. The
source-bound whole canonical Hadamard control has native mass 2248 and
progress 2066, worsening their difference from 56 to 182; intrinsic adapters
and side correction remain separately chargeable. No complete changed-call
invoice or new kappa is claimed. The selected frontier is unchanged.

## Reproduction

Python 3.12, standard library only, from the repository root:

```sh
python3 -B research/p104-translated-progress/verify.py
python3 -O -B research/p104-translated-progress/independent.py
python3 -O -B -m unittest discover -s research/p104-translated-progress -p test_verify.py -v
python3 -B scripts/research_package.py --package research/p104-translated-progress
```

The primary checker authenticates nine canonical inputs (including the retained compiler notice and license), reconstructs all
14400 root pairings and the 104 physical ports, binds all 1410 original
transport widths, checks all 280 canonical endpoint cocycles, and recomputes
the translated control. It imports the pinned native compiler only to
instantiate its actual canonical-frame convention; it does not import the
channel generator or treat that compiler as an independent checker.

The separate checker imports no producer or primary verifier. Dense binary
arithmetic checks all 518400 products of Sp(4,2), 2160 matched translations,
and the actual 18-by-18 counterexample/adapter matrices. Exact Gaussian
rational operators independently recover six Cq/inverse Pauli actions.
Six unittest methods include seven actual optimized-CLI receipt/source faults
(each preceded by a passing private-fixture baseline) and mathematical controls for unmatched endpoints, even labels, changed
outputs and non-invariant native width. Typed receipts and duplicate JSON keys
fail closed. All commands support a read-only, Git-free source export; test
mutations affect only disposable private copies.

These checks support the scoped proof. Unsigned symplectic ranks do not
certify phases, the complete physical channel, signed-floor/precision or
all-size admission. The old native phase checks retain their own source scope.
