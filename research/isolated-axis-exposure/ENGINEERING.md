# Verification decisions

Build the Lever changed the deliverable from a bare proof note to two
rerunnable exact checks. Prove It Works requires the committed registered
commands and the same commands in a Git-free byte export. Unslop keeps
the claim tied to its call contract and its unrun obligations.

Power-of-Ten inspections cover the three new Python scripts. They have
structured control flow, no recursion, no dynamic imports or code generation,
and explicit exceptions that survive `-O`. No predecessor code is imported.
Functions stay below 60 physical lines. Data and state are local except
immutable package paths and the four-cut constant. CLI inputs are parsed
once; receipt emission is exclusive and cannot repair a missing receipt.

All science loops use fixed finite ranges. The primary check uses at most
7! permutations, 64 bounded axes per generator, 6! completions and five
spacings. Actual primary families contain at most 49 axes. The independent
factorization check uses at most 11 axes and words of length at most two;
it checks the depth-three upper construction separately. Controls use at
most 16 package files, exactly two source inputs and six mutations. Each
child has a 60-second timeout, and registered jobs have 120-second bounds.
This is bounded research verification, not the physical tape router.

Rule 3, managed-runtime deviation: Python tuples, sets, dictionaries and
integers allocate during execution. These fixed domains bound their live
sizes; the independent reached set contains only states within two moves
on 11 labels. No unbounded user search parameter is exposed. Replacing
these structures by fixed-capacity arrays is required before expanding
the census, rather than claiming fixed-memory compliance now.

Rules 5 and 7 use explicit contracts and acceptance comparisons instead
of removable assertions. Temporary control copies must be owned regular
files with different device/inode pairs from their sources. Copies use
exclusive byte writes, never metadata/mode copying, and no chmod. The
temporary root owns every copied file. Cleanup cannot encounter an
inherited interpreter or symlink. Child exit codes, result markers,
mutation anchors, output writes and byte identities are checked.

Rule 10 uses CPython 3.12 with `-I -W error -B`, also `-O`, registered
metadata/source-pin checks and publication-byte/history checks. The
programs make no performance claim. The universal bound is a proof,
not an extrapolation from measured runtime. No broad historical suite,
Lean build, Docker run or production GL64/T74 payload is required or
claimed for this isolated theorem.
