# R429 binary reader cost bounds

For one fixed binary correction matrix M = KR on 111 E8 root lines, this package proves two necessary-cost bounds:

| Model | Covered domain | Bound |
| --- | --- | --- |
| Cold source/target factors, charged by rational pairing rank | Ten or eleven arbitrary binary outer-product terms, including factors outside the retained code | Total tariff at least 56 |
| Separately materialized readers, charged by rational source-span dimension | Any number of binary readouts R = BC, including rows outside the retained code | Total cost at least 53 |

The second bound excludes the specified three-seed caller at primitive exponent a ≥ 1/500, provided it retains the fixed bulk, common-axis credit 222 and nonnegative omitted pressure. Neither 53 nor 56 is claimed attainable. These are different cost models; their bills cannot be substituted for one another.

The nine-term bound 63 supports the first proof. It is not a new numerical result: Joel Pulikkan / PR620 reported the P111 value; Russell Seligmann / PR757 and Cody Harris / PR761 supplied independent fixed-label proofs. R429's roots are identical in order to PR555's fixture, covered by PR757, and its KR is the same affine pairing kernel. They differ from PR545/PR761's fixture. The new ten/eleven-term bounds allow factors outside the R429 label code, where those fixed-label theorems do not apply.

## Proof and coverage

The written cold-factor proof uses an all-coset uniqueness lemma for readers of rational support rank at most six, then covers every factor-rank case. The separate materialized-reader proof uses generalized support-union inequalities, exhausts every rank partition of cost at most 52, and rejects its sole equality profile. See [PROOF-COLD.md](PROOF-COLD.md), [PROOF-READOUT.md](PROOF-READOUT.md), and the separate AI [cold-factor](REVIEW-COLD.md) and [readout](REVIEW-READOUT.md) reviews. See also [source integrity](REVIEW-PORTABILITY.md) and [validation](VALIDATION.md). Their independent implementations and complete receipts are included in the registered replay.

The primary replay covers:

- R and K reconstructed from the frozen D/A word; all 511 nonzero reader supports and exact minimum distance 48.
- Both source/target support censuses, 81 special pair tariffs and 3,050 partial dual sets for the nine-term bound.
- All 4,900 E6/D6 flats against 511 codewords: 2,503,900 modular rank lower certificates.
- All 111 unit cases against 502 generic targets; all 56,721 unit/codeword toggles and 638 hyperplane bases.
- All 61,320 near-cap cases supporting the eleven-term proof.
- All 340,260 rank partitions of cost at most 52 and an exact rational logarithmic lower bound for the fixed-caller pressure.

These finite certificates support written coverage arguments. The E8 root-system/parabolic reduction remains an explicit mathematical premise, independently checked on the standard parabolic representatives. Modular rank supplies a rational lower bound; equality uses the stated orthogonality or dimension upper witness. No formal-kernel or independent human certification is claimed.

## Reproduce

From the repository root, with Python 3.12 and its standard library:

```sh
python3.12 -B scripts/research_package.py --package research/r429-binary-reader-floors
```

All registered stages are read-only. `verify.py` authenticates and compiles frozen source bytes with the explicit path and receipt adapters in `ADAPTATIONS.json`. Mathematical code is unchanged, original assertions remain active under `-O`, and matching poisoned bytecode is bypassed, including nested imports. Colliding normalized provenance keys are rejected. Every mathematical receipt field is compared with JSON scalar types preserved. Only original absolute provenance paths are normalized; no field is ignored.

`FROZEN-SHA256.json` and `ORIGINS.json` bind all 33 predecessor and independent-check files. `SOURCES.json` pins canonical Git inputs and attribution references. The unpublished local R429 receipt and word have no upstream Git blob; their full hashes and reconstructed R/K equality are retained. This package does not execute the full native compensation word. Older 49/55 bounds are retained as dependencies or controls; the current proofs state exactly where they are strengthened.

## Limits

Both tariffs assume additive charges for separate binary scalar terms. Shared queries, operator-valued or nonlinear readers, a changed code, a different caller credit, native gathering/copy/erase, arbitrary dirty restoration, owner placement, rounding, physical tape and complete supplier admission remain outside these results. The old 49-cost control shows that the chosen pressure certificate no longer proves rejection; it does not certify a passing completed moment. No selected-frontier change or new κ is claimed.
