# Nine-term changes of reader basis do not lower the cold-contact tariff

For a source support with rational root span U and target support with span V,
grant a reader the best cold output frame `U intersect V-perp`. Its necessary
descent rank is `rank(pairing(U,V))`. This is an optimistic cost model: source
preparation, storage, actual COPY, delivery and cleanup are not certified free.

Every exact nine-term binary factorization of the actual rank9 correction
`K R` is `(K T)(T^-1 R)` for an invertible9-by-9 binary T. The producer checks
both code spaces completely. Each has nine directions supported on rational
hyperplanes and502 spanning all eight coordinates. Full rank modulo3 proves
each rank8 claim; exact nullspace witnesses prove the eighteen rank7 claims.
Both sets of hyperplanes have the same nine normal lines, in different orders.

A full/full term costs8; a hyperplane/full or full/hyperplane term costs7.
A hyperplane/hyperplane term costs6 if its normal lines are orthogonal and7
otherwise. In a dual-basis factor, two distinct selected normal labels are
orthogonal; a same-normal pair costs7. Let a and b count special source and
target directions, and c count same-normal pairs. The total tariff is

    72-a-b+c.

If a normal label is selected on both sides, its binary dual pairing is1,
so those two directions must occur in the same factor. Thus c is precisely
the intersection size of the two selected sets of normal labels. Their union
has at most nine elements, giving total tariff at least63. The original
factorization attains63 in this optimistic model.

This is a complete nine-term basis result, not a bound for overcomplete
factorizations or shared-query circuits. With ten or more terms a factor
can leave one or both retained code spaces. That remains a constructive
