# Implementation and verification decisions

The exit predicate is one published, independently reviewable strict-volume
Count-selector package with exact source closure, committed replay evidence,
clean reusable checkout and released process-held ownership. The session's
append-only decisions and execution receipts live outside the checkout in its
assigned cache directory. There are no additional agents, checkouts or threads.

Build the Lever led to the literal verifier, independent slab oracle and actual
CLI mutations. Prove It Works requires the actual final committed Git-free
export in addition to working-tree execution. Separate Before Serializing
Shared State keeps this package and all outputs private to worker 5; shared
Git mutations and reservations use their specified OS advisory locks.
Unslop keeps the prose scoped to the proof and evidence. No elapsed-time
benchmark or multiplication-exponent improvement is claimed.

## Boundary and state

strict_selector imports the unchanged Count arithmetic, positive saturation,
Owned inventory, Profile, width/bounds/level constructors, fallback and release
operation from the authenticated PR3518 export. New logic consists of the
strict threshold, trial, fit comparison, final materialization and bisection
composition. All input-dependent control reads Count tapes. Host integers are
compiled profile constants or checking-only oracle values. no_decode remains
active during every literal selection.

The seven returned Counts and Boolean fits flag are the public shape. Returned
rows are exact q^k, stock remains exact S, and no-fit is the inherited explicit
sentinel. The source input is borrowed and preserved byte-for-byte with a
canonical head. Every trial closes before the next. A final Owned context
returns only explicitly transferred plan fields; the threshold stays local.
Consumers must close all seven Counts. The source/runtime is activated only
inside installed, with source paths and temporary exports restored on exit.

The old ordinary padding planner rejects the new q^k<S domain. This package
does not silently install a callback into it. A later consumer needs the
strict-padding adapter plus completed-callee and physical-cost premises.
The family decision is to stop at this setup obligation. Unknown payload,
restoration, source access, full-cover, compiler, precision and outer costs
remain unknown, with their inherited charges preserved.

## Power of Ten inspections

1. Control flow is structured and nonrecursive. New selector exits are empty
   legal interval, failing upper endpoint, passing zero, completed bisection and
   exception propagation. Owned/context managers close completed-trial scopes
   on every exit. The injected second-trial failure checks the unwinding path.
   Arbitrary interruption inside inherited arithmetic remains unclaimed.
2. The selector's depth loop contracts n by at most r/m each step and has at
   most 1+ceil(log_(m/r)(max(1,e))) iterations. Bisection starts with gap<=e
   and halves it, so it has at most 1+ceil(log2(e+1)) iterations. The inherited
   exponent scan has at most bit_length(k) bits, stock exponent at most
   bit_length(D), and fixed-power/width loops have their retained finite bounds.
   The GL-order loop has exactly m compiled iterations. Owned cleanup visits
   a fixed vocabulary, never an accumulated trial list. The integer census has
   exactly 2880 cases; the literal subset has 990; threshold pairs total4096;
   CLI mutants total7. Source extraction has21 bounded regular members.
3. Count roles follow the fixed vocabulary and O(wh)-cell proof in PROOF.md.
   Python collections and integers allocate dynamically, so direct static
   allocation compliance is unavailable. The managed-runtime deviation below
   bounds new live state. The source loader and oracle are checker machinery.
4. Every new function stays below60 physical lines. The longest is the
   independent slab oracle at59; source.installed is50, checks.rejections is53
   and the public select function is40. The exact function-length receipt is
   retained externally. No forwarding layers were added to meet a line count.
5. All selector contracts use the retained need/positive functions, which run
   with -O. Exact final rows must meet the threshold. The verifier uses explicit
   ValueError checks and typed JSON comparison; Boolean/integer receipt drift
   cannot pass Python's loose equality. Ownership, blank closure and head
   invariants are checked at the real Tape allocation/write/clear boundary.
6. The threshold and candidate state are local to one Owned trial. No frozen
   source, shared backend, runtime default or selected record is mutated.
   The observer's patch scope restores both counts.Tape and cardinality.Tape.
7. Public q/profile/compatibility/original contracts are checked before setup.
   The new threshold requires positive stock. All subprocess exits and bounded
   timeouts are checked. Retained source authentication checks size, archive
   SHA256 and per-file SHA256 before execution. The exact source bytes and
   original commit/path/blob identities are recorded in PREDECESSOR.json.
8. There is no eval, generated program or unbounded plugin registration. The
   only dynamic source loading executes the explicitly retained frozen modules
   after byte authentication. It retains their original notices and behavior.
9. Count/tape references are shallow. The inherited source loader and context
   managers require bounded dynamic dispatch. The observer subclass and the
   seven failure closures exist only in the checker. There are no callback
   chains in the mathematical selector beyond one local candidate constructor.
10. Verification runs strict Ruff diagnostics E4,E7,E9,F,B,I,UP, Ruff format,
    Python3.12 with -W error and compile validation, registered normal/optimized
    commands, independent slabs and actual optimized CLI controls. No repository
    configuration is relaxed. Existing frozen inputs stay byte-exact.

## Bounded deviations

Rule: 3, fixed memory after initialization.
Location: strict_selector.py, source.py and checking scripts.
Reason: CPython allocates integer/container/context objects, and inherited
Count operations allocate owned tapes. Direct allocation prohibition would
require the separate production compiler/refinement work.
Scope: this opt-in executable Count refinement and its offline verifier.
Compensating control: fixed named Count inventory, O(wh) cell proof, at most26
roles including the input, one closed trial at a time; finite oracle domains;
21 authenticated source members with no member above400000 bytes. Controls
copy at most32 regular files of at most500000 bytes and run at most7 children
with90-second timeouts.
Verification: literal observer checks both Count allocation bindings and blank
closure, including success, fallback and an injected completed-trial failure;
large selector checks actual tape extent. Actual export replay repeats them.
Follow-up: compile the arithmetic to the physical fixed-role transition table
before making production allocation/refinement claims.

Rule: 7, arbitrary failure handling inherited from source.
Location: retained PR3518 Count arithmetic, including arithmetic construction.
Reason: proving interruption/allocation-failure cleanup for all frozen internals
would change predecessor scope and requires their resource/refinement audit.
Scope: the successful setup contract and errors after a completed trial only.
Compensating control: public invalid inputs fail before allocation; all complete
scopes close their owned Counts; the injected completed-trial failure is tested.
Verification: seven explicit boundary/failure controls with observed no leaks.
Follow-up: inspect every inherited partial-allocation exit before claiming a
transactional physical implementation. This package makes no such claim.

Rule: 9, bounded indirect calls.
Location: source loader, local candidate constructor, context managers and
checker-only allocation observer/failure injection.
Reason: these source/runtime interfaces use ordinary Python dispatch.
Scope: one authenticated frozen namespace, one selector candidate constructor,
two observed Tape bindings, one integer-only JSON receipt callback and7 fixed
invalid-input/failure cases. The callback converts integers above2^53-1 to
exact decimal strings; JSON booleans never enter that callback.
Compensating control: source-byte authentication, explicit local targets,
module-path restoration and closed allocation scopes.
Verification: source/proof corruptions reject before execution; final actual
Git-free commands and typed receipts check all affected paths.
Follow-up: replace source-loading dispatch with direct compiled calls when a
production compiler is supplied. There is no new plugin mechanism here.

No direct static type checker is claimed. The interpreter, explicit runtime
contracts, compile validation, strict Ruff and exact behavioral checks are the
available diagnostics for these dynamic inherited Count interfaces. Broad
historical suites, selected GL64 payload replay, Lean/Docker and independent
human/formal acceptance remain unrun. The selected-baseline orientation command
was attempted but lacked sparse selected source directories; direct Git reads
resolved its certificate, manifest and review without claiming a full baseline
pass. This source omission does not affect the self-contained new package.
