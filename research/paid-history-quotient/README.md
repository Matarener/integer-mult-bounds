# Additional paid returns with retained observations

This package gives an exact finite-dimensional audit of additional paid returns.
It includes every supplied initial observation before it applies a lower bound.
A correctly versioned observation can remove a charge. A copy of an old version
need not remove it. The complete kappa calculation does not change.

## Statement and proof

Let R be a finite-dimensional unital matrix algebra over Q, with dimension r.
A field row is a d by dN rational matrix on N named independent input fields.
Let H be the left R-module generated by the supplied initial rows. Let T be
the left R-module generated by all required final rows. Set

```
Delta = dim_Q(H + T) - dim_Q(H).
m >= ceil(Delta / r).
```

Here m counts additional paid calls. Each call returns one actual new field
row at the same capacity. The call can act on a row that uses earlier paid
returns. Ordinary operations are left actions by R and scalar row combinations.
They preserve the current history module. Each actual paid return t adds Rt,
whose dimension is at most r. Keep a conceptual copy of every paid return,
even after physical overwrite or clear. After m returns the history dimension
is at most dim(H)+mr. It contains H+T at completion. Subtraction proves the bound.
No commutation or R-linearity of a paid operator is needed. All rows must denote
linear maps on the same independent input space. Target rows include required
dirty returns; zero scratch has no independent input column.

The bound is necessary. Delta=0 means that the target rows lie in the supplied
ordinary closure. It does not prove that the required storage, scalar operations,
ownership, access, or final erasure are free. The dimension bound need not be a
sharp return count for a restricted paid alphabet.

The code forms R from the identity and the supplied ordinary generators. It
repeatedly left-multiplies new basis elements by each generator. Stabilization
occurs after at most d squared independent elements. The resulting span contains
every generator word, so products omitted from an initial generator list cannot
create a false positive charge. Exact rational elimination computes H and H+T.
There is no floating-point rank decision. The direct tool accepts JSON with
`dimension`, distinct `inputs`, `ordinary_generators`, `initial`, and `targets`.
Each initial or target row has d rows and d times N columns. Use integer values
or rational strings. Example: d=2, inputs=["x"], no ordinary generators,
initial=[I_2], targets=[diag(1,-1)] gives Delta=1 and m>=1. Supplying the target
as an initial observation gives Delta=0.

## Evidence and reproduction

```sh
python3 -B scripts/research_package.py --package research/paid-history-quotient
python3 -B research/paid-history-quotient/audit.py /path/to/interface.json
```

Python 3.12 and its standard library suffice. The registered normal and optimized
checks cover all cached subsets for one through five distinct inputs, 96 literal
programs with feedback and overwrite, and all 1152 prefixes. Controls distinguish
old and current versions, require full ordinary closure, and reject ambiguous
input names, malformed matrices, floats and zero denominators. Every check uses
an explicit exception. The written proof gives the general finite-matrix result;
the finite tests do not prove an all-width native statement.
