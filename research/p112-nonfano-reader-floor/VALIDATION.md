# Verification scope and engineering decisions

The universal result is the written proof in PROOF.md. The finite marked-target
lemma has three explicit field configurations, 24 old automorphisms and all
21 marked pairs. The primary implementation checks all 2,688 candidate
implications, including 288 source and 672 reader premises. Integer pair and
triple minors bind the original rank pattern in every characteristic other
than two. The separate implementation uses determinant rank, all 5,040
permutations to recover the 24 automorphisms, GF16 arithmetic and original
characteristics zero, three, five and seven. It checks 10,752 candidates.
This is a separate implementation in this package, not a claim of independent
human or proof-kernel review.

Each of 21 committed literal fixtures has factor ranks (3,4), external query
values and a cancelling reader on separate spectator ports. Both exact
112-by-112 operators contribute 526,848 checked entries. The original and
transferred supports and all five rectangular Gram tariffs are checked.
The complete expanded identity contributes another 50,176 entries and rank224.
The independent tariff implementation enumerates binary span images, rather
than using the primary binary row elimination. Fixture bills are not minima.

The optimized CLI controls first run both implementations on a private copy,
then reject seven corruptions with specific diagnostics, then rerun both after
restoration. They exercise the unmodified binary template for the O/O case,
an oversized rational exponent, a wrong field polynomial, a changed rational spectator value, a new forbidden
query support, a false tariff receipt and changed live source bytes. Seven
local controls cover rational halves, inconsistency, empty systems, inverses,
shape, field-value and capacity errors. Scientific checks use explicit
exceptions and remain active with Python optimization enabled.

The card's first planning control, complex-local-word-ceiling/verify.py,
passes. It is existing planning arithmetic, not a new result. The broader
research_baseline.py orientation stopped on omitted selected dependency
directories in the sparse checkout. No full selected replay is claimed or
needed by this isolated theorem. Early exploratory code treated partition
port indices as binary labels and gave an invalid apparent saving. Mapping
indices through the authenticated recipe labels removed it. The retained
exact fixture checks and independent Gram check use actual binary labels.

## Engineering choices and bounded deviations

Build the Lever changed the result into exact rerunnable lemma, literal-array
and corruption checkers. Prove It Works required the actual operators and
rectangular tariffs, plus committed-byte and Git-free replay. No pending
predecessor theorem is a proof premise. PREDECESSOR-PROOF.md is an unchanged
comparison artifact, and COMPARISON.json separates it from ancestry pins.

Power of Ten inspections cover the three new Python scripts. Their calls are
acyclic; there is no recursion. Loops range over seven points, 32 subsets,
24 or 5,040 permutations, 21 fixtures, five terms, 112 ports, 224 expanded
coordinates, or a binary span of at most 512 elements. Input reads are capped
at 1MiB, with 8KiB templates and 32KiB partition limits in the primary path.
Linear elimination has at most 112 rows and six columns. The corruption suite
runs a fixed number of subprocesses, each with a 90-second timeout; registered
commands have 120-second timeouts. No function exceeds 60 formatted lines.
Contracts and meaningful checks use ordinary exceptions, including under -O.
Subprocess statuses, linear inconsistency and field inverses are checked.
Private temporary copies have scoped context-manager cleanup. Copies create
new regular files exclusively, verify owner and distinct device/inode before
writing, and use no metadata or mode copy. Symlink package entries reject.
Three copy controls check bytes, exclusive destination creation, symlink
rejection and unchanged source bytes.

Rule 3, fixed allocation. Python fractions, JSON parsing, sets, lists and the
standard library allocate dynamically. This deviation covers only the bounded
standalone verification process. Finite capacities above bound live data;
there is no service, growing queue or steady unbounded input stream. The
controls test read/shape/capacity errors and release private copies. A port
beyond the fixed 112/224 fixture domain requires a new capacity review.

Rule 8, runtime loading. test_controls.py uses runpy.run_path for its single
fixed local verify.py to test entry boundaries. It constructs no source code
and loads no caller-chosen module. This test-only deviation is bounded to one
local module with normal -I/-O CLI corruption replays as the compensating
check. Production scientific paths use ordinary direct functions.

Ruff0.17.1 formatting and E4,E7,E9,F,B,UP,SIM,I checks are the recurring focused
diagnostics. Python runs with warnings as errors. An exploratory --select ALL
run reports annotation/docstring/standalone-script style findings; its output
is retained in the session diagnostics. No diagnostic suppression was added.
Installing project-wide annotation or namespace-package policy is outside this
isolated research package. This is not a claim that all optional Ruff rules
pass. Revisit those style choices if the package becomes a supported library.

## Limits

Other seven-point rank patterns and a complete five-term theorem are unproved.
The general characteristic-two expanded-identity statement is existing context,
not republished as a new contribution. Physical/native execution, all-size
compiler admission, complete consumers and both suppliers remain open. Lean,
Docker, a full selected replay, and independent human/formal proof-kernel
review were not run. No selected-frontier file is changed.
