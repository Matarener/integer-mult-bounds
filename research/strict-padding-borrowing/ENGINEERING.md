# Engineering decisions and verification boundary

The exit predicate is one independently reviewable strict-padding result with
exact source pins, proof, executable row adapter, separate arithmetic oracle and
failure controls. The session decision trail is external to the repository.
The autonomous-run playbook was used. No child agent or independent reviewer
was used. Public research coordination and publication follow the donor's
explicit authorization.

Build the Lever changed the deliverable from a padding observation into a
rerunnable selector and Count-tape adapter. Prove It Works required literal
frozen-tape endpoints, optimized corrupted public CLIs and committed-export
replay. Test Behavior, Not Implementation made the checks assert minimum
borrowing, exact basis outputs, preserved borrowed inputs and erased returned
data. Separate Before Serializing Shared State kept this package and its
session outputs private, with process-held worker ownership and short advisory
locks for shared Git and peer reservations. The unslop pass kept the public
claim tied to the changed covering premise and its remaining consumer costs.

## Power of Ten inspection

1. The new call graph has no recursion. Structured try/finally blocks close
   new Count objects and padded/returned tapes. Retained source scans rewind
   borrowed inputs. Controls exercise success, source/output aliasing, a
   failing callee, wrong heads, dirty added rows and short/long returns.
2. Host widths are bounded by 2^64-1, dimensions by 64, depth by 4096 and
   table digits by 2^24. The child map contracts strictly. Bisection has at
   most e.bit_length()+1 iterations. Toy stock tables have at most 128 levels
   and 1031-bit products. Count inputs are at most 4096 bits; a doubled
   comparison can use 4097 bits. The legacy planner has fewer than R+S
   countdown steps, and row scans have the explicit prefix/row/body Count
   products as bounds. Frozen extraction has four members and an authenticated
   84-file inner inventory. Each CLI subprocess has a 30-second timeout;
   registered commands have 120-second outer process-group limits.
3. Python and the retained tape simulator allocate variable-length objects.
   This is a managed-runtime deviation from static allocation, confined to
   this bounded checker and logical adapter. Count capacity is enforced before
   planning; complete also bounds prefix/body counts. The new-domain planner
   has only a constant number of live Count tapes. Literal endpoint fixtures
   have at most 90 genuine input bits; the isolated CLI fixture copies only
   declared source files and the package. Failure checks inspect erased owned
   returned data and canonical heads. Python library allocator internals and
   all-width physical fixed-capacity compilation are not verified here. The
   follow-up is a real fitted Count-tape/C0 setup invoice before integration.
4. Functions are kept below 60 physical lines in repository formatting. The
   longest mutation runner was split into a finite mutation specification and
   its execution. This separates test cases from ownership and subprocess
   cleanup rather than hiding a common invariant behind forwarding wrappers.
5. ValueError-based contracts remain enabled under -O. They check typed and
   monotone threshold tables, input capacities, bisection returns, exact
   product certificates, strict volume and completed-return conditions. The
   receipt comparison serializes types, so true is not the integer one.
   Duplicate JSON fields reject. Checks exceed the one-per-50-lines signal.
6. The adapter receives the retained padding module explicitly and never
   overwrites it. Source activation is confined to one synchronous context in
   an isolated replay process. It rejects preloaded predecessor names and
   restores path/module/cache state on exit. Temporary exports use the caller's
   external TMPDIR. No shared interpreter mode or shared source is changed.
7. Returned counts, tapes and subprocess exits are consumed or closed. The
   adapter propagates callee and restriction failures after owned cleanup.
   Input shape/capacity failures occur before payload access. The semantic
   row-pointwise callee premise is explicitly retained, rather than inferred
   from runtime zero checks. Abrupt process death and OS allocation failure
   are outside the completed-callee contract, as in the retained source.
8. The only new dynamic loading is one authenticated, fixed source-loader
   file from a pinned canonical archive. It loads the unchanged bounded
   predecessor closure in its documented namespace. This is a source-reuse
   deviation from static imports; exact outer SHA256, inner source inventory,
   no-preloaded-module guard and corruption controls constrain it. Replacing
   the loader requires an equivalent source-export contract first. No eval,
   synthesized code or run-dependent source generation is used.
9. The callee callback is the required completed-row boundary. This is an
   explicit indirect-call deviation, with caller-owned input, distinct output
   and finally cleanup. Tests use one synthetic rowwise reversal and seven
   fixed bad-return modes. No selected C0 target or arbitrary production
   callback is admitted by these fixtures. All other new calls are direct.
10. Repository Ruff checks and formatting, Python -W error, normal/optimized
    registered replay and actual corrupted CLI checks are the affected
    diagnostics. No new lint suppression is introduced. This package does
    not alter shared lint configuration or add a type-checker dependency.
    Its opt-in registered commands enforce science and failure behavior;
    recurring per-package Ruff enforcement is not supplied by this hook.
    Add that repository-wide policy separately if maintainers request it.

## Review and limits

The mathematical review checked necessity as well as sufficiency of S<2R,
the excluded equality case, the global one-digit bound, the last legal-k
boundary and the selected threshold drop. A second local lens checked source
closure, copied fixture isolation and every owned-resource exit. These are
self-review passes, not independent human or proof-kernel review.

An initial independent selected-witness check incorrectly reused the toy rank
m-1=63 instead of selected rank 42; it rejected at the forward-depth endpoint.
The independent toy digest already agreed. Another initial control expected
Tape.clear to erase the retained LEFT marker, but the documented operation
erases data and restores the head while preserving that marker. The control
now checks exactly that contract and also rejects returning the borrowed
source. Both original diagnostics and the corrected, source-hashed control
receipt are retained in the external session. Neither failure was hidden or
turned into a passing scientific claim.

The source proof is conditional on completed rowwise C0, physical refinement,
uniform costs, fresh fields, restoration and the remaining retained consumer
premises. Synthetic basis endpoints do not establish those premises. No full
selected cold replay, historical suite, Lean/Docker run, native GL64 payload,
formal compilation, supplier admission or selected-frontier update is claimed.
