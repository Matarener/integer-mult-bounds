## Exact composed endpoints and return

Write `v=y+A x` for the inherited original 4,058-event channel. In the retained
eight-pivot decomposition `A=[[I,B],[B^t,B^t B]]`, PR3882 returns

```
X_J=q=x_J+B x_N,    Y_J=w_J,
X_N=w_N,           Y_N=v_N=y_N+B^t q,    w=x+y.
```

The sums occupy hyperplanes; q and v_N occupy FULL. Its explicit inverse is
credited predecessor work. Even granting a free logical gather of residuals
into `r=(q,v_N)`, substituting r for the original source in the next inverse
shear gives `(r-w,w)`, with error `r-x` of **rational rank 104**. A literal
one-source fixture separates this from the desired `(-y,w)`.

The new return adapter preserves every sum and restores the fixed physical
boundary `(X=x FULL, Y=w H_i)`, with all 72 arbitrary dirty helpers unchanged.
It uses 1,152 unit additions, 104 halves, 104 doubles and exactly 192 conversions.
The lower bound follows from the necessary dimension change on 96 X locations
and 96 Y locations. Free role renaming and changed return locations are outside
that bound. See [PROOF.md](PROOF.md) for the complete word and scope.

After source restoration, the bounded inverse reader realizes

```
(x,w,h) -> (x-w,w,h) = (-y,x+y,h).
y = -X_out,    x = Y_out+X_out.
```

It lifts Y to FULL, subtracts Y from X and descends Y: 104 unit additions and
208 conversions. These are actual paid operations in the local schedule.
The output preserves all input information; no residual is privately erased.

## Fused correction and fair baseline

All Y fields are lifted to FULL. The source pivots themselves provide the
temporary q values, and are restored before the optional reader consumes X:

```
X_J += B X_N
Y_J -= B X_N
Y_N -= B^t X_J
X_J -= B X_N
Y_N += X_N
```

This returns exactly `(x,x+y,h)`. Adding `X -= Y` before the final Y descents
gives the tested inverse-shear endpoint. Every scalar gate has both operands
in FULL. The source and target hyperplanes, all coefficients and all arbitrary
dirty rows are checked, not inferred from port supports alone.

## Complete-cost decision

Both fully fused routes retain profile `(1282,58,86,104,48,24,8,8)` and mass
2,576, giving the unchanged local screen `2576/(9*280)=46/45>1`. For the
retained source-preserving nine-stage paired-chain coverage law, the favorable
whole rank bill is

```
remaining coverage = 72*832 - 9*2312 = 39096
full lower mass   = 9*2576 + 39096 = 62280
capacity          = 73*832 = 60736
M(0)              >= 7785/7592 > 1.
```

The closed terminal correction earns no new endpoint progress under that law.
Its mass is not deducted again from required idle/remaining coverage. Finite
fully paid auxiliary banks preserve the 1,544-rank excess. This is the credited
conditional coverage rejection applied to the explicit new source-preserving
word, not a new coverage theorem or a universal P104 obstruction.

The full physical bill additionally needs native wrappers/arithmetic, original
private COPY/disposal, source availability, exact owners/holding/routing/address
and control, actual entrance/temporary widths, the caller's later endpoint
copy/correction/cleanup and all-size recursive transfer. Those costs are
unresolved or inherited; they are not assigned zero. The unchanged favorable
lower bound already fails, so supplier/native expansion stops here.

**Decision: NARROW.** Preserve the sharp fixed-location adapter tariff, logical
incompatibility witness, exact caller-cut words and cost comparison. No actual
P104 global caller or favorable complete replacement coverage law is supplied.
