## Why the scalar identity is insufficient

VALUE coefficients are binary, while ADDRESS maps use exact rational matrices
or a declared odd field. The explicit F1009 source impulse has 111 distinct
portwise entrance images, and every reader column is nonzero. Therefore no
nonzero scalar encoding column can make the actual routed observation vanish
on that fixture. This excludes a uniformly valid scalar encoder; it does not
assert that the same chosen impulse separates all ports over every small odd
field. A paid operator-valued encoder remains outside the result.

At target cuts the unchanged bulk never reads a target. Source and helper
fields therefore contain no arbitrary old-target column. For actual projectors
U,V the required ADDRESS crossblock is
`U+V-2UV=(I-2U)(V-U)`. Its rank vanishes only when the projectors agree.
The exact rho adapters preserve this rank. Native-zero ADDRESS adapters and
finite binary combinations of their arrays preserve the zero-second-half
fiber; the required coefficient sends a delta outside it.

Keeping the old virtual target value does not permit the stipulated free
update: the new crossblock is nonzero, and its difference from the old one is
`(Unew-Uold)(I-2V)`, also nonzero. An input outside both kernels produces an
uncancelled output outside the preserved fiber. The proof states rational and
finite-field premises explicitly. This retained-value argument permits only
the old virtual target plus a correction assembled from surviving public
targets; arbitrary processing or mixing of retained virtual buffers is outside
it. This excludes the fixed reconstruction alphabet and chronology, not every
native encoding or shared-query circuit.

The scalar parity-zero cleanup is only over F2. Exact integer-zero cleanup,
operator-valued encoding, changed target-reading words, new intermediate
queries, integral chronological owners, rounded precision and source/tape
implementation remain separate obligations. No selected-frontier change is
made.
