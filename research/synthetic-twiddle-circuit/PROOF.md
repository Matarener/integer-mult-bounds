# A bit circuit for combined synthetic twiddles

This is an author-written proof. Independent human and formal proof-kernel review are unclaimed. The mathematical family below is unbounded. The executable compiler enforces ell in 2..256 and at most 64 axes.

## Statement and scope

Let ell>=2, r=2^ell, D>=1, 1<=K<ell, and let axis i have a_i equal to ell or ell-1. Put A=sum_i a_i. Use the named-slot layout L prescribed by the pinned transform source. A physical record address is an A-bit word in that layout's MSB-first slot order. In round 0<=h<ell the participating axes are I_h={i:h<a_i}, with d_h=|I_h|. Write b_i=x_(i,h) and k_i=sum_(v<h) 2^v x_(i,v).

There is a uniform AND/XOR circuit, with constants zero and one, whose ell+1 MSB-first output bits encode

    E_- = -sum_(i in I_h) 2^(ell-h) b_i k_i modulo 2^(ell+1).

The opposite circuit returns E_+=-E_- modulo 2^(ell+1). The circuit uses no arithmetic instruction on address values. If h>=1 and d_h>0 its gate counts are exactly

    G_+ = d_h (6h+5),
    G_- = d_h (6h+5) + 3(h+1).

For h=0 or d_h=0 both circuits are constant zero and use no gates. There are A input bits, two constants and G gate-result bits in the literal evaluator, plus ell+1 output bits. The immutable topology uses O((G+ell) log(A+G+2)) bits. The bound is independent of K except for wire placement. This is circuit size and storage, not a sequential tape-operation count.

The source already states the exponent formula and a polynomial-time address computation. This result supplies a concrete topology and a narrow accumulator, proves its cost, and gives a fixed-tape scan simulation below. It does not establish a production transform, native/root refinement, supplier or new kappa.

## Physical inputs and participation

Put b=(ell-1) mod K and q=floor((ell-1)/K). The source first extracts the top slot of each long axis, in axis order, and then extracts slots at h=b-1,...,0, with axis order inside each h. These are exactly the prefix generated by named_slots.

After that extraction, each axis has q chunks, each of K bits, with high chunks first and bits within each chunk decreasing. The source transposes axis-major chunks into chunk-major order. The slot at chunk index j, axis i, and descending offset t is therefore

    (i, b+(q-1-j)K+t),  0<=j<q, K-1>=t>=0.

This is exactly the suffix generated by named_slots. It accounts for every named slot once. No coefficient suffix is part of this input address. This derivation is from the pinned source's moves; it does not assume a pending successor's all-size formula.

In a common round every participating current axis length is u_i=2^(h+1). Hence 2r/u_i=2^(ell-h). At h=ell-1 only long axes participate. Lower rounds include all axes. In the opposite schedule the source restores lower input bits before they are read, while slot h still holds the branch bit. Thus the same physical input interpretation applies at the moment either circuit is used. Earlier processed, higher slots are absent from its terms.

## Narrow modular sum and gates

Let n=h+1 and m=2^n. Define S=sum_i b_i k_i modulo m. Multiplication by 2^(ell-h) induces an injective map from Z/mZ to Z/2^(ell+1)Z. Consequently reducing S modulo m before the shift loses no information needed by E. In particular an accumulator of ell+1 bits is unnecessary. Each term is h AND gates, followed by one constant zero top bit.

The full adder uses t=a XOR b, s=t XOR c, and next carry

    (a AND b) XOR (t AND c).

The two carry terms cannot both be one. Checking c=0 and c=1 gives the binary sum a+b+c=s+2*carry. Induction over n positions proves addition modulo m, with final overflow discarded. The code uses five gates for each of n positions, including the unused last carry. Adding each masked term therefore uses h+5n=6h+5 gates. Repeating over I_h proves the stated positive-direction count and S invariant, even when many axes overflow the accumulator.

For the negative direction, complement each S bit by XOR with one, then add one with an increment ripple. At each position the output is inverse XOR carry and the next carry is inverse AND carry. This is three gates per bit, returns -S modulo m, and adds 3n gates. Reversing the little-endian accumulator wires and appending ell-h zero wires encodes the desired multiplication by 2^(ell-h). No gate is needed for wiring, constants, or the shift. The output has n+ell-h=ell+1 bits.

If h=0 every k_i is zero, so the constant circuit is correct. An empty I_h also gives zero. These cases explain why the compiler skips all gates there. Topological wire numbering makes every operand precede its gate, so evaluation induction realizes exactly these Boolean expressions. All internal tests use ordinary exceptions and remain active under Python optimization.

## A sharp bit divisibility and affine obstruction

All output residues are divisible by 2^(ell-h). When h>=1 and d_h>0, choose one participating branch bit and its v=0 lower bit equal to one and every other input bit zero. The forward exponent is -2^(ell-h). It is not divisible by 2^(ell-h+1) modulo 2^(ell+1), so the common trailing-zero count is sharp.

More generally, for any participating i and 0<=v<h, restrict all bits except x_(i,h) and x_(i,v) to zero. The mixed difference f(1,1)-f(1,0)-f(0,1)+f(0,0) is -2^(ell-h+v), nonzero modulo 2^(ell+1). Every additive affine exponent in the physical Boolean address bits has zero mixed difference. Thus such an affine exponent cannot implement this round. The four corners in RESULT.json are a finite witness to this general proof. This does not exclude nonlinear encoded control, compositions of affine operations with auxiliary computation, or PR3087's distinct Gaussian phase contract.

## An explicit fixed-tape simulation bound

This paragraph is a scan algorithm and proof, not an executed fixed-tape interpreter. Put B=A+G+2 and store the circuit as opcode/two-wire-index rows in topological order, with binary indices of O(log B) bits. Retain the ell+1 output wire indices. On fixed separate tapes keep the current physical address, its wire-value array, the topology, a record output buffer and binary scan counters. The number of tapes is independent of D and ell.

Initialize B wire cells to zero, write the constants and address, and reset the topology head. For each gate, retain its two indices and opcode on a work tape. Scan the wire-value tape with a binary position counter. Read each operand when its index matches, compute the single AND/XOR, and write its result at the designated next gate position. A full scan and return uses O(B log B) bit operations, including index comparisons/increments. Two scans per gate suffice if the result position is passed before both operands are retained; topological numbering actually places it later. Resetting topology and counters is included in the same bound.

For each output index, scan the wire tape and append that bit to the output buffer. Clear the private wire tape and work counters, preserve the topology, and advance the physical address counter by one. Initialization, address increments, and returns cost O(B+A); the output scans cost O((ell+1)B log B). Thus one header costs

    O((G+ell+1) B log B + A)

bit operations and O(B+(G+ell+1) log B+A) working/program bits, excluding an accumulated output stream. The first all-zero address and a checked A-bit overflow delimit exactly all 2^A records. A streaming consumer needs only the current ell+1 header bits. A materialized stream additionally occupies 2^A*(ell+1) output bits and is not free storage.

Under the source's d*ell=O(p), D=d-1 and a_i<=ell, both A and G are O(p). The simulation therefore uses O(p^2 log(p+2)) operations per header and O(p log(p+2)) bits, including topology. Constructing the finite topology and named-slot list uses polynomial time and space from the shape descriptors. For the absorption step assume the source comparison bands explicitly: fixed 0<epsilon<1, positive a_r,b_d, d<=b_d*p^epsilon and r>=2^(a_r*p/d). Then log2(r)>=(a_r/b_d)*p^(1-epsilon), which eventually exceeds any fixed multiple of log2(p). Thus r dominates every fixed power of p. The header simulation is absorbed by O(rp) per polynomial record, as required by the source paragraph on exponent production. No fixed constant or numerical cutoff is inferred from this asymptotic absorption.

The code runs a random-access gate interpreter and retains a Python tuple topology. It does not execute this scan simulation, produce the source's encoded outer descriptor, move coefficient packets, or account for the complete caller's program tapes. The proof does not admit those missing components by treating their costs as zero.

## Joining the data operation

In any ring with y^r=-1, y^(2r)=1. The nonnegative residue E is therefore a sufficient exponent for the exact signed coefficient rotation. Changing direction negates that residue. The complete-transform fixtures substitute the circuit output into the retained indexed engine's monomial routine and verify both forward and opposite operators on whole ring-module columns and dense records. They establish this arithmetic join on their finite shapes. They do not execute PR3516's MSB packet interpreter or the production truncated simultaneous layer. Those interfaces require their own source closure, control lowering and physical invoices.
