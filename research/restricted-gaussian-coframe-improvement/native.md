## 3. Ordinary common-coframe decoding

**Theorem 1.** In the forward orientation, precode the Y inputs by `A` in their common ground coframe. Run the specialized centre-free coded body. Decode all Y outputs by `A⁻¹` in their common `H_8` coframe. The logical endpoint is exactly

`(X,Y,h) ↦ (X,Y+X,h)`.

**Proof.** The precoded logical input is `(X,AY,h)`. The coded body returns `(X,AY+AX,h)`, namely `(X,A(Y+X),h)`. The decoder yields `Y+X`. Since `A` acts only on the finite owner index and the same `H_8` acts on every Y payload, `A` and `A⁻¹` commute with that common fiber coframe. Thus the decoder's physical operation is exactly the ordinary owner-space matrix `A⁻¹`, with no Gaussian child hidden in a chart conversion. The ground precode is ordinary for the same reason with `H_0=I`. Helper endpoints remain autonomous for all main inputs, so precoding Y changes no helper target. QED.

**Theorem 2.** In the backward orientation, precode X by `Aᵀ` in its common `H_1` input coframe, run the specialized backward coded body, and decode X by `A⁻ᵀ` in its common full `H_9` output coframe. The logical endpoint is exactly

`(X,Y,h) ↦ (X−Y,Y,h)`.

**Proof.** The coded X output is `AᵀX−AᵀY=Aᵀ(X−Y)`. Applying `A⁻ᵀ` gives `X−Y`. Both owner codes commute with the relevant common fiber coframe and are ordinary there. Every independent helper remains unchanged logically. QED.

The negative orientation is separately constructed. No destructive centre clear is reversed and no scalar transpose inference substitutes for the physical program.
