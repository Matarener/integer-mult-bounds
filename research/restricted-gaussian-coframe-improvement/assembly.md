**Theorem 1 (complete finite program).** For every such caller, this algorithm returns the same complete main linear map on every main input, with all original helper inputs still independent and their explicitly specified new outputs.     n_B E_B(C)+n_C E_C(C)>(39/5)n_B+74 C n_C

whenever n_B+n_C>0. The new moment is the old COMPLETE moment plus this amount.

**Proof.** Each replacement supplies exactly the original main block in its declared actual convention. Its main output does not depend on any helper input, and its original helper outputs depend only on their respective inputs. It therefore has the same main action even when placed between arbitrary retained caller instructions. Summing exact complete local paid and productive differences proves the moment identity. The strict inequalities are proved in dual-transfer.md and profile-and-tails.md. No outside target or charge changes. QED.

In particular, if an actual complete caller is supplied with a deficit smaller than this exact combined gain at a fixed test exponent, the returned complete caller has a strictly positive signed moment there. This is a universal sufficient theorem on explicitly supplied programs; no unspecified profitable gadget, oracle or unknown caller is assumed as a research achievement.
