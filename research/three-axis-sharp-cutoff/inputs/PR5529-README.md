# Shorter constructive witnesses for native monomial identities

This package improves the sufficient tensor-width bound for the affine/quadratic
Gaussian monomial grammar in [PR #5369](https://github.com/CrocSwap/integer-mult-bounds/pull/5369).
For n>=2 axes, the general cutoff is 2n+3. For three axes, an exact finite
character calculation improves it further to seven. Thus widths 7,8,9,10
decide every fixed three-axis identity in this grammar. The complete kappa
calculation is unchanged.

## Contract and result

Retain the input-phase action and fixed external coefficients:

```text
U(g,q)e_x = i^q(x) e_g(x),
q(x) = c + sum_j a_j x_j + 2 sum_(j<k) b_jk x_j x_k modulo 4,
g in AGL(n,2), c,a_j in Z/4, b_jk in Z/2.
```

For P in the complex group algebra, let rho_f(P) evaluate each group term at
its f-th tensor power. The external coefficients stay fixed. Write I_r for
the ideal generated by [iI]-i^r[1]. Then

```text
n>=2 and f>=2n+3  imply  ker(rho_f)=I_(f mod 4).
n=3 and f>=7     imply  ker(rho_f)=I_(f mod 4).
```

Consequently four consecutive widths starting at either sufficient cutoff
decide equality for a single fixed P at all positive widths. The same result
applies entrywise to complete register endpoints. All independent dirty inputs
and all specified returned roles remain part of the endpoint. A width-dependent
program cannot be promoted to an all-width identity by four tests.

For nine axes the sufficient window changes from 22..25 to 21..24. This changes
an algebraic test bound. It does not reduce a physical supplier's paid cost.
The sharp two-axis cutoff six in PR #5522 remains stronger in that dimension.
No least representation cutoff for n>=3 is claimed here.

## A nonalternating Gram form saves one column

A phase character has statistics (r,u,v), where r and u_j are modulo four and
v_jk are modulo two. As in the predecessor, set the binary symmetric matrix M
by M_jj=u_j mod 2 and M_jk=v_jk. A tuple of points must have Gram matrix M,
coordinate counts u modulo four, length r modulo four and full affine span.

Choose an invertible binary matrix B whose column sum s differs from u modulo
two. This is possible for n>=2: use B=I unless u mod 2 is the all-ones vector;
in that case replace its first column e_1 by e_1+e_2. Start the tuple with zero
and the n columns of B. It already has full affine span. The residual Gram
matrix R=M+BB^t has diagonal u+s, which is nonzero. Thus R is nonalternating.

Every nonalternating symmetric binary matrix R has a factor YY^t=R with
exactly rank(R)<=n columns. Here is an explicit proof and algorithm. Symmetric
elimination splits the form into unit lines, hyperbolic pairs and a radical.
There is at least one unit line. A unit z and a hyperbolic pair e,f can be
replaced by z+e, z+f, z+e+f; these three vectors are orthonormal. Repeat to
obtain an orthonormal basis v_i for a complement to the radical. Then

```text
R = sum_i (R v_i)(R v_i)^t.
```

Indeed the orthonormal vectors resolve the bilinear form on the quotient by
its radical. This gives the columns of Y and uses polynomial binary linear
algebra. Nonalternation is essential: a nonzero alternating form can require
an extra Gram column. The rank lower bound also proves that this factor width
is exact for the chosen R. Binary symmetric factorization is classical.

Append the columns of Y. The tuple now has the required Gram matrix and length
at most 2n+1. If its coordinate counts are w modulo four, then u-w is even.
Append two copies of the single vector z with coordinates (u_j-w_j)/2 modulo
two, unless z is zero. This changes the coordinate counts as required and
preserves all pair parities. The length is at most 2n+3.

For any f>=2n+3 with f congruent to r modulo four, append zero points to reach
f. They preserve coordinate counts, pair counts and affine span. The resulting
tuple realizes every character at every such f. This proves the improved
constructive bound.

## Why character witnesses decide the complete endpoint

The predecessor's Fourier argument is retained. Write P as a sum over affine
maps g and diagonal phases. At a fixed residue r, combine the constant phase
coefficients. If P is outside I_r, finite Fourier inversion gives an affine
bucket and a nonconstant phase character with a nonzero Fourier coefficient.
Use a tuple X with that character and full affine span, and put Y=gX.
A different affine map cannot send X to Y. The matrix entry from X to Y is
therefore exactly the nonzero Fourier coefficient. Conversely every element
of I_r evaluates to zero at residue r. This proves the displayed kernel bounds.
The four residue ideals have zero intersection, which proves the four-test
statement. This step neither assumes nor proves that full affine span is
necessary for representation faithfulness.

## Exact three-axis character calculation

For n=3 there are 2048 characters including the constant residue. For a
multiplicity vector m on the eight binary addresses, write m=a+4t with
0<=a_x<=3 and t_x>=0. Define its character by

```text
r = sum_x a_x modulo 4,
u_j = sum_x a_x x_j modulo 4,
v_jk = sum_x a_x x_j x_k modulo 2.
```

Let d(a) be the affine dimension of its positive support, with d=-1 for the
empty support. The exact shortest full-span realization of this residue vector
has length

```text
L(a) = sum_x a_x + 4(3-d(a)).
```

Each new supported point requires four copies and increases affine dimension
by at most one. Conversely any affine subspace extends to the full space by
exactly 3-d new points. These two facts prove the formula, including empty
support. Therefore the exact minimum for a character is the minimum of L(a)
over its residue vectors a in {0,1,2,3}^8. Four-copy zero padding preserves the
character and full span at every later width of that residue.

The executable checks all 65536 residue vectors and all 2048 characters. The
maxima of these exact minima, ordered by residue 0,1,2,3, are

```text
(8,9,10,7).
```

A separate enumeration of all 43758 nonnegative multiplicity vectors of total
width at most ten gives exactly the same 2048 minima. Every minimum also has
an explicit full-span witness. This finite exact certificate and the padding
argument prove that the three-axis representation has stabilized by width
seven. They do not exclude stabilization before the full-span witness bound;
that would require a separate analysis of nontrivial affine stabilizers.

## Evidence and reproduction

```sh
python3.12 -B scripts/research_package.py --package research/shorter-native-phase-witness
```

Python 3.12 and the standard library suffice. Normal and optimized warning-strict
runs print `PASS_SHORTER_NATIVE_PHASE_WITNESS`; the launcher prints
`PASS_REGISTERED_RESEARCH_PACKAGE`. Each run checks 1023 nonalternating binary
forms through dimension four, 2624 constructed characters through 17 axes,
17408 literal Gaussian-phase identities, the two complete three-axis censuses
above and seven controls. The controls reject an alternating input and show
that Gram parity alone misses a two-unit linear phase change.

No predecessor executable is imported. These finite checks corroborate the
all-dimension written proof; no independent human or proof-kernel acceptance
is claimed. The selected cold replay, native physical emission, full compiler,
precision, stock, movement and outer-transfer checks were not run.

## Open next questions

Determine whether the three-axis representation already stabilizes before
width seven. Start with the affine pointwise stabilizers for characters whose
full-span minimum exceeds the width, and compute their common group-algebra
kernel. A character-realization minimum alone is not a lower bound for the
complete representation. Physical application still needs a source-bound
complete endpoint and its full paid invoice.
