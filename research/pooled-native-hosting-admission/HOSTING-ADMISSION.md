## Operators and spectators

Let V=(F2^73)^f and let the coefficient module be Q(i)-valued complete arrays
on V times an arbitrary spectator set. For a column vector v in F2^73, write
X_v for translation by v on one column and

```
C_v = ((1+i)I + (1-i)X_v)/2.
```

Every X_v commutes with every X_w, hence all C_v and translations commute.
Write C_[A],f for the product of C_v over the literal ordered original axis
list A, separately in each of the f columns. This notation includes every
inactive coordinate and spectator by an identity factor. It does not identify
arbitrary bases of the same subspace: the actual vectors in A are material.
The scalar signed shear between two role streams is applied once, independently
of f. Only the unary operators and coordinate permutations are lifted across
the f columns.

For an invertible binary matrix d, set (P_d u)(x)=u(d^-1 x), column by column.
Then P_d X_v P_d^-1=X_(dv), and the same conjugation rule holds for C_v.
These are complete operator equalities, so no independence, cleanliness or
absence of correlation is required of persistent inputs.

## Literal charts and every cover label

The source port q has odd weight and is not the all-ones 9-bit vector. Choose
the source's first missing coordinate a and put v=q+e_a. The even-weight vector
v is isotropic. The transvection T_v=I+vv^T is an orthogonal involution:
T_v T_v^T=I because v^T v=0. Applying it to the standard basis with coordinates
0 and a swapped gives the exact port basis B_q emitted by port_basis; its
first vector is q. The checker verifies all 112 actual bases.

A helper chart consists of the exact slice A[offset:offset+width], followed
by the source's literal spectator completion, then the remaining B_q vectors.
It is a permutation of that orthonormal basis. The checker reconstructs all
6,489 emitted helper charts and checks their complete 73 coordinates and
digests, including inactive spectators. The data chart at positive stage s
uses the eight transvections with vectors B_q[1+i]+e_(9+8(s-1)+i).
These vectors are isotropic and mutually orthogonal, so their product is
orthogonal. The checker checks all 1,008 actual port/stage matrices as well.

Let sigma have those chart vectors as its columns. The source stores the
columns as a tuple, which, when consumed as matrix rows, is sigma^T=sigma^-1.
For each d in O(73,2) the literal group key is

```
(base_family, rank(d sigma^-1)).
```

Right multiplication by sigma^-1 is a bijection of the entire group. If
h=d sigma^-1, then d=h sigma. Consequently the completed helper endpoint in
the common view is

```
P_d C_[e0,...,e(width-1)],f P_d^-1
  = P_h C_[A[offset:offset+width]],f P_h^-1.
```

The native endpoint preserves its remaining axes literally. For data,
the source entry mask is sigma^-1 times the original entry mask, so
P_d X_(sigma^-1 entry) P_d^-1=X_(h entry), and likewise at exit. Both members
of a productive data pair have the same sigma. Thus the actual completed
physical endpoint for that pair is exactly the one used in the phase proof
below at physical cover label h. No transpose or inverse of the full backward
role matrix is presumed.

Within each call the 632 base families are distinct and in the live namespace.
For different d, every role therefore reaches every physical cover member
exactly once and the persistent packets are disjoint. The native theorem
returns private scratch to zero, so it may be reused after each complete group.
Although the interior native word mixes its roles, its completed endpoint
separates each helper and each productive port pair. Regrouping that completed
cover sweep by physical label h is therefore valid. Regrouping its interior
instructions would not follow from this argument and is not used.

The rank/unrank routine covers the entire group, not an unspecified subset.
For a valid orthonormal prefix, its orthogonal complement W is nondegenerate
and nonalternating. Its characteristic vector w satisfies
<w,x>=<x,x> for all x in W. There are 2^(s-1) norm-one choices in dimension s.
After choosing a norm-one row u, the new complement's characteristic vector
is w+u. This complement is alternating exactly when u=w. That excluded case
is possible only when s>1 is odd; the one-dimensional final row is allowed.
Every other complement is again nondegenerate and nonalternating. Induction
on s constructs an orthonormal basis for each such complement, giving the
exact row-choice count

```
2^(s-1) - 1_(s>1 and s odd).
```

The source solves the prefix equations and fixes the next row bits in
lexicographic order by exact affine solution counts, excluding just that
characteristic row. Every allowed row has the same suffix count by the
preceding induction. Mixed-radix rank/unrank is consequently mutually inverse
on all O(73,2). The bounded check independently enumerates the full groups
in dimensions 1 through 5 (1,2,6,48,720 matrices), compares every rank/unrank
value and checks every character there. Four labels in dimension 73 are
additional probes; the written induction, not those probes, covers dimension
73 and all its 2,628-bit labels.

## Whole-call chronological retiming

For each replica and each original idle child, define its allowed interval
from the **actual** execution schedule: after the last preceding scalar
observation of its pair and before the child's original idle event. A complete
local invocation on the productive pair is an observation; a bridge observes
both pairs. An idle unary C/translation is not a scalar observation. The
checker reconstructs all 7,200 intervals, including the zero-rank slots, from
all 10,802 actual events. For each replica the projected order is exactly the
original 30 pre-padding events, with the original pair, child, coefficient,
orientation and signed terminal data. All 3,240 actual local dispatches occur
exactly once, using only the three active providers.

Every one of the 1,321,920 assignments passes the strict test

```
last_observation_event < complete_call_event < original_idle_event.
```

It also matches the original child pair/side, physical family, port, width,
literal compact offset and spectator completion. There are no productive/helper
aliases within a native invocation. A family may be borrowed by many successive
complete invocations; each such invocation has the separated endpoint already
proved. All intervening effects on that family in its interval are unary
translations or C factors, so the completed hosted factor commutes through
them to its original idle boundary. No factor is moved across a scalar
observation. This remains valid if another native word reads the dirty family
internally: that entire word is first replaced by its complete separated
endpoint. There is no interleaving inside an invocation.

The fill offsets partition the **original** axis lists consecutively. The
checker verifies each offset before incrementing it by the provider's actual
helper width. At the original idle event, every positive suffix is present
exactly once with its original family and pending offset; every exhausted
suffix is absent. The complete accounting is

```
residual profile        = {3:22788, 5:1620, 48:138492}

```

Thus hosted factors times the residual equal the original idle C product
exactly. The original idle translation remains at its actual boundary even

children in this construction. These statements hold for every physical
cover label by the preceding bijection and for every f by columnwise
multiplication.

## Full original chronology and final cover correction

It remains to identify the original global endpoint, including its signs and
Pauli translations. This checker independently derives it from the **physical
native pair endpoints**, rather than importing the old gauge checker's verdict.
For one column let F=C_[e0,...,e8], Q=C_q and D=F Q^-1. The two endpoints are

```
forward:  (x,y) -> (D x, D y + F Q^-2 x)
backward: (x,y) -> (D x - F y, D y).
```

Their chart-conjugated factors and the actual entry/exit masks are substituted
at each of the nine stages. In a Fourier character z, C_v has phase
i^(v dot z mod 2). Its exponent is the complete polynomial modulo 4

```
sum_(j in supp(v)) z_j - 2 sum_(j<k in supp(v)) z_j z_k.
```

Terms of degree at least three vanish modulo 4. A translation contributes
2(v dot z mod 2). Exact linear coefficients modulo 4 and every quadratic
coefficient are therefore a complete identity test for these unary factors.
The checker carries all 73 variables, not a sample of coordinate characters.

For each of the 112 ports, start with eight gauges
(C_q,I,C_q,I,C_q,I,C_q,I) and the scalar 8 by 8 identity matrix M. At a local
endpoint multiply the target gauges by the exact chart-conjugated diagonal
factors and entry/exit translations. The off-diagonal physical factor times
the old source gauge equals the new target gauge; this permits the single
signed scalar row addition in M. At each signed bridge the two relevant
gauges agree exactly, permitting its two row additions. The idle factors
are added on their original roles; the terminal Y translation precedes the
signed exchange (X,Y)->(Y,-X). The check proves 3,920 exact factor equalities
including every final role. It obtains M_final=I and
D_final=C_all D_initial. Hence the complete original chronology equals
C_all on each role. These are multiplicative identities of unary factors;
lifting each factor columnwise preserves them, while the scalar M remains
applied once. This proves the endpoint for every f>=1 without tensoring a
scalar matrix sum.

For a physical cover matrix d with rows r_i, orthogonality gives

```
|d^T z| = |z| + sum_i (|r_i|-1) z_i       (mod 4).
```

Indeed, expanding the parity polynomials above leaves the shown linear
terms; each quadratic coefficient is twice the overlap of two distinct rows
and vanishes modulo 4. Every row has odd weight. Put
delta_i=(|r_i|-1)/2 modulo 2. It follows exactly that

```
P_d C_all P_d^-1 = X_delta C_all.
```

The actual final event applies that row-weight mask to **every** live family,
so its involutive translation cancels X_delta. There is no missing constant
phase: all translations and C factors fix the uniform vector, and the
polynomial constant is zero. The same equation holds separately in every
column, proving the full corrected C_(73f) endpoint.

## Evidence and limits

hosting_admission.py is an independent stdlib traversal of every actual
assignment, owner chart, residual and event, plus the complete character
polynomial computation and bounded cover checks. It uses explicit exceptions
and its normal and optimized runs agree. Targeted mutations of the whole-call
window, original-axis offset and port owner are rejected. The prior physical
binding's independent duplicate-owner/dispatch/width/Z-map controls remain
preserved in PR4270; no new receipt claims to rerun them.

The finite pass instantiates the exact-source hypotheses of this written
all-parameter proof. It is not a formal-kernel certificate, an exhaustive
enumeration of O(73,2), a production-size tape execution, an analytic estimate,
or administrative frontier admission.
