# Close the actual whole-array cell0 carry edge

The actual helper462/frame506 cell0 forward carry is always0 or1; its inverse
carry is0. PR3343 already supplies the bounded rotation geometry. This package
joins the actual low-cache selector to a literal controller across the complete
contiguous T-type payload, paying for nested suffix construction, local fiber
markers/staging, global output, same-owner installation and all private cleanup.
It removes the two completed OLD adapters from this particular carry edge.
It does not introduce a new rotation primitive.

For N=8f,D=N² and the actual T=|GL_N(F_q)|, the default table accepts a contiguous
[T]×[Q]^D×[Z] payload and paired complete old-low cache. Runtime T,Q,Z stay on
tapes. No S/H descriptor, per-fiber marked bank, GL enumeration, host gather or
OLD callback is supplied. The old cache survives unchanged for later cells;
new low0 digits remain separately owned. A literal initializer can install the
fixed actual T without enumerating matrices.

[PROOF.md](PROOF.md) proves exact source columns, the all-size layout/lifecycle
and conservative complete bounds. With generic compile-time depth d and V=TQ^dZ:

- Transitions: at most2048(d+1)V+32TDb+256(d+1).
- Visited cells: at most(d+20)V+2TDb+128(d+1), including erased regions.
- Fixed tape count:17+d; table independent of runtime T,Q,Z,w.

The signed replacement bill is explicitly A_join−(2T A_OLD+A_later0+M_adapter),
with no assumption that this is numerically negative for all tariffs. Other
high/carry layers, full low commit, enclosing backing/stock, native refinement
and P3 remain. No selected receipt, recursive profile, supplier or kappa changes.
