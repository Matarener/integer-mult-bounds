## Weighted Jensen supplies the missing joint inequality

For any fixed positive paid ranks, define

```
w_r=p_r*r/P_1,    mu=sum_r w_r ln(r),    sum_r w_r=1.
```

Convexity of the exponential gives

```
P_t/P_1 = sum_r w_r exp(-C ln(r)) >= exp(-C mu).
```

If ln(c)>mu, the source theorem's permitted endpoint u=C satisfies

```
gamma_C = P_1/(c^C*T_t)
        <= alpha * exp[-C*(ln(c)-mu)] < alpha.
```

If also B*b<=P_1, its completion ratio obeys

```
delta = B*b/(c^C*T_t) = (B*b/P_1)*gamma_C <= gamma_C.
```

Consequently a raw-positive invoice has both tail ratios below one whenever
these two transparent conditions hold. No replacement of the target
