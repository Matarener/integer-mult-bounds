# Decisions and bounded deviations

The target is exact physical-address arithmetic through four sequential data tapes, preserving the source/head, blanking private data and agreeing with an independent access bill. Supplied immutable shape control is separate. Only this package changes; canonical inputs and frozen predecessors remain unchanged.

Foundational Thinking chose four explicit tape owners before arithmetic. Build the Lever produced tapes.py and the independent arrival-time invoice. Prove It Works requires source formula/circuit agreement, actual primitive counts, restoration and optimized CLI faults. Separate Before Serializing Shared State kept outputs/claims separate and used the prescribed OS locks for shared refresh, branch registration and reservation. External decisions.tsv and original-diagnostics.json retain the decision trail and corrected initial formula failure.

## Power of Ten inspection

1. No production recursion or unstructured jump. Structured exceptions attempt output/private erasure and borrowed-head return. Actual read faults after 3, 9 and 13 prior reads test cleanup and valid retry. Cleanup failure and a second interruption are excluded.
2. Validation enforces 2<=ell<=256, 1<=K<ell, 1<=D<=64, A<=16384. Each tape has at most 16384 cells. The slot iterator has exactly A iterations, pending loops at most 255 and ripple loops at most 256; each seek has at most 16383 unit moves. Complete test domains have at most ten bits. Control subprocesses have 90-second limits; registered commands have 120-second limits. No background child is started.
3. All data tapes are preallocated and never grow. Managed Python allocation is a bounded deviation below. Shape control and observation lists are separate from the four-tape model.
4. Every added function is below 60 physical lines. The independent event bill and CLI fault driver have single responsibilities. External AST diagnostics record their actual lengths.
5. Runtime require checks enforce shape, alphabet, positions and writes under -O. Replay checks independent identities, exact bills, blanks and borrowed bits/heads. Fault controls exercise those checks.
6. Each Machine owns four Tape objects and input-independent counters. Shape fields are immutable. Address bits remain within bounded Boolean locals. No per-address table/circuit is allocated by the producer.
7. Constructors validate public boundaries; moves reject out-of-range positions and writes reject nonbits. Subprocess checks inspect exit and success marker. Byte copies check write length, regular type, UID and distinct device/inode. Source authentication rejects changed/absent/nonregular inputs. No mode is changed.
8. No generated production code. The verifier compiles three explicit source files to avoid stale bytecode, with the narrow deviation below.
9. Data accesses use current-cell methods. Shape participation lookup is input independent and outside the invoice. The sole test replacement is one address.read method, restored before retry.
10. CPython3.12 isolated warning-error replay, optimized science/controls, registered replay, metadata/pins, final-HEAD source-history/bytes and committed Git-free replay are required gates. Ruff E4/E7/E9/F uses the existing executable if available. No native compiler, Docker, Lean or full selected cold replay is claimed.

## Deviations

Rule: 3, fixed memory capacity.
Location: Python Tape representation, shape iterator and observation code.
Reason: CPython allocates integer objects, frames and iterator state during execution; a list cell is not a physical Boolean cell.
Scope: This bounded reference execution and verification.
Compensating control: Fixed tape lengths and finite shape limits, with a separate proved four-tape/Boolean-local model. Shape control, diagnostics and Python overhead are explicitly outside C.
Verification: Complete small domains, bounded wider fixtures, exact capacities and independent primitive counts; no packed-memory measurement claimed.
Follow-up: Include encoded scheduler/counter storage and control work in a complete physical implementation.

Rule: 8, restricted dynamic evaluation.
Location: verify.load.
Reason: Cached bytecode may differ from authenticated source; compiling bytes just read removes that ambiguity.
Scope: Two explicit local modules and the authenticated canonical oracle, never a data-derived target.
Compensating control: Explicit paths, source SHA256 checks, isolated Python and source-corruption controls.
Verification: Normal/optimized replay, changed/absent source rejection and final source/export hashes.
Follow-up: Replace only with a loader guaranteeing execution of the exact read bytes.

Rule: 9, indirect calls.
Location: checks.failures temporarily replaces address.read.
Reason: Cleanup must be tested after input has made private data nonzero.
Scope: Three bounded test faults, never production dispatch.
Compensating control: One target, at most A observations, reliable cleanup and original-method restoration before retry.
Verification: Failure observed, private/output blanks, borrowed source/head preserved, then exact same-machine retry.
Follow-up: Broaden only under a separately stated fault model.

The encoded-control/compiler obligation is a scope boundary, not a claimed rule exemption. Exact data counts are not the host interpreter's full instruction count or supplier tariff. The all-size proof is author-written; independent human/formal acceptance remains unclaimed.
