## Power of Ten inspection

- All new control flow is structured, with no recursive calls. File handles
  and temporary directories use context managers. Subprocess failures and
  timeouts propagate as failures; each control checks its expected rejection.
- Mathematical dimensions are fixed at 112 ports, nine label bits, 16 groups
  and 32 indicators. The primary triple loop has exactly 4,960 iterations.
  The local prime-field loops have 12,492 states. Each elimination is bounded
  by at most 112 rows and columns. Control subprocesses have 120-second timeouts.
- Python requires dynamic allocation. This is a managed-runtime deviation
  from fixed allocation, scoped to these one-shot replay programs. Live source
  reads are capped at 1 MiB, metadata/fixture reads at 32 KiB. Matrices are at
  most 112 by 112 and the retained excess list has 4,960 integers. No input
  dimensions or work queues grow during replay. A streaming rewrite is only
  needed if the supported fixed geometry is deliberately enlarged.
- All functions are below the 60-line review ceiling. Invariants use explicit
  exceptions that remain active under optimization, including geometry,
  identity, support, source, field and bill checks. No assertion is required
  for acceptance. Mutable state stays inside each function or owned temp copy.
- External byte and receipt boundaries are checked. The sole trusted geometry
  source and retained fixture are hashed before use. Library arithmetic and
  iterator allocations remain runtime mechanisms, bounded by the dimensions
  above. No dynamic evaluation, generated code, decorators or runtime registry
  is introduced. The corruption lambdas have five fixed test-only targets.
- Python offers no pointer-depth control. Data access and direct function calls
  are shallow. The test subprocess boundary is deliberate and bounded. It
  checks optimized CLI rejection rather than calling a mock acceptance path.
- Diagnostics use isolated interpreters, `-Werror`, and source compilation.
  Registered replay declares Python 3.12, standard library only. No global
  lint configuration or unrelated historical code is changed.
