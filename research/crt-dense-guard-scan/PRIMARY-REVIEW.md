## Code and mathematical review

The normal kernel never reads emulator coordinates, lengths, address integers,
or action totals. All non-tape values have fixed finite range and fixed-depth
helpers can be inlined. Lexicographic comparison retains the first differing
MSB, accepts lower equality and rejects upper equality. Source geometry maps
low active digits correctly, excludes arithmetic target parity, and leaves
inactive control/Y/back bits SKIP. This matches the independently defined
interval predicate over arbitrary dirty padded addresses.

The zero counter is processed first; carry occurs after each emitted bit,
including the all-ones value. Overflow is distinct from cleanup: a subsequent
literal pass blanks every counter cell and its END marker, then returns.
Input and output ownership contracts are explicit, including retained LEFT
infrastructure and the caller's obligation to clear a prior owned output
before physical-role reuse. No source/E callback is hidden in the kernel.
