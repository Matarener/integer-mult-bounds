# Cyclic classes of balanced depth-three chain schedules

A correct balanced schedule can have a shorter rotation period than its
length. This package proves an exact repetition law for every modulus and
uses it to count cyclic classes from the literal counts W(m,c). In particular,
**a unit-target schedule can repeat only three times**. The exception needs
m=3n, 3 not dividing n, and c=n^3 modulo 3. Combining this with the credited
balanced existence theorem makes those conditions sufficient too, except
at exactly (m,c)=(6,5) and (12,1).

For example, at (m,c)=(3,1), the known 24 correct length-nine words form
**four cyclic classes**: two of size nine and two of size three. Dividing
24 by nine would be wrong. At (4,0), the 2370 words give 201 classes, including
seven classes of period six. [PROOF.md](PROOF.md) gives the complete formulas,
their proofs and the exact restrictions.

This is a **scoped proof with finite exact corroboration**. It adds a
rotation-period classification and an exact counting transform to
[Nick Petalas's #6037](https://github.com/CrocSwap/integer-mult-bounds/pull/6037);
it does not extend that census's upper modulus or prove its all-m distinctness
conjecture. No new kappa, supplier, paid-profile saving or physical speedup
is claimed.

## Result and useful boundary

Let d|m, n=m/d and s=binomial(d,3)n^3. The number of words fixed by a rotation
of order d is zero if d is even and n odd, or if d does not divide c-s.
Otherwise it is W(n,((c-s)/d) mod n). Burnside's lemma gives the cyclic count;
divisor Möbius inversion gives every least-period count. The convention
W(1,0)=6 is combinatorial and makes no characteristic-one ring claim.

For a unit target, let R=W(m/3,((c-(m/3)^3)/3) mod (m/3)) in the allowed
threefold case, and R=0 otherwise. The number of cyclic classes is

```text
(W(m,c) + 2R) / (3m).
```

This gives a new all-m divisibility check W-R = 0 modulo 3m and a precise
way to deduplicate literal schedules. It does not compute W in closed form.
Rotations preserve the universal algebraic endpoint and letter counts;
they need not preserve routing, precision or word-dependent implementation
cost. No call is removed or priced as free.

## Evidence and reproduction

Python 3.12, standard library only, from the repository root:

```sh
python3.12 -I -W error -B research/chain-cyclic-schedules/verify.py
python3.12 -I -O -W error -B research/chain-cyclic-schedules/verify.py
python3.12 -I -W error -B research/chain-cyclic-schedules/audit_mutations.py
python3.12 -B scripts/research_package.py --package research/chain-cyclic-schedules
```

The verifier is read-only. Its JSON receipt contains
`PASS_CHAIN_CYCLIC_SCHEDULES`, the exact result and every package file's SHA-256.
The mutation audit writes only temporary private copies and reports
`PASS_CHAIN_CYCLIC_MUTATIONS`.

[EXPECTED.json](EXPECTED.json) is generated by an actual replay, not a
handwritten success receipt. The registered checks cover:

- All **793,182** balanced words for m=1..5, by a position-based enumerator.
  It independently counts every target, fixed-point population, least period
  and cyclic class. There are 15 target cases; m=1 is only the auxiliary case.
- **536,472** rotations of correct words, checked by full four-role integer
  unitriangular matrix execution, plus 1,776 position/matrix comparisons on
  every word for m<=3. Every scalar dirty basis coefficient is retained.
- A separately implemented chronological residue DP for m=1..8. Every
  intermediate count vector has its full multinomial mass checked. These
  small-m literal counts and the DP independently reproduce the frozen W rows.
- **291,408** repeated-block tests: every balanced block with 1..4 copies
  of each letter, repeated 1..8 times. All unreduced pair/triple identities,
  parity gates and restored target shifts agree with a separate chronological
  counter. The largest resulting modulus is 32.
- Exact transformed tables for m=1..24, all **179** unit-target cases,
  nonnegative integral period populations, and agreement between Burnside and
  the least-period orbit sum. **Rows above m=8 inherit #6037's counts**;
  they are derived tables, not an independent high-m census.
- Thirteen explicit false-claim controls and eleven actual private-copy mutations,
  each rejected in normal and optimized Python: nine formula changes, one
  source-byte change and one expected-table change. Positive private-copy
  probes pass in both modes.

The initial full scientific replay took about 13 seconds locally on
CPython 3.12.10, Windows 11 x64. Normal and optimized registered replays and
publication checks are recorded in [VALIDATION.md](VALIDATION.md). Finite
tests corroborate the written proof; no proof-kernel or independent human
review is claimed. The two implementations were written by the same assisted
author. No selected-supplier cold replay or full m=2..24 predecessor census
is included.

## Implementation bounds

All loops in the registered driver have explicit finite bounds. Literal
enumeration stops at m=5 (756,756 words in the largest case); the residue DP
stops at m=8, with at most two layers of 81 dictionaries, each with at most
512 residue keys. The repetition driver stops at 96 letters. The largest
retained numerical table is m=24. Arithmetic uses Python exact integers.
There is no stochastic search, external solver or runtime network request.

Python dynamically allocates bounded tuples, dictionaries and integers;
this is the declared managed-runtime deviation from allocation-free coding.
The mathematical proof is uniform; the program is a bounded checker and does
not claim to execute every modulus. The mutation runner uses at most 24
sequential bounded child probes, never concurrent scientific replays.
