## Reproduce

Python 3.12 or later, standard library only. Direct commands need no Git, network,
TMPDIR setting, writable package or pending predecessor Git objects:

```sh
python3 -Werror -B research/selected1094-release-grid/verify.py
python3 -O -Werror -B research/selected1094-release-grid/verify.py
```

The registered command is:

```sh
python3 scripts/research_package.py --package research/selected1094-release-grid
```

The direct verifier authenticates source modules before loading, bypasses
preexisting bytecode caches, uses strict integer profile types and rejects
boolean counts, unpaid child mass, the next κ grid point and invalid η/β.
Normal and optimized modes explicitly enforce every new acceptance check.
The vendored modules retain their original assertions; their mathematical
results receive explicit checks in the wrapper even under optimization.

For Power of Ten, the new call graph has no recursion, loops have fixed source
bounds of 9 bindings, 16 profile ranks, 144 calls, 36 group factors and seven
bootstrap steps. The inherited logarithm reductions need at most six divisions
for the enforced widths at most 73. Python allocations are a managed-runtime
deviation confined to these fixed finite inputs and exact rational expressions.
Module loading has three fixed authenticated targets; it introduces no plugin
or arbitrary dispatch. Frozen vendor formatting and historical CLI helpers are
unchanged. Rewriting them would alter selected source bytes outside this task.
