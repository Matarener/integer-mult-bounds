# Full-frame BIT outputs: physical boundary and budget correction

**Scoped negative results; no new κ.** The direct-copy word passes local
scalar replay and the scalar bridge tests, but it fails the physical frame
junction of the retained template. Even granting those junctions for free,
the template's complete rank bill exceeds one at zero saving. A second
experiment rotates both endpoint roles using an E8 complex structure; its
literal terminal repair consumes all remaining rank deficit.

The earlier local-only version of this package reported a favorable bit cap
near `κ=0.018456786532` and a hypothetical complex cap near `0.016682654226`.
**Those planning claims are withdrawn.** The former screen incorrectly
retained the incumbent coverage law after enlarging every target endpoint.
It reduced idle mass by an extra rank per target without an implementation.
The analogous complex screen had no replacement coverage proof either.

## What the scalar tests establish

The tested direct word uses the selected 111 E8 live root lines:

```text
R = 0; D = A = C = []; ret = []
B[t] = (FULL, 111+t, [t]) for t=0,...,110
scatter = 111 empty rows
sources start at their lines; targets start at zero
every source and target ends at FULL
```

Its exact local map is `y_t <- y_t+x_t`, with sources restored and local
profile `{7:111,8:111}`. H1–H5's scalar predicates still pass. Exporting it
through the retained record tools gives 222 local moves, 111 scalar additions,
zero copies and rank mass 1,665. The retained C++ bridge tests pass 444, 888
and 1,110 scalar columns at 5, 9 and 11 stages, with every omitted bridge
detected. A changed-source mutant is also detected.

`columns_k.cpp` uses MOVE records to accumulate a histogram, then omits them
from its scalar matrix product. It consequently does not check address-frame
compatibility between successive invocations. A passing bridge test cannot
establish that a FULL-ending child is admitted by the next physical caller.

## The first physical junction fails

Let `P=qq^T/4`, `K=I8-P`, and let `A` be an orthonormal basis of `K`.
The retained geometry uses

```text
rho = [[P,A],[A^T,0]],  rho^2=I15
rho diag(0,I7) rho = diag(K,0)
rho diag(P,I7) rho = diag(I8,0).
```

`boundary_audit.py` reconstructs these identities with exact rational
Householder charts on all 111 ports. For the selected endpoint pair
`(source,target)=(I8,K)`, complementing and swapping roles for the next
reflected call matches both preceding output frames. For `(I8,I8)`, the
next reflected call requires `K` on both physical banks, while the previous
call leaves `I8` on both. All 222 port/bank comparisons have a rank-one
discrepancy. At `q=2e0`, the address input `(head=e0,tail=0)` distinguishes
them: `D_I` swaps this coordinate; `D_K` fixes it.

This is a concrete address-operator counterexample, rather than a failure of
the scalar XOR identity. Removing the template's nine-COPY assertions does
not repair it.

## The retained idle schedule has no positive budget

For `L=2K+1` stages, retain the actual recipe and idle advances from
`global_k.py`. With `v` ports, `T` replicas and no helpers or copies:

```text
m = 1+7L, W = 2KvT
local mass = 15vLT
idle mass = 14vLT(K-1)
mW - paid mass = -vT.
```

The script reads the pinned pure recipe, reconstructs its chronological
levels and idle events, and checks the complete integer profiles. These
budgets optimistically omit any repair of the already failing junctions.

| stages | m | live families | paid mass | mW | moment at a=0 |
|---:|---:|---:|---:|---:|---:|
| 5 | 36 | 14,208 | 515,040 | 511,488 | 145/144 |

Every child rank lies below `m`, so the moment increases with positive
saving. These profiles cannot support positive saving under the retained
schedule. The prior nine-stage relaxation had silently removed 31,968 units
of idle rank mass, exactly `L*T*v`. A rank-seven endpoint accounting control
recovers the incumbent deficit `W`; it is an arithmetic control, not a
helper-free construction with the selected endpoint.

## Different experiment: rotate the source and target endpoints together

A fixed E8 complex structure

```text
J(x0,x1,x2,x3,...) = (-x1,x0,-x3,x2,...)
```

preserves all 120 root lines, satisfies `J^2=-I`, and gives `p perpendicular
to Jp`. Thus one can copy at `(Jp)^perp`, leave the source there, and advance
the target to FULL. The local increments are `{1:1,6:1,7:1}` per port,
retaining the original total mass 14 rather than the direct FULL/FULL mass
15. This changes the selected source-FULL endpoint as well as the target
endpoint; it is outside H4's retained source-final-frame premise.
Reassigning high/low owner roles gives `(x,y)->(x+y,x)`, of order three
over F2; the projective port-label permutation has order two.

The exact coordinate-core experiment follows six such invocations in
dimension 43. It tracks actual commuting address-swap operators as well as
the two data values. The scalar endpoint is the identity and all local moves
are nested, but the inactive address direction moves through axes
`0 -> 1 -> 8 -> 15 -> 22 -> 29 -> 36`. The two returned arrays have address
operators `D_(I-P0)` and `D_(I-P36)`. Abstract port-label closure did not
return the physical inactive coordinate.

The literal correction `D_(P0+P36)` aligns the second endpoint. Its rank is
two, using the entire apparent deficit:

```text
6*(6+7+1) + 2 = 86 = 43*2.
```

The corrected moment is one at zero saving and strictly greater than one
at `a=1/499`. This rejects this coordinate-core walk with a separate
terminal repair. It does not exclude joint source/consumer rewrites,
different core histories or an architecture that fuses the missing endpoint
operation into work already charged elsewhere.

The complex structure itself is established E8 geometry; see the Gaussian
line construction credited to Joel Pulikkan / GamingPuzzled in
[the Gaussian clique package](../gaussian-clique-copy-bound/README.md), by
Sagar Thakrar. This probe tests its changed paired endpoints and actual
address closure. A cached overlap search covered 413 open PRs and 2,478
Discussion records fetched on 2026-10-18 at 18:08–18:09 UTC. It found that
related geometry; it was offline and does not certify novelty.

## Reproduce

Python 3.12, a C++17 compiler and Boost headers, from the repository root:

```sh
python3.12 scripts/research_package.py \
  --package research/full-frame-bit-output-probe --check-only
python3.12 scripts/research_package.py \
  --package research/full-frame-bit-output-probe
```

`verify.py --write-result` explicitly regenerates `RESULT.json`. Normal
replay is read-only. Native checker binaries and candidate records are built
in a temporary directory. The rational boundary and operator audits use the
standard library; their guards also run with Python optimization enabled.
