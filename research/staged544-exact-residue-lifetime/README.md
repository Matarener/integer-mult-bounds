# Exact odd-residue arithmetic for the real helper277 lifetime

This package replaces the unsupported local-to-lifetime inference with a
source-bound result: PR3945 helper277 has49 scalar touches, FIVE rank-one
physical climbs, and a separately restored buffer981 with49 inverse-cleanup
touches. Exact dyadic arithmetic over `(Z/(2^b-1)Z)[i]` preserves the actual
whole-word dirty-helper identities without a rounding-error record. A literal
X/CNOT/Toffoli construction implements the arithmetic with no additional
workspace. It is a changed numerical contract, not an admitted supplier.

The important source correction is explicit in [CORRECTION.md](CORRECTION.md):
PR4017's completed rank-five residual is not one paid chronological rank-five
call. The actual paid sequence consists of five rank-one climbs. Its finite
macro theorems and counts are unaffected; its generic nonadditivity example did
not establish failure of this entire literal lifetime.

The implementation has a total reversible extension to every bit string, with
unused all-ones codes specified. Ring semantics and numerical recovery require
canonical residues. Endpoint numerical output is recovered exactly on grid
Delta/32 when `M>2048A`, for input real-component integer magnitudes at mostA.
For `A<=2^p`, `b=p+12` suffices. A separate, much larger all-cut decode bound is
reported; it is not the width used by the b32 circuit benchmark. Restoring the
old output grid, recursive denominator growth and actual caller affordability
remain unresolved. No discarded low bits or recovery records are hidden.

cost29,766,862,848 Toffoli gates, before the optional endpoint decoder and all
other provider work. The isolated completed residue macro costs3,103,910,912

versus18 earlier word primitives is a representation tradeoff, not a speedup
or a whole-lifetime baseline comparison. Explicit rotation/SWAP counts are
included; fixed source-wire connectivity does not establish physical locality,
constant-time memory scans or a native platform timing result.
