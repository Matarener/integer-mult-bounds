# Validation contract and limits

PROOF.md is a mathematical argument, not a kernel-checked theorem. The exact
receipt is corroboration. All arithmetic uses integers or rational Fractions.
No floating-point decision or runtime benchmark claim occurs.

The primary engine multiplies eight-coefficient formal matrices on the right.
The separate engine applies Hamilton quaternion permutations to every basis
input in reverse factor order. Its faithful regular representation sees every
group coefficient, including signs. Comparing only binary characters would
identify i and zi and accept the explicit wrong sign control.

Every successful direct replay authenticates both canonical live inputs and
the retained PR3450 proof. Generic metadata additionally binds the historical
catalogue and selected record through Git. The retained foreign proof's bytes
are available in this publication; its old commit is not a replay dependency.
No predecessor source is edited or imported as executable code.

## Engineering choices

Build the Lever led to the deterministic verifier and receipt rather than
hand-reported examples. Prove It Works led to actual endpoint/tariff producer
faults, complete dirty regular columns and an actual relocated CLI.
Separate Before Serializing Shared State led to one private output directory,
exclusive worktree ownership, and OS locks around shared Git and reservations.

The Power of Ten inspection covers the four new Python files. Control flow is
iterative, no function exceeds 60 lines, and guards remain active under -O.
Exact function sizes and command receipts are retained in the session report.
No service, retry loop, shared interpreter change or detached child is added.
File writes are limited to exclusive explicit receipt output and private
temporary test copies. Subprocesses use a 60-second timeout and check exits.

Rules 2 and 3 have a managed-runtime deviation. Python and unittest allocate
objects dynamically. Replay dimensions are capped at eight roles and 64
factors, the exhaustive alphabet at three roles and depth three, and attaining
fixtures at width four. The largest census has 178,809 words and processes
one at a time; it stores no growing word ball. Matrices have at most 64
byte-valued coefficients and regular columns at most 512 byte-valued entries.
Source and temporary-copy sizes are fixed by the declared committed manifest.
The test copies its finite package tree, not an arbitrary user directory.
Future wider experiments require new bounds and receipts.

Rule 8 has a bounded import deviation. Isolated Python omits the script
directory, so verify.py and test_package.py explicitly add their own resolved
package directory, then import named local modules. These are the only added
import targets. E402 annotations record that required ordering. Rule 9's
test-only dynamic dispatch is limited to unittest and patches of the actual
construction/tariff functions; patches release through context managers.
Python has no manual pointer dereference or preprocessing stage. Checked
subprocess results and scoped files supply the corresponding resource checks.

Diagnostics use warning-as-error execution on Python 3.12 and the host Python,
Ruff's E/F/B/UP/SIM rules on all four files, function-size inspection and
git diff --check. E402 ordering is the explicit exception above. Existing
sources are only authenticated and remain unchanged. No repository-wide
source rewrite is in scope.

## Publication gates

Run registered metadata/replay and behavioral commands before committing.
After commit, check exact publication bytes and source-history availability,
export the committed package and declared inputs, replay standalone commands
without Git, then compare export payload bytes, modes and inodes. Availability
and integrity checks are distinct from proof. Do not chmod an export or its
runtime and do not follow symlinks during cleanup.

The full selected cold replay, Lean, Docker, native supplier/outer invoice,
physical caller and all-size multiplication proof are unrun. Hosted CI status
is separate from local replay. No new kappa, supplier admission or selected
frontier change is claimed.
