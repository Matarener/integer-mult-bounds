## Exact source execution

The historical stage extracts only these unchanged original function definitions:

- `bit_cap_copy_local.py`: `need`, `canonical`, `rank`;
- `bit_signed_audit.py`: `identity`, `add`, `row_weights`, `parity`,
  `block_norms`, `code`, `global_bound`;
- `bit_prune_audit.py`: `execute`;
- `bit_pruned_growth.py`: `coefficients`;
- `signed_quotient_search.py`: `score`.

Dependencies are explicitly supplied standard-library objects and the preceding
functions. Original imports, filesystem constants, entrypoints and search loops
are excluded. Each selected definition must occur exactly once. The exact
authenticated bytes are parsed and compiled with `dont_inherit=True,optimize=0`;
no mathematical expression, coefficient, domain or loop is patched.

The independent integer and range programs import no producer implementation.
Their complete source files are authenticated and compiled with assertions
enabled. They write only fresh external temporary results during verification,
which are compared with the separately frozen complete receipts. Missing fixed
evidence fails; it is not regenerated into the package.

The compressed controller retains all ordered events and its legacy code list.
The unused legacy code is explicitly examined as a differing source contract.
The retained original suffix program is not a runtime input: it concerns a
different 660-input word, and the fresh adjoint checker supplies the relevant
651-input calculation.

## Distinct validation stages

Committed-byte and source-history checks establish publication provenance.
The registered replay verifies the stated finite claims and controls. A
read-only Git-free export checks portability. Automatic hosted CI is reported
separately on the PR's actual head. None of these is a formal-kernel proof,
human acceptance, physical rounded implementation or supplier admission.
