# The common-main coordinate coframe route cannot fund the standard caller

**Scoped negative result; no new kappa.** Every coordinate coframe assignment
in the stated full nine-axis source class has paid rank mass minus independent
helper rank mass at least **2464**. Eight exact flow/cut certificates prove this
minimum. One assignment attains it in both orientations with

```
paid:     796 H1 + 348 H8 + 281 H9
helpers:  405 H9 + 3 ordinary identity outputs
```

All 408 helper inputs stay in the bill. The three identity outputs get no
positive Gaussian credit. The attaining assignment leaves every native warp
ordinary. The lower bound also permits arbitrary coordinate coframes at warp
endpoints and charges their replacement Gaussian transports.

For **every p >= 1**, every prefix split in the standard query-thinned caller,
and every supplier saving **0 <= C <= 1/100**, the full target-minus-paid
moment is at most

```
-(53126/125)(p+2) - 112 < 0.
```

The p16 rank surplus is at most **-10192**. Thus increasing the caller size
cannot fund this particular centre-free construction in that interval.
The result does not exclude a different native word, non-coordinate Clifford
coframes, a different caller, or retained coupled state.

Python 3.12 and its standard library suffice:

```sh
python3.12 -B scripts/research_package.py --package research/common-coframe-coordinate-cut
```

The registered normal and optimized checks authenticate the source, check every
integral flow against its capacities and conservation equations, and check
flow equals cut. They reconstruct the literal attaining invoice and reject six
changed certificates. No optimizer runs during verification. Expected marker:

```
PASS_COMMON_COFRAME_COORDINATE_CUT no_new_kappa
```

are inherited premises for the construction. The price rejection grants that

physical implementation or claim that one was replayed. No complete native,

## Open next questions

A useful continuation must change a premise of this result. One option is a
non-coordinate Clifford coframe assignment with a complete source-bound bill.
Another is a changed native word with an independently checked endpoint. The
first check is the complete paid and helper inventory, before a larger caller
or ordinary compiler is built. [TASK.json](TASK.json) gives the first steps and
missing obligations. This certificate does not justify another coordinate
search on the same graph.
