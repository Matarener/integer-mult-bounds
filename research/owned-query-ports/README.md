# Owned-query adapters and portable split-port search (no new κ)

This package proves sufficient temporary-field constructions for a two-port shear and a shared rank-one ADD block. It replaces a forced common contact chart with independently chosen source/destination charts and one fully paid bridge. The temporary has no productive credit; explicit initialization, erasure, scalar work, monomial routes and owned stock remain charged.

**No κ improvement was found.** The reference is the open conditional κ = 0.00302015 in [PR #4470](https://github.com/CrocSwap/integer-mult-bounds/pull/4470), not a new or selected result. The construction is elementary linear algebra; no literature or repository novelty claim is made.

## Reproduce

From the repository root, with Python 3.12 and no third-party Python packages:

```sh
python3.12 -B scripts/research_package.py --package research/owned-query-ports --check-only
python3.12 -B scripts/research_package.py --package research/owned-query-ports
```

A Git-free export can run `python3.12 -I -O -B research/owned-query-ports/verify.py`. The single pinned external input is the retained exact Clifford source; the repository exporter includes it.

The default replay checks 14 phase-bearing primitive instances, 24 rational input columns, all 1,224 × 1,224 CSS distances, the 34,790-vertex/50,067-edge frozen graph and the complete baseline paid profile `{1:2237, 2:388, 3:494, 4:147, 5:36, 8:8}`. It includes false-rank, phase, metric and invoice controls. These are scoped primitive/snapshot checks, not a new 632-column native supplier replay. Both the 11 fixed rank-one warp charges and eight whole rank-eight center calls remain included.

Optional portable C++17 discovery, requiring `g++` or `clang++`:

```sh
python3.12 -B research/owned-query-ports/run_search.py
python3.12 -B research/owned-query-ports/run_search.py --cxx clang++ --full
```

The first command compiles in temporary storage and checks a strictly improving toy adapter plus 30 binary graphs against exhaustive optima. `--full` additionally runs the frozen α-expansion, label-swap and plateau searches. Rounded cut capacities and floating moment costs make their output discovery evidence, not exact optimality. A discovered label assignment requires separate physical and mathematical verification. Temporary output is not published as a bound.

## Evidence and limits

[PROOF.md](PROOF.md) gives the sufficient identities and costs. [SEARCH-RESULTS.json](SEARCH-RESULTS.json) records the original bounded runs: 1,224 expansions, 2,415 swaps, 60 plateau passes and 773 additional line/hyperplane labels, with no accepted improvement. The additional-label run is historical evidence, not reproduced by `--full`.

`GRAPH.txt.gz` is a frozen graph snapshot from PR #4470's chronological supplier. This package recomputes its metric and bill, but does not regenerate its embedding from the full source word. The campaign-specific exporter, SciPy searches and private drive paths are excluded. Source binding to the original whole native word remains a future obligation. Gzip compression bytes are not mathematical equality: the verifier checks the decompressed payload.

Local checks ran on Windows. Python uses the standard library and C++ uses standard C++17; **Linux execution has not been verified**. No universal barrier, unconditional multiplication theorem, practical speedup, full native proof or selected-frontier update is claimed.
