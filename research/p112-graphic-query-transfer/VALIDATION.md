# Verification scope and bounded implementation

The written theorem applies to every finite graphic substitution sequence.
The finite certificate covers K2,K3,K4,K5, a five-edge Wheatstone bridge in
each of five unmarked positions at three representative marked pairs, and
one literal nine-term six-port operator. No finite search is promoted to an
unbounded classification. The non-Fano orbit and literal transfer premises
are inherited exact proof inputs and restated in PROOF.md.

The primary computes exact rational and GF4 ranks of expanded columns.
The independent implementation uses integer path sums and separating cuts
for every graph subset, then 3-by-3 rational determinants and all 64 GF4
functionals for the base marked implications. It collapses new subsets by
cuts, rather than eliminating expanded matrices. Literal ranks use a zero
sixth coordinate and a nonzero 5-by-5 minor in the second checker. Binary
rectangles are eliminated directly in the primary and counted plane by
plane in the independent check. Both compare the same frozen result.

The control program runs both actual optimized CLIs before and after four
mutations. It corrupts an endpoint, a rectangular charge, a frozen count,
and a marked GF4 template. For the template control it updates the private
source pin so scientific predicates must reject it. Canonical hashes are
checked after restoration. All copies are exclusive owned regular files
with device/inode inequality. No modes or shared sources are changed.

CPython 3.12 direct, registered, metadata/pin and final committed source-history
gates are the publication checks. The final committed package is exported,
integrity-checked and its three direct commands replayed without Git on PATH.
Exact command/environment/output and source/export identity receipts are
retained with the contribution session. A passing source-history gate is
source-integrity evidence, not human or formal mathematical acceptance.

## Power-of-ten assessment

No recursion, generated code, unbounded retry or indirect dispatch is used.
Graph loops have at most five vertices, ten edges and 1,024 subsets.
Marked checks have three templates, five placements, 2,048 rank subsets
per field/placement and nine query bits. Rank matrices have at most twelve
columns and six coordinates. Determinants use at most 5! permutations;
GF4 functional enumeration has 64 elements. Literal matrices have six
ports and nine terms. Data files are limited to 128 KiB at JSON boundaries;
coefficient shapes/ranges are validated before scientific use. Real CLI
subprocesses have 60-second timeouts and the registered jobs have declared
120/300-second limits. Explicit exception guards remain active under `-O`.
Functions fit the 60-line review bound after formatting.

Rule 3 deviation: Python's exact integers, fractions, JSON and standard
library allocate at runtime. The interpreter does not expose fixed arenas
for these operations. This deviation is limited to the fixed certificate
sizes above; no arbitrary CLI size option or search is exposed. The finite
matrix/subset bounds and bounded input bytes constrain live data. The
registered timeout separately limits job lifetime. Both optimized scientific
CLIs and mutation controls exercise these bounds. A variable-size search
would need a separate capacity contract before addition.

Ruff checks E4,E7,E9,F,B,UP,SIM,I and format checks apply to the package.
No shared lint/build configuration or predecessor source is modified.
