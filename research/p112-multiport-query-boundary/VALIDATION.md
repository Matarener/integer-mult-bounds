# Verification scope and implementation decisions

The falsifiable predicate is equality of both exact outputs with RESULT.json,
plus rejecting all four corrupted private fixtures through both actual CLIs.
The mathematical floor applies to the 13 displayed compatible placements and
arbitrary finite graphs on their three fixed terminal potentials. The 17 other
placements refute only unrestricted use of the supplied transfer templates.

The primary uses rational Gaussian elimination and GF4 elimination with
w^2+w+1. The independent method imports no primary code, uses integer minors
for rational ranks, and enumerates every GF4 annihilator. Subset counts are
finite coverage counts, not performance measurements. Projection checks cover
all 1,024 subgraphs of K5 with three terminals and two internal vertices.
The proof, rather than a graph-size extrapolation, establishes arbitrary size.

Controls change the expected result, corrupt a literal reader, corrupt a
pinned template, and repin a corrupted template. They verify positive CLIs
before and after restoration. All verdicts use explicit exceptions and remain
active under optimized Python. The private copies use exclusive file creation,
check regular ownership and distinct device/inode identities, and never copy
modes or chmod a source, shared interpreter or link.

## Power-of-ten decisions

The executable scope is the three new Python files and their four bounded live
inputs. There is no recursion, subprocess shell, dynamic code construction or
unbounded retry. Subset loops have at most 256 masks in the independent rank
audit, 1,024 graph masks, 256 functionals, 24 determinant permutations and
30 attachments. Rank matrices have at most twelve columns and five coordinates
in the primary, eight columns and four coordinates in the independent method.
The independent rank cache holds at most 8,192 bounded entries. Controls allow
24 package files and four input files, twelve subprocess runs total, each with
a 30-second timeout. Every subprocess result and predicate is checked.

Rule 3 deviation, managed-runtime allocation: CPython fractions, integers,
iterators and collections allocate during each finite computation. Matrix,
subset and cache capacities above bound live program data. CPython allocator
internals are not instrumented. A fixed-capacity native implementation would
be a separate verifier with the same exact output contract.

Rule 9 deviation, standard-library iterator/caching dispatch: itertools and
lru_cache use bounded runtime dispatch. The only cached target is rational_rank;
there is no callback supplied by a fixture. Remove the cache if this is ported
to a fixed-memory environment. Files and subprocesses have scoped cleanup.

CLI fixtures are bounded regular JSON files. Source and witness values are
validated before the finite algorithms. The committed fixtures, not a general
untrusted-data service, define this tool's input domain. Error checks catch
hash, endpoint, rank, tariff and result mismatches. No assertion is needed for
scientific success. Ruff diagnostics and formatting are run on the new package.

No selected supplier replay, Lean, Docker, broad census or physical execution
is claimed. The source/history/export checks certify retained bytes and declared
availability; they do not establish mathematical acceptance.
