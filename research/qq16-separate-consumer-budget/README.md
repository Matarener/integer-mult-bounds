# QQ16 separate-consumer budget and the missing idle credit

No new kappa was obtained. The literal QQ16 core matches the selected
centre-free profile, but the local producer, decoder and endpoint tariff do
not supply a complete global owner/frame continuation. In particular, they
do not identify which selected idle-remainder work the new operations replace.
The actual complete moment and its admissible saving interval remain unknown.

This package answers one bounded admission question. It gives a source-bound
rank ledger and a conditional unchanged-idle rejection. It does not reject
QQ16 in general or establish a favorable supplier bill. The initial additive
screen was withdrawn as an unconditional claim before publication because it
silently retained the old idle work. The correction is part of this result.

Family decision: narrow and stop at this admission gap. The weakest unresolved
item is an actual source/owner continuation with exact coefficients that maps
new work to the displaced remainders. The bounded test now stops because none
of the pinned local words or endpoint recipes contains that global mapping.
No additional adapter, precision, inverse or search round follows this result.
A complete optimistic physical allowance is therefore unavailable; the C=0
screen is conditional and must not be reported as a complete QQ16 obstruction.

## Reproduce

The registered runner requires Python 3.12. The direct scripts support Python
3.12 or later and use only the standard library. From the repository root:

```sh
python3.12 -Werror -B scripts/research_package.py --package research/qq16-separate-consumer-budget
python3 -I -Werror -B research/qq16-separate-consumer-budget/verify.py
python3 -I -O -Werror -B research/qq16-separate-consumer-budget/test_verify.py
```

Default replay is read-only and needs no environment variable. `verify.py --emit`
prints the recomputed receipt. Source paths, allowed usages, blobs and hashes
are fixed in SOURCES.json, whose own bytes are pinned in the verifier. Direct
commands work in a Git-free export containing the eight declared inputs.
Validation distinguishes booleans, integers and floats. Tests exercise equality
versus strict mass acceptance, bool counts, changed core ranks, input drift,
source-usage reclassification and typed receipt corruption in private copies.

No selected cold replay, full native/caller replay, Lean, Docker, physical
implementation, complete mathematical exclusion, human or proof-kernel review
is claimed. CHECKS.json and the verbatim designated internal peer receipt record
actual committed/export verification separately from inherited premises.
