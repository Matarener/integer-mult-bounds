# Verification boundaries

PROOF.md proves an all-characteristic-two contradiction from 21 explicit
predicates. The programs certify those finite old predicates, their
integer or half-integer certificates, a concrete exact rational operator,
its actual bills, and the retained positive star map. They do not enumerate
all target fields or formalize the written argument. The complete 512-subset
rank table is over Q. Only the 21 certified premises are used to extend the
old-field statement to every characteristic different from two.

The direct scientific/control commands in README.md are registered in
VERIFY.json on CPython 3.12 with isolated optimized execution. No check
depends on Python assert. The package is standalone. The exact pending
positive-control data is retained and hashed, so cold replay has no foreign
Git-object dependency. Generic metadata/history checks, committed export
integrity and actual Git-free replay are separate gates.

Six actual data faults each run through both scientific CLIs: changed
terminal geometry, omitted proof premise, broken reader coefficient,
missing literal premise row, altered retained star map, and a false bill.
Twelve failures must carry the intended diagnostic. Every fault is restored
and replayed, in addition to two initial positives. Source SHA256 values
are checked unchanged after controls. The tests use exclusive byte copies
of seven owned regular files and verify source/destination inode separation.
No modes or metadata are copied. Context and predecessor credit are in
ORIGINS.json and COMPARISONS.json, not foreign ancestry pins.

## Code inspection

Build the Lever led to two deterministic checkers and executable corruptions.
Prove It Works requires literal operator entries and rectangular Gram ranks,
then committed-byte/history and actual exported-source replay. The ten rules
were inspected on the three local Python entry points, their standard-library
calls, file readers and subprocess boundaries. Frozen/shared code is unchanged.

1. Control flow is structured, without recursion. Failure propagates as a
   nonzero exception. TemporaryDirectory removes owned copies on all exits.
2. The mathematical dimensions are fixed. The main table has 512 subsets,
   its star control 64; GF4 annihilators have at most 256 vectors. Literal
   matrices have 42 ports, 21 active rows and 9 queries. JSON files have a 1 MiB
   limit. Controls make 26 bounded child calls with 30-second timeouts. No
   detached research process or solver is used.
3. Python and its libraries allocate dynamically. This is a managed-runtime
   deviation, scoped to finite fixtures and at most seven copied inputs.
   Input-size/dimension checks, sequential execution, bounded output and
   process timeouts limit work. Integer/Fraction/parser internals are not
   claimed allocation-free. A native fixed-buffer implementation would be
   needed if this becomes a real-time verifier. Actual success/fault paths
   are replayed, and owned temporary storage is removed on either path.
4. Functions are kept near the 60-line ceiling. Literal operator comparison
   is a separate responsibility from premise/source validation. Function
   lengths are recorded externally during publication inspection.
5. Meaningful require/check contracts enforce geometry, independent marks,
   complete predicate coverage, integer/half-integer certificates, exact
   operator entries, support zeros, source hashes, bills and control counts.
   They remain active under -O. No disabled assert supplies evidence.
6. Mathematical tables are local immutable tuples or local owned lists.
   Child processes write only exclusive disposable copies. No shared
   configuration or frozen mathematical input is edited.
7. File, hash, copy-byte and subprocess results are consumed and checked.
   CLI exceptions fail closed. Shapes and file limits are checked at the
   JSON boundary. A timed-out child fails the control rather than passing.
8. There is no eval, generated executable code or runtime registration.
   Fixture generation is ordinary rational elimination; committed witness
   bytes are checked directly. JSON is data. No dynamic plugin is imported.
9. Calls name their target functions directly. Python references and standard
   iteration dispatch are managed-runtime mechanisms, not a claim of C-style
   pointer compliance. Data access is shallow and file authority stays local.
10. Publication runs focused Ruff diagnostics and formatting, warning-as-error
    CPython 3.12 direct/registered checks, and optimized actual-CLI faults.
    The opt-in replay workflow repeats the declared checks on relevant changes.
    Hosted CI, an independent reviewer, formal acceptance and historical broad
    suites are not claimed by a local pass.

Python object allocation and standard-library dispatch are explicit runtime
deviations. Finite fixed fixtures and actual failure-path replay compensate
within this package; no real-time guarantee is claimed. No suppressions or
repository-wide lint policy changes are introduced.
