# Complex function composition: an actual paid improvement and a changed query producer

Apache-2.0; substantial OpenAI assistance. All predecessor packages remain
unchanged. This directory contains new finite constructions and explicitly
scoped negative certificates. It does not establish a new multiplication κ.

## Retain the native pruning

The strongest immediately reusable result is `pruned-native/RESULT.json`.
Deleting 28 exactly unconsumed centre-assembly operations together with their
scheduled inverses preserves the complete clean-J operator in all four
providers and both orientations. The independent literal replay treats all
632 persistent inputs as arbitrary, including all 408 helper inputs. It
checks their restoration, legal scalar frames and dyadic coefficients.

Write H_r(C)=r^(1-C). The paid profiles change as follows; base and extra
variants agree.

| Provider | Old profile | New profile | Rank mass |
|---|---|---|---:|
| THREE | 2487 H1 + 713 H2 + 224 H3 + 102 H4 + 20 H5 | 2453 H1 + 716 H2 + 224 H3 + 74 H4 + 48 H5 | 5093 |
| FOUR | 2489 H1 + 713 H2 + 227 H3 + 99 H4 + 20 H5 | 2455 H1 + 716 H2 + 227 H3 + 71 H4 + 48 H5 | 5092 |

The exact saving per core call is

\[
34H_1-3H_2+28H_4-28H_5.
\]

There are 31 fewer recursive calls, but no rank-mass reduction. At the two
diagnostic primitive values C=.001745 and C=.004, the saving is approximately
0.1292770134 and 0.2956617046 H1 per call, respectively. The overall invoice
and its much larger remaining repair gap are handled in
[`../invoice/PROOF.md`](../invoice/PROOF.md). This local gain must not be
reported as a 31-unit recursive saving or as a new κ.

The deletion also removes 56 ADDs, reducing the conservative scalar primitive
allowance by 448 to 115382 for THREE and 115360 for FOUR, in either direction.
The word uses the same 632 persistent fields, zero external cleanup fields,
and zero owned centre fields. Exact physical recipes are emitted and decoded
for every newly coalesced child edge, including the global phase and both
orientations.

The prefix bounds do not increase: forward formal row L1 is at most 457,
with maximum coefficient magnitude 32 and denominator 32; backward L1 is at
most 258, with maximum coefficient magnitude 6 and denominator 64. These are
exact logical-prefix bounds, not a rounded recursive-error proof.

**Interface limitation:** the complete endpoint operator is preserved, but
the old eight final centre queries are not. A caller using only the clean-J
endpoint can use this replacement. A caller reading historical intermediate
centre queries must supply and price a new producer. This distinction is
recorded in the machine receipt.

## The 24+32 contact witness now has a native word

The previous geometric witness has been turned into an actual chronological
construction for query R3, on THREE-base. It forms a 24-coordinate partial
query in an existing rank-seven frame and a 32-coordinate partial query in a
new rank-seven frame. Five unit-coefficient preparation ADDs and five inverse
ADDs are explicitly emitted. The two partials sum to the complete 56-coordinate
query plus its exact dirty-helper nuisance. The nuisance has 45 nonzero helper
coefficients after cancellation.

Both the reference and candidates implement the same **partial repair**:

\[
Y\gets Y+\left(I-\frac14\sum_{k\ne3}R_k^T R_k\right)X,
\]

with X and every helper restored. The backward word is its inverse transpose.
This comparison tests one complete query acquisition and its actual consumer;
it is not a completed eight-query ordinary-response controller.

The second candidate is a real change of premise: the two rank-seven frames


## The consumer has now been tested across time

`mixed_contact.py` transports the original demanded consumer function through
every cut of the unchanged B, tail and dirty cleanup. At each cut, it prices a
restricted delivery graph carrying scalar copies of the already formed query.
There are 10646 inspected post-event cuts: 2674 require a frame at distance at
least six from G6; the other 7972 require at least 28 distinct frames. The
necessary delivery costs exceed H8 once the producer's 2H1 formation is
included. Exact Clifford tableaus verify the distance formula on all 1155
catalogued frames. See the precise free-warp and scalar-copy qualifications
in [`PROOF.md`](PROOF.md).

`staggered_consumer.py` then removes the one-cut restriction. It grants scalar
injections at every register and every chronological cut, all subsequent
unchanged operations, unlimited copies and their distribution for free.

| 0 | 0 | 0 | 0 | No |
| 1 | 1 | 25 | 9 | No |
| 2 | 14 | 145 | 58 | No |
| 3 | 80 | 5286 | 533 | No |
| 4 | 351 | 6738 | 632 | Yes, necessary projection only |
| 5 | 726 | 8591 | 632 | Yes, necessary projection only |

This projection is physical: every actual warp and its inverse fixes the
512-dimensional basis vector |0>, including phase. It therefore respects all
identities among the actual operators. The distance-at-most-three rejection
has a one-coordinate witness: every admitted impulse has zero final value
at Y[3], while the demanded R3 function has coefficient 1/4 there. All 726
individual frames within distance five also have exact separating witnesses.

Thus staggered scalar delivery inside these nearby frames fails for a specific
output reason. A successful candidate in this model must use multiple frames
and at least one at distance four or greater. Distance-four feasibility is not
a native circuit, and the projected calculation does not guarantee dyadic
coefficients, chronological distribution, restoration or a lower bill.

## Next discriminating construction

The next bounded test is a small dyadic set of distance-four contact frames
whose complete impulse operators realize the demand, followed by an explicit
chronological delivery tree. It must charge the two rank-one formation calls,
every frame transition, source preparation and return, dirty compensation,
and owned-field hosting. The current construction has less than H8 available
for this complete acquisition. If that menu fails, the consumer trajectory
must change enough to create a function-spanning G6 or nearer contact, or
several queries must share a different demanded function. Merely moving the
old complete scatter to another single cut cannot use this producer cheaply.

## Reproduce

From the repository root, using standard-library Python 3:

```sh
python3 -B research/kappa-function-composition/complex/prune_native.py
python3 -B research/kappa-function-composition/complex/contact_native.py
python3 -B research/kappa-function-composition/complex/mixed_contact.py
python3 -B research/kappa-function-composition/complex/staggered_consumer.py
```

Each program writes only this new directory, authenticates frozen inputs and
records artifact hashes. The second, third and fourth commands are sequential
dependencies. For a read-only replay of preserved receipts, give `--out` a new
directory and use the cumulative root validation procedure. The native
checker and Clifford compiler are reused from attributed, pinned predecessors;
the new construction and search code do not replace those predecessors.

Literature selection, exact model differences and the associated probes are
recorded in [`PRIMARY-LITERATURE.md`](PRIMARY-LITERATURE.md).
