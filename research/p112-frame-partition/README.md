# The P112 orthonormal frame packing number is thirteen

The literal 112 P112 binary labels have **maximum disjoint Gram-I8 packing
number exactly 13**. In particular, they cannot be partitioned into fourteen
orthonormal 8-frames. This closes [PR3356's first open
question](https://github.com/CrocSwap/integer-mult-bounds/pull/3356).
That predecessor exhibited thirteen frames and left the cardinality upper
bound of fourteen unresolved. Its thirteen-frame witness is retained here
and checked again.

The exclusion is a finite exhaustive computational proof. It uses a complete
4,032-frame census, seven explicit source-preserving symmetries, and two
separately implemented exhaustive exact-cover checks. It strengthens the
two-support even-group colouring construction's channel floor from 28 to 30.
It does not prove an arbitrary scalar or block fitting-rank lower bound of 30,
price a native COPY program, improve kappa, or change the selected result.
No proof-assistant or independent human review is claimed.

## Seven symmetries reduce the full question to two cases

For a nonzero even-weight nine-bit vector `v`, define

```text
T_v(x) = x + dot(x,v) v, over F2.
```

Because `dot(v,v)=0`, `T_v` is an involution and preserves the bilinear
pairing. The two cross terms in `dot(T_v(x),T_v(y))` cancel in characteristic
two. For each listed pair `(a,b)`, apply `T_a` and then `T_b`:

```text
(3,48), (3,72), (3,123), (5,40), (9,36), (129,159), (257,287).
```

Every composition permutes the literal 112-label set, as checked on all
ports. Therefore it permutes the complete frame census and preserves
disjointness. The subgroup generated by these seven permutations has exactly
two frame orbits:

| Orbit | Frames | Fixed representative ports |
| --- | ---: | --- |
| Ordinary | 3,584 | 82,89,95,100,104,107,110,111 |
| Special | 448 | 58,61,67,82,89,95,110,111 |

The names only identify these two orbits. They are not additional restrictions
on the permitted frames. The first implementation computes connected
components of generator edges. The independent implementation uses dense
nine-coordinate arithmetic, checks every generator's full 112-square Gram
preservation, and uses breadth-first orbit traversal.

Suppose a fourteen-frame partition exists.

1. If it contains an ordinary frame, apply a subgroup element carrying that
   frame to the ordinary representative. This gives an exact cover containing
   that representative, with all 4,032 frames still permitted.
2. Otherwise it consists entirely of special frames. Carry one frame to the
   special representative. The whole partition remains in the 448-frame orbit.

Both exact-cover problems are exhausted and return UNSAT. Thus neither case
can occur. The independently implemented second search also exhausts the
all-special case without fixing any representative.

## Exact exhaustion and its checks

`dlx.cpp` is an iterative dancing-links exact-cover search. At each node it
selects an uncovered column with the fewest remaining rows. It considers every
remaining row in that column, removes all conflicting rows, and reverses those
changes before the next branch. A zero-size column is a contradiction; zero
remaining columns is SAT. These alternatives cover every exact cover because
each uncovered port must occur in exactly one selected frame.

`independent.cpp` uses active-row flags, column counts and an explicit removal
stack. It has no linked matrix and imports no primary search implementation.
Its restoration restores the removed flags and counts rather than pointer
links. Both searches use explicit depth and node capacities and have no
recursion. Exhausting a node budget returns UNKNOWN, which the proof replay
rejects. An exhausted complete search returns UNSAT. A process timeout fails
verification; it never supplies an exclusion.

The deterministic primary receipt is:

```text
all 4,032 frames, fixed ordinary representative: UNSAT, 53,202,862 nodes
special orbit, fixed special representative:   UNSAT,        701 nodes
maximum disjoint 8-frames: 13
```

The independent implementation must reproduce the full ordinary tree count.
The independent unfixed special case exhausts 21,808 nodes. Node
counts describe exhausted search trees; they are not performance claims or
substitutes for complete traversal. The 60,000,000-node cap exceeds the full
ordinary tree. Both registered commands have 600-second outer timeouts, with
540 seconds for each native solve.

Twelve primary controls check duplicate packing ports, changed source bytes,

## Packing and restricted colouring consequences

The retained thirteen disjoint frames cover 104 ports, so the maximum is at
least thirteen. No disjoint packing can contain more than fourteen frames,
since there are only 112 ports. The exhaustive exclusion of fourteen proves
that the maximum is exactly thirteen.

For the existing construction that partitions ports into **even orthonormal
groups**, then uses two disjoint scalar supports per group, every group has
at most eight ports. Indeed, a Gram-I_k set is linearly independent in F2^9,
so `k<=9`; even `k` is at most eight. Fourteen groups could cover 112 ports
only if every group were an 8-frame, which has just been excluded. Therefore
at least fifteen groups, and at least thirty channels in this construction,
are necessary. The old cardinality argument gave only 28.

This does not prove that fifteen groups or thirty channels are attainable.
It does not constrain arbitrary overlapping, asymmetric, non-colouring or
block-valued fitting factorizations. Native copied-information rank, payload
preparation, transport, restoration, hosting and a complete supplier invoice
remain separate obligations. No complete multiplication theorem follows.

## Reproduction

Python 3.12 or later and a C++20 compiler are required. Python uses only the
standard library. Both scripts compile their own native implementation with
`-O3 -Wall -Wextra -Wpedantic -Wshadow -Wconversion -Werror`, and remove their
temporary build directories on every normal or exceptional exit.

Use one external directory for temporary builds and logs:

```sh
run_dir=/path/to/a/session-owned/output-directory
mkdir -p "$run_dir"
python3 -W error -I -O -B research/p112-frame-partition/verify.py --work-root "$run_dir"
python3 -W error -I -O -B research/p112-frame-partition/independent_check.py --work-root "$run_dir"
TMPDIR="$run_dir" python3.12 -W error -B scripts/research_package.py --package research/p112-frame-partition
```

The scripts accept a source export containing this package and the one declared
input at the same relative path. They need no Git repository, network service,
SAT solver or optional discovery dependency. `RESULT.json` is compared exactly
with the primary output. The optional `verify.py --output NEW_EXTERNAL_PATH`
writes a new receipt for review; it does not modify package files.

`VERIFY.json` registers both complete commands and declares the sole external
input. These are package-local checks. The selected supplier cold replay,
Lean, Docker and physical supplier admission were not run or claimed.
