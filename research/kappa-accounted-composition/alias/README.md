## The proposed local contracts

Let A be the eight selected original data ports, U the other 104, and
`v = A + L U`, with `K=L^T` and `L K=13 I`. The frozen kernel is

\[
H=\begin{bmatrix}I-KL&-K\\11L&12I\end{bmatrix},\qquad H^2=I.
\]

The forward wrapper follows a complete H forward call, when its source X is
at the common full frame. Eight arbitrary cache fields P advance from identity
to full frame through eight rank-nine children. Three same-frame linear
steps and a swap give

\[
U'=U+K(d-v),\qquad A'=d,\qquad P'=v.
\]

Here d is the arbitrary original P input. The original H target output is
unchanged. The wrapper does not clear or assume zero in any persistent field.

The backward wrapper precedes an H backward call. It moves each of the eight
selected original X fields from its actual input line to the identity frame,
exchanges `(C Y, X_A)` with `(-X_A, C Y)`, and returns the selected field to its
input line. Here `C=[L,I]`. Each round trip costs two rank-one children. With
original X=(a,b), Y=(c,e), the complete prefix plus H backward word has output

\[
X_U'=a-c-Kb,\quad X_A'=e+2Lc+12b,\quad
Y_U'=c,\quad Y_A'=-b-Lc.
\]

This is a pre-call operation. It does not assume that a backward source is
coframed after the call.
