# Exact paid frontier for a fixed cubic native coframe

This contribution was produced by Nick Petalas. It is a scoped proof with
exact finite corroboration and a phase-exact Clifford circuit witness.
No new kappa or selected-frontier change is claimed.

## Result

On m repeated binary symplectic planes, prescribe S(x,z)=(z,x+z). Choose
one internal Lagrangian L, retain the standard boundary L0 at both ends,
and charge both entrance and exit. Each prescribed S occurrence must use
that same internal coframe. Put a=d(L0,L), b=d(L,S L).

The exact Pareto frontier is (j,m-2j), for 0<=j<=floor(m/2). All charts
obey 2a+b>=m and b=m modulo 2. For any increasing concave tariff phi with
phi(0)=0 and positive loop weight k, the exact full graph optimum is

```
min(k phi(m), 2 phi(floor(m/2)) + k phi(m mod 2)).
```

For phi(r)=r^t, 0<t<=1, and even m, its normalized value is
min(k,2^(1-t)). Two copies and two native occurrences improve the
one-copy value 2 to 2^(1-t), with both boundary children paid. For odd m
the exact unnormalized optimum is min(k m^t,2((m-1)/2)^t+k).

[PROOF.md](PROOF.md) gives the universal proof, explicit attaining charts,
and an actual Gaussian-dyadic two-plane circuit. Its conjugated internal
operator is monomial, with every phase retained. This settles the exact
cost of this transported common-coframe contract; it does not extend
Ali Romman's PR6171 tensor-reduction theorem to prescribed native maps.
That theorem and its explicit native-equation limitation are cited, not
audited or replayed.

## Scope and implementation limits

The common internal coframe and prescribed native occurrences are part of
the model. Time-varying coframes, changing the scalar word, and synthesis
that shortcuts U^k are excluded. U^3=I is an immediate reason unrestricted
synthesis can have a different optimum. This is a local changed-model
result, not a rank optimum or emitted word for P104. Rank-zero native
operators still have ordinary costs. Dirty-helper hosting, rounded
precision, tape movement, stock, compiler closure, productive output
delivery, the BIT interface and the outer theorem are unpriced here.
No selected cold replay, Lean or Docker run, physical supplier admission,
complete multiplication theorem, or independent human/formal review is
claimed.

The reference construction supports m<=32, with at most 64 binary
coordinates and 64 rows per elimination. Exhaustive RREF enumeration is
capped at m<=4, with at most 16 free bits per pivot set and 70 pivot
sets. Literal sets have at most 16 points; dense matrices are at most
4x4. Functions are below 60 lines, control flow is nonrecursive, and
explicit exceptions enforce capacities and mathematical invariants.
Warning-strict normal and optimized replay provide the available Python
diagnostics. Power-of-Ten rule 3 has a managed-runtime deviation: Python
allocates integers, Fractions and finite collections during this bounded
one-shot computation. The stated caps bound live mathematical data.
No fixed-allocation or real-time implementation is asserted.
