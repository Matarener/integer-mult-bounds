# Binary head-distance continuation frames

Scoped constructive proof with exact finite corroboration.

New construction and proof produced by Nick Petalas. Apache-2.0.
Independent human and formal proof-kernel review are unclaimed.

The local continuation contract of Mihir Srivastava's
[PR #5364](https://github.com/CrocSwap/integer-mult-bounds/pull/5364) can use
binary head-return distances with the same nineteen tapes and nine symbols.
Let H_i be each role's head-to-end distance, H their sum, d the opaque binary
descriptor length, and L the sum of bitlength(H_i), with bitlength(0)=0.

```text
Unary control frame:   d + 35 + H symbols
Binary control frame:  d + 35 + L symbols
```

The new construction records actual head movement with a little-endian
counter on the existing reverse-scratch tape. It clears that counter into
the frame and reconstructs it at return. All parent bytes, physical heads,
role flags, descriptor, older stack symbols and scratch return exactly.
Proper finite nesting is permitted, and child cleanup remains paid.

With sixteen distances of 4096 and an empty descriptor, the executed frame
uses **243 symbols instead of 65,571**, saving **65,328**. Its complete matched
push/pop costs 1,577,893 read/write/unit-move actions for empty child words.
This is an exact symbolic action invoice, not a runtime benchmark.

[PROOF.md](PROOF.md) proves restoration, nesting, the grammar and the exact bill

    22d + 24H - 10P + 22L + 613 + 2G + 5W,

where P sums popcounts of the distances, W sums all seventeen child-word
lengths, and G sums their return head offsets. Therefore the complete bill
is at most **22d + 46H + 613 + 7W**. This exchanges a larger linear action
constant for smaller headers. Scratch uses at most max(d,max_i bitlength(H_i))
working symbols, plus its marker and terminal blank. Its historical extent
is reused, and erased cells remain part of physical backing.
