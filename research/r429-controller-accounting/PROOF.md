A physical owner family is
`replica*888+(2*pair+side)*111+port`. Every old width-eight helper slice

For every deadline, `new_remainder = old_remainder disjoint_union deleted_slices`.

This is an exact physical partition, not a fractional repacking argument.
Both independent reconstructions check all 123,552 surviving owner roles.

## 3. Known terminal completion and the strict remaining budget

Each of the four hole banks has 111 fields. The named complete terminal
construction uses N E^-1 N, where N is the fieldwise rank-one native gauge.
Two gauge sweeps cost 2*4*111=888 rank-one children per replica. The
intervening scalar inverse code still needs a physical access invoice.

Adding 888*32 to H[1] gives completed mass 1,819,488. The available budget
is 64*28416=1,818,624, so this completion exceeds stock by 864. It exceeds
the older candidate's mass 1,808,352 by 11,136; the baselines differ.

For M(a)=sum H_completed[r]*(r/64)^(1-a), with acceptance M(a)<28416,
all nonzero child ranks lie between 1 and 42. Thus for every a>=0,

```
64*M(a) = sum H_completed[r]*r*(64/r)^a
        >= 1819488 > 64*28416.
```

This is a lower bound on the actual moment. Extra nonnegative costs cannot
fix it at the same stock. Rank-zero census entries are omitted before powers.
A changed stock, child domain or endpoint requires a new argument.

At a=0 the prefix leaves 861 rank units per replica. Strict acceptance
requires an integer terminal bill at most 860, before other costs. The known
888 construction must therefore save at least 28, not merely 27.

For the stipulated ordinary-coverage ledger at L=2B+1 stages, B>=1,
with n ports and three rank-one local repairs per stage,

```
D=(L-1)n-3L-2Bn=-3L<0.
```

With T replicas the excess is 3LT; B=4,L=9,T=32 recovers 864.
The displayed algebra is all-parameter. A hosted layout is only source-bound
here for nine stages; no all-B construction or whole-machine realization is
inferred. The nonnegative-exponent conclusion additionally requires every
counted child rank to lie in its actual ambient range.

The two-gauge cost is not a universal decoder lower bound. Omitting just
one gauge changes the arbitrary-input map: for invertible E and nonidentity
N, `(N-I)E^-1 N` is nonzero, and similarly on the right. For E=I, an exact
witness is `(q/2,0)`, which one gauge sends to `(0,q/2)` while two restore it.
Both gauges may cancel for a separately proved commuting E; that changed
construction is outside the present invoice.

Likewise the 444 FULL-gather source ascents are a cost of lifting four banks
of 111 rank-seven caps to FULL. They are not an observer lower bound. Scalar
augmentation rank 9 supplies no nine-channel native reader. The preserved
ordered source word has an 81-channel factor; no minimality of 81 is claimed.

## 4. Variable row-section obstruction

Let J be n by n over any field. Let A_0,...,A_(2k) be invertible and suppose
A_s agrees with J outside row set P_s. Put P=union P_s and

```
E=(A_(2k) A_(2k-1)^-1) ... (A_2 A_1^-1) A_0.
```

For each adjacent pair,

```
A_(2i) A_(2i-1)^-1
 = I + (A_(2i)-A_(2i-1)) A_(2i-1)^-1.
```

The added matrix is supported only on rows P_(2i) union P_(2i-1).
For any coordinate p outside that support, left multiplication leaves row p
unchanged. Applying the ratios in order and then using A_0=J outside P_0
shows E_row_p=J_row_p for every p outside P. No commutation, common section,
involution, finite quotient order or RW=0 assumption is used.

Consequently every row where J differs from identity must lie in P if E=I.
For the actual binary R438 augmentation J=I+KR, all 111 diagonal entries
are zero. With nine stages and at most three repair rows at each stage,
|P|<=27; at least 84 diagonal entries of E differ from identity.
More generally, with at most r rows per stage, identity requires
rL >= |{p : J_row_p != e_p}|. If L must be odd and r=3 here, L>=37.
This is necessary, not sufficient, and gives no attaining controller.

The diagonal count alone does not lower-bound rank by 84. For example, over
F2 the 2 by 2 swap J has two zero diagonal entries but rank(J-I)=1;
taking every A_s=J and empty repair sets gives that same odd endpoint.
The independent section proof records additional actual-matrix rank information
separately from this general warning.

For a physical constant VALUE function on one uncovered family, every ADDRESS
permutation acts trivially. Thus its augmentation diagonal mismatch is an
actual source specialization, not merely a numeric surrogate. Native factors
and nonconstant inputs still need their own operator/access analysis.

Paid terminal decoders, changed final codes/controllers, non-row-supported
repairs and changed observer contracts are outside this theorem. See
[REVIEW-SECTIONS.md](REVIEW-SECTIONS.md) for the exact source reconstruction,
finite section/return-line census and bounded rank refinements.
