# Same two-N completion fails at every odd stage count

This is an accounting identity for the existing complete ordinary-coverage
contract and its known two-N terminal implementation. It is not a lower
bound for other terminal decoders, native factors or controllers.

Let B>=1 be the number of hole banks, n the number of physical ports and
L=2B+1 the odd alternating stage count. In this construction, the complete
ordinary-coverage rank deficit before the three-copy local repairs is
`(L-1)n`. Three local rank-one copies at each stage cost `3L`. Two endpoint
normalizations on each hole bank cost `2Bn=(L-1)n`. Consequently the complete
rank deficit after that terminal construction is

```
D=(L-1)n-3L-2Bn=-3L<0.
```

This already fails at exponent zero before fallback, new precision/tape
work or terminal allocation. For B=4,L=9 and T=32 replicated copies the
excess rank mass is `3*9*32=864`, agreeing with `BIT-OWNER-PRUNE.json`.
Changing B while retaining these same coverage and terminal contracts cannot
repair the deficit. A changed coverage, stock, endpoint or controller is
outside this calculation.

## Why the tempting288-child scalar terminal invoice is not admitted

At scalar augmentation, all address operators are set to identity. The
common-E schedule then has rank(E-I)<=9 because its five forward and four
inverse factors collapse to the same scalar code A. On actual native data
the stage source codes have different owner/address charts. They are
operator-valued and need not commute or collapse. The preserved raw ordered
word supplies81 channels (nine stages times nine local defect channels),
not a demonstrated nine-channel native endpoint factor.

The tempting `4 hole banks *9 channels *rank8 descent=288` therefore uses
an unproved native factorization. It also omits access at the actual hole
cut. In the existing all-bank FULL-gather implementation, each hole bank
has111 ordinary fields at its own rank-seven caps. Raising those fields to
the required common rank-eight FULL frame costs111 rank-one ascents per
bank,444 globally. Those visits must be paid before a FULL-frame source
query can be formed. Even granting a hypothetical nine-channel factor,
this access plus288 would already cost732, before output alignment and
cleanup. Normalizing and returning all fields gives the known888 terminal
children, with rank-zero code arithmetic between the two sweeps.

The444 figure is the cost of this particular FULL-gather construction, not
a universal lower bound on native observers. A new copied-query network,
shared legal cut, wider observer or other readout may change that invoice;
it must provide its own ordered arbitrary-input word and actual source,
output, dirt and restoration access. Scalar augmentation rank alone cannot
provide those interfaces.
