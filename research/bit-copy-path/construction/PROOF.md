# The actual R438 centre cannot be rerouted cheaply through its postscatter suffix

This is a source-bound obstruction, not a changed supplier. For each of the
nine actual retained totals, replacing its COPY7 by any finite family of
independent snapshots of that **same unchanged total**, delivered during the
postscatter suffix through closed nested private-frame walks, costs at least
seven query ranks, with no reduction of the corresponding unweighted paid
rank moment. This remains true with free public retiming, scalar ADDs and
final source/helper restoration. The proposed private
COPY1 / promote1 / demote1 episode is a valid local operator, but cannot
deliver the whole required centre contribution.

The result uses exact rational frame geometry and the literal Boolean word.
It does not exclude mixed new query totals, a changed upstream factory, new
public downward queries, or another public source/target interface. It does
not improve the fixed allocation ceiling or establish a new kappa.

## The copied-field contract and tariff

Fix one j and write `F=F_j`, `q=q_j`. A branch copies q from unchanged F
into a private frame `G subset F`, then follows a finite sequence of nested
private MOVE edges, reads into public receivers at equal frames, and returns
to G before its guarded ERASE against the same source q.

Write

```
r = 7 - dim(G),                 m = sum of private MOVE ranks.
```

The charged branch tariff is `r+m`. Every private MOVE in both directions
is included. A rank-zero same-frame copy is granted free for this lower
bound, even if a chosen concrete API does not provide it. Scalar reads,
workspace, source preparation, all public retiming and final cleanup are
also granted free. Charging any of those costs only strengthens the result.

COPY/ERASE is the inherited exact copied-total pair. The private decoded
value is q throughout its reads, and ERASE sees its original q at G.
`../composition/` supplies the separate exact address-operator derivation
for private promotion. The old fixed private ABI's prohibition of MOVE
inside a snapshot lifetime is not used as a mathematical obstruction here.

Different branches may copy the same q independently. The theorem does not
permit a branch to become a privately mixed new query total, borrow an
uncounted downward native query, omit its return, or erase against a
different snapshot.

## A single closed private walk

Let L be the intersection of every private frame visited by a branch,
including its entrance, every read frame, and its returned frame. An upward
MOVE cannot shrink the running intersection. A downward MOVE of rank d
shrinks it by at most d. Because the private walk is closed, its total
upward and downward ranks are both `m/2`. Therefore

```
L subset G subset F,
dim(L) >= dim(G) - m/2 = 7-r-m/2.                 (1)
```

At an ADD from the private field, the public receiver's frame contains L.
The contribution subsequently propagates only through upward public MOVEs
and equal-frame ADDs. Consequently a nonzero contribution from this branch
can reach target p only if

```
L subset K_p, equivalently u_p is orthogonal to L. (2)
```

This is a support restriction. Cancellations over F2 can remove paths or
output coefficients; they cannot create a coefficient at a target to which
no permitted path exists. Reads at G before the first MOVE or after the
return satisfy the same condition.

If this one branch supplies all of `k_j`, its recipient roots span Q^8.
Equation (2) forces L=0, and (1) yields

```
r + m/2 >= 7,
r + m >= 14-r.                                  (3)
```

Thus a strict reduction of the COPY rank to `r<7` requires total branch
tariff at least eight. At r=1 the complete path needs tariff at least
thirteen to supply the full `k_j`, although a rank-three local excursion
can serve a smaller set of targets.

## Any finite number of independent copies of the same total

For branch i, let `L_i`, `r_i`, and `m_i` be as above. A recipient root
projects onto F into

```
F intersect L_i^perp,
```

whose dimension is at most `r_i+m_i/2` by (1). The support of the total
delivered coefficient is contained in the union of the branch supports.
The span of the projections of that union therefore has dimension at
most the sum of these bounds.

The required `k_j` recipient roots project onto a rank-seven subspace,
namely all of F. Hence

```
7 <= sum_i (r_i+m_i/2) <= sum_i (r_i+m_i).         (4)
```

Direct public reads of q at unchanged F add only roots in `F^perp`; their
projections onto F are zero and do not improve (4). This proves the stated
seven-rank floor even for arbitrarily many independent same-query branches.

The proof is over rational or real frame geometry. The decoded coefficient
calculation is over F2. No uniform assertion about every odd-characteristic
specialization of intersection dimensions is made.

## Rank-moment consequence

Keep the same rank-to-child conversion and the same stock and ownership
premises. For `0 <= b < 1`, define

```
Phi_b(r) = 64^b r^(1-b),        Phi_b(0) = 0.
```

Let `t_l` be the positive integer paid ranks of all replacement COPYs and
private MOVEs. Equation (4) gives `sum_l t_l >= 7`. For `a=1-b` in `(0,1]`,
the function `t^a` is subadditive on the nonnegative reals: writing
`s=x+y>0`, the facts `(x/s)^a >= x/s` and `(y/s)^a >= y/s` give
`x^a+y^a >= s^a`. Repeated application and monotonicity yield

```
sum_l Phi_b(t_l) >= Phi_b(sum_l t_l) >= Phi_b(7).
```

Thus dividing the same-total path among independent branches cannot save
this paid rank moment either. All extra public retiming costs were granted
free, so pricing them cannot weaken the inequality. This does not compare
different recursive owner allocations, changed helper stock, or different
rank-to-child conversions; those remain separate obligations.

These controls separate valid local private transport from delivery of the
complete target pattern. They do not reject the local transport identity.

## Earlier-cut and acquisition screens

The written postscatter theorem has no downstream COPY. Two separate finite
screens examine changes outside that premise.

`acquisition_screen.py` deletes each of the nine original COPY episodes in
turn and permits every source-to-helper ADD at an already visited common
frame throughout literal A. Sources remain their original x throughout A;
the helper-helper network and B are fixed. An inserted acquisition
`h += x_i` contributes a computable suffix target vector. For each of the
523 required `(deleted centre, source column)` repairs, the desired missing
column lies outside the span of all such influences. The emitted dual
functional annihilates every candidate influence and detects the missing
column. Failure persists when all partial-helper restoration is granted
free. This is a complete screen of that acquisition class, not a theorem
about changed helper-helper networks or new source frame paths.

`late_factory_screen.py` starts when each retained centre first becomes its
complete q, through the first COPY cut. The nine cut counts are
`56,49,42,35,28,21,14,8,1`, totalling 254. The eight remaining downstream
COPYs are included in each suffix influence calculation. The screen allows
a new COPY of rank at most four, reads into arbitrary public registers,
and early upward retiming within an existing MOVE after the last old-frame
use, counting COPY and ERASE source reads as uses. It grants all scalar
work, MOVE splitting and inverse cleanup free.
It rejects all 90 catalogue-frame cases. A further nine relaxations allow
a different arbitrary real frame for every receiver and cut, while
retaining the source-hyperplane and existing-next-MOVE constraints; all
nine also fail. Each rejection has an exact binary separator.

`newcut_screen.py` records the analogous 1,700-cut B screen and its simple
separators. This finite calculation is secondary to (4). It also tests
all 301 rank-six, rank-seven and full catalogue reader frames for a fixed
promoted private reader frame: all 2,709 cases fail. Taking their completely
free union has rank 111 and permits every desired pattern. This is a useful
scope control: changing private frames can enlarge the reachable target
support. Equations (1)--(4), including the required return and every MOVE,
provide the tariff obstruction. Initial COPY rank alone does not price
that arbitrary promoted walk.

None of the failed screens produces a candidate word. In particular no new
integer lift, inverse cleanup, positive envelope, owner invoice or physical
ABI is silently inferred from a solved scalar equation.

## Open next questions

A construction must change a premise to evade this result: acquire a
different useful total before the fixed completed-centre window, change the
helper-helper network or source frame path, introduce and price new public
downward queries, or compose several genuinely different query totals.
The known coded-source construction changes the source endpoint and has a
separate caller/decoder obligation. No source-preserving cheaper actual
word, full compiler admission, precision improvement, or meaningful kappa
improvement is established here.
