# Full BIT caller: the price of retaining a rank-four helper for COPY

Apache-2.0. Substantial OpenAI Codex assistance.

This note has two results. First, it prices every local call and idle
completion in the six constructed nine-stage callers. A protected old host
preserves the earlier strict COPY saving, but all three consumer callers have
a strictly larger recursive query tariff, including the inherited surcharge,
than the constructed ordinary caller that reuses those hosts. This comparison
holds for every power exponent `0<b<1`; it is not a claim about total measured
machine runtime.

Second, a fractional allocation relaxation gives the exact optimum for the
entire fixed whole-helper inventory, even after dropping all chronology and
per-call disjointness restrictions. Its admissible primitive saving under
the inherited full-moment criterion is below `0.001743393260914`. Even if the complex supplier and all implementation
interfaces were ample, the retained outer map could improve the selected κ
by less than `4.047382%`, not 10%. Exporting a rank-four helper into one of
these COPY consumers strictly worsens this relaxed optimum.

These are a finite caller comparison and a written allocation theorem with
exact arithmetic certificates. They do not admit a new native supplier or
change the selected κ.

Equation (1) is a conditional recursive-query contraction test. If the

coefficient alone does not establish the native width/volume recurrence,

## 2. The final remainder, not the first boundary, determines the saving

Redirect one rank-four helper from an old rank-28 public window to a
genuine rank-seven COPY query. Its COPY completion becomes rank three.
Let `r` be that old public host's final reference remainder **after every
later helper assigned to the same window**. The complete change is

\[
\Delta H=e_{r+4}+e_3-e_r-e_7,                  \tag{2}
\]

omitting `e_0`. The earlier closed stage-zero boundary had `r=24`. That
value cannot be transplanted past later owner fills.

For `r>3`, strict concavity gives
`Phi(r+4)-Phi(r) < Phi(7)-Phi(3)`, so (2) saves query cost.
For `r=0`, it costs `Phi(4)+Phi(3)-Phi(7)>0` by strict subadditivity and
also adds one child to the surcharge. At `r=3` the power change is zero.

The owner construction emits the following six complete invoices. Each
has all 288 local calls, all 126,144 helper roles, all 71,040 idle endpoint
rows including rank zero, 10,369,440 local ADDs, 63,936 bridge ADDs and
2,592 COPY/ERASE episodes. There is no additional helper bank.
`check_invoices.py` reconstructs each histogram directly from the literal
idle rows and the actual local H, rather than importing the owner checker.

| Policy | Ordinary reference root bracket, including surcharge | Consumer root bracket, including surcharge |
|---|---|---|
| Reuse old hosts fully, `r=0` | `(0.001742200652684, 0.001742200652686)` | `(0.001742059196608, 0.001742059196610)` |
| Limit later old-host fill to 16, `r=8` | `(0.001741631982308, 0.001741631982311)` | `(0.001741716310006, 0.001741716310008)` |
| Freeze old hosts, `r=24` | `(0.001741582528043, 0.001741582528045)` | `(0.001741780146956, 0.001741780146958)` |

The first reference has 901,625 children. The other five invoices have
901,725. Every row has the same stock and rank mass. Each lower endpoint
has a certified upper bill strictly below `64W`; each upper endpoint has
a certified lower bill strictly above it. Positive coefficients make the
bill strictly increasing, so these are root brackets, not failed
sufficient tests.

The two protected-host policies preserve the matched consumer saving.
However, protection has an opportunity cost: the ordinary reference that
fully reuses the old hosts is cheaper than all three consumer versions.

This last statement is uniform in `b`, not just a comparison of decimal
roots. For each consumer let
`D=H_consumer-H_reuse_reference`. The exact receipt verifies

\[
\sum_r rD(r)=0,\qquad
\sum_rD(r)\min(r,t)\ge0
\]

at every rank knot, with strict positivity somewhere. Between knots the
second expression is linear and outside them it is either zero or
constant. The integral representation of every strictly concave power
with exponent in `(0,1)` then gives
`sum D(r)Phi_b(r)>0`. Each consumer also has 100 additional children.
Thus the complete inherited tariff is strictly larger for all `0<b<1`.

This comparison does not attribute the improvement over the selected
PR589 BIT endpoint to the new consumer. The selected supplier has a
different R439 local word and owner histogram. All six new query
invoices exceed its endpoint `0.001733427039589844234749`, but the best
of these six is the ordinary R438 caller without the new consumer.

## 3. A complete allocation relaxation

Now permit any reallocation of the same whole rank-eight and rank-four
helpers into the source's bins. Ignore stage windows, call disjointness,
common charts and integrality of the **number** of bins assigned each
pattern. Each bin still contains a legal integer pattern:

\[
a,d\in\mathbf Z_{\ge0},\quad 8a+4d\le R,
\quad\text{with remainder }R-8a-4d.
\]

Allow a fractional number `x_(R,a,d)` of such bins. This is a lower-cost
relaxation of every legal whole-helper allocation; it is not an attained
fractional physical circuit.

Suppose `k` distinct rank-four helpers serve genuine rank-seven COPY
queries, for any integer `0<=k<=1440`. The remaining public inventories
are `N8=124704`, `N4=1440-k`; the local histogram is
`288H+k(e3-e7)`. Public remainder mass increases by `4k`. No useful-output
credit is assigned twice.

The following fractional primal solution uses every public bin and every
remaining helper exactly:

| R | a | d | Number of bins |
|---:|---:|---:|---:|
| 7 | 0 | 0 | 21,312 |
| 14 | 1 | 0 | 14,208 |
| 28 | 3 | 0 | 12,768+k |
| 28 | 3 | 1 | 1,440-k |
| 42 | 5 | 0 | 67,872/5 |
| 42 | 0 | 0 | 3,168/5 |

Its complete idle histogram is

\[
J^*(k)=21312e_7+14208e_6+(12768+k)e_4
       +\frac{67872}{5}e_2+\frac{3168}{5}e_{42}. \tag{3}
\]

The exact full relaxed profile is therefore

\[
H^*(k)=288H+k(e_3-e_7)+J^*(k)
      =H^*(0)+k(e_4+e_3-e_7).                 \tag{4}
\]

## 4. Exact LP dual and an all-parameter proof

For fixed `0<b<1`, set

\[
\lambda_8=(\Phi_b(2)-\Phi_b(42))/5,\quad
\lambda_4=-\Phi_b(4),
\]
\[
\mu_7=\Phi_b(7),\quad
\mu_{14}=\Phi_b(6)-\lambda_8,\quad
\mu_{28}=\Phi_b(4)-3\lambda_8,\quad
\mu_{42}=\Phi_b(42).
\]

The dual constraints are

\[
\lambda_8a+\lambda_4d+\mu_R
\le\Phi_b(R-8a-4d).                           \tag{5}
\]

There are 64 integer occupancy patterns. The checker certifies all 64
at each reported root's upper endpoint, at the necessary 10% endpoint,
and at `.002`, using exact rational intervals. The six positive primal
patterns in the table are exact dual equalities. Primal and dual
objectives agree, proving optimality at every checked point.

Here is a written proof for **every** `0<b<1`. The left-minus-right
slack in (5), with its sign reversed, is concave in `(a,d)`. It suffices
to check the vertices of each integer-pattern convex hull:

* `R=7`: `(0,0),(0,1)`;
* `R=14`: `(0,0),(1,0),(1,1),(0,3)`;
* `R=28`: `(0,0),(3,0),(3,1),(0,7)`;
* `R=42`: `(0,0),(5,0),(0,10)`.

Six vertices are the exact equalities above. The other constraints follow
from strict subadditivity of `r^(1-b)`, including
`Phi(42)<Phi(2)+10Phi(4)`, except for

\[
5\Phi(14)+\Phi(2)-5\Phi(6)-\Phi(42)>0,          \tag{6}
\]
\[
5\Phi(28)+3\Phi(2)-5\Phi(4)-3\Phi(42)>0.        \tag{7}
\]

To prove both, cancel the common factor `64^b` and put `p=1-b`.
Each expression is a nonzero sum of four functions `r^p` with distinct
positive bases. Such a function has at most three real zeros counting
multiplicity: divide by its smallest exponential and differentiate, then
apply Rolle's theorem inductively to the remaining three exponentials.

Both expressions vanish at `p=0` and `p=1`. Their derivative at zero is
strictly positive and their derivative at one is strictly negative. These
signs are exact integer comparisons:

\[
\frac{2\,14^5}{6^5\,42}>1,\qquad
\frac{2^2\,14^{70}}{6^{30}\,42^{42}}<1,
\]
\[
\frac{2^3\,28^5}{4^5\,42^3}>1,\qquad
\frac{2^6\,28^{140}}{4^{20}\,42^{126}}<1.
\]

They imply positivity immediately inside both endpoints. A failure of
strict positivity between them would contribute at least two further
zeros counting multiplicity, contradicting the three-zero bound.
Thus (6) and (7) hold throughout `0<p<1`, proving (5) and optimality
of (3) for the entire open exponent interval.

### Parametric resource corollary

The dual does not depend on the bin multiplicities or helper inventories.
Let the bin counts `C7,C14,C28,C42` be nonnegative, and let `F,D` denote
the numbers of whole rank-eight and rank-four helpers. Suppose

\[
0\le D\le C_{28},\qquad
C_{14}+3C_{28}\le F\le C_{14}+3C_{28}+5C_{42}.
\]

Put `t=(F-C14-3*C28)/5`, so `0<=t<=C42`. Assign respectively
`C7,C14,C28-D,D,t,C42-t` bins to the six tight patterns in the preceding
primal table. These counts are nonnegative and exhaust every bin class.
They use exactly `C14+3*C28+5*t=F` full helpers and `D` partial helpers.
The common primal/dual optimum is therefore

\[
J^*=C_7e_7+C_{14}e_6+(C_{28}-D)e_4
      +t e_2+(C_{42}-t)e_{42}                 \tag{8}
\]

for every `0<b<1`. This permits nonnegative real resource right-hand
sides in the mathematical LP; physical family and helper counts remain
integers, and pattern multiplicities in the relaxation may be fractional.
It makes no chronological or physical realization assertion.

If `0<=k<=D` helpers are instead exported into `k` genuine rank-seven
COPY jobs, the retained inventory is `D-k` and remains in this resource
regime. Replacing `D` by `D-k` in (8) adds `k e4`; the completed COPY
change adds `k(e3-e7)`. Thus the optimized complete relaxed tariff changes
by `k(Phi(4)+Phi(3)-Phi(7))`, strictly positively when `k>0`.
This is an opportunity-cost theorem for the whole stated resource
regime, with the same bin shapes and whole-helper contracts. The checker
verifies the resource and donation identities coefficient by coefficient,
and verifies the actual nine-stage inventory as a specialization; it
does not infer this corollary from a finite sample of parameters.

Consequently (4) is the optimal relaxed bill for all those exponents.
Its per-donor change is

\[
\Phi_b(4)+\Phi_b(3)-\Phi_b(7)>0.               \tag{9}
\]

An optimal allocation retains each rank-four helper to erase a rank-four
public remainder. The apparent COPY saving forfeits that more valuable
use. This is a global opportunity-cost statement within the stated
inventory, not a claim that every individual legal consumer placement
must worsen its matched reference.

The optimistic roots, with zero surcharge, are:

|---:|---|
| 0 | `(0.001743393260913,0.001743393260914)` |
| 100 | `(0.001743251611103,0.001743251611104)` |
| 900 | `(0.001742119241980,0.001742119241981)` |
| 1,440 | `(0.001741355725345,0.001741355725346)` |

Equations (4) and (9) cover all intermediate donor counts without
1,441 separate searches. The zero-donor upper endpoint is a ceiling
for the entire mechanism, regardless of chronology or integrality.

### Granting every bad packet free

The LP theorem concerns the rank tariff. Dropping its positive fallback
surcharge does not by itself discount the good work by the exceptional
residue fraction. To strengthen the fixed-stock screen, assume the
inherited good/bad split guarantees at least a `1-epsilon` fraction of
each child's good work, where `epsilon=10^-16`. Grant every bad packet
zero cost and check the still more favorable bill

\[
\widetilde B_k(b)=(1-\epsilon)\sum_r H^*(k)(r)\Phi_b(r).
\]

At every upper endpoint in the table and at the necessary 10% endpoint,
the checker proves `widetilde B_k(b)>64W` using exact lower bounds.
For `k=0` at its stated upper endpoint the raw excess is greater than
`2.6803*10^-9`, whereas `epsilon*64W=1.818624*10^-10`; the exact
discounted excess remains positive. Thus the same displayed decimal
ceiling survives this discount. Multiplying (9) by `1-epsilon` retains
strict positivity, so the zero-donor rejection covers every donor count.

This statement fixes the public stock at `W=28416` and concerns the
native moment screen under the stated good-fraction premise. It does
not reinterpret the rank tariff as a lower bound on every possible
algorithm's actual running time.

### Additional full-progress helper banks

At every certified upper endpoint and target in `SCREENS.json`, exact
signs also give `lambda8<-8` and `lambda4<-4`. Suppose `A` full helpers
and `B` partial helpers move from public hosts to extra full-progress
stock `X`. Grant that stock an ideal rank-64 completion, even though
rank 64 is not a contracting recursive child. Its idle mass is
`64X-8A-4B>=0`; its cost minus its output-stock credit is at least
`-8A-4B`. Applying the public dual to the reduced helper inventories
raises the total lower bound by

\[
A(-\lambda_8-8)+B(-\lambda_4-4)\ge0.
\]

Thus added fully paid full-progress banks cannot evade any certified
ceiling or target rejection. This extension is asserted at the certified
exponents, not for all `0<b<1`. New banks with independently required
partial-progress outputs have a different contract and are outside it.

The same conclusion survives discounting the **public** work by
`1-epsilon` if extra bank completions still pay their full residual rank
mass. The exact additional penalties then are

\[
A\bigl((1-\epsilon)(-\lambda_8)-8\bigr)
+B\bigl((1-\epsilon)(-\lambda_4)-4\bigr),
\]

and both coefficients are certified positive at every tested upper
endpoint and target. This retains the explicit undiscounted unit-mass
completion premise for the additional banks. It does not cover
arbitrarily increased bank stock whose completion work also receives
an unconstrained free-bad discount.

## 5. Outer comparison and the 10% target

The copied selected assembly is byte-for-byte the current certificate,
SHA-256
`1122cb3a575f8c788345fc1bf4c108ac7c3250fb81a5988671f5eb04b3ab3045`.
Its selected value is

\[
\kappa_{\rm sel}=836330098538459/500000000000000000
               =0.001672660197076918,
\]

and it binds on the complex supplier, whose endpoint is below every new
complete BIT query root. Substituting each new BIT lower endpoint into
the retained seven-level bootstrap reproduces exactly the same selected
κ; all 47 outer inequalities are checked. This calculation admits none
of the new supplier's missing implementation premises.

For a necessary bound independent of finite bootstrap rounding, every
retained outer assembly satisfies

\[
\kappa<\frac{c}{1+c},
\]

where `c` is its BIT endpoint. To reach
`K=11*kappa_sel/10`, it therefore needs

\[
c>\frac K{1-K}
=\frac{9199631083923049}{4990800368916076951}
>0.001843317785504024003736989724.              \tag{10}
\]

At (10), even `H*(0)` exceeds `64W` by more than
`590.603137635021650149691091093154` raw units. The 100-donor relaxation
exceeds it by more than `591.488492471965400762795010866872`.
Every further donor worsens the bill by (9). All omitted costs favor
acceptance, so the 10% target is excluded for the entire stated mechanism.
The exact discounted checks above also reject that target while granting
every bad packet free at fixed public stock; the optional extra-bank
extension retains its separate unit-mass completion premise.

The best relaxed ceiling yields

\[
\kappa<\frac{0.001743393260914}{1+0.001743393260914},
\]

less than a `4.047382%` gain over the selected record, even with an ample
complex supplier. This is a ceiling, not an achieved gain. With the
selected complex supplier unchanged, the certified substitution gives
zero κ improvement.


Normal and optimized modes must produce identical receipts. The interval
engine uses only integers and exact fractions: a positive atanh series
after binary range reduction for logarithms, a positive Taylor series for
exponentials, explicit omitted-tail bounds, and outward rounding to a
256-bit dyadic grid. No floating-point result decides a comparison.

Negative controls reject a missing helper in the primal resource rows,
inflation of a tight dual price, omission of public idle mass, retention
of the old stage-zero delta after full reuse, and the selected endpoint's
next grid point. Source extraction retains assertions as explicit checks
under `python -O`. Local arithmetic sources are loaded from their actual
read bytes with `compile(..., dont_inherit=True, optimize=0)`, bypassing
local `.pyc` caches. Semantic controls ignore a deliberately poisoned
module cache and preserve a deliberately failing source assertion even
when the parent interpreter runs with `-O`.

`../independent/check_inventory.py` provides a separate arithmetic route:
integer nth-root bisection at `b=1/573`, with independently derived
source inventories and no imported moment engine. Its weaker endpoint
also rejects the 10% target. It does not independently certify the tight
decimal root brackets above.

The schedule specialist owns physical-family disjointness, literal frame
charts, arbitrary-input restoration and every later source-window
obligation. The native specialist owns copied-total ABI, real adapter
costs, changed integer-prefix growth, precision, source access and tape.
Those obligations must hold before any positive query endpoint becomes
a supplier endpoint.

The allocation theorem assumes unchanged nine-stage public window ranks,
whole rank-eight/rank-four helper progress that occupies disjoint
directions within each window, the fixed local H, and direct rank-four
completion of rank-seven COPY jobs. It does not exclude a changed local
word, genuine deletion/sharing of an entire COPY path, new public
chronology, nonorthogonal operator fusion, or independently useful
partial-output demand. Each changes the mathematical problem and needs
a new complete inventory and invoice.
This is a ceiling for the stipulated recursive-query tariff and transfer
criterion, not a lower bound against every possible multiplication
algorithm or a changed native tariff.
