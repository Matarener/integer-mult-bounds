# The BIT COPY floor for closed snapshot paths

**Scoped obstruction and complete planning budgets; no new supplier or κ.**

This investigation changes the proposed query word, rather than applying the
preceding fixed-word allocation ceiling to a different construction. It finds
a stronger obstruction to replacing one of the nine actual centre copies.
It also tests the existing 429-helper coded word in the actual recursive
caller. Neither route supplies a κ improvement.

## Main result: closed snapshot paths cannot cheapen a centre COPY

Each retained centre has a seven-dimensional frame \(F_j\). Its required
scatter column \(k_j\), reconstructed from the literal R438 word, reaches
port roots spanning all eight dimensions.

Allow any finite number of independent copies of the **same unchanged
centre total**. Copy \(i\) may start in any subframe of \(F_j\), costing
\(r_i\), and follow an arbitrary closed path of nested private frame moves,
costing \(m_i\) in both directions. It may add into any compatible public
register during the continuation after the last original COPY. Public
frames remain monotone and the continuation contains no further COPY.
Scalar additions, legal public retiming, and other cleanup are granted free
for this necessary bound. The private copies must be restored for their
guarded ERASEs.

The written geometric argument proves

\[
   \sum_i\left(r_i+\frac{m_i}{2}\right)\geq 7.
\]

Consequently the replacement cannot reduce either the total paid query rank or
its recursive moment
\(\sum_\ell 64^\beta r_\ell^{\,1-\beta}\), for \(0\leq\beta<1\).
For a single copy of rank \(r<7\), the complete rank cost is at least
\(14-r\geq8\).

This includes moving the private copy outside the original centre frame.
For example, a rank-one COPY followed by a rank-one promotion and its
rank-one inverse is a valid local transport costing three. It still cannot
deliver the complete actual scatter column. A private slot starts and ends
zero; no arbitrary private dirt is discarded.

See [the proof](construction/PROOF.md) and
[independent review](independent/REVIEW.md). The argument quantifies over
the stated continuous frame class; its application to these nine centres
uses exact finite source and rational/real geometry checks. It is not a formal-kernel
proof, or a bound on mixtures of different totals, changed public queries,
or a rebuilt factory.

## Earlier cuts and the recoded caller

Two finite screens test ways around the late-continuation premise.

- Source acquisitions at all existing common-frame cuts in the actual
  factory cannot replace any deleted centre scatter. Even relaxing the
  five partial-helper terminal conditions leaves exact binary separators.
- Copying each completed centre earlier at **COPY rank at most four**,
  before the remaining centre copies, fails across all **254** eligible
  cuts. The screen includes the
  unchanged downstream COPYs and allows an arbitrary real intermediate
  frame separately for each receiver. It does not cover a changed
  incomplete total or a changed factory graph.

The existing R429 source-code construction has a real local saving, but
its unmodified substitution into the nine-stage caller fails. The complete
888-column scalar defect has rank 63. An integral ADDRESS impulse in the
last pair produces a nonzero TAIL component that no invertible terminal
decoder made solely of scalar mixing and separate HEAD/TAIL routes can
erase. Restoring the scalar source code locally does not remove the
mismatch between successive fresh blocks.

[The caller proof](composition/PROOF.md) binds this failure to the actual
order-28 code and native charts. Its priced repair floors cover two
specified interfaces: a minimum nine-reader common-cap repair costs at
least 63 rank units per local call; the previous one-snapshot-per-repaired-row
interface needs all 111 rows. Shared or differently routed repairs remain
outside those floors.

[The private-transport and wrapper appendix](composition/PRIVATE-MOVE-PROOF.md)
also prices an explicit correction around each coded call. Cancelling and
commuting its full-bank sweeps, while keeping both the calls and individual
code factors in their fixed chronological order, leaves at least nine
sweeps: 999 rank-one requests. That exceeds the allowance below 526 per
nine-call block. Reordering code factors or replacing these sweeps by other
routed queries is outside this particular cancellation argument.

## Complete budget consequence

The comparison uses the existing \(m=64\), \(W=28416\), 288-call controller
and includes returned helper-owner obligations and the inherited child
surcharge. The target is the necessary BIT endpoint for a 10% gain over
the selected κ, under the retained outer relation:

\[
 c_*=\frac{9199631083923049}{4990800368916076951}.
\]

| Proposal | Remaining allowance at \(c_*\) |
|---|---:|
| Delete one COPY7 in every local call | Less than 4.978 tariff units per call for its replacement |
| Use the existing coded R429 word | Less than 58.383 per call for all added repair children |

The second row returns all 72 owner rank units per call from the nine
deleted helpers. Its complete rank saving before decoding is 60 per call.
These are planning allowances under the declared owner relaxation, not
constructed chronological schedules.

The historical P111 label-decoder mass floor of 63 is **prior work**.
Even granting the most favorable direct-reader histogram consistent with
that floor, \(4e_6+e_7+4e_8\), the complete optimistic BIT endpoint is below
`0.001743442083496`. Under the retained outer relation its possible gain
over the selected κ is below **4.050289853587%**. This consequence applies
only to that direct-reader class. It is not a global upper bound on BIT
algorithms.

[The budget proof](bounds/PROOF.md) and
[exact receipt](bounds/BUDGET.json) give rational intervals, the complete
histograms, and adjacent rejection/pass tests. A separate positive-binomial
calculation checks the numerical signs. The selected complex endpoint
remains binding, so a BIT-only saving would not by itself change the
selected κ.

## Open next questions

A successful construction must change something excluded by the proved
class: the queried totals, their factory or public query events, the
restoration contract, or a shared routed caller repair. It must emit the
complete arbitrary-input word and pay its native queries, helpers,
chronological owners, rounding, storage, and outer costs. Merely moving
the same completed snapshot later, or treating a source code as a free
terminal decoder, does not meet those requirements.

Two concrete questions remain:

- **Can different queried totals share a paid path?** This changes the
  unchanged-total premise of the theorem. Start with one complete changed
  factory/query word, check every dirty-input column and restoration, and
  price its full child histogram and returned helper owners. The blocker is
  the absence of a favorable literal candidate.
- **Can a shared routed correction repair the coded caller cheaply?** This
  lies outside the direct-reader and fixed-order wrapper bounds. Start with
  one complete nine-call operator correction, charging every native query
  and source observation against the stated repair allowance. The blocker
  is the absence of a complete legal correction; scalar endpoint agreement
  alone does not establish native caller compatibility.
