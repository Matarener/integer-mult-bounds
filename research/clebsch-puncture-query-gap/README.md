# Sharp 13-vertex puncturing threshold for a binary query construction

Every 13-vertex induced restriction of the fixed Clebsch full-parity matrix
has binary rank six, while integral edge/private-coordinate sharing needs
seven coordinates. No restriction with at most 12 vertices gives a strict
saving using this fixed matrix. The full 16-vertex code is classical; the
new finite result determines its exact induced-subset threshold. It supplies
a smaller witness to Open next question 1 of JoyboyBrian's
[#5023](https://github.com/CrocSwap/integer-mult-bounds/pull/5023).

Claim type: finite certificate and scoped written deletion-robustness proof.
The [proof](PROOF.md) also shows that removing any five vertices preserves
rank six. It distinguishes the rank of this supplied matrix from unrestricted
minimum fitting rank. No exact unrestricted optimum or new kappa is claimed.

The graph has vertices F2^4 and XOR differences {1,2,4,8,15}. It is triangle-free
and contains overlapping odd cycles. Every induced subgraph remains triangle-free.
For each subset S,
the verifier compares rank((I+A)[S,S]) with |S|-nu(S), the optimal integral
edge/private-coordinate bill. The strict-saving cases are exactly

| Vertices | Rank | Sharing bill | Subsets |
|---|---:|---:|---:|
| 13 | 6 | 7 | 560 |
| 14 | 6 | 7 | 120 |
| 15 | 6 | 8 | 16 |
| 16 | 6 | 8 | 1 |

The package stops at this result. Physical realization and profitable complete
caller accounting need separate work.

## Code bounds

The verifier has no recursion, subprocesses, third-party imports or shared mutable
state. Vertex loops are bounded by 16, the census and matching tables by 65536,
row spans by 64 and literal inputs by 8192. Functions stay below 60 lines.
Python allocations are a managed-runtime deviation from fixed steady-state
allocation; two 65536-entry integer tables dominate live working storage.
No compiler configuration is changed; both registered runs enable warning
errors and check the same evidence with and without Python assertions.
