# Uniform completion does not transfer from E0 to the physical encoding

## Statement

Let each port carry a copy of one address space. Write a two-bank state as
`(r, w)`. Let `U_C` apply one address operator `C` on every port of both banks.
Let `D` and `H` be scalar matrices on the ports, with `H` diagonal and
`H^2 = H`. Define the scalar-bank encoding and the physical encoding by

```
E0(r, w) = (D r + H w, w),
L(r, w)  = (D r + H T w, w),
```

where `(T w)_p = T_p w_p` and each `T_p` is an address operator. Let `J0 = I - H`
and

```
Pi(r, w) = (J0 r + H w, H r + J0 w).
```

`Pi` is the literal N-slot swap. It fixes the J slots. Then:

1. `U_C E0 = E0 U_C` for every address operator `C`.
2. `U_C L = L U_C` if and only if `C T_p = T_p C` whenever `H_pp = 1`.
3. `U_C Pi = Pi U_C` for every `C`, and therefore
   `U_C (Pi L) - (Pi L) U_C = Pi (U_C L - L U_C)`.
   The literal-slot encoding commutes with `U_C` exactly when `L` does.

In the four-point model below, `H = diag(0, 1)`, `T_N = C_{e1}`, and
`C = Z_{e1}` satisfy the scalar identity and fail both physical identities.
The same `Z_{e1}` commutes with `C_{e2}`. Every translation chart commutes with
every other translation chart, so a uniform completion that stays in that
family still passes through `L`.

This is not an adjacent completed-call pair, not a native bill, and not a
kappa.

## Proof

Scalars commute with every address operator, and `U_C` uses the same `C` on
every port. For a scalar matrix `M`,

```
U_C (M v)_p = C sum_q M_pq v_q = sum_q M_pq C v_q = (M U_C v)_p.
```

`E0` and `Pi` are built from scalar blocks, so both commute with every `U_C`.
That is the positive control for a scalar-bank encoding.

For the physical encoding the second block is not scalar:

```
U_C L(r, w) = (C D r + C H T w, C w),
L U_C(r, w) = (D C r + H T C w, C w).
```

`D` and `H` are scalar, so `C D = D C` and `C H = H C`. The states agree if
and only if `H C T w = H T C w` for every `w`, which is
`C T_p = T_p C` on every port with `H_pp = 1`.

Because `Pi` commutes with `U_C`,

```
U_C Pi L - Pi L U_C = Pi U_C L - Pi L U_C = Pi (U_C L - L U_C).
```

`Pi` is invertible (`Pi^2 = I`), so it preserves vanishing of the commutator
and does not restore a failing one.

## Finite witness

Order the addresses of `(F_2)^2` as `0, e1, e2, e1+e2`. Translation acts by
`(X_u f)(x) = f(x+u)`. The character `Z_{e1}` multiplies by `(-1)^{x·e1}`.
These are the same translation and character operations used to state the
chart formula and the normalization identity in PR #3954, §§3–4. They are
rederived here; that package is not imported.

The Pauli relation `Z_{e1} X_{e1} = - X_{e1} Z_{e1}` holds, while
`Z_{e1}` commutes with `X_{e2}`, and `X_{e1}` commutes with `X_{e2}`.
The boundary chart of PR #3954 is

```
C_u = ((1+i) I + (1-i) X_u) / 2.
```

Commutation with `C_u` is equivalent to commutation with the Gaussian-integer
operator `S_u = (1+i) I + (1-i) X_u = 2 C_u`, because the commutator scales by
the central integer 2. Direct multiplication gives

```
[Z_{e1}, S_{e1}] =
  [  0    2-2i   0     0  ]
  [-2+2i   0     0     0  ]
  [  0     0     0   2-2i ]
  [  0     0   -2+2i  0  ].
```

The `(0,1)` entry `2-2i` is the recorded witness. Thus `Z_{e1}` does not
commute with `C_{e1}`. It does commute with `C_{e2}`.

Take two ports, `H = diag(0, 1)`, and the non-scalar integer matrix

```
D = [[1, 1], [1, 2]].
```

The general identity already covers every scalar-entry `D`, including the
104-port pivot matrix of PR #3954. This check uses the 2×2 matrix above so
that the certificate does not depend on reloading that pivot. Both verifiers
rebuild the operators and test:

- `U_Z` commutes with `E0`;
- `U_Z` fails to commute with `L` and with `Pi L`, on 4 of the 16 basis
  directions, and `Pi` carries one commutator to the other;
- `U_{S_{e1}}` commutes with `L` and with `Pi L`;
- replacing the N-port chart by `S_{e2}` restores commutation with `U_Z`.

## What this does not decide

A uniform completion whose operator lies in the algebra generated by the
translations still commutes with every `C_u`, hence with `L` and `Pi L`.
The obstruction bites only when the common operator fails to commute with an
active port chart. PR #3954's positive control says "any" common operator,
and the reason it gives is that the encoding coefficients are scalars. That
reason applies to `E0` and not to `L` or `Pi L`.

The sentence does not by itself produce a matched physical caller. This note
does not construct the adjacent completed-call pair requested by discussion
#1166 comment 19034066, and it does not price owners, orientation, width, or
tape.
