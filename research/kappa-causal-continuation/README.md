## Reproduce the scoped evidence

Python 3 with NumPy is required for the bounded complex coefficient search.
The other new verification code uses the standard library. Keep assertions
enabled. From the recovered repository root:

```sh
python3 -B research/kappa-causal-continuation/validate.py
```

The validator checks this package's exact inventory, reconstructs the two
predecessor packages from their pinned closed inventories, and reruns the
new constructions in an isolated tree. It compares fresh artifacts with
the frozen results and then runs the 41-stage predecessor replay. It does
not rewrite predecessor sources. `--new-only` omits those inherited replay
stages while retaining source authentication; `--integrity-only` checks
inventories without running the probes.

`VALIDATION.json` is the definitive replay receipt, including exact stage
counts, comparison hashes, scope, and any failures. `INTEGRITY.json` binds
all other continuation files, excluding only itself and `VALIDATION.json`.
