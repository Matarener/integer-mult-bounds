# R437 COPY: linear-address dirty echo boundary and fixed replacement budget

This package resolves a changed COPY proposal following [PR3982](https://github.com/CrocSwap/integer-mult-bounds/pull/3982): remove its196 ordinary interchanges by coupling arbitrary dirty payload buffers, using linear ordered body-address ADDs and the existing reversed child. **A single proper-width reversed child cannot implement the all-class COPY contract in this linear-address, enlarged pointwise-gate model. A fixed two-rank-seven replacement also fails the exact paid moment before cleanup costs.** No new kappa is claimed.

The proof combines local-ring projector conjugacy with time-unrolled circuit dependency and triangular-group address orbits. It permits arbitrary Boolean gates at the same physical address, not only linear XOR echoes. Any dependency path crosses the one chronological child event at most once; its address word lies in `U` or `U W_l U`. At output address `e_n`, those words cannot inspect a source bit with leading index `n-1` when `l<n`. The valid shifted rank-seven projector on indices57..63, with arbitrary diagonal ancestor units, requires exactly that bit. This holds over every admitted local ring and every positive tensor multiplicity; it is not a tiny-cube extrapolation.

The source-bound profile has2592 COPY executions and deficit10272. Charging two rank-seven children on every COPY adds18144 rank mass. The optimistic moment is already **9513/9472 > 1 at exponent zero**, and increases for nonnegative saving exponent. All scans, cloning, readers, cleanup, preparation, stock and lifetime reserve costs are additional. This closes that fixed replacement proposal, not every possible way to escape the one-child obstruction.

The distinction matters:

- The dependency theorem requires a fixed payload-independent event/address schedule, coordinatewise payload gates, globally forward ADD pullbacks and at most one standard outer child. New address-dependent routing or global payload-controlled communication changes the alphabet. Affine address translations, including addition from a fixed nonzero header digit into a body coordinate, are also excluded: they destroy this orbit invariant and require a separate complete cost analysis.
- The two-child cost result concerns **two rank-seven children per every COPY**. It is not a theorem that two arbitrary children have total rank at least14. Mixed widths, adaptive schedules and the original good/fallback construction remain outside that conclusion.
- For an adaptive extra rank-seven child, the zero-exponent mass condition is `theta < 107/189`; the proof gives the stricter positive-exponent formula. The orbit witness does not establish the fraction of actual classes requiring extra work.
- The existing63 readers already share one private residual. Further constant fanout changes constants; packing independent sources increases operand volume. Neither alone absorbs the positive upper-tariff exponent gap. An actually growing same-source cohort needs its own equality, consumer and lifetime proof.

See [PROOF.md](PROOF.md) for the exact macro contract, full relative obligation ledger, all-f argument and optimistic recurrence. The one-event obstruction persists with arbitrary fixed dirty helpers even if restoration is waived, so mandatory restoration cannot evade it. Completed child semantics expose one transformed output and no extra payload channels. Prefixes, fresh rows and spectators remain separate physical fibers.
