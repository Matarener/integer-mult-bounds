Literal absorption of coded thin queries in the whole odd-E8 K primitive

Result
For every fixed dyadic lambda, the pinned whole-K native program has a literal
coefficient variant with exact normalized physical endpoint
  F_lambda = diag(D,D) L((1+lambda) C Q^-1)
           = F_0 L(lambda C Q^-1).
Its pinned backward companion similarly has endpoint
  B_lambda = diag(D,D) U(-(1+lambda) Q C)
           = B_0 U(-lambda Q C).
Here C is the actual odd-E8 K owner recoding and C^2=I; [C,Q]=0 is not assumed.
Only existing scalar ADD coefficients change. No paid child, monomial map, owned
field, input, output or phase path is added. For lambda=-1 all scalar ADDs are
omitted and the endpoint is diag(D,D). For lambda=1 one additional actual coded
thin preconditioner is absorbed without another Gaussian call. This is a local
sufficient compiler identity, not a complete multiplication bound or new kappa.

Actual source
The source is PR 5464 head 3981f9539e63630681f6903e3c6a50b3a0d2f2dd,
research/odd-e8-whole-k-native. SOURCES.json pins six retained files by exact
content hashes; scientific gzip payload hashes are separately recorded. The
phase-complete emitted root cube has 512 ports and 1,024 independent main inputs.
Its complete native construction uses two opposite selector-parity classes.
Each class spans a degenerate nine-space with rank-one restricted pairing and
radical dimension eight; the two classes are orthogonal and meet in that radical.
All original physical inputs x_p,y_p are arbitrary independent ground fields.
No helper or owned temporary is supplied or assumed free.

Let L_p be the pinned ordinary real normalizer, Q the central one-axis Gaussian,
D the product of the other 24 Gaussian axes. Its geometric coordinates are
  u_p=L_p Q^-1 x_p,  v_p=L_p y_p.
The source entrance Phi_[q_p] L_p Q^-1 is an emitted ordinary monomial despite
the virtual Q^-1 in the coordinate definition. Thus no incoming Gaussian service
is assumed. The original source's common-window scalar matrix is the actual
K_odd=(K1+K2+K3-K1 K2 K3)/2, where each K_i is an involution and the three owner
factors commute. It is symmetric, squares to I and has exactly 76 entries per
row: 12 entries of magnitude 1/4 and 64 entries of magnitude 1/16. Every nonzero
K_odd[r,s] joins opposite selector parities.

Exact frame and chronology proof
For a source parity epsilon, all X_s of that parity ascend from their own line
to the same literal Phi_S(epsilon) by an H8 path. Opposite-parity Y_r ascend from
ground to that identical Phi_S(epsilon) by an H9 path. The program executes every
such source and reader path before its cut ADDs, then executes
  Y_r += K_odd[r,s] X_s
for every nonzero coefficient. Sources are never overwritten. Every reader
retains its arbitrary old value with coefficient one. Only after all these ADDs
do source H16 and reader H15 exit paths run. The two parity windows use disjoint
source/reader role sets and therefore do not invalidate each other's data.

Replace every displayed coefficient by (1+lambda) K_odd[r,s]. The exact same
literal source/reader frames still match; all 1,024 independent geometric input
columns give
  u'_s=u_s,
  v'_r=v_r+(1+lambda) sum_s K_odd[r,s] u_s.
All paths, normalizers and absolute phase opcodes are retained literally. Their
pinned physical identities yield the normalized endpoint claimed above with
C_rs=K_odd[r,s] L_r^-1 L_s. This is genuine delayed execution of a coded input
preconditioner through a Gaussian window, rather than an unexplained frame tag.
For lambda=-1 the zero-coefficient ADDs are deleted as actual instructions.

The inverse-transpose companion is emitted in the same chronological order from
the source. Each real scalar ADD swaps source/target and negates its coefficient;
every monomial and positive Gaussian child has the pinned literal inverse-
transpose conversion and fixed boundary maps. Since a two-bank shear has square-
zero off-diagonal block, inverse transpose is linear in the scalar multiplier.
Thus scaling its existing ADDs by the same 1+lambda gives the stated B_lambda,
with no commutation of C through Q. Its concrete actual chart names have the
pinned conjugate prefix, and its ADDs still join exactly matching charts.

Distinction from an uncoded query
For the same external port p, X_p and Y_p enter opposite S9 windows. Their chart
transport has Gaussian rank two, as the pinned source checks; it is not an
ordinary same-frame ADD. Consequently this construction does not absorb an
uncoded y_p+=Q^-1 x_p service. It absorbs the actual C Q^-1 code because every
nonzero coefficient joins the opposite ports that truly meet in one window.
No same-rank or equal-dimension retag is used.

Reciprocal code identity
Define b=C Q^-1 and a=Q C. C^2=I gives a b=b a=I by adjacent cancellation,
without commuting C and Q. Thus abstract thin shears have the exact relation
  L(b) U(-a) L(b) = [[0,-a],[b,0]],
whose square is -I. For two stages i,j the ordered ratios
  b_j b_i^-1=C_j C_i,
  a_j^-1 a_i=C_j C_i
are ordinary owner recodings. These are sufficient algebraic interfaces for a
future actual coded controller. They do not prove that different stages' codes
commute, that a global controller closes, or that all target gauges unload.
Native F_lambda and B_lambda also perform their D diagonal actions; they must
not be substituted for free thin shears in a word that ignores those actions.

Complete local operation counts
For the emitted root cube, every variant keeps exactly
  512 H8 + 512 H9 + 512 H15 + 512 H16
paid children. Forward ordinary monomials remain exactly
  7,680 P + 7,680 D + 3,072 X + 3,072 phase.
Backward ordinary monomials remain exactly
  7,680 P + 7,680 D + 6,656 X + 3,072 phase.
If 1+lambda is nonzero, there are 38,912 scalar ADDs. If it is zero, there are
zero scalar ADDs. There are no helpers, new independent inputs, owned fields,
COPYs or CLEARs in any variant. Coefficients remain fixed dyadic constants;
actual precision and machine-level scalar implementation must still be paid.
For lambda=1 their magnitudes double and denominator exponents decrease by one;
this is not a hidden additional arbitrary-precision division. The per-reader
component-l1 scalar prefix bound is at most 1+7|1+lambda|. All physical maps and
Gaussian children are unitary; complete global rounding propagation remains an
outer caller obligation. No recursive paid histogram is improved by this local
identity alone.

All-width scope and evidence
The proof uses only linearity at actual common frames, fixed scalar coefficients
and composition of the retained lifted unary operators. At width f, every scalar
coefficient is applied once and each one-copy scalar phase is lifted as i^(f theta).
The proof never tensors an owner matrix sum or expands Q_f into a constant number
of monomials. Its all-width physical scope is inherited from the pinned generic
phase/frame proof, not inferred from the finite checks below.

Run python3 -B verify.py using Python 3.12+ and the standard library. It checks
all source hashes, all 262,144 entries of the scalar K square over exact integers,
and actual frame/cost/1,024-column replays in both orientations at lambda values
0,1,-1,-2,1/2. Wrong scalar coefficients and wrong physical charts are rejected.
The transformed non-ADD event lists agree literally with the original native
paths, so no phase or child change is hidden. RESULT.json records all ten cases.
This does not rerun every Clifford phase proof, all 2,744 cube instances, a native
machine compiler or any Lean kernel. The source construction and full generic
family proof remain explicit pinned inputs. For the whole family the same
constructor-level coefficient replacement applies to every disjoint cube.
