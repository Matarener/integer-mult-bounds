# Programmable native stages, coded-thin fusion and exact dyadic precision

This package closes three constructive interfaces from the preceding Word RAM/native work. **It does not establish a superior κ or a complete multiplication caller.** The terminal all-width central-Q gauge remains unresolved, and no ideal invoice is presented as an admitted bound.

1. [Programmable native stage](native/INTERTWINER-PROOF.txt): an actual event emitter changes the same-frame cross-parity transfer to any rational amplitude while preserving the Gaussian paths and all 1,024 independent input columns. Five amplitudes, including zero, are checked; output files refuse overwrite.
2. [Coded-thin fusion](fusion/PROOF.txt): an additional actual C Q⁻¹ transfer is absorbed into existing native ADD coefficients, with no additional Gaussian child, field or phase path. Both orientations and ten cases are checked. This is not an uncoded I Q⁻¹ request.
3. [Exact precision](precision/PROOF.txt): the actual dyadic forward/backward streams admit fractional storage B = g + ⌈25f/2⌉ + 4, with explicit magnitude and signed-payload bounds. [Composition](precision/COMPOSITION.txt) gives constructive exact-grid propagation for a completely emitted dyadic caller. Arbitrary rational amplitudes require their own rational/rounding implementation; the dyadic theorem does not cover non-dyadic denominators for free.

## Exact economic boundary

Each 512-port local module retains paid profile {8:512, 9:512, 15:512, 16:512}, no helper target bank and no new owned field. Nonzero amplitude uses 38,912 actual scalar ADDs; amplitude zero deletes them. Scaling is paid ordinary work, not a zero-cost arithmetic oracle.

Ordinary pre/post codes give a paired letter Lᵢ = diag(CᵢDᵢ,DᵢCᵢ), satisfying AᵢQ = QBᵢ. This lets Lᵢ commute with the standard thin shears. However the ordinary closing swap of the one-stage controller produces diag(BᵢQ⁻¹,AᵢQ). The second branch decodes by an ordinary code; the first generally does not. This final placement issue is not removed by a proof-only conjugation or by the one-column expansion of Q. Independent worker checks agree. We do not advertise the earlier ideal p19 arithmetic as a new bound.
