## Exact first mismatch and mapping class

Let A and T be the eight selected sets in the QQ16 packet, U their
96-port complement, R its actual 8-by-112 centre matrix, and K=R^T/4.
The independent formula check gives

```
f = R x
X'_U = x_U - K_U f
X'_A = K_A R_T x_T
X'_T = K_T f
Y'_U = y_U + X'_U
Y'_S = y_S + x_S - X'_S       (S = A union T)
```

In particular, selected gauge44 returns `X'_0=x_0`, whereas QQ16 returns
`X'_0=(x_76-x_81+x_87+x_92)/2`. Input x_0=1 with every other data and helper
symbol zero is already decisive.

This includes permutations, signed/diagonal role gauges, and arbitrary
invertible constant mixing of those roles. A physical correspondence whose
restriction is such an invertible P also fails this necessary test.
Different entrance and exit encodings, a noninvertible relation, a change
of native representation that does not preserve the tested subspace, and
paid adapters are outside this class. No claim of a complete program
bisimulation or all-purpose representation obstruction is made.
