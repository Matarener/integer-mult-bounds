# Exact quadratic-phase interface certificate

Prepared by Chris R / Clear1nsight with substantial OpenAI Codex assistance.
Apache-2.0. This is an independent finite audit of Dugongue's PR3945, not a
claim that its native checker is wrong or a new multiplication theorem.

## Domain and conventions

The logical coordinate space has dimension 512, indexed by `x in F_2^9`.
Write `X^u |x> = |x+u>` and `Z^v |x> = (-1)^(v dot x)|x>`.
Products act right to left. Every scalar coefficient below is an exact Gaussian
integer divided by an explicit power of two. The verifier uses Python integers,
not floating point, sampled states, the predecessor tableau compiler, or numpy.

For invertible binary columns G, set Q_G = I + G^(-T)G^(-1) over F_2.
Its specified Z4 quadratic refinement is

    q_G(y) = sum_i (Q_G)_ii y_i + 2 sum_(i<j) (Q_G)_ij y_i y_j mod 4.
    K_G |x> = i^(q_G(Gx)) |Gx>.

The source's canonical frame T_U is K_B C_[r] K_B^adjoint, where B completes
the given ordered basis U by successive coordinate vectors, r=dim U, and
C_j=((1+i)I+(1-i)X_j)/2. Its inverse conjugates the Gaussian coefficients.
The local warp is T_E K_G^(sign) T_U^adjoint. The cold terminal residual is
T_E, since its entrance U is empty. These definitions preserve global phase.

The new evaluator finds inverse columns by exhaustive permutation inversion,
constructs the quadratic form from their binary dot products, and propagates
sparse Gaussian numerator dictionaries one coordinate at a time. It independently
decodes a serialized monomial's binary rows, translation, Z4 linear coefficients,
symmetric quadratic rows and global phase. A compiler recipe is R, C_[rank], L
in chronological order. Reference recipes are generated by the frozen source
compiler; the verifier never imports that compiler or its dependent checkers.
A shared mathematical convention is unavoidable and is stated above; no claim
of independently deriving the construction's physical model is made.

## Complete finite interface equality

Both frozen providers have exactly 26 helper terminal extensions from width 4
to width 5; every one has the same empty entrance in old and new words. Their
first helper is 277:

    old [388,75,41,26]
    new [388,74,40,26,1]

Exactly 5 of the 72 warp records per provider change their entrance/exit frame;
the binary map and register identity are unchanged. Another 47 records change
only their chronological index. We compare both signs of each genuinely changed
warp, at old and new interfaces. We do not confuse these 47 index shifts with
new native operators.

The 144 source occurrences deduplicate to 40 exact descriptors: 24 residuals
and 16 signed warp interfaces. Each descriptor includes the actual ordered
frames and, for a warp, its binary columns and sign. Coverage is reconstructed
from the four frozen words by verify.py, independently of the recipe generator.
Every descriptor is evaluated on all 512 input basis columns, comparing every
output coefficient after exact dyadic normalization: 20,480 column equalities.
RESULT.json commits a digest of the normalized complete action of each class.

Equality on a basis proves equality for arbitrary complex input, hence for any
arbitrary dirty coordinate state at this local interface, including relative
and global phases. It also tensors with untouched registers. This does not
by itself reprove the whole emitted program's chronological composition,
all dirty-buffer restoration, or the supplier contract. The old terminal
recipes are calibration controls; they are not proposed substitutes for the
promoted width-5 interfaces. All signed warps have zero recursive rank; the
residual recipe ranks are exactly 4 and 5 respectively. Zero recursive rank
does not mean zero physical or uniform precision cost.

## Why the binary inverse is insufficient: the lift cocycle

The binary symplectic action of K_G on Pauli labels (x,z) is

    M(G) = [[G, 0], [G + G^(-T), G^(-T)]].

Direct multiplication gives M(H)M(G)=M(HG). This does not determine the signed
lift. The exact phase difference

    d_(G,H)(x) = q_G(Gx) + q_H(HGx) - q_(HG)(HGx) mod 4

is an even linear character, 2 ell dot x. One way to see this is to use
q_Q(a+b)-q_Q(a)-q_Q(b)=2 a^T Q b mod 4, noting that all binary operations
inside q use XOR. The composed quadratic polarizations cancel under the
identity for M. The parity cancels as well; since d(0)=0, the remaining even
additive function is exactly a binary linear character. Consequently

    K_H K_G = K_(HG) Z_ell.

The certificate calculates ell from the nine coordinate inputs and then
checks this identity on every one of the 512 inputs for each ordered pair of
the four actual changed binary maps. These 16 algebraic pair controls are not
asserted to occur adjacently in either word.

For an actual map in the changed interfaces,

    G = [1,2,8,32,44,128,59,66,489],
    G^(-1) = [1,2,28,4,79,8,130,32,431],

our exact certificate finds

    K_(G^(-1)) K_G = Z_256.

This is a relative sign on exactly 256 of the 512 basis coordinates, not a
removable global phase. In particular the input x=256 is sent to its negative
by this binary-identity product. The phase-correct inverse is

    K_G^adjoint = Z_256 K_(G^(-1)).

The source uses the correct adjoint; it passes the signed audit. This witness
rejects the tempting implementation shortcut of substituting the canonical
lift of the binary inverse. It is a precise source-bound warning, not a
counterexample to the author's construction. A physical implementation of the
Z correction needs its own paid contract; this audit supplies an exact local
operator identity and assigns no free implementation tariff.

## Failure controls and limits

Fourteen controls reject wrong residual left/right global phases, warp global,
linear and quadratic phase changes, translation, signed inverse, terminal,
singular binary map, wrong charged residual rank, swapped residual wrappers,
an omitted descriptor and a relabelled provider. A global-phase mutant preserves
all 512 permutation columns while failing the exact phase comparison. Every
serialized monomial is also composed with its independently decoded inverse
on every input column. Normal and optimized Python must give the same result.

The frozen author NATIVE receipts bind the literal changed word hashes and
native source hashes and report all five native stages passed. Their status
is authenticated historical evidence. Fresh equality here covers the stated
40 classes only. Full changed scalar frame-transition recipes, the complete
CLIFFORD-RECIPES serialization, whole emitted program, ordinary/outer release
replay, and all-size or uniform resource admission remain outside this proof.
See LEDGER.json and RELEASE-BINDING.json for the exact inherited/unknown split.
