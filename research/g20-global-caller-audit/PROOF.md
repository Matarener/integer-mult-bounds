## Exact local interfaces

The local native proof gives the action on arbitrary F2-valued functions. Let
T_P denote transport by the paired-address involution H_P for projection P.
For each of the 111 ports, the actual entry/exit frames are

```

```

The checker reads these frames from the emitted word. It checks L perpendicular
to U and constructs an invertible matrix W whose first column spans L and whose
other seven columns span U. It checks both inverse products and
`P_L W = W diag(1,0,...,0)`. The 111 matrices and inverses are in RESULT.json.
Their denominator least common multiple is 4. The full and zero frame identities
are covered by the authenticated native theorem. Thus W sends the local line to
one coordinate and its complement to the other seven coordinates.

Use the same W on both paired address halves. The paired sums and differences
then obey the same conjugation. Put the first coordinate in the common central
line and the other seven in the block for this stage. Different full stages use
disjoint blocks. The central line plus 18 blocks has dimension 127. Extend each
map by the identity on unused coordinates. The maps remain invertible modulo
any q coprime to 4. Together with the local theorem, q coprime to 12 suffices for
these rational identities. This statement does not choose the compiler's prime
or prove a physical tape tariff.

Write tau for the central involution and sigma_s for the stage involution. The
local theorem and these actual endpoints give

```
x' = T_L T_full x = sigma_s x
y' = T_U y + T_full x = sigma_s y + sigma_s tau x.
```

The two address maps commute and square to the identity. Over F2 this block
operator is itself an involution. Therefore the same released local word can
serve either controller orientation; the direction only exchanges the two banks.
This checks a required implication that a scalar RAW endpoint alone cannot give.
