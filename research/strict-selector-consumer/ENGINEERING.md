## Power of Ten inspection

1. All new code has structured exits and context-managed release; no recursion. ExitStack owns numerical words, templates, ring constants and bridge Counts. strict_call closes all plan Counts in finally. Factory cleanup and interrupted inherited macros remain explicit premises.
2. Scientific loops are bounded by eight full cases, seven geometry cases, eight no-fit cases and two callee failures. Origin scans have explicit finite volume bounds inherited from fixtures. New binary scans terminate at canonical delimiters, with finite lengths fixed by the input Counts and exact power bounds. Role inventories cap each arena at 256. Source extraction permits 28 regular consumer members, two arithmetic modules and four shared-runtime comparisons, each bounded in bytes. CLI children have 30-second timeouts. The external orchestration uses bounded waits and no scheduler.
3. Managed Python allocation is a deviation. It occurs in Count arithmetic, dynamic template words and checker provenance maps. Source bytes are capped at 500000, consumer members at 200000, arithmetic modules at 20000, metadata/input inventories and fixtures are bounded, and only one replay runs at a time. The logical numerical inventory is four arenas of at most 256 words, plus four templates, with values bounded as in PROOF.md. No fixed-allocation physical C0 or Python heap guarantee is asserted. Replacing this checker allocation with a sealed physical root requires a separate proof and complete cost.
4. Every new function is at most 60 formatted physical lines. Shape observations and fallback endpoint arithmetic are separate meaningful checks. The final session function-length receipt records exact lengths.
5. Meaningful need/require contracts remain active under -O. They check source hashes, canonical symbols, high margins, numerical role ownership, Count preservation, full endpoints, call chronology and cleanup. No assertion-based acceptance is introduced.
6. State lives in a single call or context. Input Counts/payload are borrowed; returned payload is owned. Existing callbacks and test patches restore state in finally. Shared Git and reservation changes use their separate process-held OS locks, outside computation.
7. Every source read/write and subprocess return is checked. A callee raising at entry is tested at both calls. General allocation failure inside old numerical constructors is unclaimed. The initial undersized template run exposed that inherited rejection path and is retained as a diagnostic rather than counted as successful cleanup coverage. A callback with larger live-role/index requirements must supply a different proven capacity.
8. Python module loading/import dispatch is a bounded loader deviation. Exact source bytes are authenticated before import; cold namespaces, private bytecode paths, regular exclusive copies and isolated CLI entry are checked. No dynamic code generation is introduced in science. The one -c CLI child only injects a named module for a rejection test. Full arbitrary hostile-process import-state protection is unclaimed.
9. Completed factory/F callback dispatch is the deliberate semantic boundary. The tested targets are the direct atom-swap model and the pinned source Node/Driver. Their actual endpoints, borrowed metadata and chronological returns are checked. This is not a proof for arbitrary callback implementations. Data access is otherwise direct and shallow.
10. Scoped Ruff E4/E7/E9/F/B/I/UP and formatting, warnings-as-errors compilation, registered Python 3.12 normal/optimized science and actual optimized CLI controls are required. Shared historical suites, Lean, Docker, full selected replay and hosted CI acceptance are unrun. The package runner adds private bytecode isolation. Final publication/source-history and actual committed Git-free export checks bind the result to the published bytes.

The source runtime, frozen inputs and prior branches are unchanged. Session cleanup never chmods an interpreter or export alias, never follows a symlink and preserves inherited empty directories and passive app services. This file records bounded deviations, not universal compliance claims about frozen predecessor code.
