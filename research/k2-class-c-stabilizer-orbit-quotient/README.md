# Class-C V2 stabilizer orbit quotient

**Status: scoped partial result.** This is a sound candidate reduction for one first-flat orbit in the open class-C four-flat checker request. It does not kill a residue row, complete an `s4z` run, or change the selected multiplication result.

## Result

For the config `6554 = (6,5,5,4)` in [Discussion #2954](https://github.com/CrocSwap/integer-mult-bounds/discussions/2954), use the `s4z` ordering `(a,b,c,d)=(5,6,4,5)`. Let `P` be the 112 pinned labels in `F_2^9`; for a subspace `V`, let `Lambda(V)` be the set of P112 indices whose labels lie in `V`. Let `G` be the group generated by the 12 permutations in the pinned `gens.txt`.

The verifier establishes, by exact finite checks, that:

1. Each generator is induced by an invertible linear map on all of `F_2^9`, checked on the 112 labels and all 512 vectors.
2. Each generator permutes all 18,100 typed rows of the pinned `data88.txt` catalog by the rule `Off(h) -> g(Off(h))`.
3. For each such permutation, `REAL_MAPS.json` supplies one exact invertible rational `8 x 8` linear map on `Q^8` carrying every listed one-dimensional or two-dimensional direction space to its catalog image. The verifier checks each matrix exactly against every row; the matrices are finite proof witnesses, not floating-point evidence.
4. The five-flat with RREF basis `(4,8,32,210,321)` is fixed by the first five generators. Its full G-orbit contains 2,688 distinct root masks; conjugating the subgroup to the least root-mask representative (mask `197427`) gives a subgroup of that representative's stabilizer.
5. Among all six-dimensional subspaces of `F_2^9`, the 788,035 RREF subspaces induce 776,806 distinct P112 root masks. The conjugated five-generator subgroup partitions those masks into exactly 47,850 orbits. One V2 representative per orbit reduces this first-flat candidate list by the exact factor `776806/47850 = 16.234190177638x`; the largest orbit has 32 masks.

The flat index masks in `s4z` are these intersections with P112, so duplicate six-flats with the same root mask are deliberately counted once, as in the checker.

## Why the quotient is sound

For any subgroup `H <= G` fixing a chosen first flat `V1`, the map `V2 -> g(V2)` for `g in H` is a bijection on the V2 mask universe. The checked label action gives `Lambda(gV)=g Lambda(V)`. The checked direction action maps every tested `Off(h)` to the corresponding support, and the checked invertible rational map preserves real span dimension. Therefore the set of qualifying directions, the feasibility of the remaining two-flat covers, and the final span rank are invariant under `H`. Every V2 orbit has the same result, so retaining one representative per orbit cannot change the checker verdict.

The numerical orbit count is a source-bound exhaustive enumeration. The safety proof for applying the quotient is the equivariance argument above plus the finite checks that bind `G` to the listed catalog. The claim is conditional on the upstream statement that `data88.txt` is complete for directions with `|Off(h)| <= 88`.

## Scope and limits

- The count applies to one G-orbit of five-flats, for the `(5,6,4,5)` ordering of config `6554`. It does not give the aggregate reduction across all first-flat orbits.
- The verifier uses the least root-mask representative convention to make the conjugating witness deterministic. The pinned `s4z.c` uses union-find roots instead; deriving the conjugate subgroup for each existing representative or adopting the least-mask convention is integration work.
- No `s4z` pair closure was run. The 16.234x number is a candidate-count reduction for the V2 mask set, not a wall-clock speedup.
- No row in `rows17.csv` is killed. No part of the conditional RRC result is verified here.
- No supplier, lower bound for all multiplication algorithms, or `kappa` improvement is claimed. The reviewed selected result remains `kappa = 0.001672660197076918` in the scoped, conditional construction.

## Reproduce

From the repository root, after the package and its inputs are committed:

```sh
python3 -B research/k2-class-c-stabilizer-orbit-quotient/verify.py
python3 scripts/research_package.py --package research/k2-class-c-stabilizer-orbit-quotient --check-only
python3 scripts/research_package.py --package research/k2-class-c-stabilizer-orbit-quotient
```

The verifier uses Python's standard library, exact integers, and `fractions.Fraction`. It checks the three declared source hashes and includes rejecting controls for a non-permutation, a bad support action, and a singular real-space map. The registered replay allows at most 600 seconds.
