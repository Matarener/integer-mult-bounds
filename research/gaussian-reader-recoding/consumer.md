## 2. A clean-bank query tile for the actual raw provider

Let J₀ = [[0,1],[-1,0]] be the ordinary signed swap on the two main banks. Let c be any fixed ordinary operator polynomial in J = Q². In particular, c = 1 and c = J are allowed.

**Theorem 1.** One raw invocation, exactly 112 clean-bank Q⁻¹ queries and eight additional Q mode requests implement

    (x,y) ↦ D U_c(Q)(x,y),
    U_c(Q) = [[0,1],[-1,cQ]],

while returning the eight mode inputs as independent R jobs and retaining all 400 other helper jobs. Every main and helper input remains arbitrary. Its complete paid and helper profiles are

    P_tile = P_raw + 120 H1,
    H_tile = H_aut + 8 H9.

No query on a contaminated bank is assumed.

**Proof.** Execute the raw provider, then apply J₀. The new main fields are

    X = D y,
    Y = −D x + R y − R W h.

The clean field is now literally X, the outgoing physical field queried by the forward thin-query orientation. Apply Q to the eight mode fields. They become Rh − RZy. For each port j, compute t_j = Q⁻¹X_j in owned storage. Then Jt_j = QX_j = Ry_j. Accumulate the ordinary Z contributions Z(Jt) into the mode fields and simultaneously add (c−1)Jt_j to main Y_j. The mode fields become

    Rh − RZy + ZRy = Rh.

Add W times these completed mode outputs into Y. The source identity WR = RW cancels the original −RWh. Thus the main endpoint is

    X = Dy,
    Y = −Dx + Ry + (c−1)Ry = −Dx + cRy,

which is the claimed D U_c(Q). No D/W or D/Z interchange occurs. Each t_j can be read and cleared after its own contributions, so a sequential owned query buffer suffices, in addition to finite scratch for the ordinary maps and the native source's owned fields.

The 112 source queries and eight mode requests are the only added Gaussian children. All eight returned Rh fields depend separately on their original h inputs. The source's other 400 helpers are untouched. All signs, J corrections and monomial maps remain literal. The same composition identities hold under the source's all-column interpretation at every positive digit width. ∎

The tile changes the controller's logical matrix. Adding J₀ after a full call and retaining the old controller factorization is incorrect. In particular this proof does not turn the original wrong-bank thin query into a free repair while claiming unchanged path targets.

## 3. A fully closed three-tile word

    productive: 224 H25 + 3(H_aut + 8 H9).

**Proof.** Every D_s commutes with Q and all scalar main-bank matrices, so factor their product from the main word. Direct symbolic multiplication gives

    U_e U_d U_c =
    [[−dQ, −1 + cdQ²],
     [1 − edQ², −cQ − eQ + ecdQ³]].

Set c = e = 1 and d = J = Q². Since Q⁴ = I, both off-diagonal entries vanish; the diagonal is −JQ = −Q⁻¹ and −Q. This equality retains the actual even power and phase.

The three D blocks contain 24 independent fresh directions and the surviving Q is on the separate common central direction. Each main output therefore has rank 25, after its whole-job input/output monomial normalizers. No input fields are identified. Theorem 1 gives each local helper and paid multiset, and different invocations use different original helpers. The two reciprocal orientations follow from the completed independent Gaussian endpoint, its explicit even-power inverse normalizers and the ordinary transposition construction. ∎

This is a complete clean-bank controller macro, with an exact Laurent identity and no missing boundary consumer. Its invoice does not fund an improved supplier. ## 5. A larger ordinary two-sided stabilizer of the rank-nine Gaussian

The next positive identity concerns an actual pair of address operators. It is not a rebase of the whole coupled provider. It explains a possible representation change while keeping the missing W/Z compatibility explicit.

For one address column let C_v = aI + bX_v, with a = (1+i)/2, b = (1−i)/2. Put

    R = product_(j=0)^8 C_ej,
    D = product_(j=1)^8 C_ej,
    χ = e₀ + e₁ + ... + e₈,
    Qχ = C_χ.

**Theorem 4.** There are explicit ordinary complex monomial maps L,T such that

    L R T = R,
    L C_e0 L⁻¹ = Qχ,
    L D T = R Qχ⁻¹.

Consequently R Qχ⁻¹ is one rank-eight Gaussian request between explicit ordinary monomial boundaries. These identities lift to every positive column width with their exact phase.

**Proof.** Let S be the diagonal map S e_x = i^(−wt(x)) e_x and H the normalized real Walsh transform on nine bits. Entrywise expansion of the Gaussian kernel gives

    R = ζ S H S,

where ζ is its fixed scalar phase. Choose a binary invertible G with first column χ and the other eight columns any basis of the even-weight hyperplane. Such columns exist because χ has odd weight and hence is outside that hyperplane. Let P_G e_x = e_(Gx), and define

    L = S P_G S⁻¹,
    T = S⁻¹ P_(G^T) S.

The elementary character identity P_G H P_(G^T) = H yields LRT = R with the original ζ unchanged. Both L and T are explicit permutations with diagonal fourth-root phases.

For y = Gx, direct conjugation of X_e0 by L changes the basis label by χ and contributes phase

    i^[1 − 9 − 2x₀ + 2wt(y)].

The parity of wt(y) equals x₀: only the first column of G has odd weight. This exponent is divisible by four. Hence L X_e0 L⁻¹ = Xχ exactly, with no residual scalar phase. The C identity follows by its displayed linear expression in I and X. Finally D = C_e0⁻¹ R, so

    L D T = (L C_e0⁻¹ L⁻¹)(LRT) = Qχ⁻¹R = RQχ⁻¹.

The maps are finite binary permutations and fourth-root diagonal phases. Their f-column lifts preserve composition; the equality has phase exactly one in each column, so no unrecorded width-dependent sign appears. ∎

For example, choose the other columns e₀+e_j for j = 1,...,8. These form an explicit basis of the even-weight hyperplane, so the construction does not rely on a matrix-selection oracle. Its indexed arithmetic and phase passes remain real finite native work.

The actual source W and Z commute with R and with Qχ, by the retained per-column characteristic-translation symmetry. Hence they commute with RQχ⁻¹. This does not show that whole-provider application of L,T preserves W and Z: those couplings are transformed too. In particular, a common input map T_y that preserves the actual projector Π = WZ/14 and conjugates the new central Gaussian back to the old one would imply [Π,Q] = 0 whenever [Π,Qχ] = 0. Such a condition cannot be inserted as an assumed unknown gadget. No actual compatible provider rebase is supplied here.
