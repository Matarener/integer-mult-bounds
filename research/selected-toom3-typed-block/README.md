# A typed boundary test for one selected Toom-3 candidate

**One actual nine-climb group is an invertible 4,608-dimensional linear map.
It cannot factor through the 3,072-dimensional input boundary of a same-width,
Toom-only coefficient module. The obstruction extends to rational encoders
and rational decoders by transcendence degree. No replacement or new kappa
is claimed.**

This answers the first source-binding experiment left by Gonzalo Mier's
[PR #3974](https://github.com/CrocSwap/integer-mult-bounds/pull/3974), head
`23bb4de61d629e3f103a65baa7882b34042ab10f`. It pairs fast bilinear algorithms
with linear-algebraic information bounds and typed reversible interfaces.

The first forward phase-A group contains registers
`546,560,547,568,548,558,549,570,464`. Eight climb from the empty frame to
`[459]`, one to `[75]`. The actual incoming forms have a nine-by-nine identity
minor, so arbitrary dirty inputs cannot be identified with only three
coefficients per operand. We reconstruct both 512-dimensional Clifford maps
on **all 1,024 basis columns**, including phases and halving, and independently
check their exact Gram matrices. The selected block rank is **4,608**.

| Explicit coefficient interface | Capacity in scalar dimensions | Deficit |
|---|---:|---:|
| One variable coefficient triple, one fixed factor | 1,536 | 3,072 |
| Two affine variable coefficient triples, decoder may read both | 3,072 | 1,536 |
| Five product blocks, affine or rational output decoder | 2,560 | 2,048 |
| Actual selected nine-payload boundary | 4,608 | 0 |

The rational extension uses `K(x)=K(Fx) subset K(E(x))` and transcendence
degree, or equivalently the generic Jacobian chain rule. Decoder denominators
must remain nonzero after substitution and all input-dependent side data
must be counted. The original affine-encoder result permits an arbitrary
decoder; the rational-encoder extension requires rational decoding.

The obstruction assumes outputs receive data only through the coefficient
blocks. General circuits may retain original inputs or use bypasses; five
child calls alone do not imply this factorization. The deficits are algebraic
information dimensions, not native cost lower bounds. Wider coefficient
spaces and changed interfaces remain open. Noncommutative Toom convolution
itself remains valid with central interpolation scalars.

[PROOF.md](PROOF.md) gives the exact contract, source event indices, input
forms, proof, missing obligations and expansion decision. [RESULT.json](RESULT.json)
is regenerated by the bounded verifier. **Zero source blocks are replaced;
selected kappa remains 0.001672660197076918.**

## Reproduce

```
python3 scripts/research_package.py --package research/selected-toom3-typed-block --check-only
python3 scripts/research_package.py --package research/selected-toom3-typed-block
```

The two registered runs (normal and optimized Python) bind the selected
archive, reconstruct the first eligible group, derive its input minor, check
all basis columns and exact Gram matrices, compare the result, and exercise
six failure controls, including a legal birational-coordinate fixture and
rejected lost-scale/undefined-denominator boundaries. They do not replay the complete selected supplier.
The canonical-frame evaluator is retained predecessor code; the recipe
interpreter and sparse Gram check are new separate implementations. No
independent human or formal-kernel acceptance is claimed.

## Open next questions

Can one explicit bypass or wider-coefficient construction preserve the nine
independent dirty payloads while delivering five **legal** children, with
complete frames, precision, output and scratch restoration costs? First write
that interface and verify all nine outputs on basis inputs, then compare the
complete paid profile against the selected supplier. The present Toom-only
contract is paused; another larger event-window census cannot repair it.
The checked alternative `I_8 tensor T_[459]` packs the first eight lanes into
a 4,096-dimensional, twelve-bit payload, but its Fourier rank remains one.
Its larger native call and full invoice remain open. Structured obligations
and the stop rule appear in `TASK.json`.
