## Why arbitrary Clifford frame gauges are covered

In the full2mf binary symplectic space, use the isometry-invariant metric
`d(U,V)=mf-dim(U intersection V)` on mf-dimensional subspaces. At each
fixed ADD both operand frames share the same Lagrangian L_v. For an edge
G from u to v its relaxed tariff is `d(L_v,G L_u)`, equal to the native
B-rank of the corresponding frame-conjugated segment. Splitting that
segment cannot reduce total rank mass below this value.

At an ADD, either straight or crossed path pairing is valid because every
incident endpoint uses that same L_v. It does not assert a scalar swap of
independent values. Pulling back successive path frames by chronological
partial products and applying the triangle inequality gives the rank of
the path holonomy as a lower bound on its edge tariffs. Exhaustive
edge-disjoint paths can then be summed without duplicate charges.

This proof places no tensor-product restriction on the candidate frame
gauges: they may mix all mf coordinates. Only the fixed source holonomies
need the saved tensor-plus-scalar form, so their ranks scale by f. Physical
input/output frames are fixed at Z; any mentioned monomial boundary gauge
is within the Clifford/Z-preserving model. Arbitrary changed nonlinear
boundary operators are not silently treated as Clifford Lagrangian gauges.

The source rank bills attain the floors, proving sharpness in this
mathematical fixed-graph rank model. Some path ranks can exceed the parent
