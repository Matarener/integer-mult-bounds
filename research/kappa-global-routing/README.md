# Mutable function routing and scheduled complex cleanup

**Verified local improvements and explicit next interfaces; no new multiplication κ.**

The complete account is [REPORT.md](REPORT.md). This scope carries forward all
earlier unmerged research without changing frozen predecessor files.

The main positive results are:

- An h19 eight-output BIT producer with **76 dirty helpers and 16,875 ADDs**,
  compared with 10,228 helpers and 50,500 ADDs for its uncoded joined-tree
  comparator. It groups sources by the function needed at the consumer.
- A complete local complex word with **all 91 cleanup roles borrowed from
  existing registers**, no external cleanup bank, and all 408 persistent
  helpers restored. A paid reversible helper basis reduces the full scalar
  allowance to **115,830 THREE / 115,808 FOUR**, both directions. The recursive
  child profiles remain unchanged.
- Explicit source/contact probes that distinguish real ways to change the
  prior model from retuning a rejected fixed-history route. Their native
  construction and whole-supplier costs remain separate obligations.

## Reproduce

Apply the cumulative overlay to the supplied compact base first. From the
resulting repository root:

```sh
python3 -B research/kappa-global-routing/validate.py \
  --output kappa-global-routing-validation.json
```

Python 3 and NumPy are required. The driver authenticates this complete scope,
the preceding causal checkpoint, and the two older closed dependency
inventories. It runs all new stages in an isolated copy, removing their outputs
before regeneration and comparing complete canonical proof payloads afterward.
It records compression-container byte identity separately from mathematical
payload equality.

The prior 55-stage receipt is authenticated and reused with unchanged source
bytes. Those stages are not counted as newly run. This is a research-module
replay, not a selected-result cold replay or a complete multiplication theorem.
Individual generators and audits are documented in their respective folders.

## Open next questions

The immediate κ-relevant tests are a BIT source producer that can legally
supply a second output block, and a complex contact at one of the new joins
that eliminates more recursive cost than its split source and carrier paths
add. Every proposed word must restore arbitrary borrowed contents and price
all source, output and helper transitions. The report gives the exact existing
allowances and stop conditions.

Keep the combined complex word as the implementation baseline for caller
ownership and precision work. Further scalar reductions need a concrete
