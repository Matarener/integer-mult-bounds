# Complete caller for the shorter G20 word

This package installs the released PR5828 word in all 18 physical calls of
PR5708. It emits the full global stream, query source records, call intervals,
private lifetimes and productive-owner list. It closes the global compilation
obligation left open by PR5807 and PR5828. Their local savings are credited
predecessor work; this package does not count them as a new local discovery.

| Global events | 317,004 | 311,244 |
| ADD events | 249,240 | 243,480 |
| Paid queries | 56,223 | 56,223 |
| Productive inputs | 11,022 | 11,022 |
| Private slots / peak live slots | 48 / 48 | 48 / 48 |
| Positive majorant bit length | 384 | 379 |
| Coarse finite primitive bound | 952,838,314,401 | 952,838,302,881 |

The complete stream realizes all 5,760 ADD savings from the two local
constructions. The retained positive fee counts each saved ADD once as a
field scan and once as a raw event. Thus the full finite bound falls by
11,520. This is a small decrease in a coarse bound. The bound still charges
parking, every route, matrix work, target matchers and all private work.
It is not a measured runtime saving or a new kappa.

## Construction and source identity

The exact PR5708 source archive and the official PR5828 package export are
retained in inputs/. SOURCES.json gives their commits and SHA256 values.
The old source files are unchanged. compile.py is an explicit adaptation of
PR5708's global_retirement.py. ADAPTATION.json lists every body change and
the new header. The checker compares the complete adapted source with that
record. The new entry point takes the checked local word and output directory
as arguments. All source compiler checks remain. No module is patched at run
time, and no source check is bypassed.

Each call keeps the exact public, helper and private owner map and direction.
The compiler rebuilds each query's event index, prefix hash, owner version,
erasure epoch, native frame and RAW input. It also rebuilds all 2,529 private
lifetimes. In particular, old event hashes are never reused after removal of
an ADD. The 7,548 port markers and all controller, thin, idle and boundary
operations outside the 18 local cores are unchanged.

## Proof and verification

The complete PR5828 replay runs first. Its exact local truth tables and
forward/reverse maps establish the changed scalar word. A direct comparison
against PR5708 checks every native/reset event and its exact current input,
plus the initial/final frames and private owners. Each native call therefore
has the same source-specific action as before. The retained native premises
remain dependencies; no new native implementation theorem is inferred.

A second global interpreter uses bitset rows over characteristic two. It
starts with all 11,070 independent public and arbitrary dirty private inputs.
It checks the exact query records as it executes the full stream. Its final
matrix is identity on all 11,022 productive inputs and zero on all 48 private
inputs. A separate reverse sweep verifies the transpose of that full matrix.
These checks cover 122,544,900 Boolean coefficients without random sampling.

All 56,223 actual query values, owner identities, ranks and native frame pairs
agree with the old caller. The productive-owner list and full signed invoice
agree exactly. A separate lifetime scan checks each private first write and
clear, with no overlapping use of one live owner. The fresh positive majorant
is smaller, and it stays below the original 1,024-bit envelope. This majorant
is not a sharp rounded-error bound.

The complete finite fee is recounted from the new stream. The recursive
invoice is unchanged, so the source's conditional ordinary saving and its
analytic inequalities have the same numerical inputs. The new event and fee
bounds satisfy the same finite envelopes. The package does not rerun or
claim to strengthen the outer analytic theorem. The selected result is unchanged.

Controls reject stale query event indices, owner versions and erasure epochs.
Every emitted artifact is regenerated and compared, including the complete
source-record stream and all call/lifetime boundaries. Gzip payloads are
compared after decompression so compression-library output is not a theorem
premise. Frozen archives are authenticated before use.
