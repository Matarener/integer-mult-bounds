# Linked-library bridges and exact limits

The registered source catalogue was queried for integer congruence/divisibility,
Kronecker substitution and positional-digit multiplication, capped at eight
hits per query. Informal-note retrieval covered three additional bounded
queries. Direct source inspection then selected the modules below. This is
bounded discovery across the registered library, not an exhaustive search
or a new compatible-import/kernel certificate.

| Source | Contribution and adaptation limit |
|---|---|
| Mathproof.Computability.IntegerMultiplicationProductApplications20261015 | `commonWidth_spec`, `fixedBits_eq_bits_padding`, `zmod_product`, `signed_residue_label` motivate explicit exact-child widths and trustworthy low residues. The new reference actually computes and pays for its packed child; the existing tape theorem is not an uncharged encoding or native caller. |
| Mathproof.ComplexityMineS20260902 | `crt_iso`, `crt_iso_mul` give the ring-map precedent for transporting products. The power-of-two residue lane uses a single reduction map, while the source tensor CRT still requires pairwise coprime source axes. |
| Mathlib.Data.Int.ModEq | `modEq_iff_dvd` supplies the classical reason equal congruence classes differ by a multiple of M. The new unique-lift proof adds the strict interval-width argument and constructive rational decoder. |
| Mathlib.Data.Nat.Digits.Defs / Lemmas | `mul_ofDigits` and positional bounds guide packing/carry semantics. The new proof separately checks that each packed convolution coefficient is below the slot radix; no no-carry hypothesis is omitted. |
| Mason Hale's certified-gaussian-recovery | Supplies the actual unchanged numerical backend and finite uniform operator certificate. The new affine precision transfer is derived from its exact extraction counts and checked against fresh source constructors. |
| PR3878 physical expansion handoff | Identifies CRT/integer recovery as a remaining join. This package uses the dense certified predecessor, not the unjoined fast physical tiles, and does not claim to complete that physical route. |

Exact source hashes are in LIBRARY-BRIDGES.json. Source-catalog hits are
discovery evidence. No new typed-DAG composition, source kernel replay or
transitive-axiom audit is claimed. The informal universal lifting/packing
theorem and the regenerated all-input finite-box certificate are distinct
from the selected whole-multiplication theorem and its physical cost.
