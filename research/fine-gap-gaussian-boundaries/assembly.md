## 1. What a native κ statement means

Let p be a fixed positive constant times log n, and let V be the number of coefficient records, with Vp = Θ(n). A complete native multiplication algorithm uses O(p)-bit words, including raw products and finite-point guards. Its cost has the form

    sum_j O(V p^(e_j) polylog p) + exp(o(p)),

and it returns the exact ordinary packed product by its separately proved coefficient recovery and carrying procedures.

**Theorem 1 (complete-row conversion).** If every exponent e_j is strictly less than 1−κ, for a fixed κ, and all constituent algorithms and their correctness/precision contracts are supplied, then the complete algorithm costs O(n/(log n)^κ).

**Proof.** There are only finitely many rows, so their positive gaps 1−κ−e_j have a positive minimum η. For each fixed logarithmic power A, (log p)^A = o(p^η). Thus every displayed row is O(V p^(1−κ)) = O(n p^(−κ)). Since p = Θ(log n), this is the claimed cost. The preparation exp(o(p)) is smaller than n p^(−κ) once n = exp(Θ(p)). Add the finitely many costs. Exactness is the supplied composition of the constituent identities and strict recovery theorem, not a consequence of the exponent comparison. ∎

The word "complete" includes address formation, constants, owned storage, pointwise products, restoration, all recursive children, final rounding and input/output. It does not refer only to the Gaussian inverse row.

## 2. The actual existing fused native transfer

Let q_C > 0 be a genuinely admitted uniform native Gaussian provider saving: for every growing selected width e, the actual independent Gaussian job has cost O(V e^(1−q) polylog p) for every fixed q < q_C, with the source's exact endpoint, owned-state, all-input and semantic-depth contracts. In the source-bound native route this premise is furnished by the specified finite productive word and its strict majorant, not an optimal-circuit oracle.

Retain the complete fine-padding, gauge-free circuit, selected-coordinate, batched boundary, polynomial-record and recovery proofs listed above. Put c = 3/32, the explicit conservative native boundary saving inherited from the stated Strassen construction. For parameters ε, β, ξ the paid native savings are

    main                         εq,
    fused Gaussian               1−ε+qβ,
    group scans                  1−ε+β,
    boundary                     c+ξ−ε,
    sparse visits                1/2+ξ−ε,
    record products              ε,
    fixed additional passes      1.

The retained core-face row has a much larger fixed margin in the parameter family below. The source also requires

    0 < β < ε < 1,       1/2 < ξ < ε,
    ε+r < 1,            β+2ξ−2+r < 1,
    β+1−ε < 1,          β+2(1−ε) < 1,

where r is a freely chosen positive spare exponent for logarithmic Gaussian parameters. These are hypotheses of the written source constructions, not merely preferences of a numerical optimizer.

**Theorem 2 (source-bound provider-to-multiplier transfer).** For every

    0 < κ < min(q_C, 3/32),

the retained fused native construction gives complete packed multiplication cost O(n/(log n)^κ), conditional only on the explicitly retained algebraic and analytic source proofs.

**Proof.** Choose q with κ < q < min(q_C,c). For a positive δ to be chosen sufficiently small, set

    ε = 1−δ,       β = 1−3δ,
    ξ = ε(1+q)−c+ℓ,

where ℓ is a small fixed positive number. At δ = ℓ = 0 the cap ξ equals 1+q−c, which lies strictly between 1/2 and 1 because 0 < q < c < 1/2. Choose ℓ and then δ small enough to keep 1/2 < ξ < ε and εq > κ. Also choose 0 < r < δ sufficiently small.

The fused Gaussian saving is q+δ(1−3q), while the main saving is q−δq. Their difference is δ(1−2q) > 0. The boundary saving is exactly εq+ℓ. The sparse-visit saving is εq+ℓ+1/2−c. The group-scan saving is 1−2δ, and the record saving is 1−δ. These all strictly exceed κ after reducing δ if needed; fixed passes have saving 1.

The thin-table constraint is β+1−ε = 1−2δ < 1, and membership is β+2(1−ε) = 1−δ < 1. The remaining chirp exponent is

    β+2ξ−2+r = 1+2q−2c−δ(5+2q)+2ℓ+r.

Its strict margin at ℓ = r = δ = 0 is 2(c−q) > 0. Select ℓ and r small enough that it remains below 1. All other strict source inequalities persist in a sufficiently small positive parameter neighborhood. The core-face term has exponent ε+β+48−128+2, which stays negative. The complete source algorithms therefore meet every row with a strict κ margin. Apply Theorem 1. ∎

This general parameter argument is the inherited fine-padding lifting principle, made explicit in native notation. It is not a new paid provider. In particular, choosing ε closer to 1 only approaches q_C; it is not a new mechanism for surpassing that supplier saving.

## 3. The strengthened line-inverse route and a different full transfer

The companion inverse note supplies a direct fine-gap inverse algorithm. Together with the inherited direct native forward Gaussian map, its intended completed per-line contract is O(S log p) work, exp(o(p)) shared preparation and O(p)-bit precision for the actual source matrices. Unlike the fused route, this uses ordinary line applications and does not require an assumed fast tensor fusion of every Gaussian adapter.

**Theorem 3 (unfused complete assembly).** Suppose the actual forward and inverse maps on each source axis have this completed per-line contract, and retain the exact cyclic embedding, pointwise/record multiplication, original-label twiddles, arbitrary-input native Gaussian provider and integer recovery proofs. For d = Θ(p^ε), 0 < ε < 1, the complete native cost is

    O(V[p^(1−εq) + p^ε + p^(1−ε)] polylog p) + exp(o(p)).

Consequently every fixed

    κ < q/(1+q)

is obtained by choosing ε = 1/(1+q), provided those line contracts apply uniformly at that ε.

**Proof.** The main common-level transform has Θ(p/d) levels. Its actual selected-width-d provider call costs O(V d^(1−q) polylog p), so their sum is O(V p d^(−q) polylog p) = O(V p^(1−εq) polylog p). There are V/S_i independent fibers on axis i. The completed O(S_i log p) line routine therefore costs O(V log p) per axis; summing d axes gives O(V p^ε polylog p). The retained global-precision record products cost O(V p/d polylog p), and fixed twiddle/address/recovery passes fit the displayed rows. Shared preparations sum to exp(o(p)) because the source axes have log length Θ(p/d) and the number of axes is polynomial in p.

The three native savings are εq, 1−ε, and ε. If q < 1, setting ε = 1/(1+q) makes the first two equal q/(1+q), while ε is larger. Any strict smaller κ absorbs every fixed logarithmic factor by Theorem 1. The exactness and whole-tensor precision premises remain actual line/outer theorems, as required in the statement. ∎

This is a positive complete transfer for the new line algorithm. With the same q it is weaker than the already available fused supremum q; its significance is a simpler sufficient Gaussian-adapter contract and possible applicability to providers whose full fused interface has not yet been established. It does not silently grant that broader provider interface.

For the earlier production-scale Beatty-run specialization a = Θ(d sqrt p), the proved local guard a/θ = Θ(d² sqrt p) restricts d to O(p^(1/4)) when θ = Θ(1/d). Its direct use in Theorem 3 gives a main saving only q/4 at d = Θ(p^(1/4)). The improved inverse bound is real, but this substitution alone is not a larger complete κ. The stronger fine-gap construction is needed even to apply the unfused lifting near ε = 1/(1+q).

## 4. A positive normal form for genuinely independent changed Gaussian targets

The following theorem isolates what endpoint charts can be normalized cheaply. It does not assume that a coupled local word has already been diagonalized into independent targets.

Let X and Z be the coordinate and momentum subspaces of the standard binary symplectic space of dimension 2m. Let P be the subgroup stabilizing the computational Z Lagrangian. Its quantum lifts are computational-basis monomial operators: an invertible affine permutation of labels followed by a quadratic root-of-unity phase. Keep absolute phase as part of the specified lift.

**Theorem 4 (monomial–Gaussian–monomial normal form).** Let U be an explicitly specified Clifford operator with symplectic matrix S, and let r be the rank of the X-from-Z block of S. There are explicitly constructible computational monomial operators M_L,M_R and a scalar phase ζ such that

    U = ζ M_L (H_r tensor I) M_R,

where H_r is the normalized Hadamard transform on r selected address bits. The number r is invariant under left and right computational monomial multiplication.

**Proof.** The dimension of Z intersect S(Z) is m−r because r is the rank of the projection of S(Z) to X. The group P acts transitively on Lagrangians L having a given intersection dimension with Z. Here is a constructive proof of that fact. First choose a basis of I = L intersect Z and extend it to a basis of Z. An invertible coordinate change in P sends I to the last m−r coordinate momenta. Pass to the symplectic quotient I-perp/I. There L/I and Z/I are transverse r-dimensional Lagrangians. Transversality writes L/I as a graph over the coordinate-position subspace. The Lagrangian identity says its graph matrix is symmetric. A symmetric shear belonging to P removes that graph matrix, sending L/I to the standard position subspace. Lift this shear and retain I pointwise. Thus a constructed P_L sends S(Z) to the Lagrangian obtained by swapping the first r position/momentum pairs of Z.

Let w_r perform those r swaps. Then w_r^(-1)P_L S stabilizes Z, so it belongs to P. Rearranging expresses S as P_L^(-1)w_r P_R for an explicitly constructed P_R in P. Lift P_L and P_R to computational monomial Clifford operators and w_r to H_r. Two lifts of the same binary symplectic action differ by the explicitly retained Pauli/phase data; those data are absorbed into the monomial factors and ζ. Hence the displayed exact operator equality holds with its absolute phase. Every operation used is a finite basis extension, symmetric shear, or phase normalization, not a tensor-isomorphism decision oracle.

Finally, left/right multiplication by matrices in P preserves dim(Z intersect S(Z)), because P fixes Z. Therefore r is invariant. ∎

**Corollary 5 (independent heterogeneous Gaussian outputs).** If a complete word has an exact all-input endpoint

    direct_sum_i U_i

on arbitrary mutually independent fields, and each U_i is supplied with the normal form in Theorem 4, then computational monomial wrappers turn it into independent canonical Gaussian targets of ranks r_i. Different output charts need not be forced into one common chart. Their actual ranks and normalizers must be used by the subsequent finite productive compiler.

**Proof.** Apply the specified right normalizer separately to each input field, execute the complete word, and apply the specified left normalizer and phase correction separately to each output field. The direct-sum endpoint prevents any cross-field term. Theorem 4 proves the resulting target on every independent input. The heterogeneous ranks are the actual r_i; no rank-eight target can be credited merely because another job occupies a rank-eight ambient space. ∎

**Native scope.** For a fixed finite template lifted over f digit columns, its finite binary basis maps and quadratic phases have bounded descriptions. With selected width o(p), their complete address/phase tables are generated in exp(o(p)) preparation. Direct indexed visits and the stated word masks/shifts implement each monomial field pass with polylog(p) native overhead. The factors are unitary, so they add no operator-norm amplification. The total finite wrapper allowance is included in the provider's nonrecursive work. An arbitrary width-dependent dense basis is not declared free by this fixed-template statement.

## 5. Why the available quotient profile is not yet such an input

The cached PR4629 description reports a large complex-only number. Its actual repaired local descendants supply two typed alternatives, with 56 ordinary and 56 exceptional main pairs. Writing D for a seven-axis Gaussian and Q for a disjoint central-axis Gaussian,

    A = diag(D,D) S_y(Q^(-1)),
    B = diag(1,Q) A,
    C = A diag(Q,1).

The source `HETEROGENEOUS-CONTROLLER.md` constructs physical port permutations and the exact backward-convention wrappers. `FREE-ENDPOINT-GAUGES.md` proves that a complete diagonal controller may have honest changed initial and final central gauges. Both are positive sufficient local/interface constructions. Neither states that the particular changed B/C chronological word already has a profitable complete diagonal endpoint.

**Theorem 6 (whole-word gauge telescoping with exact independent targets).** Suppose a complete chronological word M_s ... M_1 has an exactly proved diagonal endpoint T = direct_sum_i T_i, including its scalar boundary programs. For boundary gauges G_0,...,G_s, physically implement each event as M'_j = G_j M_j G_(j−1)^(-1). Then the raw-input endpoint is

    M'_s ... M'_1 = G_s T G_0^(-1).

If G_0 and G_s are fieldwise diagonal gauges, the output remains a direct sum of honest changed independent targets. Every nonmonomial event correction must be counted among the paid calls.

**Proof.** Multiply the displayed event operators in chronological order. Every adjacent G_(j−1)^(-1)G_(j−1) cancels. The surviving two endpoint gauges surround the originally proved T. Because both are block diagonal by field, the resulting map has no cross-field dependence. It is the actual operator on raw inputs; no input gauge is physically applied unless it occurs in the emitted word. This proves the identity but does not alter the cost of implementing any M'_j. ∎

This is the scope in which free initial/final gauges are legitimate. Theorem 4 cannot be applied to a diagonal block that has not been shown to exist. The full local A primitive is a Gaussian diagonal times a coefficient-field shear, which is generally nonunitary; it is not itself a single address-space Clifford merely because its Gaussian entries are Clifford operators. Applying a symplectic double-coset theorem to that whole role-mixing matrix would therefore use the wrong category. In particular, replacing A by B or C inside a controller is not justified by the observation that the pricing code does not read the local frames: the source's symbolic factorization explicitly assumes the A operator identity. Its correctness is an operator statement, not a syntactic condition on which JSON fields the code reads.

The actual external bridge operations in the inspected controller are scalar ADDs. Odd central Gaussian shears occur inside the local A primitive and are already included in its provider profile. Turning an external scalar ADD into a crossed-gauge operation can introduce a paid Gaussian bridge; it is not automatically a query saving. The complete left/right scalar boundary programs and the resulting target central parities remain part of any constructive new controller proof.

## 6. Precise consequence for the next κ improvement

Theorems 1–3 give complete positive native lifting constructions on their displayed actual inputs. Theorems 4–6 give constructive chart and gauge interfaces for a new heterogeneous provider. Thus a genuine new complete κ can follow from either of two concrete positive developments:

1. An actually admitted stronger independent Gaussian provider, with its complete paid moment, finite uniform compiler, owned/phase/precision contracts and heterogeneous normalizers. Theorem 2 transfers its saving cofinally up to the explicit boundary limit; Theorem 3 supplies a simpler alternative once the fine-gap line routines apply.
2. A new complete main-transform service whose actual moment is better than the inherited selected-width provider recurrence. Its algorithms and independent outputs must be supplied, rather than inferred from a cheaper adapter.

No such stronger independent provider is proved in this note. In particular, the complex-only headline from PR4629 is not substituted for q_C. The positive results here preserve and precisely widen usable interfaces, but do not turn an unproved B/C controller into a new numerical κ.
