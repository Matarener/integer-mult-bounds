# Native G20 retirement and an ordinary BIT supplier

The conditional ordinary BIT saving is `0.003486609089`. The source
PR5512 saving is `0.003483969976`. The exact increase is `0.000002639113`.
This result gives more BIT capacity for a future complete multiplication
construction. It does not increase the selected multiplication coefficient.
The complex component and its complete caller still require their own bill.

## 1. Contract and attribution

The fixed native, arbitrary-function, all-column, ROW, spectator, finite

## 2. Emit and retire four whole owned fields

Make fields `462, 463, 466, 468` owned. Clear each complete field at entry.
Keep every source operation through its last nonzero source read. Those
source record indices are respectively `16202, 16206, 16160, 16139`.
The protected rank-four reads occur before these cuts and remain paid.
Clear each field immediately after its cut. Set its return frame at that
clear. Omit its later destination operations and reads of the resulting
whole zero. This removes four rank-three queries, four rank-one queries,
four other tail ADDs, and 32 cold zero reads per local call.

The source invariant represents a field in frame F by one normalized
linear row in the independent input functions. ADD requires the same
coframe on both operands. A native query changes the coframe and keeps
that normalized row. Thus a zero normalized row is the zero function for
every native input width under the retained coframe identity. It is not
only a scalar zero at a sampled point. Specializing an owned input to
zero and then replaying these rows proves each omitted read is zero.
After the last nonzero read, a field has no effect on any retained output.
Its remaining return path can therefore be replaced by whole-field CLEAR.
No retained original input is cleared, and no live frame is renamed.

The resulting local word has 645 retained original fields and 15 owned
fields. The 15 include the source centre, its shadow, the source nine
relations, and these four new helpers. Every owned entry can contain an
arbitrary dirty value; the entry CLEAR removes its complete column.
The output on each retained field is the same physical source map. The
owned outputs are all zero. The local paid histogram is

```text
rank       1     2   3   4    5   6   7
count   1305  1342  73  40  102  10   9
```

The source exact rational coframe checks are retained. Forward native
replay tracks all 660 original and dirty columns over moduli 101 and
10201. A separate adjoint implementation uses other address points at
both moduli and checks all transpose columns. CLEAR has the total zero
linear extension; it is not inverted. These finite tests support the
coframe proof. They are not a substitute for its all-width assumptions.
Missing entry CLEAR, an early retirement, and retained-input erasure all
fail the verifier.

positive gain for every such exponent, with the new target debit included.

## 5. Four finite ordinary levels

Let `g=2^-36+10^-20` and `rho=1/100`. The cover guard `2^45*g>256`
holds. Start with the completed source backend `b0=0.003483969976`.
At each level freeze the preceding completed algorithm, then set

```text
a_j=(1-rho)*(uniform-g)+rho*b_(j-1)
b_j=floor(10^12*a_j)/10^12
```

The four new admitted values are `0.003486582698`, `0.003486608825`,
`0.003486609086`, and **`0.003486609089`**. Every improvement, adapter,
stock, and rounding gap is positive. Each level gets new finite constants
and a fresh threshold from its completed all-width fallback. No level
calls itself as its atom backend. A fifth level has the same admitted
value on this decimal grid, so it adds no useful result here.

## 6. Check the immediate extension strategy

Before freezing the word, `extensions.py` checks 1,174 further cohorts.
These include every one of the 423 possible single additions, all complete
pure-helper supports at source reads or queries, and the whole eligible
helper set. Each cohort contains the chosen four. The emitter constructs
each specialized word and counts all additional removed paid queries.
Every extra owner debits one rank-eight target per local call. For
`0<=C<=1/100`, the sum of removed ranks is already less than the lower
bound on that target debit. Since `r^(1-C)<=r`, none of these cohorts
can improve the chosen bill. This is a bound for the declared finite
census. It does not exclude other subsets or a changed reconstruction
program. Its purpose is to test the next step in this constructive
strategy before presenting a small local gain as the end of the search.
