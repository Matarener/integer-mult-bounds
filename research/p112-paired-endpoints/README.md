# P112 paired endpoints and paid isolated contacts

This package completes a fixed nine-dimensional paired-endpoint calculation
for the retained 112 P112 ports. Its new local correction pays for literal
physical return of an arbitrary dirty helper. It also preserves the signed B4
identity and the exact maximum eight for one fixed triangular-zero source-batched scheduling
model. These are local identities and a restricted finite scheduling result.

## Results and covered domain

- The 112 ordered P,Q,R contracts have two common lines and a rank-seven residual.
  The checker retains 456 exact phase-bearing canonical/native gauge maps and
  both rank-seven child lowerings at every port. The chosen projector phases
  require 112 nonzero translations when adapted from the native positive gate.
- The signed B4 controller is checked over the Laurent ring Z[z,z^-1], hence
  for every invertible common operator K. Separate exact native executions
  cover global address dimensions 11 and 12, with one residual axis per stage;
  they are not executions of a 65-dimensional or56-dimensional supplier.
- For the fixed order-three orthogonal partner map, all 5824 old orthogonal
  edges have minimum contact ranks 1, 2, 3 with counts 104,2912,2808. Every chosen
  contact is checked in all 512 Fourier characters, including its signed phases.
- For coefficient +1 or -1, a rank-two or rank-three isolated dirty contact
  uses four signed ADDs and
  native rank mass 16 or 18 after explicit physical helper return. The rank-one
  case uses a direct ADD, two rank-seven data transitions and no helper.
  Omitting the return leaves the helper in a changed physical frame. Other
  coefficients require their own scalar lowering cost.
- The fixed triangular-zero source-batched dynamic program has maximum eight. That bound does
  not cover other partner maps or arbitrary edge interleavings.

[PROOF-ENDPOINTS.md](PROOF-ENDPOINTS.md) gives the endpoint, phase and Laurent
arguments. [PROOF-CONTACTS.md](PROOF-CONTACTS.md) gives the geometric minimum,
actual isolated word and paid invoice. Complete deterministic records are
stored under `artifacts/`; semantic comparison checks every typed field.

## Limits

The isolated words do not supply a shared simultaneous word: their source and
target frame paths can conflict across edges. Their individual costs must not
be added and presented as a compatible global supplier. Canonical/native maps,
monomial wrappers and terminal operations remain paid. No helper ownership,
rounding, full recursive stock, physical tape admission or new kappa follows.
The native compiler is replayed on representative contact transitions; complete
contact phase and rank coverage uses the stated exact analytic/character method.

The universal written identities, finite exact certificates, restricted dynamic
program and separate AI reviews have different coverage. No formal-kernel or
independent human verification is claimed. `TASK.json` declares the changed
scope relative to the current task catalogue.

## Reproduction

Python 3.12 standard library only. From a checkout, run:

```sh
python3.12 scripts/research_package.py --package research/p112-paired-endpoints
```

From a read-only Git-free package export, run each registered command directly:

```sh
python3.12 -I -O -B /absolute/package/verify.py --stage endpoints
python3.12 -I -O -B /absolute/package/verify.py --stage geometry
python3.12 -I -B /absolute/package/controls.py --package /absolute/package
```

Outputs and temporary fixtures are external to the package. Executed checkers
and the compiler use captured authenticated source bytes with assertions enabled.
Expected JSON records are compared after decoding compression; gzip-container
variation is not mathematical inequality. Frozen source bytes retain exact hashes.
`ORIGINS.json` maps every frozen input to its Git source or original preserved
research path. `DATA-PHASES.json` is provenance only and is never claimed as a
semantically replayed supplier certificate.

## Open next questions

A useful next step is one explicit chronological caller with compatible source
and target paths, literal helper return and a complete paid invoice. The current
isolated contacts do not provide it. A different partner map or general
interleaving needs its own model and certificate before claiming a larger
schedule. Rounded recursion and physical storage/access remain blocked until
such a complete word exists. `TASK.json` records the reason, first step and
blocker for each question.
