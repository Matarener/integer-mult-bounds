# C02 source and acceptance-boundary audit

This review concerns the two registered endpoint and geometry stages of the
P112 paired-endpoints package. It is an independent source/control review with
substantial OpenAI Codex assistance. It does not claim an independent replay
of the complete mathematical stages or a formal-kernel proof.

## Executed dependency closure

The root verifier executes only the two declared fresh checkers. It reads and
authenticates each complete script buffer, supplies that buffer to an isolated
child interpreter over standard input, and compiles it with
`dont_inherit=True, optimize=0`. Both fresh checkers authenticate and execute
the captured `clifford_exact.py` buffer. They do not import the historical
programs or active sibling modules. There is no frozen-module bytecode-cache
read path.

The endpoint runtime inputs are the exact `CANONICAL-WORD.json.gz`,
`GLOBAL-TEMPLATE.json.gz`, original decoded `ORDER3-GEOMETRY.json`, and
`clifford_exact.py`. It consumes the port order, entire signed B4 recipe and
ordered P/Q/R contracts. The geometry stage independently derives the
contracts using only the same port input and compiler. The historical geometry
receipt supplies no edge census or scheduling conclusion to the fresh geometry
stage.

The root checks both full ordered arrays, their length 112, and an independently
recomputed canonical digest. Canonical JSON uses sorted keys, compact separators
and no trailing newline. Complete expected-record comparison preserves scalar
types and list order; duplicate keys and nonfinite constants are rejected.
The original historical geometry is decoded from authenticated compressed
bytes into external scratch, and its exact original digest is checked again
by the endpoint checker.

`DATA-PHASES.json` is authenticated provenance. Neither new stage semantically
replays it. The old `ENDPOINT.json` and `CANONICAL-GAUGES.json` are likewise
historical evidence, not expected results silently accepted in place of fresh
complete receipts. Original programs are preserved unchanged to disclose
derivation and attribution. Their hard-coded paths and importlib loading are
not executed.

The scientific source is commit
`20ecf2891d80b5acf18d980b2164fb44ea7faa90`. This review directly compared the
retained Git-sourced inputs/notices/license with local objects at that exact
commit, and preserved-research entries with their named original files.
Compressed adaptations retain both stored and original digests. The frozen
manifest, origins, final review inventory and core snapshot delimit subsequent
fresh-checker and documentation additions.

## Actual mathematical acceptance

Endpoint operator equality checks complete signed Pauli images and an exact
nonzero column. The former determine a Clifford operator up to scalar; the
latter fixes the global scalar. The independently derived projector kernel
uses exact Gaussian integers and powers of two. A full convolution kernel
determines every translated input column.

The canonical residual identity has the correct chronological order:
apply the entrance map M_E, the chosen residual T_R, then the inverse terminal
map M_U^-1. Both maps are paid. The finite native models execute the full
signed source recipe, required inverse translations, and literal terminal
swap/sign operations. The separate Laurent-ring calculation covers every
invertible common operator K. The native executions have address dimensions
11 and 12; no 65-dimensional or 56-dimensional supplier execution is inferred.

Geometry acceptance tracks three independent arbitrary input fields, including
the dirty helper. Phase operators are exact arrays of all 512 character
values. The helper return is a physical inverse transition, not merely a
restored logical value in a changed frame. Each local invoice includes four
signed ADDs and six positive-rank occurrences for ranks two and three.
The additional positive cancelling ADD pair is accepted by the operator gate
and rejected by the invoice gate, establishing that these obligations differ.

Every all-edge rank comes from the exact phase polar matrix. The twelve
compiler lowering samples do not replace that full all-edge argument and are
not represented as exhaustive lowering of every adapter. The source-batched
maximum uses a fixed O and the explicitly stipulated triangular-zero model.
Its recurrence and compatibility-coloring bound do not quantify over arbitrary
edge interleavings or other partner maps.

## Control integrity

Endpoint mutations enter the actual phase, tableau, Laurent or native endpoint
gates after input authentication. Exception-based probes match the intended
error code, and unexpected acceptance is raised outside the caught branch.
The phase-deletion probe demonstrates an actual global-i defect passing the
remaining signed-Pauli comparison.

The geometry checker executes fourteen intended rejections and fourteen
deletions of those same production guards. Dirty-input, omitted return,
delivery-sign and global-phase defects have explicit nonzero Gaussian
character witnesses. Deleting the selected field check leaves all other
field checks active. The rank-three omission tests the actual degenerate
required span. Scheduling and invoice controls address separate predicates.

The compact review controls additionally force a phase-index collision and
require exact 512-byte payload comparison, so a digest is not substituted for
operator equality. Identical phase reuse is a positive control.

Source and hash rejection controls are reported separately from mathematical
controls. Full-receipt mutation controls alter complete authenticated records,
including nested omissions and scalar types. The paired-contract array gate
is tested with an altered array retaining its original digest, and deletion of
that exact comparison admits the defect. These tests do not pass merely
because an input hash changes.

## Scope retained

The package proves fixed endpoint identities, paid isolated dirty contacts,
the conditional common-operator controller, and a restricted finite scheduling
maximum. It does not provide a compatible simultaneous many-edge word,
canonical/native occurrence schedule, helper ownership assignment, rounding
contract, recursive storage/access admission, or new multiplication bound.
