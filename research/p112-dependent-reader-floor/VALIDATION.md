# Validation and limits

The new all-field result is the written theorem in PROOF.md. Its proof does
not assume a finite field census, numerical optimizer or coefficient-height
bound. The combined all-three-query corollary also inherits PR3414's independent
query theorem at the exact source in SOURCES.json. This package proves the
new dependent-query case without importing that predecessor's code.

## Executable coverage

The primary script authenticates the selected 112 labels and the unchanged
PR3370 partition by SHA256 and Git-blob hashes, validates the complete partition
and checks every within-group binary Gram entry. It reconstructs 96 rational
pair operators and 96 binary replacements on all 112 squared entries each.
There are 2,408,448 operator-entry checks. The four literal pairs are (0,1),
(0,2), (0,31) and (28,31), indexing the 32 alternating indicators. They include
opposite halves of the same group and different group sizes. Six coefficient
families use two or three projective directions, with and without proportional
repetitions and a zero query. Sparse readers and readers with exact global
cancellation are both tested. Every replacement has tariff at least the
pair floor and at most the original tariff. These are exact algebraic
fixtures, not performance measurements or a census of all P112 factorizations.

The separate script imports none of the primary algebra. It exhausts 133
projective direction sets and 23,637 coefficient tuples over F2,F3,F5,F7. It
checks every resulting axis output can be delivered using a subset of its
old active readers after a separately enumerated binary injection. It builds
all 50,176 expanded entries of literal K using explicit nine-bit coordinates,
obtains I224 and computes the literal tariff 224 with set elimination. It
also rejects all 256 binary images of an abstract four-direction example
on twelve reader sites. That example is not a literal P112 cost witness.

Five behavioral control groups check source/reader support, proportionality,
direction capacity, invalid readers, a false operator and binary rank. Five
actual optimized CLI corruptions reject changed live bytes, changed retained
certificate bytes, changed receipt formatting, a false tariff and the separate
checker's changed live input. A restored positive optimized CLI run passes.
Ordinary checks leave committed receipts unchanged. Receipt equality is an
exact canonical-text comparison, including JSON types and formatting.

## Power of Ten assessment

The committed scripts have structured, nonrecursive call graphs. Every
function remains within 60 physical lines after formatting. Primary loops are
bounded by 112 ports, 224 binary coordinates, 16 query entries, three direction
classes, eight binary masks, six direction fixtures, four pairs, two reader
modes and two duplication modes. Finite-field loops use four fixed primes at
most seven, eight projective points, at most 56 three-point subsets, 343
coefficient tuples and eight subset masks. The abstract four-direction check
uses exactly 256 assignments and six pairs. Test copies contain this package
and one pinned 814,141-byte input; five mutation attempts and one restored
positive CLI run have explicit subprocess limits. Reads in the primary check
are bounded by 1 MiB for labels and receipts and 32 KiB for metadata. The
separate checker uses the same explicit 1 MiB and 32 KiB read capacities,
with its own bounded-reader implementation.

ValueError contracts remain active under optimization and cover source pins,
partition shape, orthogonality, list capacity, distinct directions, source
support inclusion, actual reader inclusion, exact operators and tariff bounds.
Control copies use copyfile, which creates private writable files without
copying read-only source modes or changing any source permissions. The first
read-only export found the old copytree default preserved read-only modes;
this fixture issue was fixed in an ordinary follow-up commit. Mathematical
proofs, source inputs and receipts were unchanged. Temporary directories use
context managers, subprocess outcomes are checked
or deliberately inspected as negative controls, and failures propagate with
nonzero status. The only writes are explicit receipt regeneration and scoped
temporary controls. Runtime replay never writes Git metadata or published
inputs. Source authentication limits malformed external shapes before main
processing. Numeric coefficient fixtures and internal helper arguments are
trusted program data, not a public input API.

## Research decision

The original coverage-law card is refined into the explicit dependent-list
handoff from PR3414, recorded as scope_status changed in TASK.json. This is a
central decoder-interface obstruction rather than a replacement hosted
coverage identity. Build the Lever produced the rerunnable replacement and
source-bound algebraic checks. Prove It Works required complete actual-operator
entries, actual-reader tariffs, CLI failures and committed/export validation.
No new abstraction or shared runtime repair was needed.

The family decision is to pause after this implication. A future construction
needs an exact cheaper factorization and a complete boundary and cost ledger,
including a consumer that does not repay the apparent saving. No physical
cost is silently treated as zero. Four or more projective directions, external
query dimensions, changed fitting matrices and changed native operations are
unresolved. All native, compiler, analytic and outer multiplication assumptions
remain separate. Independent human and formal proof-kernel review are unclaimed.
