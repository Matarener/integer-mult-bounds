## Complete arbitrary-input block

    M = [ KT        0    0          0    0        0 ]

Both pivot rows, every original current input column, source response and
completed public rows remain in this matrix. Its complete inverse is saved

Forward/inverse composition in both orders is checked on all six inputs.
No inverse of an arbitrary nonunit sum is used as a free primitive.

To derive it, the literal query5 source/delivery/SWAP/accumulator/postwarp,
then five fresh queries and final source relocation, first give the six

    (Ta, Tu, T(b-r-Kz), P(r+Kz), TKz, Tc).

## Useful rank-neutral factorization

A shorter scalar/address implementation of this matrix is obtained by:

1. Apply K on bank4, ADD bank3+=bank4, ADD bank2-=bank3.
2. Apply T separately to all six banks.
3. Apply K on bank0; ADD bank2-=bank0.
4. SCALE bank3 by -1; ADD bank3+=bank4.
5. Run the source's final scalar/core segment beginning at its first
   `dual p shared T reader`, including W, final pivot K and output BANK_SWAP.

The exact executable sequence and inverse matrix are in `CUT58.json`.
This jointly removes the old P/R pair and its intervening source relocations,
but its native invoice is still three K queries of rank2, six T queries of
rank2 and one W query of rank4: total22. All displayed ADD/SCALE/SWAP scans
must be charged. The simplified sequence is an exact operator identity,

## Validation and limits

The source is pinned to the frozen admitted two-site receipt. Every used
forward/inverse unary is rebound to its original source event, literal
signed circuit, Gaussian phase residue, selected native recipe and embedding.
The complete block and its literal inverse pass exact normal and optimized
Python replay. Omitting the source b-accumulator changes the matrix, as does
losing the RP=-T sign. These controls reject clean-input-only cancellations.

This is finite q2, all positive f through the exact tensor-family phase
algebra. The source's whole caller is unchanged. No broad optimizer ran,
no native improvement or moment is claimed, and no BIT, owner, controller,
precision, storage, partial-volume query or borrowed-axis gate is discharged.
The rank tariff uses same-volume full-bank macros only; a heterogeneous or
striped query model needs separate weighted accounting.
