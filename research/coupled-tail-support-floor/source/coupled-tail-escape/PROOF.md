# Exact coupled-cleanup boundary at the q2 final-a cut

The admitted q2 word has native rank mass76f and endpoint stock72f. Fix its
physical prefix through event68. That prefix costs66f. Replace the entire
suffix starting at event69, just before the final independent-a J query,
by any new coupled cleanup on the current banks, with optional extra dirty
banks restored. A strict native mass improvement below stock would require
the replacement to have normalized native mass below6.

The exact suffix is not cheap enough under a bounded whole-bank scan word.
It contains an unavoidable original-current-input coefficient of native
arity6f. The argument below changes neither source nor current boundary and
permits arbitrary new scalar coupling topology within this local block.
It is therefore distinct from the earlier fixed-ADD-graph frame certificate
and isolated two-existing-site screens.

## Complete arbitrary-input local target

Use the actual six incoming physical banks x0,...,x5 at the event69 cut.
They are arbitrary independent arrays: the fixed prefix is reversible, so
its image is the full product space. No current public bank is promised zero
or correlated with another one for purposes of this local replacement.

Set F=F5, let J be the actual frozen phase-correct skew response, and define

    A = F J F^-1,
    Q = J^-1 (P1 N0^-1 J) J,
    W = F Q^-1 F^-1,
    R = -N5 P5.

The chronological reverse-current step is P5, then N5, then the literal
minus sign, hence its operator is exactly R in this order. The native
arities of A,W,R are respectively2f,4f,2f. All complete circuits, phases,
selected recipe pointers/embeddings and inverse pointers are retained from
the unchanged admitted source. Both J applications are charged separately.

Direct exact replay of events69 through90 gives the full local matrix
(rows and columns ordered0,...,5):

    [ A       0   0          0           0       0 ]
    [ -WA     0   I-W        WR          I-W     0 ]
    [ -A      0   I          0           0       0 ]
    [ -AWA    A   A(I-W)     A(W-I)R     -AW     0 ]
    [ 0       0   0          0           I       0 ]
    [ 0       0   0          0           0       I ].

In particular bank2 is changed by its required public isolation; it is not
quietly restored to its incoming value. Banks4 and5 are arbitrary retained
inputs. The matrix involves four mutable bank outputs, even if a proposed
coupled controller calls only three of them active and treats bank2's ADD
as an outside scalar reader. That choice cannot discard its coefficient.

An explicit inverse, with y the six output banks, is

    x0 = A^-1 y0,        x2 = y2+y0,       x4=y4, x5=y5,
    z  = W^-1(y1-x2-x4)+y0+x2+x4,
    x3 = R^-1 z,
    x1 = A^-1 y3+z-y1+x4.

These are unitary operator inverses with paid source recipes, not free
inversion of a nonunit coefficient. The producer independently replays the
actual serialized local inverse and checks both matrix product orders on
all six arbitrary incoming columns in the exact all-f tensor-family algebra.

## Native bill and the arity-six coefficient

The suffix's entire native inventory is

    final-a A:2, reverse-current N5:2, W:4, final-original-k A:2,

so the local bill is10 and the unchanged prefix bill is66. There are no
hidden SCALE gates in this suffix. Its source ADD and BANK_SWAP scans are
listed in the receipt and remain paid. A new local replacement must realize
the same matrix and the same current-input boundary; the current coefficient
from inputbank3 to outputbank1 is exactly the single Clifford

    C = W R = (F Q^-1 F^-1)(-N5 P5).

Its B-block rank is6f. This is checked independently from the actual literal
source circuits, including the minus sign and Gaussian phase. The receipt
also lowers the coordinate operator to a rank6 selected Fourier child with
explicit physical monomial adapters, then independently recompiles it.
That recipe is only a witness for C's row support; it is not a completed
cleanup factorization or a new recursive supplier.

Because both monomial adapters preserve row support, each row of C_f has
exactly2^(6f) nonzero original-address coefficients. The actual family is the
saved scalar phase times C_1 tensorf, so this holds for every positive f,
with no finite-f extrapolation and no scalar/permutation stand-in for C.

## Support proof for any new local topology

The native invoice here sums FULL-BANK query macroarities at the same bank
volume V_f as the fixed source. Actual selected child embeddings and their
primitive meaning must be retained. Partial-volume or striped queries do
not automatically have this unweighted native histogram; repricing them
requires a separate weighted argument.

Consider the matrix of a proposed replacement on all current-bank and extra
dirty-bank coordinates. Initially every row is an identity row with support1.
If clean auxiliaries were expressly allowed, their zero coefficient rows
would also satisfy this upper bound; no such promise is needed here.

An invertible monomial adapter, address permutation, field SCALE or literal
bank routing does not increase maximum row support. A native Clifford of
actual B-rank r has2^r nonzero entries per row, and therefore multiplies the
maximum support by at most2^r. A scalar binary ADD increases it by at most2.
A reversible COPY/target accumulation with two input rows is such a counted
binary operation; there is no free fan-in COPY. Arbitrary scalar coefficients
and cancellations can decrease support, not violate this upper bound.

Consequently, if R_f is the sum of all native B-ranks in the replacement
and S_f counts its elementary binary ADD/accumulation scans, every output
row has support at most2^(R_f+S_f). The exact outputbank1/inputbank3 block
already has2^(6f) nonzeros in each row, so necessarily

    R_f + S_f >= 6f.

This argument applies to arbitrary scalar/monomial coupling topology and
any number of restored arbitrary dirty registers. It does not assume that
the replacement intermediate coefficients are single Clifford rays, that
the old ADD graph is preserved, or that edits are row-confined. Additional
dirty inputs cannot change the required coefficient on the old inputbank3.

For a fixed local scan word with S_f=O(1), this implies

    liminf_(f->infinity) R_f/f >= 6.

Adding the fixed66f prefix prevents a total normalized mass below72 at this
cut. In the present integer-per-f query architecture, a candidate saving at
least6 from the original76 bill would use local mass at most4; it would
instead require S_f>=2f. This is the optimistic charge gate, before owner,
controller, COPY, precision or outer moment costs are added.

This is not a pointwise native-only bound6f for one finite f: the exact
finite-f statement is R_f>=6f-S_f. A growing O(f) ADD word is a conditional
escape from the bounded-scan conclusion. Its full scan costs belong to a
separate transfer analysis. Here an elementary ADD is explicitly a scan
of the same full bank of volume V_f=2^(12f); each scalar/address operation
is charged, rather than hidden in a projected or partial-bank operation.
No exclusion of a different partial/fused-scan controller is inferred.

Changing an earlier source/fresh-progress cut, the physical entrance/exit
gauges, or the target contract changes this local matrix and reopens the
problem. The weaker inequality does not prove the local minimum is6 or10,
nor say that no other coupled caller can improve the stock. No expensive
enumeration was run after the gate. No BIT or improved kappa is asserted.
