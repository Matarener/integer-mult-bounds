## Cost model and limits

The unweighted full bank/address support induction gives
`native arity + binary ADD count >=rho*f-O(1)` for a required coefficient
with support `2^(rho*f-O(1))`. It includes arbitrary dirty banks and exact
restoration. A growing ADD count is priced using the separately pinned
[positive-volume full-scan argument](source/root-joint/FULL-SCAN-TRANSFER.md).
Unweighted mass becomes the complete moment only under
[equal-volume full-bank child normalization](source/joint-native/COST-SCOPE.md),
including queried dirty helpers and separately charged query sites.
Positive fixed relative volumes alone do not imply that normalization.

The three gate domains and the constructive fusion are separately scoped.

arbitrary simultaneous changes. Cross-cut query fusion elsewhere, changed

input/target contracts, unequal volumes, local scans and other transfers

## Review and reproduce

Start with the three readable proofs above, this README, `REPLAY-MAP.md`
and the five unchanged mathematical producers under `source/joint-native/`.
Then read the fusion proof/schema, `verify_fusions.py`, and the independent
literal auditor `source/fusion-audit/audit_fusions.py`. Fixed native witnesses
are checked directly; expensive native synthesis is not repeated.
Large fixed JSON files are generated evidence, not additional authored
proof. Compression reduces transport size, not mathematical review scope.
Every original byte is preserved, including all physical events and all
saved routing witnesses; there is no projection or field deletion.

From the repository root, using Python3.12:

```sh
python3.12 -B scripts/research_package.py --package research/j-caller-interface-gates
python3.12 -B scripts/check_research_commit.py --package research/j-caller-interface-gates --check-source-history
```

The manifest runs the portable `verify.py` normally and with `-O`. Direct
commands from this package are `python3 -B verify.py` and
`python3 -O -B verify.py`; `--json` prints the full summary. They require
only standard-library Python and no Git, network, original directory or
runtime fetch. They write no files. Individual archival generator entrypoints
outside `VERIFY.json` are not advertised as independent portable commands.

`BINDINGS.json` inventories committed transport hashes, complete logical
input hashes and sizes, all25 frozen source pins, and source-to-package
edits. Gzip inputs are authenticated as committed immutable transports,
then decompressed to the exact pinned original bytes before producer reads.
Logical aliases exist only in memory. No executable data deserialization
is used. Changed transport, changed logical bytes and malformed compressed
payloads reject; identical payloads pass. The compiler hashes and compiles
the same source bytes without `.pyc`, preserving historical assertions
under optimized parent Python. Receipt comparison omits only explicitly
enumerated provenance keys; those original bytes are separately authenticated.
The original normal/optimized fusion receipts differ only in their mode
label; their mathematical contents are checked equal. Registered parent
normal/-O modes keep the historical source assertions enabled.
Original-byte integrity, exact finite replay, written proof, hosted CI and
mathematical admission remain distinct gates.
