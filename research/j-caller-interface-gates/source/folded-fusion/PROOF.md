## Exact finite obstruction for further single-site absorption

`one_site_absorption.py` does not run a frame or random search. It
fixes every scalar gate, ADDRESS and every prefix native except one;
it deletes any nonempty subset of tail native events. If `T_old` and
`T_new` are the original and deletion tail maps, the unique required
prefix correction is

    C = T_new^-1 T_old.

At a prefix cut, this is pulled backward through each current event E
by `C <- E^-1 C E`. A single native replacement at bank b is possible
only if C equals identity in every matrix block except `(b,b)`;
the unique replacement is then `C_bb G_old`. All unchanged original
identity slots are included. No source bank is silently initialized.

rank-mass decrease is available in this declared one-site absorption
