## All-q identities and the new required coefficient

The stage2 edit is exact on arbitrary independent entering fields.
The zero net delivery ADDs cancel. The new source query P2 N2 followed
by the source post P2 is N2 on that source. Every other bank also gets
N2. Uniform N2 on all banks commutes with each scalar entrance/exit
ADD, so the star and its inverse cancel. This is a changed physical
source query, not a free replacement of a retarded source code. Its new
retarded owner code is exactlyI.

The initial shared exposure has local matrix
`M0=[[I,0],[J,I]]`. Replacing its first J by literal scalar -I, retaining
the final J^-1, gives `M1=[[J,0],[-I,I]]=M0 diag(J,I)` because
**J_f^2=-I for every f**. The scalar -I carries the whole-field unit;
it is not the uncorrected tensor of f copies of -I. The code uses phase
exponent2, which gives that correct constant unit.

Let `Q=J^-1 B1 J` and keep the source's later Du,Dv/readers. The actual
new homogeneous owner block is

    H=diag(Du,Dv) Swap [[Q,0],[Q-I,I]] diag(J,I).

Its inverse original-t/current-V coefficient in the actual target FJ is

    C=F Q^-1 Dv^-1 F^-1.                            (1)

There is no initial left J in (1); the right preload changed the
required cleanup. Public L cannot change this coefficient of the unique
full inverse. The independent literal inverse-row replay matches (1),
including all four Gaussian f residues, for both final artifacts at
q2/q3. The optional U fusion leaves the current V and thus (1) unchanged.

For all q, (1) has exactly **(2q+2)f** native arity. To see this without
finite-f extrapolation, work on one p or q half and one bit. The binary
phase/permutation product is
`(Gamma,pi)(Delta,rho)=(Gamma+pi Delta pi^T,pi rho)`. The entrance
Q^-1 has shear `[[0,1],[1,1]]` on common0/fresh1 and permutation P1.
The Dv word has shear consisting of odd diagonals5,7,...,2q+1 and
permutation cycle `0->5->7->...->2q+1->0`. Conjugation by F leaves

    Gamma(C)=[[1,1],[1,0]] on(0,1)
             plus diag1 on odd5,7,...,2q+1.

The first block has rank2 and the q-1 odd diagonals are disjoint. The

## Independence and phase/recipe coverage

The audit imports the frozen exact Clifford implementation and the
prior independent gate-by-gate X-character model. It does not import
the contribution's joint_algebra, quadratic_charts or verify_fusions.
Each literal event circuit is recompiled, and its full f-residue tensor
phase is derived directly. Forward replay sends every original bank
to its own FJ output. The *serialized* literal inverse replays to the
diagonal inverse of FJ, proving both inverse orders without assuming
the contribution's inverse-generation helper.

Every used forward/inverse recipe pointer and every new fusion recipe
is recompiled from its monomial adapters and native C gates. Signed
tableau equality is supplemented by an independent exact Gaussian
matrix-element check: the selected recipe's sparse physical column is
compared to a Walsh sum of the definition circuit's derived X-character
phase. This fixes the Gaussian ray. Recipe embeddings, actual native
arity and all-f tensor exponents are checked as well.

Actual omission of either the new initial -I or the new uniform source
fresh query fails the complete original-column replay. These controls
change the literal word, not only an output label. The contribution's
additional stale-source, stale-downstream-inverse and reverse-gate
controls remain its separate corroborating evidence.
