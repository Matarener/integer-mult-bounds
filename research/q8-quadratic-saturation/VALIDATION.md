# Validation scope and bounds

The written result is the exact quotient minimum 2t for homogeneous negative
targets with t divisible by four. The explicit eight-call witness is not a
full Q8 identity. The verifier derives its nonzero invertible cubic defect,
rather than treating quotient acceptance as full acceptance.

## Commands and finite coverage

The registered CPython3.12 commands are listed in VERIFY.json. They compare
all RESULT.json fields and run three optimized behavioral control groups.
Standalone replay needs the package only. No solver is a runtime dependency.

The primary implementation uses binary row masks and exact eight-bit group
packets. A separate Hamilton implementation shares no multiplication table,
projector update or polynomial recurrence. They agree on 2208 faithful
role/group input columns, including generic words that mix active and dirty
roles. Exact full twelve-call negative endpoints are positive controls.
The direct-sum fixtures include two independent restored dirty spectators.
All 120 deleted-factor controls fail their corresponding endpoint test.
There are 64 group products and 125 quotient basis-associativity controls.
These finite checks corroborate the written direct-sum argument; they do
not establish an unbounded full-Q8 minimum.

The defect inverse `(2,6,8,15)` is checked on both sides. Every regular error
rank is derived from the actual full endpoint. A separate explicit-span
rank calculation checks the four-dimensional defect rank. The complete
five-dimensional quotient is checked against all 64 Q8 products. Neither
projection nor a single formal coefficient is assumed multiplicative
without that homomorphism check.

Behavioral controls replace the actual full-endpoint, polynomial, Hamilton
and rank producers with faulty versions. Boundary controls reject illegal
idempotents, labels, noninteger masks, width/call/rank/span overflow.
An actual relocated `-I -O -Werror -B` CLI replay passes in a private
Git-free directory. Receipt corruption and retained-source corruption fail;
`--write` refuses an existing output without changing its bytes.

## Power-of-ten inspection

All new code has structured control flow without recursion. Gate validation
bounds roles at 16 and calls at 48. Full matrices have at most 256 packet
entries; the regular rank calculation has at most 128 vectors of 128 bits.
Polynomial coefficients have at most 4*16 rows. The explicit span oracle
accepts at most 8 vectors, so at most 256 span elements exist. Each checked
input is fixed or bounded before loops. Generic fixtures use 50 words with
at most 10 calls and 6 roles. Every new function is below 60 physical lines.
All mathematical checks use explicit ValueError guards and remain enabled
under optimization. State is local; no shared mutable mathematical cache,
file writer, subprocess, network or solver exists in the scientific model.
Returned subprocess codes, output lengths and copy identities are checked.

Rule3 deviation, Python managed allocation. `model.py`, `oracle.py` and
`verify.py` allocate bounded immutable integers, tuples and local collections
during evaluation. Python cannot prohibit runtime allocation. The caps above
bound live mathematical data; no unbounded queue or streaming input exists.
The verifier holds one endpoint/word fixture at a time. Standard-runtime
allocator overhead is not independently instrumented. A fixed-storage
native port is the follow-up if these caps no longer suffice.

Rule8/9 deviation, standard unittest registration and mock substitution.
Only `test_package.py` uses unittest reflection and patches four named local
producers. Targets and lifetimes are explicit context managers. There is no
dynamic code execution in the scientific implementation. The three actual
optimized behavioral groups verify required dispatch and restore patches.
A static test dispatcher is the follow-up if unittest must be removed.

Rule10 diagnostics. Run warnings as errors, optimized controls, and scoped
Ruff with E,F,B,UP checks and a 120-character line bound. Test environment
creation is confined to private external TMPDIR. No chmod, copy2, metadata
copying, symlink following or shared-runtime modification is used. Export
copies are exclusive owned regular byte copies with distinct source/dest
inodes, and are hashed before and after actual committed Git-free replay.
The publication receipt checks raw committed bytes and source ancestry.
