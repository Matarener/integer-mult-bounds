## Result and scope

The retained complex construction has the exact mixed characteristic root

```

```

This directory supplies its complete tariff, exact source bindings, parameter

is checked. No H-based improvement is claimed here.

The accounting improvement came from changing which completed arrays are
independent productive jobs. An autonomous helper of width 6, 7, 8 or 9 need
not be forced into a rank 57 output. The p3 controller also replaces some
unneeded whole idle paths by exact input/output scalar adapters, producing
rank 25 and rank 57 main outputs. Both changes preserve arbitrary inputs and
charge every remaining recursive call.

## Why the mixed-to-uniform step is substantive

Merely summing rank powers does not implement a recursive algorithm.
`FINITE-PRECOMPILATION.md` uses Sussman's Theorem 1G integer class flow, then
clears every ordered exit batch and source complement to whole arrays.
Each independent source array receives its complementary coordinates and
its source job exactly once. The complete finite program has only rank 1
leaves. A direct potential induction proves that some fixed top rank N has
the desired ordinary uniform saving.

No winning enormous template is claimed to have been written out. The
outer work supplies a concrete compressed choice of N and explicit bounds.
All finite scalar programs, routing words, field inventories, center banks
and precision constants remain actual fixed program constants. A suspended
unit retains its own center; the proof does not reuse one center for all
units at the same depth.

On BIT, the matching is performed before lowering internal projectors to
weighted canonical queries. The complete rational-cover program is built
with one common external weight, and its equal-rank jobs are joined by
fixed whole-fiber routes `g -> g*S`. Only the final rank 1 leaves are lowered.
This is the implementation in `../bit/DELAYED-COVER-BRIDGE.md`; the old
immediate-normalization argument had an actual weight mismatch.

## What the H work established, and what it did not

The native involution H replaces the full-identity local bill by a bill
smaller by 56 rank units per call. With the same p3 packing, a hypothetical
correct H controller has an available complete correction allowance of

```
228.06458440184225522412186424456699568...
```

at C=.004. That is enough for one 224H1 head-conjugation bill, leaving
4.0645844018422552241... units. It is not enough for three such bills.

The actual p3 scalar adapters work over a free noncommutative stage ring.
They produce the three interval products T2T1T0, T6T5T4 and T6...T0, each
twice. Thus this part never needed different H_s to commute. The physical
Q boundary sits on opposite sides of the two copies of each interval.
Directly closing the three problematic copies costs 672H1; the rank surplus
becomes −56 even at C=0. This is a failed implementation, not a lower bound
on all coupled boundary corrections.

The phase probe repairs a separate technical issue. Each old owner G_s
preserves a full Gaussian's polar form but has an even linear phase defect
d of weight 4 or 8. The signed monomial `Gamma_s=Z_d G_s`, where Z_d is a
physical coefficient character, is involutive and preserves the full
Gaussian including its absolute phase. It also preserves the port's q and
maps the old hole `F9*Cq` to `i*Ffresh8`. All 896 stage/port cases pass; the
independent companion audit lowers them to actual XOR-bit, SWAP-bit and
character operations. These are valid reusable primitives. Their complete
native whole-word substitution and a cheaper global H closure are not
claimed.

A further dyadic completion family is available:

```
H_lambda = J + (13+lambda) E_A [L,I]
         = I + [-K;(12+lambda)I] [L,I].
```

For dyadic units lambda (signed powers of two), this is invertible with a dyadic inverse.
The chronological choices −1/2,1,−2 multiply to identity in a common chart.
The exact actual-owner negative control shows why that identity cannot
simply be copied across distinct stages.

The final focused screen gives two further limits. In a universal
free-operator model, two complete-bank Q passages cannot implement all
three distinct Q K Q words even with all six streams and arbitrary Q-free
polynomial mixing. Its coefficient-span witness has rank3 against a
two-event upper bound 1. This excludes only that universal two-event model;
actual low-rank operator relations and partial-bank calls are outside its
scope. Separately, an actual old-block coordinate-sector
witness proves that a fresh-axis H word does not automatically supply the
inverse of an old monodromy. Reusing the old support cancels transform axes
as well as state; the accounting records that loss.

The strongest next lever is the actual rank-eight query geometry and its
legal frame contacts. The native embedded logger uses eight existing cold
helpers to return `d + C*X`, where `C=[L,I]` and `C*H=-C`, with no new
recursive children. After a post-source H wrapper, its precise defect is
`d - C*X_new`. The eight helper outputs require explicit restoration before
receiving independent output credit. A joint decoder could use this
information across the three interval jobs, but a single query bank has
not been proved sufficient. See `../complex/COMPOSITION-CONTRACTS.json`.

The final companion BIT probe also shows that requiring an involution can
overconstrain the local design. Its actual zero-repair operator has corank
3; three rank 1 row completions make it invertible. Forward wrappers use
G and reverse wrappers use its inverse. Arbitrary-input native replay
passes, but the direct three-boundary bill still exceeds its rank surplus
by 21. This is a better local contract with the same outstanding global
interface; see `../bit/PR589-MINIMUM-COMPLETION.json`.

A useful next probe should supply a costed geometry-aware query decoder,
a scalar controller with fewer independent negative interval jobs, or a
typed recursive contract with an actual inverse-state adapter. Generic
common-head sharing and same-chart identities alone are insufficient.

## Reproduction

Run these from the repository root, writing receipts to a separate replay
directory so the retained source-bound certificates remain byte-stable:

```sh
mkdir -p research/kappa-rebuild/architecture/replay
python research/kappa-rebuild/architecture/controller_tariff.py --output research/kappa-rebuild/architecture/replay/P3.json
python research/kappa-rebuild/architecture/identity_mixed_certificate.py --output research/kappa-rebuild/architecture/replay/P2.json
python research/kappa-rebuild/architecture/identity_mixed_certificate.py --prefix-cut --output research/kappa-rebuild/architecture/replay/P2-PREFIX.json
python research/kappa-rebuild/architecture/free_involution_wrap_probe.py --output research/kappa-rebuild/architecture/replay/FREE-H.json
python research/kappa-rebuild/architecture/aggregate_h_probe.py --output research/kappa-rebuild/architecture/replay/AGGREGATE-H.json
python research/kappa-rebuild/architecture/joint_boundary_probe.py --output research/kappa-rebuild/architecture/replay/JOINT-H.json
```

The exact certification commands use the Python standard library. The
optional LP discovery scripts additionally use NumPy/SciPy. Read
`LITERATURE.md` for primary-source attribution, the precise applications
tested, and the arithmetic/timing gaps that prevent directly importing an
unrelated theorem. `SOURCES.json` records the source provenance and copied
source hashes. `ARTIFACT-MANIFEST.json` inventories the frozen files in this
directory; it does not certify sibling files beyond their own receipts.
