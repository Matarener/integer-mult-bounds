# P112 common30 span and the literal 2^5,6,7^5 caller

For ONE common set S of at most30 live P112 sites, all characteristic-zero
normals whose residual support labels have binary rank<=7 span at most
**three dimensions**. A literal independent triple at30 attains three.
For |S|<=29 there are at most **two projective directions**. This settles the
exact relaxed geometric obligation for the historical (b,t)=(5,6) independent
piece profile **2^5,6,7^5**: six small pieces have support cap30<distance53,
force quotient dimension6 and intersection dimension5, then the five rank7
pieces require five independent code directions, contradicting5>3.

[PROOF.md](PROOF.md) supplies the complete root-normal/characteristic-zero
reduction, finite graph coverage, threshold29/30 and actual quotient transfer.
[RESULT.json](RESULT.json) stores exact digests, counts, literal normals and
cut labels. The five-direction caller uses linear independence; a count of
projective directions alone is not substituted for span dimension.

The finite domain contains43,435 seven-spaces,5,212,200 root/space pairs,
24,264 completion records and9,828 compatible distinct-owner pairs. All4,480
admissible triples require cut30;3,584 are independent. The primary traverses
2,688 four-node extensions of independent triples, all rank3. A separate
implementation directly checks **all3,360 compatible quadruples**, including
those with dependent first triples, and finds zero Gram determinants. It
uses separately coded shell/Cramer labels and affine-generator spaces,
imports no primary/predecessor executable and matches full record/graph
digests. This is computational corroboration within one donor/assistant
context, not independent human or formal-kernel acceptance.

## Reproduction

CPython3.12, standard library only, from the repository root:

```
python3.12 -I -Werror -B scripts/research_package.py --package research/p112-common30-span
```

The three explicit optimized commands are in [VERIFY.json](VERIFY.json).
They read pinned sources and compare results; they do not rewrite evidence.
The direct scripts also work in a source export with the declared input paths.
Controls compare the independence-pruned search with a subset oracle across
all1,024 graphs on five vertices (testing every graph that spans three in this
fixture); they check a real attaining triple, reject a synthetic independent
fourth direction, expose the characteristic-two boundary and reject actual
optimized CLI source/manifest corruption. No selected cold replay, Lean,
Docker or physical/supplier validation is run.
