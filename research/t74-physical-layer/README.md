# A physical T74 complex layer

I implement the complete PR2979 T74 complex caller and normalized root under
the retained native, hosting and ordinary-backend interfaces. I obtain the
conditional layer bound

    O(V d^0.99830289 (log(2d))^0.99830289) = O(V d^0.998305).

The layer saving is 0.001695, compared with the preceding 1/600 target.
I preserve the spaced-axis and long-record domain. This result supplies
neither the broader ordinary H2 statement nor a new integer-multiplication
exponent. See [PROOF.md](PROOF.md) for the quantified claim and inherited
assumptions, and [LAYER-BOUND.md](LAYER-BOUND.md) for the exact cost margins.

I bind both providers and both scalar orientations, compile their native
warps, and implement checked release of 91 private zero buffers. I preserve
the complete positive-child histogram. The global program has 666 calls,
2,222 events and 66,304 live families. I carry its actual owner charts through
recursive packet gathering, parent parking, restoration and root rounding.

## Reproduce

From the repository root, use Python 3.12 with numpy 2.2.6:

```sh
python3.12 -B scripts/research_package.py --package research/t74-physical-layer
```

[VERIFY.json](VERIFY.json) registers three cold commands. Each opens its
own authenticated archives and writes only temporary replay data. The native
command uses the retained assertion-based checkers with assertions enabled;
the new checks run under `-I -O -Werror -B`. The runner isolates bytecode caches.

The two archives retain PR3385's 74-file package export and the exact T74
native/controller data with its closed replay-source subset and notices.
The current checkout needs no unmerged predecessor commit to run these
commands. `freeze_inputs.py` records deterministic transport, not mathematical
acceptance. `prepare_inputs.py` exposes the optional author data-preparation
prefix from the exact 637-file source; its full Git export recipe remains in
PR2979. The default replay needs only the committed archives and declared inputs.
The production constructor also authenticates its finite inputs when called
directly; a changed warp phase fails before compilation.
