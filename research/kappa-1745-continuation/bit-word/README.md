## What changed and why it works

The main new freedom was to stop treating every intermediate dirty response as fixed. Only the required SOURCE observations, productive target action, legal frame paths and return of all arbitrary inputs need to be retained. Once the actual dirty response changes, the compensation matrix must change with it.

Let the raw A/COPY/scatter/B computation act as

\[
z' = U z,\qquad y' = y+x+K b,
\]

where `z` contains SOURCE and dirty-helper inputs, `x` is the SOURCE input and `b` is the entire arbitrary dirty-helper vector. In this finite word every non-target ADD is reversible and targets never feed the non-target registers. The initial D section writes the **actual** `K b` to the targets. The C section is the literal inverse of the actual non-target A/B operation sequence. OverF2 this gives the required final `y+x` and restores every coordinate of `z`.

This is checked on all659 input columns; it is not inferred only from zero-initialized helpers. D is emitted at frame0, so changing its support does not create a positive-rank recursive frame charge. Its ADD count and its effect on integer coefficient bounds are still charged. The final independent record replay checks the complete COPY lifecycle, all actual frames, the five-stage881-column construction and both integer prefix bounds.
