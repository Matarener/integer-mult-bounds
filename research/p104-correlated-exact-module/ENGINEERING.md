# Verification decisions

The exit predicate is a sharp source-bound entrance theorem with exact source
paths, a written necessity/sufficiency proof, complete local basis checks and
meaningful failure controls. A full supplier or improved kappa is outside it.

Build the Lever changed the deliverable from one cancellation example to
rerunnable module and source-slice checkers. Prove It Works required actual
literal source paths and optimized CLI failures, in addition to the algebra.
Unslop keeps the claims scoped to the dependency slice.

## Power of Ten inspection

The call graph has no recursion. Every arithmetic loop is bounded by nine
bits, 512 addresses, 4096 residues, eight fixtures or source-authenticated
5398 events and 2070 native occurrences. The fixed cone has 257 events and
58 banks. Source reads allow at most 4 MiB, expanded inputs 16 MiB and the
receipt 1 MiB. The temporary export stops at 64 inventory entries, rejects
symlinks and changes no permissions. Each subprocess has a 120-second timeout.
The registered commands each have the same bound. No background child is
launched. The temporary-directory context removes its owned files on success
or exception. All child return codes are checked explicitly.

Functions fit within 60 physical lines. Explicit exception contracts validate
source hashes, dimensions, frames, ranks, residues and outputs even under
Python optimization. Failed basis checks are accepted only at the two named
arithmetic boundaries. The wrong-sign control checks a genuinely nonzero
output. A canonical serialized full receipt rejects Boolean/integer confusion.
There is no dynamic evaluation, code generation or unbounded registration.
Calls and state are local; the separate checker imports no primary executable.
No source or shared runtime is mutated by replay.

Rule 3, fixed allocation, has a managed-Python deviation in all four scripts.
Python allocates lists, tuples, integers and parsed JSON during verification.
The scope is one finite invocation. The compensating bounds are the fixed
512-coordinate arrays, at most 58 live banks, authenticated finite source
inventory, capped byte reads and bounded export. There is no steady service
or growing queue. The Gaussian fixture norms are at most 128 before quarter
scaling and unitary transport, so the finite arithmetic is small. Python and
JSON library allocation is not an allocation-free physical implementation.
Registered and Git-free replay verify resource cleanup. A physical evaluator
would need a separate fixed-storage implementation and is not priced here.

Rule 9 has a bounded callback deviation for the rejection controls and their
four locally defined operations. Ordinary Python module dispatch is visible
in the imports; the primary and separate numerical paths remain distinct.
The callbacks introduce no plugin registry or alternate production target.
The actual optimized CLI tests exercise their failure paths.

For Rule 10 the affected scripts run with warnings as errors, normal and
optimized Python, and scoped Ruff E,F,B,PLE,PLW,RUF diagnostics with line length
100. The registered manifest retains warnings as errors on every replay.
Ruff is a development check, not an installed mathematical dependency.
No diagnostic is suppressed. Frozen predecessor executables are not imported
or changed; their full suites and mathematical premises remain explicitly
inherited. No new test of an unchanged root is substituted for the source
admission question.
