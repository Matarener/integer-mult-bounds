# Mixed singular Kronecker determinant characters

This completes the determinant-character question for every supplied direct sum of singular Kronecker blocks. It includes unequal indices, both orientations, arbitrary multiplicities and zero-index blocks, provided both full factor dimensions are positive. The theorem holds over every field. Regular blocks and discovery from an arbitrary tensor are separate problems. **No new kappa is claimed.**

Write a right index-e block as R_e and its transpose as L_e. Each distinct right type contributes the integer vector `(e,-e-1)`; each left type contributes `(-e-1,e)`. The complete determinant image is generated by these multiplicity determinants and the explicit common GL2 slice lift. All off-diagonal intertwiners are included in the proof.

Choose one type vector v0 and a primitive integer row ell that annihilates it. Let `d=gcd_i(ell dot v_i)`. With the exact slice exponents A,B in [PROOF.md](PROOF.md), a triple (x,y,z) occurs precisely when

`x^ell1 * y^ell2 * z^(-ell1*A-ell2*B)` belongs to `(K*)^d`.

For d=0 this means equality to one. Over F_q, the number of special-linear orbits inside the GL orbit is exactly **gcd(q-1,d)**. Equivalently, d is the gcd of same-orientation index differences and opposite-orientation sums e+f+1. Multiplicities affect the slice character but do not change this orbit count.

Examples show why the mixed result is different from the single-type rule. R_1 plus R_2 has one SL orbit over every finite field. R_1 plus L_1 has three over F4. R_1 plus L_2 has four over F5. The zero pencil formed from positive numbers of R_0 and L_0 has full determinant image.

The executable constructs a stabilizer witness for every accepted determinant triple, with any prescribed GL2 slice action of that determinant. It also corrects a supplied GL tensor map to a determinant-one map with exactly the same tensor image when the character permits it. It does not discover the supplied model or the initial map.
