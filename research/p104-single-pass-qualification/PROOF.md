# Source-bound elimination of duplicate qualification passes

This is a verification-engineering argument about exact deterministic computations on one frozen word, not a proof of the multiplication theorem.

Let I_B(w) return the complete ideal metadata and local weights and E_B(w,a,R) the complete error trace and signed witness dictionaries for backend B. In the authenticated source, Fraction `ideal`/`error_trace` and integer `Engine.ideal`/`Engine.error_trace` allocate their state locally, use exact arithmetic, and do not read random, time, file or caller-global state. They do not mutate w,a,R. The complete source contract calls I_B(w), defines R from all operation counts and then calls E_B(w,a,R). Qualification subsequently calls the byte-identical functions on the same complete word, weights and rounded operation set to obtain values for cross-backend comparison. These repeated calls are not additional independent scientific implementations.

The replacement retains a deep copy of the full outputs of the first actual I_B and E_B calls in each separately executed complete contract. It does not replace either backend computation with the other's output. Canonical input fingerprints bind the whole word; the trace binding also requires the precise independently computed weights and full rounded operation set. Arguments are fingerprinted before and after each invocation. Only actual successful calls are recorded, exactly once each, and only a successful complete enclosing contract permits consumption. Corrupt source, missing calls, duplicate actual calls, input changes, failed complete contracts or output drift prevent admission. Deep copies isolate the retained values from later mutation of returned values. Output fingerprints are rechecked at one-use consumption.

Consequently the complete ideal/weight and trace/witness equality predicates receive the same exact values as the unchanged qualifier's second calls. Full original RESULT equality is checked separately against each independent complete contract and between them. Every literal input/defect attaining fixture, signed final transpose check and original semantic rejection remains inside those untouched calculations. The original seeded 120-program differential is called unchanged with raw backends, including full trace/witness and reverse equality, plus all three integer failures. The coefficient scale and complete scientific receipt are still computed/compared to the original source record.

The Fraction calculation retains its own newly loaded original precision module. Its factory is wrapped only to observe the first-pass returns; the factory is restored in `finally`. The raw reference module, integer arithmetic and literal/reverse oracle code stay unchanged and authenticated. A context has no cross-command storage or reuse. The argument assumes the normal deterministic interpreter model; this does not claim hardware-fault independence from two repetitions of the same computation.

The finite gate precedes construction. The complete actual-word comparisons, six-process measurements, normal/optimized full commands and sealed export checks are additional implementation evidence. A source or word successor requires fresh purity/input/coverage review and finite feasibility. Physical native correctness, reset implementation, exact owned zero return, tapes, compiler/outer admission and the five framework assumptions remain predecessor obligations. No kappa change follows from this optimization.
