# Five rank-four BIT terminals and a fixed-controller cost bound

This package retains an explicit local BIT word with 433 width-eight and five
width-four dirty helpers. Its exact stream operator restores every source and
helper over the integers and gives the required public shear modulo two. The
complete local histogram is H={1:1322,2:1342,3:79,4:39,5:102,6:11,7:18}: 2913
children, rank mass5101, 36005 scalar ADDs, nine rank-seven COPYs and one private
zero field. No native supplier or improved multiplication exponent is claimed.

The five terminal helpers are462,463,464,467,470. Their ZERO preconditioning
changes the old H4 cleanup syntax. `PROOF.md` supplies the exact arbitrary-function
stream interpretation; `verify_word.py` independently checks all660 persistent
input columns, integer source/helper restoration, public Boolean action, both
inverse orders, private cleanup, 636 actual rational projectors and2394 nesting
pairs. The integer lift may retain even dirty coefficients in public targets;
its real/complex endpoint is not asserted to be a clean shear.

`admission/README.md` adds explicit reversible coordinate words for all three
terminal charts. Their Q/Q^-1 lengths are24,70,70; the complete D_E lengths
are100,284,284. These use arbitrary input coordinates, no scratch, and only
unit signed ADD, NEGATE, HALF, DOUBLE and SWAP over Z[1/2] and every odd field.
They are address-coordinate counts, not native payload or tape costs. The same
supplement gives exact dyadic prefix bounds and a defect-sensitive error model
with a counterexample to inferring exact private erasure from finite accuracy.

## Reproduce

Use Python3.12 and the standard library, from the repository root:

```sh
python3.12 scripts/research_package.py --package research/bit-five-rank4-terminals
```

`VERIFY.json` runs the package in normal and optimized Python. The checker
resolves inputs relative to the files, so a Git-free export works from any
working directory. `SOURCES.json` pins the one external geometry input and
upstream orientation. `LOCAL-PROVENANCE.json`, `WORD-ADAPTATION.patch` and the
supplements retain authenticated local originals, transfer manifests and exact
relocation adaptations. Absolute historical paths in provenance are not runtime
dependencies. SHA256 integrity does not establish authorship or mathematical truth.
