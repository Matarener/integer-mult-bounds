# QQ16 actual pair: a routed obstruction to selected-only repair

The first actual selected F0/B1 pair does not supply #4015's QQ16 recovery
entrance or the next bridge endpoint unchanged. A coordinated patch confined
to the sixteen selected output ports also fails: an exact legal owner-dependent
input changes an **ordinary** bridge output from zero to **1/2**. This package
closes that specific patch experiment and records the remaining paid connection.
It supplies no cheaper multiplication construction and no new κ.

These are specialised exact identities, not full physical adapters.

The full helper/precision/physical contracts are inherited obligations.

The decisive test keeps payload constant and restores actual cover dependence.

zero versus +1/2. A **post-pair** adapter whose writes are confined to A∪T in
