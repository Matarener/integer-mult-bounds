# Joint Gaussian transitions cannot cancel their scale charges

This contribution was produced by Nick Petalas. Apache-2.0.

For any finite set of complex helpers, prescribe multiplication of helper j
by `2^(a_j) (1+epsilon_j*i)^(b_j)`, where a_j is an integer, b_j is zero or
one, and epsilon_j is either sign. Permit arbitrary signed unit ADDs between
any real coordinates, doublings and halvings, with free permutations and
negations and any finite amount of restored dirty workspace. The exact
minimum is

```text
doublings/halvings = sum_j |2a_j+b_j|
signed ADDs        = 2 sum_j b_j
total             = their sum
```

Both lower bounds are attained by the same word, and apply separately to
its inverse. This is a **scoped proof with exact finite corroboration**.
It answers Open next question 2 of Sagar Thakrar's
[PR #1566](https://github.com/CrocSwap/integer-mult-bounds/pull/1566), which
leaves joint Gaussian transitions outside its separate-transition theorem.
The new result is the joint lower bound; the standalone transition words and
Gaussian-gauge setting retain their predecessor credit.

In particular, the requested reciprocal pair `(1+i), (1+i)^-1` costs exactly
six primitives, comprising four ADDs and two scales. Its determinant is one.
Using only the total determinant valuation would miss both necessary scales.
The same endpoint cost applies to the return; a round trip with no required
intermediate boundary can of course be the empty word.

## Proof and finite evidence

[PROOF.md](PROOF.md) uses the classical index distance between rational
lattices. A signed ADD preserves the integer lattice; a scale changes the
distance by at most one. The final block-product distance adds the absolute
block valuations, including opposite signs. Separately, each odd Gaussian
block needs two mixed rows and every ADD can create at most one. Explicit
three-operation words plus scalar powers attain both bounds. The proof
covers all integer exponents, helper counts and finite restored dirty
workspace. It does not depend on a finite search or a predecessor replay.

The standalone verifier checks exact rational matrices, all-input inverse
restoration and literal primitive counts. A separate finite quotient enumerates
the lattice intersections directly. Short arbitrary words test both invariants
on endpoints outside the target family. Controls remove a scale or ADD,
change the conjugate, leave workspace unrestored, or violate the input domain.
The fixed run checks 1,011 attaining endpoints, 42 finite lattices, 216 lattice
triangles, all 4,681 short words and 14 rejecting controls. The largest
checked attaining word has eighteen gates. Counts come from enumeration;
the universal theorem comes from the written proof.
[RESULT.json](RESULT.json) is generated by the verifier and binds every other
package file by SHA256; default replay compares the entire generated result.

## Scope and implementation limits

The `complex-new-helper-inventory` card is explicitly changed to this scalar
compiler side question. The selected baseline binding control passed; this
was orientation, not a scientific selected replay. Pure joint transitions
cannot evade the stated charge through cross-helper determinant cancellation.
The result stops here; it does not justify more gauge searches in this class.

General phases outside the conjugate family, nonunit odd coefficients,
clean initialized workspace with singular operations, COPY/clear and fused
non-block-diagonal endpoints are outside scope. So are rounding, routing,
coefficient production, physical ownership, native admission, full-word
scalar optimization, complete paid profiles, compiler/stock/outer premises
and a complete multiplication theorem. No new kappa or selected-frontier
change is claimed. Independent human and formal proof-kernel review are
unclaimed. No Lean, Docker or selected cold replay was run.

The finite checker allows at most four helpers, four extra real coordinates,
dimension twelve and even-block exponents from -8 through 8. Odd-block
exponents run from -8 through 7, a domain closed under inversion. Stored words
are capped at 256 gates; the fixed tests use a smaller domain. The lattice
enumerator uses at most 4^4 residue points, and the short-word census uses
eight gates through length four. There is no recursion, subprocess, network,
dynamic code evaluation or shared mutable output. Functions fit in 60 lines.
Input receipts and each source file are capped at one MiB.

Power of Ten rule 3 has a managed-runtime deviation in verify.py. Python
allocates exact integers, fractions, lists and sets during this offline
finite check. The preceding enforced bounds cap all live data; only one
case or short word is processed at a time. Warning-strict normal and
optimized replays check the same bounded path. A fixed-buffer implementation
would be required if allocation guarantees become a caller requirement.
Rule 9 has the corresponding standard-library arithmetic-dispatch deviation,
limited to integers and Fractions with visible direct calls. No separate
static type checker or linter is a dependency; warning-strict execution is
registered in CI. No shared build settings are changed.

Local execution used CPython 3.12.15 on macOS 27.0.1 arm64. Hosted replay
and source-history availability are separate publication checks.
