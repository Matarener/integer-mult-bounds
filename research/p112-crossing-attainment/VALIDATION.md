# Verification scope and engineering decisions

## Scientific coverage

The proof establishes the all-size statements. The two finite implementations
share fixture bytes and a result format, but the primary computes ternary
penalties and solves pinned component constraints, while the second builds
actual scalar-factor supports and rectangular binary Gram matrices. The second
does not import the first or its energy/criterion functions. Both compare the
entire ordered total-charge stream, histogram, minimum and first witness.
The independent replay also enumerates every binary MMM choice in the fixtures.

The 109 three-cell cases exhaust all subsets of the seven possible coordinate
membership types that leave every target group nonempty. The 32 six-cell cases
use generator seed 20261018 and one-in-four inclusion from the 26 possible
incidence records, with singleton records added for unused cells. They are a
fixed committed sample, not an exhaustive six-cell classification. The eight
private/common cases include strict, equality-threshold, skew and post-threshold
examples. The exact committed fixture bytes are authoritative.

There are 26,487 VVV assignments and 39,784 actual doubled-operator entries.
The latter are split equally over integers and F3/F5/F7, 9,946 each, for both
families, with two external scalar coordinates and generic parameter values.
No floating-point computation, probabilistic verdict or large-integer transport
enters the result. Integer stream encoding is decimal text with newline framing.

Controls corrupt six contracts and two result records through both real CLIs,
with -I -O -Werror -B. Geometry faults update the fixture hash so authentication
cannot mask a missing contract guard. Each fault must reject with its intended
diagnostic. Every restored copy must pass again. The source and temporary copy
must retain their device/inode, mode and SHA256 identities. Copies use exclusive
regular-file byte creation, without copied modes or chmod, and must have different
source/destination inodes. TemporaryDirectory owns only those four copied files.

## Power of Ten assessment

The three scripts are the entire scientific runtime. JSON/Path/hashlib/itertools
and subprocess/tempfile/os/stat in controls are standard-library mechanisms.
No predecessor or ambient module is imported. All CLI paths derive from the
script's own regular location. No recursion, dynamic evaluation, generated code,
indirect callback chain or shared mutable registry is used.

Every accepted fixture file is at most 2,000,000 bytes, has at most 256 cases,
3..9 cells and 1..64 coordinate lines of arity 1..3. Every cell is nonempty,
every group exists, indices are exact integers rather than booleans, and each
line has at most one occurrence in each group. The explicit worst-case ternary
loop is 3^9=19,683 per case. Binary cover/MMM loops are at most 2^9=512.
Connectivity propagation has nine passes over at most 64 edges. Each binary
matrix has at most 192 rows/columns; elimination has 192 iterations per row.
Actual immutable fixtures are much smaller. All subprocesses have 30-second
bounds; the registered commands have 120-second bounds. The generic launcher
is unchanged, and arbitrary worst-case accepted inputs are not promised to
finish within those timeouts. Exhaustion fails explicitly.

All argument/range/identity guards use normal exceptions and remain active under
-O. Functions have one responsibility, local state and explicit return values.
All subprocess exit codes and diagnostics, byte-copy lengths and returned
rank/result/identity values are consumed. Cleanup uses a scoped temporary owner.
There are no shell subprocesses or network commands in scientific replay.

Rule 3 deviation: CPython and standard-library operations allocate during
execution. Static no-allocation operation cannot be implemented in this managed
runtime. Enforced fixture dimensions bound the largest live raw matrix by
192 by 192 binary entries represented as at most 192 Python row integers.
Histograms have at most 257 possible tariff totals, streams hash incrementally,
and only one assignment/matrix is live at once. JSON and the complete result
record are bounded by the fixture/record byte checks. Follow-up is a fixed-buffer
implementation if this verifier is ever required in a no-allocation environment.
The platform's internal allocation is not instrumented here.

Rule 10 limitation: warning-as-error execution and available Ruff diagnostics
cover the touched Python. No repository-wide static-analysis policy is changed.
Ruff E/F/I/B/UP/ASYNC/SIM diagnostics pass, including strict zip-length checks.
The full optional scan also reports annotation/docstring, named-constant,
package/copyright, trailing-comma, print and exception-style suggestions. The
subprocess suggestion refers to fixed argv using sys.executable and owned local
script paths, with no shell or caller-controlled executable. Those suggestions
remain documented rather than suppressed; incompatible docstring rules cannot
all be enabled together. They do not establish mathematics or managed-runtime
resource guarantees. Follow-up is a repository-wide type/doc/style policy if
these standalone research CLIs acquire a typed caller API.
There is no compiled-code build or configured static typechecker for this package.
Any diagnostics actually run are recorded separately from mathematical replay.

## Limits

Registered metadata and source-history checks establish declared provenance and
committed-byte consistency, not the theorem. The scientific/control commands
need only package-local bytes and CPython 3.12. They are separately replayed at
the actual publication HEAD in a Git-free export. Before/after hashes and distinct
inodes bind that replay to committed bytes. The report records the exact HEAD
of each check; no prior run is silently attributed to a later commit.

Independent human/formal review, hosted CI, selected full cold replay, Lean,
Docker, broader non-coordinate geometry, characteristic two, arbitrary queries,
physical native/coefficient/frame/restoration/hosting/precision/stock costs,
compiler/all-size admission and full supplier/consumer obligations are unclaimed.
