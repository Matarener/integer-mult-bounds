# Current R437 whole-word translation audit

This package extends Nick Petalas's [PR2989](https://github.com/CrocSwap/integer-mult-bounds/pull/2989)
conditional compiler audit to the complete current R437/OQ4 source event
skeleton. It compares the retained logical Driver with the actual finite
compiler and dispatcher on every one of the source's 288 calls, 903456 residual
sites and 29 global checkpoints, using one formal low-class label and arbitrary
symbolic family packets. The source has 660 staged roles, including private 659.
All local and family XOR inputs/outputs are traced, and each emitted disposal
must complete. The actual `Machine.run` loop is separately checked under explicit
recursive-cut contract actions.

The added result is **current-source symbolic translation coverage**. The
conditional ordering lemma and omitted-owner admission guard were already
established in PR2989; [PROOF.md](PROOF.md) restates the lemma with the present
source boundary and preserves its credit. This is neither an independent
numerical implementation nor execution of production packet bodies. The
primitive, residual, stock, history, physical parking, precision, full cost and
ordinary/native/router premises remain explicit.

## Exact scope and evidence

The frozen current inputs are ai-nanachi's R437/OQ4 word/template at
`a24f9ff95c12fd0b6792e3f710569237efd72db2`, retained byte-for-byte through PR3936
scientific commit `125f5afad680ef128e386fa58e76eef5fadaa5d6`. The current canonical
runtime and task base are `20ecf2891d80b5acf18d980b2164fb44ea7faa90`.
[SOURCES.json](SOURCES.json) lists exact Git blobs, SHA256 and origin paths.
PR3967's actual rank26/COPY515 return audit supplies prior context, not a hidden
assumption that its 46-bit controlled body was a volume-valid production packet.

The verifier extracts the actual Driver, LocalState, compiler, Cursor and
dispatch method AST. It makes one explicit test-only compiler adaptation:
stream the append-only operation list to the checker, preserving append order,
instead of retaining millions of instructions. Primitive calls construct
compact SHA256 expression terms. The two paths compare every ordered residual
result and every ordered XOR input/output, all global family states, and cleanup.
This is differential source reuse. The written induction explains substitution
of complete physical packet operators under their stated contracts; finite term
hashes alone are not a formal-kernel proof.

The full current source is reconstructed at the event/index level, including
rank26 IDLE27776, rank42 IDLE27777 and actual COPY1603. Projector algebra, evaluated
chart equality and the full request-record digest are covered by predecessor
artifacts and are not recomputed here. Distinct chart *tokens* do not prove
native packet separation modulo q. The concurrent transport lane supplies a
separate current chart certificate; this package retains separation as an
explicit hypothesis even if that certificate is not admitted.

[EXPECTED.json](EXPECTED.json) records the exact counts/digests and five rejected
semantic mutations: replacing clone by destructive move, losing private output,
using stale family state for scatter, omitting private disposal and reversing
XOR roles. A tiny two-low case runs in both mode 0 and mode 1. The known duplicate
owner counterexample again distinguishes logical admission from mere compiler
success. The unchanged `Machine.run` loop executes well-bracketed contract
actions at depths 0, 1, 2, 17, checking next/jump/done continuation behavior. No actual
CALL/RETURN physical contract is inferred from that loop model.

The all-low statement is a conditional nested-loop induction. **One formal low
label is not an enumeration of GL64**, and opaque good-block residual symbols do
not test actual good/fallback numerical bodies. No native producer, physical
full-volume payload, complete GL64 program, old-source digest portability,
visited-cell bound, supplier admission or new kappa is claimed.

## Reproduce

Python 3.12, standard library only, from the repository root:

```sh
python3 -B scripts/research_package.py --package research/r437-whole-word-refinement
```

The registry authenticates provenance and runs a complete read-only symbolic
replay, optimized semantic controls and an actual Git-free quick export with
changed/missing/symlinked input rejection. The full symbolic receipt is compared
exactly. `verify.py --quick` runs only bounded semantic controls, not the actual
whole-source event sequence. The export check runs that quick scope explicitly.
