# R437/OQ4: uniform native/common owner transport

This package closes the chart-invertibility premise retained by Nick Petalas's
[PR2989 audit](../physical-compiler-correspondence/README.md), and refreshes its
owner-separation certificate to the actual current R437/OQ4 source. It establishes: **all owner packets within a call are disjoint, for every odd prime q,
every invertible common low class and every high lift**. The actual current
R437/OQ4 charts have exact dyadic determinant ±1; every same-family chart pair
has an entry difference ±1 or ±1/2. Consequently the compiler may rely on the
original Driver's owner-key separation predicate without testing enormous GL64
cohorts. The [proof](PROOF.md) then gives the typed gather/route/local/scatter
commuting square for an arbitrary completed local map and arbitrary dirty data.

This is a new current-source independent arithmetic certificate, plus an explicit
application of the existing uniform interface arguments. The catalogue/compiler and primitive tape implementations are
reused and credited. It does not certify the complete multiplication theorem,
execute a full GL64 physical packet, admit a supplier or change the frontier.

The two mathematical viewpoints are finite-field group actions on low/high
matrix fibres and disjoint packet interfaces. Their conjunction identifies the
precise implication: injective owner keys permit staged local execution followed
by chronological scatter into the latest family state.

Evidence in [RESULT.json](RESULT.json):

- 1,235 actual chart labels: 236 determinant +1, 999 determinant -1 over Z[1/2].
- 5,619 same-family role pairs across nine canonical calls; explicit 32-fold
  symmetry gives 179,808 pairs across 288 calls. Every pair has a dyadic-unit
  entry witness, so its distinction survives every odd characteristic.
- The exact current ordered request digest is
  `cbfea55f5cd0b74a2a0d4292ad0139d2b5bb73127951127698030bc90c73c532`.
- The full transport counts are253,728 N completed gathers,253,728 N completed
  scatters and 379,584 N completed routes, where N=|GL64(F_q)|. The transport bill
  is253728 N(G+S)+379584 N R, with setup, transfer and disposal inside each tariff.

  header at(q,w)=(3,2),(5,3),(7,4); low-only retagging loses those carries.
- Controls reject duplicate charts, an odd-prime determinant, an odd denominator
  and a chart difference vanishing modulo3. A separate small semantic control
  exhibits the lost write from scattering into a stale family snapshot.

The universal assertion follows from the exact dyadic certificate plus the
algebraic proof. The finite carry controls are diagnostic checks, and the small
stale-scatter example is not a physical production replay. The new checker
predicates remain enabled under optimized Python.

## Reproduce

From the repository root, standard-library Python 3.12:

```sh
python3 scripts/research_package.py --package research/r437-native-transport --check-only
python3 scripts/research_package.py --package research/r437-native-transport
```

The registered commands authenticate every declared input and regenerate the
complete exact certificate against its frozen JSON, normally and with `-O`.
They are read-only. Optional `check_transport.py --write` regenerates the receipt
when deliberately changing a source; do not use it to excuse a mismatch.

All pending-source bytes needed for replay are retained in this package. The
adapter is byte-for-byte PR3967's source, derived from zxv/PR3690; canonical
caller inputs are declared in `VERIFY.json` and SHA-256/Git-blob bound in
`SOURCES.json`. No remote predecessor Git object is needed for cold replay.
