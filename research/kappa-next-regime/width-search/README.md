## Exact width exclusions and their limits

For a possible common entrance subspace E, only helpers whose first-contact
frame contains E are eligible. Their columns of the complete dirty response K
must have a nonzero binary kernel direction. The credited intersection-closure
theorem reduces the test to the original first-contact planes and their
one-dimensional intersections, including lines that are not SOURCE roots.

`entrance_closure.py` independently reconstructs the original R437 raw response
before checking 213 line classes and 153 plane classes. Every restricted K has
full column rank. A separate row elimination agrees with the credited column
engine, and the engine's six controls are retained. This closes arbitrary-size
helper-only kernel supports at common first contact for that fixed word.

`composed_entrance_closure.py` repeats the complete calculation for the final
word. K is still identical, but helper469's first contact changes from frame94
to184. The first-contact inventory changes from 283 lines/154 planes to
282 lines/155 planes. All 366 classes still have nullity zero. The final
receipt is `COMPOSED-ENTRANCE-CLOSURE.json`.

`center_return_search.py` checks direct restoration of a copied center at every
existing B cut of the original word. All nine centers are never scalar sources
in A/B. A successful restoration to its arbitrary original dirty input at its
rank-seven COPY frame would permit omitting its FULL cleanup writes and
reducing its exit width. The search includes every eligible current non-Y
donor, without assuming any donor is clean. There are 713 cuts for each center,
or 6,417 cases. Each failed span has an explicit binary separating covector
that annihilates all eligible donor rows and detects the desired restoration.

`composed_center_return.py` repeats all 6,417 cases after the permanent carrier
changes. It also finds no solution, with fresh separating covectors. Its
receipt is `composed-center-return/RESULT.json`. These tests concern one
common-frame linear reset. They do not exclude multiple stages, changed COPY
timing, simultaneous center restoration or a changed donor graph.

## Remaining directions

The completed gain comes from changing the scalar word and allowing a dirty
covector to persist until existing cleanup. Subsequent work should keep that
full dirty model and the complete tariff. Further permanent last-use factoring
is a directly compatible mechanism. Any new word must reopen its width census
before reusing these fixed-word exclusions.

The word track's prefix-GL study also found rational entrance spaces outside
the old root-line catalogue for some **changed** prefix graphs. Those are not
physical width candidates yet: they need literal rational entrance
representations, complete dirty compensation, native gauge records and a full
owner/width invoice. Root-line catalogue failures must not be described as
universal obstructions to those changed graphs.

For return-based helper reductions, the next distinct family is a multistage
relay or retimed capture that changes donor availability. The one-step reset
family tested here is now closed for both original and final words.
