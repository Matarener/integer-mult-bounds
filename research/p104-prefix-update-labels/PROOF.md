# Conditional code construction and update proof

This contribution was produced by Nick Petalas. Apache-2.0.

## Premises and claim

Let G be a finite abelian group of source states and H a subgroup acting by translation.
For the application G is the 64 period cosets of PR3070's rank-two word, and H
is generated by 2e_j. Let d be its defect function and let a code state be the
future signature S(x)=(d(x+h)) indexed by h in H. Only this signature description
and the fiber profile `{1:8, 2:24, 8:1}` are imported from PR3070. No independent
proof of those P104 premises is claimed.

The same argument works for any finite abelian G, any H and any d whose
signature fibers have the given profile. The code construction is finite and
explicit, and the optimal mean is conditional only on that profile and an
initially uniform source state in G.

## Fibers retain size under every allowed update

If S(x)=S(y), then for k in H, the entries of S(x+k) and S(y+k) are the equal
entries of S(x) and S(y), reindexed by h -> h+k. Hence there is a well-defined
update T_k on signature states. T_-k is its inverse. Translation x -> x+k is
a bijection from the full fiber of S(x) to the full fiber of T_k S(x).
The two fibers therefore have the same cardinality.

This is a consequence of the signature contract, independent of the P104
floor word. Every update sequence preserves fiber size pathwise. The assertion
still holds if later instructions depend on earlier states, since every chosen
individual update has that property. This does not assert that adaptive
instructions preserve the source distribution or are free to compute.

## Prefix construction and exact average

Use `000` for the sole size-eight fiber. For the twenty-four size-two fibers,
use the five-bit binary words for 4 through 27. For the eight singleton fibers,
use the six-bit binary words for 56 through 63.

The first word occupies exactly the four five-bit prefixes 0 through 3.
The second group occupies five-bit prefixes 4 through 27. The last group
splits the four remaining five-bit prefixes 28 through 31. Thus the words are
prefix-free and their Kraft sum is `1/8+24/32+8/64=1`.

Uniform source states give probabilities 1/8, 1/32 and 1/64 to the respective
code states. Every probability equals two to the negative displayed length.
The expected length is therefore exactly

    (8*3 + 24*2*5 + 8*6)/64 = 39/8.

Thirty-three distinct states require at least six bits in a fixed-width code.
Thus the average saving against the minimum fixed width is 9/8 bits. This does
not reduce the maximum width. Distinct signature states must remain distinct
in any exact update-capable code, since some future observation separates them.
Adding redundant states cannot reduce the optimum: choosing a shortest word
from each signature state's words preserves prefix-freeness and weakly lowers
the cost for every source in that fiber.

## Mean-length optimality

For any prefix code, let its lengths be l_i and let q_i=2^(-l_i), with
K=sum q_i <= 1. Write p_i for the positive probabilities above. The classical
log-sum inequality, or Jensen's inequality for -log, gives

    sum p_i log2(p_i/q_i) >= -log2 K >= 0.

The left side is `sum p_i l_i - (-sum p_i log2 p_i)`. Thus every prefix code
has mean length at least the entropy 39/8. The displayed code attains it.
The same lower bound applies to uniquely decodable binary state codes by
Kraft-McMillan. These coding inequalities are standard, not new mathematics.
No claim is made about block/arithmetic coding with different state framing.

## Packed updates and limitations

Our code length is a function of fiber size only. The first argument therefore
shows `length(T_k s)=length(s)` for every allowed update. Decode a word,
apply T_k, and encode it again. This defines a reversible update on valid
codewords and changes neither its endpoint nor the locations of subsequent
packed words. T_-k is the inverse. The prefix property allows boundaries to be
parsed without a separate length header. A physical implementation still pays
its dictionary, instructions, parsing, lookup, routing, workspace and cleanup.
This argument does not construct or bound those costs.

The expected storage is exactly 39/8 at every stage for an initially uniform
source, because length is invariant for each individual source trajectory.
For arbitrary source distributions the expected length can be six. This
average-storage result neither contradicts PR3070's fixed-width obstruction
nor improves a worst-case multiplication exponent.
