# Any-register four-call floor for the A5 conjugate 5-cycle pair

**Scoped algebraic theorem; no new kappa.**

## Model

Let `A5` be generated by

```text
x = (1 2)(3 4),    y = (1 3 5)
```

in the standard right-to-left permutation composition. Put `c = xy` and
`c' = yx`; both are 5-cycles and are conjugate in `A5`. Work in the full formal
group algebra `R = F2[A5]`. For every finite register width `r >= 2`, a paid
factor is

```text
D_N(g) = I + ([g] + [e]) N,    g ∈ {x, y},
```

where `N = u v^T` is any binary rank-one idempotent in `M_r(F2)` (`v^T u = 1`).
There are no free address maps, COPY, ERASE, or clean roles. Extra registers
beyond the first two are arbitrary dirty spectators that must return to `[e]`.
The target is

```text
T = diag([c], [c'], [e], …, [e]).
```

The direct word

```text
D_{E_{00}}(x) D_{E_{00}}(y) D_{E_{11}}(y) D_{E_{11}}(x)
```

attains `T` in four calls for every `r >= 2`.

## Support filter

Expanding a chronological product of paid factors, every group-algebra
coefficient that appears is a product of a subsequence of the word’s labels
(order preserved). Among all words of length at most three over `{x, y}`, the
only patterns whose subsequence-support contains both `c` and `c'` are

```text
xyx    and    yxy.
```

Every other pattern of length `≤ 3` is therefore incapable of realizing `T`.

## Obstruction for `xyx`

Write `α = [x]+[e]` and `β = [y]+[e]`. Then `α² = 0` and

```text
D_A(x) D_B(y) D_C(x)
  = I + α(A+C) + β B + αβ (AB) + βα (BC) + αβα (ABC).
```

The ring element `αβα` is the unique carrier of the group element `xyx` among
these five summands, while `αβ` carries `c` but not `c'` and `βα` carries `c'`
but not `c`. Matching `T − I` therefore forces

```text
ABC = 0,    AB = E_{00},    BC = E_{11}.
```

The identity and `[x]` coefficients then force

```text
A + C = B = E_{00} + E_{11}.
```

But `E_{00}+E_{11}` has rank two, so it is not a rank-one idempotent. This
contradicts the requirement that the middle label’s projector `B` lie in the
paid alphabet. Hence no `xyx` word realizes `T` at any finite `r >= 2`.

## Obstruction for `yxy`

The parallel expansion

```text
D_A(y) D_B(x) D_C(y)
  = I + β(A+C) + α B + αβ (BC) + β² (AC) + βα (AB) + βαβ (ABC)
```

has `βαβ` as the unique carrier of the group element `yxy`. Matching `T − I`
forces `ABC = 0`, `AC = 0`, `BC = E_{00}`, `AB = E_{11}`, and then again

```text
B = E_{00} + E_{11},
```

which is not rank-one. Thus no `yxy` word realizes `T` either.

## Conclusion

Every word of length at most three is excluded, and the four-call direct word
attains the target. The exact minimum is therefore four for every finite
register width `r >= 2`. The argument never enumerates words at a fixed width;
the finite controls in the verifier only replay the direct word, omission
mutations, and small-width idempotent counts.

## Limits

This is a formal group-algebra theorem for the stated alphabet and endpoint. It
does not price a native BIT realization of the labels `{x, y}`, nor does it
change the selected kappa.
