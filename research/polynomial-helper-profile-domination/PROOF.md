# Zero-state extraction preserves the labelled linear interface

## Contract

Let K be an infinite field and R a subring of K. There are finitely many
vector registers of a common finite dimension d. The data and dirty workspace
vary independently over K. A specified subset of scratch registers may instead
start at zero. Every gate has distinct source a and target b, a fixed K-linear
operator T, a label ell, and a fixed scalar polynomial p in R[t] with p(0)=0.
It performs one of the following operations. Powers in p are coordinatewise.

    b += p(Ta),       or       b += T p(a).

The source and other registers stay unchanged. Each gate is invertible by
subtracting the same increment. No invertibility assumption on T is needed.
The sequence, coefficients, operators, ports and labels are independent of
input values. A label records one allowed paid operator class. Multiplication
by any scalar in R is permitted in the linear class at that same label charge.
The polynomial class grants its extra pointwise arithmetic for free. This is
an optimistic operator-call model, not a physical implementation claim.

The call profile n_ell counts gates of each label. Any nonnegative tariff
sum_ell w_ell n_ell is allowed. Labels may encode rank, operator, orientation,
ports and other fixed distinctions. There is no claim that these counts alone
constitute the selected supplier's complete invoice.

## Theorem

Suppose a word in this model implements an exact linear endpoint L on every
allowed input. Include every required dirty return and clean-scratch return in
that endpoint. Replace each gate by

    b += p'(0) T a.

If p'(0)=0, delete its gate. The extracted word has the same endpoint on the
same allowed input space. For every label, its call count is at most the
original call count. Thus every attainable polynomial call profile is dominated
coordinatewise by an attainable linear profile. The attainable Pareto-minimal
profiles, and the minimum for every nonnegative tariff, are identical in the
two classes. This holds with any finite number of clean or dirty registers.

## Proof

Let J be the ideal generated by all independent input coordinates in their
polynomial ring over K. Substitute zero for the initialized clean coordinates.
Every initial register has zero constant term. Inductively this remains true
after each gate because T is linear and p(0)=0.

Modulo J squared, a polynomial p(u) with u in J equals p'(0)u. Linear T
commutes with taking degree one. Therefore either gate placement induces
exactly the displayed linear shear on the degree-one parts. This proves by
induction in chronological order that the extracted word equals the degree-one
part of the complete original endpoint, including every workspace output.

Over an infinite field, equality of polynomial functions on all independent
inputs implies equality of their polynomials. For completeness, a univariate
nonzero polynomial has at most its degree many roots. Induction in the number
of variables applies that fact to the coefficient polynomials in the last
variable. Hence an endpoint that is the linear function L has degree-one part
L itself. This proves the endpoint statement. Equivalently the proof is the
chain rule at the common fixed zero state.

A retained gate has its old T, label, ports, placement and order. Its scalar
p'(0) is in R. A discarded gate induces the identity on degree-one parts.
Consequently no label count increases. Linear gates are already polynomial
gates, proving equality of the profile minima in both directions. The same
argument applies separately at every permitted dimension. If a fixed word
uses a uniform operator family T_f, the single extracted word is independent
of f, so an all-width endpoint gives an all-width extracted endpoint.

## What the theorem excludes

Adding zero-preserving pointwise polynomial gates to this labelled linear
helper model cannot evade any call-profile obstruction proved for its full
linear scalar class. This conclusion does not require a common flag, a
commuting operator alphabet, a bound on polynomial degree, or a bound on the
number of borrowed registers across different candidate words. Each word
must be finite. The executable checks a bounded rational subcase.

The conclusion concerns exactly the same linear output contract. A nonlinear
output could carry different information and require a different consumer.
No selected-word result, supplier lower bound or multiplication theorem is
inferred here. In particular, a lower bound limited to signs or unit scalar
coefficients cannot be used if derivatives introduce other allowed scalars.
Representation changes and their frame, precision, scalar, movement and
restoration costs require their own implementation argument. The theorem
only preserves the declared operator-call labels and the algebraic returns.

## Essential boundaries

1. A nonzero constant can move the trajectory away from zero. For example,
   adding 1 to a source, adding its square to a target, subtracting 1 from
   the source, subtracting the source square from the target, and subtracting
   1 from the target produces the exact linear endpoint target += 2 source. Differentiating each gate at zero separately would
   miss the linear term. This word is outside the contract.
2. Over F2, target += source squared is the linear map target += source on
   every input, but its formal degree-one part is the identity. Thus the
   infinite-field or polynomial-identity hypothesis matters. The same issue
   arises on a restricted finite grid inside an infinite field.
3. Linearizing a word never proves that its endpoint is linear. The single
   gate target += source + source squared has the same degree-one part as
   an addition but has a different endpoint. Exact endpoint verification is
   a separate premise; basis-only testing is insufficient.
4. Branching, rounded arithmetic, discontinuous bit operations and nonlinear
   address permutations are outside these polynomial data-value gates.

The degree-one quotient, chain rule and polynomial identity principle are
classical. The contribution is their explicit labelled-profile domination
statement for this helper contract and its bounded executable extraction.
