## Reproduce

Python 3.12, standard library only; the direct verifier needs neither Git nor
network. From the repository root:

```sh
python3.12 -B research/direct584-commuting-retiming-cover/verify.py
python3.12 scripts/research_package.py --package research/direct584-commuting-retiming-cover
```

The registered command has a 600-second bound. The initial fixed-frame replay
took 165 seconds; final scoped validation is recorded in [VALIDATION.json](VALIDATION.json).
A missing certificate is an error; the verifier never regenerates it. Exact
source-container hashes bind immutable inputs, while regenerated certificate
containers are compared by decompressed JSON rather than gzip-header bytes.
