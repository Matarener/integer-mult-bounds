# Source-bound logical recursive caller for the changed word

`caller.py` supplies a new finite Catalogue and Topology to the unchanged
generic executable in `inputs/caller/`. It binds both the PR4183 word and
the frozen five-terminal word to the same mixed-width owners. The resulting
logical caller has the all-size endpoint and the baseline `p=1` time
recurrence below. This is a source-level construction and written proof,
supported by the finite checks in `CALLER.json`; it is not a formal-kernel
theorem or an execution of the enormous complete selected GL64 payload.

All 84 retained files are exact exports from
`12fa8c5c844be21bfefb38a19503fbd867a11244`, authenticated by
`CALLER-SOURCES.json`. The loader reads and hashes every file before import,
then executes those same bytes with `compile(..., optimize=0)`. It neither
reads nor writes Python bytecode, and historical assertions remain enabled
under an optimized parent. The original Catalogue's 661-role, full-width
terminal and old-profile assertions remain unchanged. The new provider
overrides construction and binding; the new Topology overrides only
`call`. The retained request templates, coefficient grammar, numerical
normal forms, Consumer, Driver, recursive Frame and scheduler are reused.

## All-size input and endpoint

Fix an odd prime q, w>=1, A=q^w, and m=64. Put

```
N=|GL_64(F_q)|, H=q^(4096(w-1)), W=28416, P=28425,
K=lcm(W,P) N H=269241600 N H,
D(n)=0 for n<64; D(n)=1+D(42 floor(n/64)) otherwise.
```

At an internal node of width n>=64, supply R=t K^D(n) fresh rows, t>=1,
and the complete ordered packet

```
[C physical frozen-prefix ordinals][R fresh rows]
[B][head A^n][G][tail A^n][S].
```

C,B,G,S are arbitrary positive extents. Repeated numerical frozen prefixes
remain separate physical ordinals. Every payload bit, including every dirty
helper packet, is arbitrary. The incoming unit a_i is generated by the
retained source-bound encoded program. It may read its frozen ancestor
prefix and coordinate i, but not this node's fresh family, low/high header,
unused rows, payload or spectators. An unrelated coefficient oracle is
outside this contract.

The output is the Boolean pullback of

```
head_i' = a_i tail_(n-1-i),
tail_(n-1-i)' = a_i^-1 head_i,       0<=i<n,
```

with every row and spectator coordinate preserved. The borrowed source,
input program and complete directory are unchanged; output is separately
owned, heads return, and owned temporary tapes and numerical words close.
The internal constructor accepts n>=64. Smaller children use its completed
leaf interface; they are not new below-64 root constructor entry points.

Here is the explicit induction transferring the retained caller theorem.
The new catalogue installs its topology once at
`catalogue._recursive_caller_topology`. Unchanged `node.selected_topology`
uses it, and every unchanged `recursive_call.Frame` passes the same
catalogue and Specifications to the child's SelectedNode. Production code

Let f=floor(n/64) and delta=n-64f. The unchanged peel handles the delta

