# Delayed carrier retirement in the complete logical BIT recursion

The PR4183 local saving fits an explicit chronological owner/controller
construction. After all idle remainders are returned, the complete
nine-stage, 32-replica template has **902,592 paid recursive requests**,
compared with **902,880** for the frozen five-terminal word using the same
owners. Both have paid rank mass **1,808,352** and live stock **28,416**.
The difference is exactly `288*(e7-e6-e1)`.

The construction now binds those packets to an actual all-size logical
caller. Its source-level proof includes coefficient access, complete
spectator packets, recursive returns, private cleanup and logical storage.
The saving survives the full fallback-inclusive recursive moment and
strictly improves the sufficient power bound for this `p=1` caller.
This is not a pointwise runtime comparison at every finite width, a fixed
physical-tape implementation or a stronger multiplication exponent.

## What is constructed

The source is [delayed carrier retirement](../bit-delayed-carrier-retirement/README.md)
at `928066009267fb32ab2c1a29b50fa3093ea18aef`. Its principal Boolean word
has 438 dirty helpers, including five terminal residuals of rank four,
and restores its private COPY stream. Both independent rank-two queries
on helpers 413 and 444 remain.

`owner.py` derives the actual 29-event controller, open source windows,
ordered helper widths, owner charts and all 126,144 helper occurrences.
It retains the R438 allocation's families and stages, compacts each
bin according to the actual widths, and dispatches every residual
complement. The five shortened helpers return **5,760 additional ranks**
globally to idle work. These ranks are charged.

Helpers can share a physical family only through distinct owned cover
classes. Explicit dyadic charts establish separation, including complete
high packets, and conjugate each actual terminal residual to its allocated
support. Complete local calls are reduced to their proven endpoints before
their residuals are moved inside untouched windows. No internal
noncommuting queries are commuted past one another.

The address-coordinate programs include chart inverses and have no
arithmetic scratch cells. Their operation counts are explicit, but are
not themselves native payload or tape tariffs. See
[OWNER-PROOF.md](OWNER-PROOF.md) and [OWNERS.json](OWNERS.json).

`native.py` is a new provider for the signed, framed literal records.
It emits the existing raw-record schema, checks both orientations,
and replays complete five-, nine- and eleven-stage Boolean columns.
It authenticates heterogeneous terminal states and checks literal
COPY/source/helper contracts separately from Boolean public endpoints.
It does not claim compatibility with the older A/scatter/B exporter.
See [NATIVE-PROOF.md](NATIVE-PROOF.md) and [NATIVE.json](NATIVE.json).

`caller.py` supplies the changed Catalogue and Topology to the retained
generic Consumer, Driver and recursive Frame. The complete candidate

the replicated count is exactly the owner/price census. Independent
source-cut checks establish that source50 has been restored at every
new read. Charged private clears satisfy the classical logical Tape
contract. The all-size induction preserves the complete ordered source

[CALLER-PROOF.md](CALLER-PROOF.md), [CALLER-REVIEW.md](CALLER-REVIEW.md) and
[CALLER.json](CALLER.json).

## Complete price and precision

With conservative ordinary BIT fallback charged per paid request, exact
rational interval calculations give:

| Matched construction | Complete requests | Fallback-inclusive moment root |
| --- | ---: | --- |
| Frozen five-terminal word | 902,880 | `(0.001737388318390108294399, 0.001737388318390108294400)` |
| PR4183 changed word | 902,592 | `(0.001737631818486007553483, 0.001737631818486007553484)` |

The rational rate `139/80000 = 0.0017375` strictly separates the two
complete moments. Two independent rational interval methods certify the
signs. For every `0 < b < 1`, strict subadditivity gives the exact
improvement

```
288 * 64^b * (1 + 6^(1-b) - 7^(1-b) + 32*64^2/10^16) > 0.
```

Both words need 114-bit local and 211-bit nine-stage positive envelopes,
charged as **128 and 256 bits**. The older 104/192 caps fail. The changed
word does not cross a charged-precision boundary. The complete finite
invoice includes source selectors, chart returns, bridges and private
work; its two-level sufficient precision remains 512 bits under the
explicitly stated inherited implementation contracts.

For the bound logical caller, the actual `O(wV)` route/leaf implementation
gives, after dividing work by fresh-row payload,

```
T(n,w) <= 200 C n + 2400000 C n^(1-139/80000) w.
```

Here `C` is a uniform source-dependent constant for a fixed odd prime
`q > 2^80`, canonical address widths, compatible root stock and generated
ancestor histories. It is not the finite scalar invoice's integer
coefficient, and address precision `w` is not a fixed 128/256/512-bit cap.
[RECURSION.md](RECURSION.md) gives the exact domain, recurrence and stock.
The logical storage bound is less than `11V_root + F_q'` symbols under
the stated root coupling.

The strict improvement is in the complete moment and resulting sufficient
power bound. At parent width 640 the new rank-seven child has width 70,
whereas the removed rank-six child had width 60. Only the former recurses.
Thus 288 fewer requests in a template does not imply fewer total
invocations or faster execution at every finite input width.

The selected complex endpoint is about `0.0016754626768081035`, below
both BIT roots. Keeping that supplier and the selected assembly unchanged
leaves the selected multiplication exponent unchanged.
