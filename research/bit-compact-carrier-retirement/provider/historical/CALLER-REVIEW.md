## 1. The exact input contract survives the change

Fix an odd prime `q`, precision `w>=1`, atom radix `A=q^w`, and

```
N=|GL_64(F_q)|, H=q^(4096(w-1)), W=28416, P=28425,
K=lcm(W,P) N H=269241600 N H,
D(n)=0 (n<64), D(n)=1+D(42 floor(n/64)) (n>=64).
```

An internal node of width `n>=64` receives an arbitrary Boolean function on
the complete ordered domain

```
[C physical frozen-prefix ordinals][R fresh rows]
[B][A^n head][G][A^n tail][S],       R=t K^D(n), t>=1.
```

All displayed extents are positive. Equal numerical frozen prefixes remain
distinct physical ordinals and may carry different or correlated payloads.
The helper inputs are arbitrary functions. No independence from retained
source or output functions is assumed.

The incoming unit `a_i` is generated by the retained encoded coefficient
program. It can inspect the old frozen prefix and coordinate `i`. It cannot
inspect this node's fresh family, low/high header, unused rows, payload bits,
body addresses, or spectators. This is a source grammar restriction, not
permission to supply an unrelated coefficient oracle.

The returned Boolean function is the pullback of

```
head_i' = a_i tail_(n-1-i),
tail_(n-1-i)' = a_i^-1 head_i,             0<=i<n.
```

Every row and spectator coordinate is fixed. The borrowed source, input
program, and input directory survive; the output is separately owned;
caller heads return; owned temporary tapes and live numerical words close.
Below-cutoff children use the retained completed leaf interface. There is
no claim of a new below-64 entry point in the internal `SelectedNode`
constructor.

The changed provider has 660 ordinary roles, private role 660, and exactly
the existing MOVE, signed unit ADD, COPY, and ERASE vocabulary.
`LocalState` derives its private index from the owner count, accepts both
unit signs, guards versions and frames, and forbids a MOVE within an open
COPY interval. Thus neither new source operations nor a new coefficient
language are needed.

## 2. Complete low packets and all odd primes

Each new residual base is a dyadic split idempotent `P` of its stated
rational rank `r<=42`. The finite prime-three split-basis check is useful
binding evidence; the following argument gives the prime-independent step.
All `(r+1)`-minors of `P` and `(65-r)`-minors of `I-P` vanish as identities
in `Z[1/2]`. After reduction at any odd prime their ranks are therefore at
most `r` and `64-r`. Their complementary images sum directly to the whole
64-dimensional space because `P^2=P`. The two ranks must sum to 64, so
they are exactly `r` and `64-r`.

Consequently, the unchanged `binding.split_basis` can select image and
kernel columns modulo each fixed odd `q`. Its dyadic column matrix `B`
satisfies `P B=B diag(I_r,0)` over the rationals and is nonsingular modulo
`q`; it is invertible over every `Z/q^w`. Choosing columns introduces no
new rational denominator. The generic normal forms use this matrix and
their actual low-class unit-pivot itinerary, not merely a rank histogram.
A nonzero pivot modulo `q` remains a unit at every precision.

For every complete low packet

```
F_d0={d0+qG : G ranges over all high matrices},
```

the owner chart gives the bijection
`F_d0 sigma^-1=F_(d0 sigma_bar^-1)`, including the high-coordinate carries.
The owner proof's same-family numerator-gcd-one checks ensure distinct
native low packets for every odd prime. This is stronger than showing
distinct individual matrices.

The helper chart uses its actual terminal projector, including the five
rank-four terminals:

```
sigma=A_port pi_slice diag(Q_terminal^T,I_56),
sigma E_terminal sigma^-1=A_port E_slice A_port^-1.
```

The idle remainder uses the same family chart `A_port`. The native chart
and idle complement therefore refer to the same directions. The 444 exact
rho15 projector identities in `CALLER.json` check the corresponding
data/idle compatibility, including stage eight's coordinates 57 through 63.

The unchanged Driver gathers and routes every complete owned packet,
executes a whole local invocation, inverse-routes each returned ordinary
role, and scatters into the latest family value. It checks uniqueness of
`(family,native_low)`. Returning one role cannot discard earlier returns
to that family. Only completed terminal residuals move through the owner
proof's untouched windows. The idle complement pays all remaining
directions. No child interior, ADD, or open COPY interval is commuted.

The runtime route compiler consumes whole rational matrices.
`inverse_chart` checks their orthogonality before using the transpose;
the arbitrary variable matrix still uses its inverse in `g P g^-1`.
All these fixed charts are dyadic. Thus this logical route has the
all-odd-prime endpoint domain. The separate historical `G=1117` selector
invoice keeps its own rational-factorization prime exclusions. The
large-prime hypothesis used for the time moment is also separate.

## 4. Source preservation through every recursive return

The new catalogue installs one topology at
`catalogue._recursive_caller_topology`. Unchanged `node.selected_topology`
checks and reuses it. Unchanged `recursive_call.Frame` passes the same
catalogue and Specifications into each child's SelectedNode. Production
code does not substitute a test Consumer or child body.

Write `f=floor(n/64)` and `delta=n-64f`. The unchanged peel operates on
the excluded `delta` pairs using their original source coordinates.
The core embedding is `phi(p)=p` below `64f` and `phi(p)=p+2delta`
thereafter. For physical child starts `a,b` and width `c`, the ordered
complete child packet is

```
[C H physical prefixes][U][B'][A^c][G'][A^c][S'],
B'=B A^a (G if a>=n else 1),
G'=A^(b-a-c) (G if a<n<=b else 1),
S'=S A^(2n-b-c) (G if b+c<=n else 1).
```

`layout.child_extents` checks both ends of both chunks, physical
contiguity, containment in one original bank, and disjointness. Exactly
one of the three spectator factors contains the original gap. Same-bank
half resets keep their middle interval, including an unpaired middle
atom when `f` is odd. This proves the ordered coordinate identification,
not just equality of packet volumes.

Fresh stock is passed as the separate factor
`U=t*9475*K^(D(n)-1)`; it is not replaced by the primitive scan product
`U*B`. The child receives the full directory of `C H` physical prefixes,
including repetitions. The internal invocation is outside the prefix
loop. The first prefix is used only to validate the encoded parent
program; it does not select a numerical high representative to replace
the complete directory.

`children.extend` appends the finite source/rank/kind/field/orientation/
half labels and encoded sizes. `Callback.step` verifies the actual
`rf`, `f`, or `floor(f/2)` width and source-specific branch.
`Callback.weight` decreases the chronological level at every VALUE
expansion, including unit children. A child's incoming grammar reads
only its frozen ancestors; the child's own new high field is not among
those ancestors. Each parent's current high field remains a spectator
for every descendant.

The scheduler permits one active child. Its Frame owns separate residue
and index banks, program copy, and work tapes. Every other staged parent
role and every suspended ancestor port remains protected and counted.
No descendant borrows those ports as scratch.

Matched ENTER/INVOKE/RETURN records retain the parent identity, source
code, geometry and flags and permit exactly one completed internal call.
The engine clears obsolete owned work, resumes the saved parent trace,
and restores heads on return. The child closes its live numerical words
and copied program.

All child widths satisfy `c<=42f<=21n/32<n`. Also `D(c)<=D(n)-1`, so the
displayed `U` is a positive multiple of `K^D(c)`; excess row factors
remain spectators. Strong induction therefore substitutes the completed
leaf or internal endpoint into each generic normal form, then into the
whole native word and the owner/controller endpoint. It proves source
grammar, spectators, arbitrary dirt and completed return simultaneously.
It remains valid at the new rank-seven cutoff: parent 576 gives width

## 6. Uniform time and the meaning of the saving

The route and ordinary leaf source still costs `O_q(wV)`. Linear address
signs keep fallback signs at `O_q(fV)`, and each fixed normal form has
`O_q(f)` adapters. The finite changed provider can enlarge the uniform
constant but does not change these powers.

The coefficient evaluator has arity at most two and decreasing
chronological level, so its work is at most `2^h` times a fixed polynomial
in `L,I,h`. Under the displayed root coupling,
`2^(h+1)<=8e^2` and `e<=w^(10000/17)` make this a fixed polynomial in `w`.
Its ratio to the complete target fibre `q^w` has a finite supremum over
positive integer `w`. Directory and numerical-frame preparation has the
same absorption. Canonical spectator counters are paid through their
scans. Hence a constant depending only on fixed `q` and the finite source
provides the `C(n+w)` overhead, uniformly in root width, spectators and
ancestor contents. The two matched providers may use their maximum `C`.

This is the all-parameter justification for the actual `p=1` recurrence.
A finite coefficient invoice alone would not establish it. Precision is
fixed at the original root, not recomputed from each descendant's width.
In particular `w=ceil(e^(139/80000))` satisfies the inherited lower
coupling.

The independent price proof includes every idle remainder and COPY
request and keeps the bridge/private work in the local overhead. Its
complete profile difference is `288(e7-e6-e1)`. Its strict moment gain
therefore survives the logical recursive construction. This means a
better complete power majorant; it does not establish pointwise ordering
of finite runtimes or invocation counts. For example the candidate's
width-70 child at parent 640 is internal while the removed rank-six
child has width 60 and remains a leaf.
