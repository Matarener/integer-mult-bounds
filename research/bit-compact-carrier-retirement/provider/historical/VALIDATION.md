# Validation scope and reproducible commands

This package extends PR4183 head
`928066009267fb32ab2c1a29b50fa3093ea18aef`, whose canonical scientific
base is `12fa8c5c844be21bfefb38a19503fbd867a11244`.
`INPUT-SOURCES.json` identifies the exact unmodified source files.

## Portable complete replay

```sh
python3.12 -I -B research/bit-carrier-owner-admission/verify.py
python3.12 -I -O -B research/bit-carrier-owner-admission/verify.py
```

Expected final line:

```
PASS_BIT_CARRIER_OWNER_ADMISSION owners=126144 queries=902880->902592 logical_caller=p1 precision=128,256,512 price_controls=3 optional_cpp_not_run no_new_kappa
```

The wrapper authenticates the complete package inventory and every bundled
input, then executes exactly the authenticated Python source bytes with
isolated imports and bytecode writes disabled. It compares complete typed
receipts, not just selected headline fields.

The owner check reconstructs all controller events, source windows, 126,144
helper occurrences, complete remainder factors and 288 dispatch descriptors.
It checks actual dyadic chart matrices, primitive inverses and same-family
low-class separation. Ten named defects cover missing or duplicate owners,
window, width and support errors, a chart collision, wrong replica,
private/live aliasing, incorrect orientation even with consistently swapped
data owners, and an equal-rank wrong terminal projector.

The wrapper emits the complete owner artifacts into a fresh temporary
directory. `independent_owner.py` reads those serialized artifacts without
importing the producer. It independently checks terminal projectors,
all spectator axes of the charts, reversed residuals, source windows,
every helper and dispatch, all 180,736 same-family pairs, and exact idle
complements. Its complete receipt must match `INDEPENDENT-OWNERS.json`.

The literal provider checks both words and orientations over all 660
independent integer input columns, including exact source/helper restoration,
literal private equality guards and both inverse orders. It separately
checks the public Boolean endpoints and their changed integer lift.
The actual frame bases and their original root spans are nondegenerate
over every odd characteristic. Complete five-, nine- and eleven-stage
Boolean replays cover 882, 1,326 and 1,548 formal columns. Omitting each
individual bridge yields 48 rejecting controls per word.

The independently implemented `caller_source_cuts.py` consumes the freshly
emitted native artifacts without importing their producer or the caller.
It checks all four source50-to-helper413 reads in the two orientations:
the current integer row is exactly the original source50 column, the
frames agree, and COPY is closed at each read. Source50 has eight temporary
ADD writes in each orientation; the witness checks their restoration
before the later read. Five defects reject source contamination, missing
restoration, a wrong read frame and an open COPY at the read. The wrapper
compares the complete `CALLER-SOURCE-CUTS.json` receipt.

The caller replay binds the same owner and literal receipts to the retained
Consumer, Driver and recursive Frame. It reconstructs both complete request
catalogues and executes the candidate's 288 local calls, covering
11,193,984 literal events. It checks all 549 candidate split bases at
prime three and all 444 exact rho15 projector identities. The all-odd-prime
and all-width extensions are written proofs, not consequences of that
single-prime test.

Six representative requests exercise both coefficient callbacks; four
routes check exact low-packet return; four traces straddle recursive
thresholds. Actual Frame/SelectedNode fixtures cover `640 -> 70` and
`256 -> 168 -> 84`, repeated-prefix directories, source/head preservation
and closed arenas. Their child bodies are controlled 23-bit transforms,
and a test-only row stock of 11 bypasses the usual 9475 divisibility guard.
They test the unchanged context/return machinery, not a complete
compatible-stock GL64 payload run. Four targeted defects reject lost
topology propagation, the old private index, a wrong terminal chart and
a MOVE inside COPY. The full typed `CALLER.json` receipt and its literal,
owner and profile bindings must match.

Only the four finite threshold fixtures memoize exact address results.
Each distinct complete input is evaluated by the unchanged `Geometry.point`;
repeated inputs receive fresh owned copies of that result. Every trace
event still executes, and all cached words are freed before the arena
audit. This fixture optimization changes its allocation and step counts,
which are excluded from the production caller's time and storage claims.
The production Consumer, Driver, Frame and frozen source files are unchanged.
The four golden streams cover 391,086 ordered events. Their uncached
reference at commit `8bb569889d4a8b4707178a50eccd93f8c23593ec` matched
the cached replay on every Event, Request and Reference field, complete
encoded word contents and heads, parent identity and final cleanup.
Both executions made the same 780,184 address calls; the registered checks
also count all 5,120 distinct complete inputs across the four fixtures.
The same four fixtures can be replayed without the cache against the same
complete-event goldens:

```sh
python3.12 -I -B research/bit-carrier-owner-admission/caller.py \
  --scope thresholds --uncached-thresholds
```

This optional reference replay performs the repeated address arithmetic;
it is separate from the registered replay's fixed time budget.

The price check binds the actual owner receipt, both complete profiles,
all idle complements, private reserve, fallback and the explicit coordinate
route invoice. Two independent exact interval methods certify every root
bracket. Three wrapper controls reject omitted idle work, crediting private
reserve as live stock, and removing the changed chart-return charge.

The registered `VERIFY.json` commands have the same scope under normal and
optimized Python. New checks use explicit exceptions. The authenticated
frozen caller loader compiles original source with `optimize=0`, preserving
historical assertions even under an optimized parent. Each registered
command has a 600-second limit, including the caller replay. A portable
pass explicitly does not claim C++ execution.

## Fresh native C++ legality

This command was executed for both words with Apple Clang 17.0.0 and
Boost 1.87.0. [NATIVE-CXX.json](NATIVE-CXX.json) preserves the full native
receipts, exact source hashes, compiler flags, exit codes and output hashes.
Only local filesystem paths in the command transcript are replaced by
documented placeholders.

```sh
python3.12 -I -B research/bit-carrier-owner-admission/native-check.py \
  --boost-include /path/to/boost_1_87_0 \
  --output /tmp/carrier-native-fresh
```

The output directory must not exist. A supplied `--provider-output` is
accepted only when its complete receipt and every emitted-file hash match
`NATIVE.json`; otherwise the runner emits fresh input. The Boost include
directory must contain `boost/multiprecision/cpp_int.hpp`.

The official archive used here is
`boost_1_87_0.tar.bz2`, SHA256
`af57be25cb4c4f4b413ed692fe378affb4352ea50fbe294a11ef548f4d527d89`.
It is an external build dependency, not a vendored research input.

The unchanged `stage_cohort.py` and `legality_h.cpp` accepted both raw
streams, with every record, ADD, MOVE, COPY, ERASE, paid-rank and terminal
frame count matched against the independent provider. Assertions were
enabled. The unchanged `columns_k.cpp`, compiled for the five-stage
instance, rejected both words with exit code 2 and exactly
`payloadfiniteprefix2^104`. It emitted no passing receipt. This is an
expected precision-rejection control; it is not a successful replay of
that scalar checker.

The new provider's exact positive envelopes require 114 and 211 bits,
charged as 128 and 256. The complete two-level arithmetic envelope has
460 bits, covered by the stated 512-bit charge. Those are exact-integer
bounds under the documented invoice, not exact rounded-child cleanup.

## What these checks do not establish

The new adapter reuses the retained generic all-size caller through its
Catalogue and Topology interfaces. It does not alter the old catalogue's
full-width terminal assumptions or claim acceptance by the old A/scatter/B
exporter or historical complete H1–H5 pipeline. The source-level induction
establishes the logical all-size endpoint and recurrence; finite probes
do not execute all input widths or the enormous full selected payload.

No full historical selected-frontier replay, formal-kernel proof,
fixed physical-tape lowering, stronger `p<1` route/leaf implementation,
exact rounded private return, or changed complex/outer supplier is claimed.
The committed-byte check and Git-free export test certify transport of
this scoped package, not any of those missing theorems. Hosted CI is
reported separately on the actual published commit.
