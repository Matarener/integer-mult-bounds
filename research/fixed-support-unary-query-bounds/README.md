# Sharp unary-query bounds with restored dirty banks

For the fixed-support carrier A=(N tensor I)SWAP with balanced N squared=-I,
exactly 2n one-bank A or A inverse queries are necessary and sufficient to
apply A squared to n independent banks while restoring any finite number of
arbitrarily dirty helper banks. Free bridges may be any GL matrix over the
algebra generated by the internal SWAP. [PROOF.md](PROOF.md) gives the
all-parameter characteristic-zero proof.

A separate [quartic theorem](QUARTIC-OPPOSITE-GATE.md) proves the same sharp
bound for an A with all four eigencharacters of z^4+1, allowing scalar bank
GL bridges. Its narrower alphabet is material. The
[scan counterexample](ZERO-HELPER-SCAN-COUNTEREXAMPLE.md) produces two full
chirps with zero native queries using exactly6mf complete ADD scans and
additional paid swaps/sign/address work. It is outside both query alphabets.

## Scope and evidence

These are written all-parameter lower bounds, finite exact identity witnesses,
and a paid primitive counterexample. They are not formal-kernel proofs,
physical tape bounds or new conditional kappa results. Changing supports,
operator-valued controllers outside the specified algebras, coupled queries,
or relaxed restoration changes the theorem's premises.

The original witness uses Gaussian rationals and the actual D8 constituents.
The [independent review](INDEPENDENT-REVIEW.md) derives the literal balanced
spectrum for every chunk size and uses the full Q(i)[D8] algebra to check all32
signs of one five-query word with noncommuting bridges. Deliberate wrong-order,
wrong-phase, missing-call and omitted-shear controls reject. This finite
coverage supports the identities; the written rank arguments supply the
quantified optimum. AI review is not independent human review.

## Reproduce

From the repository root:

    python3.12 scripts/research_package.py --package research/fixed-support-unary-query-bounds
    python3 -I -O -B research/fixed-support-unary-query-bounds/verify.py

The package is standard-library-only and its mathematical replay needs no
Git or external run directory. SOURCE metadata binds repository context;
LOCAL-PROVENANCE.json and predecessor/ retain the unpublished source lineage.
CONTENT-SHA256.json authenticates every consumed mathematical script and
fixture before source-byte execution. The relocated witness suppresses its
old WITNESS.json write; mathematical predicates are retained. Original scripts
are kept for comparison. Native recipe execution is not replayed here.

## Open next questions

A cost-aware lower bound with a constant number of primitive scans is open.
Start by specifying the allowed internal ADDRESS operators and scan bound;
the zero-query scan word prevents dropping that hypothesis. A changed-support
or coupled-query positive caller needs its own full arbitrary-input word and
complete invoice before any exponent calculation.
