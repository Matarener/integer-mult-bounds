## P1. Sixty-four chronological query syzygies

**Gaussian core.** There is a fixed finite ordinary dyadic/monomial rewriting of the reference local offer, preserving its complete physical endpoint, in which 64 disjoint triples of its surviving H1 requests admit the following causal description. After explicit physical monomial normalization, each triple requests the same canonical Q on current values a_j,b_j,a_j+b_j. The first two completed results are available before the third result is required; they remain readable until that use. Their physical charts, absolute phase and full spectator coordinates agree after the stated ordinary maps. The third result is supplied as Qa_j+Qb_j, without another recursive request. All other calls keep their original ranks. No preliminary query is introduced to discover the relation, and no additional hidden request is used to form a_j or b_j.

The identity of the 192 source request sites, their exact source-version expressions, first/last-use schedule and ordinary maps must be explicit. The statement is for every legal positive fiber width and every arbitrary assignment of all 632 productive inputs, after initialization of the actual owned fields. It does not restrict productive inputs to satisfy new relations. The relation is among intermediate query arguments in the changed finite word.

**Bridge.** The new local paid profile is bounded by p-64H1 and h is unchanged. Thus the full profile is P-1152H1 with the same T, giving Q64 at C*. The full conjecture is X_P1, including B* and A.

**Attainable-first question.** Identify one causal three-query relation with physical phase and source versions before asking for 64. This is a rank-two query relation, not a zero-query claim. It extends the source's explicit intermediate linear-relation viewpoint, but no such 64-triple family was established in the read sources.

## P2. Complementary-sector query multiplexing

**Gaussian core.** A changed ordinary prefix/suffix and native scheduling of the reference offer admits 64 disjoint pairs of H1 requests with a physically specified involution J_j, ordinary projectors E_j^+=(I+J_j)/2 and E_j^-=(I-J_j)/2, and a common rank-one Q_j commuting with J_j. At each pair, the actual required transformed arguments can be written as Q_j E_j^+ a_j and Q_j E_j^- b_j, in the correct physical charts. The remainder of each original argument is either absent by an established all-input prefix identity or is supplied from explicitly already-completed ordinary data; it cannot be discarded.

For each pair, one paid request on w_j=E_j^+ a_j+E_j^- b_j, followed by E_j^+ and E_j^- decoding, supplies both required values. The projections and all input/output monomial maps are finite ordinary programs on actual complete fields. Neither extracting a sector nor moving it between physical charts uses an uncounted Gaussian. The changed word preserves every original independent target and returns all owned storage to zero at every width, with the exact reciprocal interfaces.

**Bridge.** Each pair replaces two H1 calls by one H1 call; the literal net local reduction is 64H1. No separate target credit is assigned to the projected channels. Hence Q64 applies to X_P2 with B* and A.

**Attainable-first question.** Seek the actual sector pairing in the retained helper/mode query arguments, rather than applying the theorem to arbitrary full query inputs. The previous pure-math provider note gives a two-field multiplexing example; it does not give these 64 source-bound pairs. This is distinct from P1: the two data arguments need not be linearly dependent, but their required sectors must be complementary.

## P4. Reusing already-completed full-helper values

**Gaussian core.** A legal retiming and ordinary boundary rewrite of the reference offer exhibits 64 distinct surviving H1 sites and 64 retained cold full-rank helper jobs with a causal cross-certificate. At site j, the required input is exactly

    v_j = M_j D_j u_j,

where u_j is that helper's arbitrary original input, R_j=Q_j D_j is its declared completed full Gaussian, and the actual phase-correct ordinary map M_j intertwines Q_j with the native requested Q'_j. The complete helper value R_j u_j is already available in its original owner before site j. The required requested output is supplied by M_j R_j u_j, using ordinary maps/COPY at the actual charts. The helper remains an independent retained output and is never overwritten by the borrower.

The finite retiming must preserve all intervening readers, actual first/last availability, source versions, owner domains and every other target. It may use initialized owned copies with paid finite ordinary work. It may not access a future helper value, identify two arbitrary helper inputs, or use an uncomputed partial D_j u_j as an oracle. The statement includes every positive width and reciprocal orientation.

**Bridge.** Each reuse removes one H1 and adds no recursive call, giving p-64H1 and unchanged h. Therefore X_P4, including B* and A, satisfies Q64.

**Attainable-first question.** Find one completed helper whose exact phase-normalized output precedes the desired query use. The physical W/Z intertwiners of PR5402 motivate this direction but do not themselves prove any such completed-value timing. P4 uses one already-computed nonzero Gaussian value, rather than a zero, a sector split, or a query sum.

## P5. Thirty-two commuting two-query windows

**Gaussian core.** There is a finite ordinary retiming/conjugation of the actual local word exposing 32 pairwise disjoint native windows with two surviving H1 endpoints. In each window the exact physical operation, including every internal branch and externally visible read, has a factorization

    Q_j V_j Q_j

on the affected live field bank, with actual ordinary maps binding both Q_j occurrences to the same native rank-one operator. The intervening entire subprogram V_j, including any retained Gaussian children, commutes with Q_j as a physical operator, with an explicitly phase-correct intertwining proof at every width. Every external read of an intermediate value is either absent or is explicitly reproduced by ordinary data from the replacement; it cannot be ignored.

Because Q_j^2 is the source's explicitly ordinary central monomial, the replacement is V_j Q_j^2. It retains every Gaussian child internal to V_j, introduces no new one and removes the two endpoint H1 requests. Actual physical boundary frames and all productive/owned outputs agree with the reference. The windows must have disjoint deleted sites, so no query is credited twice.

**Bridge.** Thirty-two windows remove 64H1 locally and no targets. Thus Q64 supplies the Gaussian funding of X_P5, with B* and A required explicitly.

**Attainable-first question.** Start with one physical centralizer window and enumerate its readers. Equality of abstract Clifford symplectic matrices without the absolute phase and reader contract is insufficient. The source's real normalizers/full-Gaussian commutants and Q-square aliases motivate the question; they do not show that these 32 windows exist. This is cancellation through a commutant, not memoization of a completed output.

## P6. Twenty shadow-assisted rank-five restrictions

**Gaussian core.** A changed finite native word for the same complete local offer has 20 explicitly named occurrences replacing 20 of the current 40 H5 requests by one H1 request each. Each replacement comes from a physical reachable-module decomposition, not a claim that an arbitrary rank-five Gaussian has rank one. Precisely, at site s the all-input current argument is split by emitted ordinary projectors into a component in a specified invariant module and a complementary component. On the invariant component there are emitted ordinary input/output maps A_s,B_s satisfying, for all legal widths and all actual original inputs,

    G5_s L_s = B_s G1_s A_s L_s,

where L_s is the explicitly described reached component. The complementary transformed component is reconstructed from explicitly identified Gaussian values already completed before that site. Those values retain their full original independent helper outputs. Preparing, retaining and decoding both components uses only paid finite ordinary work and initialized owned storage; no complementary Gaussian request or target retirement is omitted.

All 20 supports, physical phase identities, availability and cleanup schedules are explicit. They jointly preserve the reference main ABI, all 408 helper targets and every independent original input. Every other request has its old rank.

**Bridge.** The local paid delta is -20H5+20H1, hence the exact whole-caller gain is

    Delta(C*) = 18*20*(5^(t*) - 1).

The elementary bound 5^(t*)>9/2 at the stated t* makes this exceed 18*64. Thus X_P6 reaches the same conservative Gaussian budget, with B* and A still open parts of the full package.

**Attainable-first question.** Locate one actual invariant-module restriction with a complementary result already available; do not assume a nonzero unrestricted full field is already restricted. This higher-risk target combines stabilizer-module reduction with a retained shadow, rather than simply removing a child rank in the invoice. No such 20-site decomposition is known from the scanned sources.

## P7. Rerouting all low-rank helpers through complementary axes

The construction must exhibit actual chronological donor paths and simultaneous complementary-axis routing for all 28 helpers. Every displaced borrower is restored to its old physical output, all full spectator coordinates remain present, and the word's real Gaussian requests are still covered by p. Every changed helper has an actual fully charged two-sided whole-job cover from its required ordinary entrance to its canonical declared exit. Fixed-word addition of fresh axes with their path debt unpaid is not the conjectured operation. No helper is credited both as its old H4 job and as a new H9 job.

**Bridge.** The exact whole-caller target increment is

    Delta(C*) = 18*28*(9^(t*) - 4^(t*)).

The mean-value bound t*9^(t*-1)>9/10 implies this gain exceeds 18*64. Thus the full X_P7 has enough Gaussian margin, together with B* and A.

**Attainable-first question.** Construct one paired donor/borrower braid and restore both arbitrary inputs before seeking the 28-helper family. Source helper promotion and coupled-carrier packing already have a long credited history; this is a stronger changed-word output contract, not a claim that fresh helper axes are free. Its independence from P1-P6 is the changed productive inventory rather than a reduced request count.

## P8. A causal realization of all thin queries using 528 latent channels

**Gaussian core.** Keep the actual 18 local standardized PR5413 occurrences and their helper owners unchanged. Replace only the 15 chronological QUERY_SHEAR stages of the actual direct controller by an explicit finite causal linear realization with at most 528 H1 requests total, in place of its 15*112 requests. Local black-box calls remain at their original relative chronology, and the realization cannot inspect their future outputs.

The emitted state-space certificate must list the latent argument maps, state transitions, input/output charts, current-source tickets, channel request times and all reconstruction maps. It must hold for every assignment of the actual original main/helper inputs and initial owned dirt. No promise about query arguments is imposed externally; any relation must follow from the actual preceding controller and local-call equations. Initialization, parking, restoration, final clear, physical reciprocal normalizers and finite precision constants are included. All other recursive jobs retain the old complete invoice, and T is unchanged.

**Bridge.** The global net H1 reduction is at least 15*112-528=1152, exactly the whole-caller Q64 budget. Therefore X_P8 with B* and A is independently sufficient for the requested conditional endpoint.

**Attainable-first question.** Give a causal low-dimensional realization of two consecutive thin stages while retaining the intervening actual main outputs. The controller's existing query thinning is predecessor work, so neither thinning itself nor arbitrary linear systems theory is claimed as new. This target asks for a much smaller actual native query module after all physical deadlines, distinct from P1's local same-operator three-term syzygies.

## Priority and scope

The intended first-pass order is P1, P4, P5, P2, P3, P8, P7, P6: local source certificates with explicit read/availability data come before changed-word helper inventories and invariant-module shadows. This order is a qualitative implementation-distance judgment, not a probability estimate or claim that any target is true. A future worker may reject an entry only after comparing its full changed-word and compatibility scope with the actual source; a failure of an unchanged-word special case is narrower.

The entries are structurally different witness requests. They share the explicitly open ordinary-BIT companion B* and the admission clause A. None should be advertised as a standalone theorem implying a new kappa until its entire X statement is established. The 0.0035 threshold and the Q64 counts are sufficient planning targets, not optimized barriers.
