# A spectral-radius method is valid, but this typed macro does not instantiate it

**Scoped negative applicability screen; no new κ.** The general heterogeneous
recursion certificate is already present in the repository. Its proposed use
would be valuable only if actual caller-compatible representations formed
recursive type transitions with a favorable fully charged moment matrix.

## Exact positive control and prior theorem

The proposed toy matrix is

```text
K = [[0, 6/5], [3/5, 0]].
```

Its square is `(18/25) I`, so its spectral radius is `3 sqrt(2)/5 < 1`, even
though its first row sums to `6/5`. An exact rational certificate avoids a
floating eigenvalue: with `v=(1,7/10)` and `rho=9/10`, direct multiplication
gives `Kv=(21/25,3/5) < rho v=(9/10,63/100)` coordinatewise. Thus the central
mathematical mechanism works.

It is not a new certificate method for this repository. The pinned analytic
theory already contains A051, a positive-vector theorem for complete typed
caller recurrences; A052 gives an exact rational two-state certificate, A054
closes cyclic transitions, and A056 explicitly budgets adapter matrices.
Those results preserve cross-type costs rather than discarding them.

## One actual typed-interface check

The closest exact, heterogeneous caller candidate found is the 3|7
order-four two-bank macro in
[`z4-hetero-two-bank-seedba18`](../z4-hetero-two-bank-seedba18/README.md).
Types A and B have reader schedules of three and seven children. The joint
macro keeps all ten typed children and saves exactly 144 ADDs at the phase
boundary:

```text
separate boundary: 2 (g(3) + g(7)) = 2 ((54,6) + (54,6)) = (216,24)
joint boundary:    2 g(10)           = 2 (36,12)             = (72,24)
difference:                                                   (144,0)
```

The complete invoice agrees: `(1552,144)` versus `(1408,144)` ADD/NEG, while
the recursive child count remains `3+7=10`. These A/B labels describe
finite reader/source schedules inside a macro. They do not describe two
different recursive size representations, and the package leaves supplier
assembly and analytic transfer unproved. No complete transition matrix
`K(a)` can be read from this evidence. Treating the saved boundary toll as a
reduction in recursive mass would be a category error.

This does not rule out a future multitype supplier. It shows that the exact
candidate screened here only changes a finite toll, while the general
certificate mechanism itself was already known. The next useful result needs
one named caller with two true recursive types, child sizes and multiplicities,
all conversion/return charges, and a strict rational certificate `M(a)v<v`.

## Open next questions

Can a named supplier provide two genuinely recursive representation types
whose complete, adapter-inclusive moment matrix admits a positive rational
contraction vector? This matters because only such a matrix can turn the
spectral idea into an all-size recursive improvement. First pin one caller,
extract both type-specific child rank lists, and include conversions,
returns, precision and storage before testing `M(a)v<v`. The present 3|7
candidate is blocked because it changes only a finite boundary toll and does
not supply selected-supplier recursive data.
