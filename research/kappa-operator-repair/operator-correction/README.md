## Why the overlay repair loses

The old six-move group requires at least five inserted completed single-stream
Fourier phase children in the retained caller-level character-block model.
Five grouped corrections suffice algebraically, with ranks `3,3,4,1,1`.
Their raw moment cost at `a=.001745` is approximately `11.9788439077` before
charging any routing, q-gauge, restoration or other overhead.

At the same exponent, the most favorable fixed-mass repacking of all twenty
old residual slots can save less than the exact rational `53397/80000`, or
`0.6674625`. This uses PR3220's allowance argument and even grants fractional
packing and free routing. It establishes a strict unfavorable complete
comparison within this fixed-stock/additive-repair interface.

The finite translation expansion is not assigned a constant all-size tariff.
PR3989's Pauli-transfer analysis identifies the tensor-volume problem for
that attempted shortcut. Absorbing work into an existing child or supplying
a different coupled native macro changes this price model and needs its own
uniform implementation and invoice.

## Reproduce

These standard-library commands only write inside this new directory by
default. Each also accepts `--output PATH` for a separate replay receipt.
All predecessor files and the composed supplier are read-only inputs.

```sh
python3 research/kappa-operator-repair/operator-correction/full_operator.py
python3 research/kappa-operator-repair/operator-correction/correction.py
python3 research/kappa-operator-repair/operator-correction/gaussian_bridge_rigidity.py
python3 research/kappa-operator-repair/operator-correction/t360_admission.py
```

To use the operator gate on a literal overlay, provide a JSON/gzip file with
the source move columns and records:

```sh
python3 research/kappa-operator-repair/operator-correction/full_operator.py \
  --moves candidate-moves.json --output candidate-operator.json
```

Its exit status is zero only when the candidate passes every required
character/tensor check; a changed operator exits one. Insufficient phase-state
coverage or an unsupported source binding raises an error. The separate
default self-test exits zero after verifying the expected baseline acceptance
and literal old-overlay rejection. Positive acceptance of an overlay file is
an operator predicate; axis ownership, native admission and its economic
invoice are separate required predicates.

Replay compares proof-relevant JSON exactly. These receipts contain no runtime
timings. Native receipts and the independently generated complete invoice are
reused through their exact input/source pins; these scripts do not run or
overwrite their generators. `REPLAY-INPUTS.json` lists the full dependency
closure of the four receipts.

## Open next questions

- **Coordinate-dependent coupled native corrections.** The finite inverse is
  explicit. A useful next attempt must implement a coupled operation whose
  uniform tensor operand volume is below the saved invoice. A one-factor
  translation identity alone is insufficient.
- **Changed controller topology or nonintegral coefficients.** The new Gaussian
  argument requires the same normalized graph modulo `1−i`. Denominators
  divisible by `1−i`, a different mod-prime topology or new phase slots change
  that premise. An actual candidate can be tested with the gauge/phase engine
  after declaring its endpoint semantics.
- **Absorption into existing paid local work.** The additive bill does not
  apply when a correction replaces existing paid children. Specify the literal
  changed local graph, complete arbitrary-dirty operator, and revised widths
  before comparing tariffs. Other agents in the parent continuation own the
  current local-word and architecture searches.
