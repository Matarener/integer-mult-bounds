## Actual operator equality, with all phases retained

The retained word has 72 warp opcodes but 58 distinct literal `G` matrices. The ten repeated classes are `[3,4,29]`, `[8,9]`, `[10,11]`, `[16,17]`, `[18,19]`, `[23,24,25]`, `[34,35,36]`, `[38,39,40]`, `[43,45]`, and `[71,72]`.

`operator_quotient.py` computes each logical `K_G` as an exact 512-column monomial with a Gaussian phase in every column. It computes negative opcodes as the **true adjoint**, not as the canonical lift of the inverse binary matrix. An independent retained Gaussian implementation checks the dense real and imaginary matrices for both signs of every physical opcode. A wrong quadratic phase, even with the same permutation, is rejected. No physical warp event, frame transition, or paid child is removed by choosing this checker.

The literal mode identifies only equal `G` matrices. The monomial mode also recognizes exactly equal complete signed products. The latter finds 71 distinct products during full retained-word and backward protected-output replay. `operator_rank.py` checks something stronger: these 71 exact Gaussian matrices have rational rank 71 when real and imaginary entries are separate coordinates. Thus there is no additional rational linear relation hiding among **these encountered products**. A changed construction can introduce other products; this is not a theorem about all possible complex circuits.

`OPERATOR-RANK.json` contains each representative operator word, a matrix digest, and its exact elimination pivot. It also contains the phase certificate and the complete retained all-input identity. The quotient searches found the same no-gain catalogues; no new supplier relies on adapting the old independent-label native checker.
