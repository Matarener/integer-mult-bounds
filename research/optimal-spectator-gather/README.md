# Optimal overlap-aware spectator gathers

A freely assigned gather for identical, aligned K-bit kernels needs exactly
`2K(h-c)` moved coordinates and `K(h-c)` binary-coordinate swaps, where h
neighborhoods are active and c source neighborhoods already coincide with target
neighborhoods. The constructor fixes the overlap and exchanges the two difference
sets. Both counts are proved optimal, even against arbitrary coordinate
permutations sending the full source set onto the target set.

This contribution was produced by Nick Petalas. Claim type: scoped proof with
finite exact corroboration. No new kappa or completed supplier is claimed.

The new assignment improves one routing step of zxv's
[PR6070 spectator-row wrapper](https://github.com/CrocSwap/integer-mult-bounds/pull/6070).
Its ordered assignment can move shared neighborhoods unnecessarily. In the
explicit h=3, Q=3, K=128G layout, moved support falls from 4K to 2K and the
shortest coordinate-swap word from 3K to K. The same complete active slots,
stock, dirty-input operator and inverse-restoration boundary are retained.
[PROOF.md](PROOF.md) states the exact changed contract and optimality argument.

`gather.py` constructs the new involution. `verify.py` enumerates a separate
permutation oracle and interprets complete exact operators. It imports no
predecessor verifier and does not rerun or audit the source theorem.

## Scope and limitations

This is a local routing construction and exact optimum. It permits a changed
assignment among identical completed kernels. A fixed ordered assignment,
unaligned neighborhoods, distinguishable operators, CNOT counts, adjacent tape
movements and arbitrary linear encoders are different optimization problems.
The executable planner has explicit finite resource caps; the proof has no
size cap. Literal vector execution is limited to 16 address bits.

The source's paid support-router theorem can use the smaller moved support.
A complete physical invoice, actual global-H production event, supplier,
rounded-callee/padding-disposal proof, native/compiler closure and outer
multiplication theorem remain unimplemented. All five selected assumptions
remain. The selected conditional kappa stays .003125804. No full selected cold
replay, Lean, Docker, independent human or formal proof-kernel review is claimed.
