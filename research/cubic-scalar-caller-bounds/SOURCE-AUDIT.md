# Source credit and contribution boundary

The preserved local cubic-caller lane supplies the original three-bank,
interaction-rank and layer arguments and exact receipts. Its earlier independent
review sharpened the interaction rank to equality. The new proof completes the
equality-case and four-pure-layer derivations, records the power-balance
interval and separates the alphabets and targets. It adds actual production
predicate controls and a separately implemented rational-matrix check. All six
original files remain byte-for-byte unchanged under `cubic/frozen/`.

Historical scripts execute from captured authenticated buffers with
`compile(...,dont_inherit=True,optimize=0)`. Both complete `receipt()` functions
run; old path-writing `main()` functions do not. Every typed field of both old
receipts is compared. The independent checker is unchanged; the wrapper adds
the fixed path to the authenticated historical receipt. No arithmetic has been
replaced or shortened. Top-level `ORIGINS.json` distinguishes the wrapper and
control adaptations from these unchanged components.

Group-algebra normalization, image/row-space rank and specialization have
prior use in eumemic's
[retained PR288 source](https://github.com/CrocSwap/integer-mult-bounds/blob/20ecf2891d80b5acf18d980b2164fb44ea7faa90/research/abelian-cayley-metric-scope/sources/pr288-README.md)
and Ali Romman's
[PR468](https://github.com/CrocSwap/integer-mult-bounds/blob/07a78bf335b0b5039a1fecd7cd74a0fe1d1605ea/research/bit-three-register-lower-bound/README.md).
These different group-algebra and register models are credited, not invoked
as unproved reductions or rerun as large searches. The method is not claimed
as new.

[PR4023](https://github.com/CrocSwap/integer-mult-bounds/pull/4023), retained as
`research/fixed-support-unary-query-bounds/README.md`, proves a different
order-four carrier theorem with swap-algebra bridges and a separate quartic
result. The present gates are scalar cubic shears with constant rational
bank directions. No alphabet reduction is asserted.

[PR4081](https://github.com/CrocSwap/integer-mult-bounds/pull/4081), retained as
`research/skew-cubic-response-gates/README.md`, proves a rank boundary for an
actual Gaussian Clifford satisfying `U^2+U+I=0` and distinct skew-response
tariffs. Its README leaves a complete three-power caller outside that gate.
A primitive-only operator may lose augmentation, so the full-ring bound here
cannot simply be applied to it. Its similarly named source file is different
from the historical `cubic-caller/cubic_gate.py` preserved here.
