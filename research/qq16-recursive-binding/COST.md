# Recursive height promotion and a compatible complete bill

This ledger separates the new conditional callback implementation from the
unchanged global QQ16 supplier problem. The rank-one child is the exact
recursive `Machine` of `research/physical-complex-controller`, rather than
PR4109's coordinate Gaussian reference. Its mathematical refinement, selected
native identities, ordinary B1/C0 backend, chronological hosting and long-record
premises remain inherited. The adapter must establish its literal physical
entry and return; the arithmetic below alone does not execute that adapter.

## One callback and its precision

Use the first frozen PR4106 event `['line','W0',0,1]` as the discriminating
instance. Every line has the same tensor width lambda; signed monomial recipes
surround one positive C tensor. Let `t=lambda-1`. PR4109's authenticated
whole-caller exact-grid theorem supplies

```
q_c = h 2^(-9-3t),        W_c = P+28+6t.
```

At every callback entry, the encoded integer components have strict magnitude
less than `2^(W_c-1)`. This permits arbitrary correlations; it imposes no
independence or stochastic-rounding assumption. PR4109 supplies the same
coarse format for every completed signed child output, not merely the final
224 recovered outputs.

The actual inherited controller's `PROOF.md`, **Inventory, height, time and
space**, gives

```
Gamma = 2^1296 product(i=1..36)(2^(2i)-1),
s = 1041408 Gamma, E=2^100000, B=s+E,
A(e) <= 2 B e.
```

Here A is an elementary coefficient-height/denominator bound. Its scalar
microinstructions are additions, signs, exact halves and powers of two;
address permutations introduce no coefficient height. The proof charges
completed earlier children by their completed widths and at most one
unfinished recursive child by its full internal height. It derives
`A(e)<=A(48 floor(e/73))+s floor(e/73)+E` internally and `A(e)<=8e`
at leaves. We use this inherited theorem, not a finite-depth extrapolation.

Use the sharper inherited leaf bound `a=8lambda` when the literal predicate
`lambda<73 or lambda^1000<d` holds. At other calls set `a=2B lambda`.
A common sufficient all-depth upper is therefore

```
a <= 2 B lambda,
q_w = q_c 2^-a,          W_req = W_c+2a+1.
```

Promote a signed coarse integer x to `2^a x`, appending a low zero block and a
high sign-extension block of length H-W_c-a, where H is the admitted
physical backend width below. The source height uses Gaussian absolute value: real and imaginary
components bounded strictly by `2^(W_c-1)q_c` imply Gaussian modulus less
than `2^W_c q_c`. A height-a expression may add at most a binary denominator
bits and multiply this Gaussian-modulus bound by at most `2^a`. Thus every interpreted native coefficient is integral on q_w and has
strict integer magnitude below

```
2^W_c * 2^a * 2^a = 2^(W_req-1).
```

This includes native intermediate values. The finite carry in the physical
coefficient transducer is governed by that primitive's own contract; it is
not silently counted as an additional stored H-bit Gaussian numerator.
The additional one-bit headroom pays for conversion from the component bound
to the inherited Gaussian norm; no unproved componentwise operator norm is
substituted. No intermediate rounding is performed. Arbitrary bounded correlated inputs
are covered by the same deterministic component bound.

The original height definition uses a base dyadic precision p and Gaussian
modulus. For the present q_c, its proof is applied homogeneously: each
numerical instruction is a complex-linear dyadic map or zeroing of owned
scratch, with no nonzero numerical constant injected. Signs, monomials and
ordinary bit interchanges are interpreted only after their exact numerical
returns. The same induction therefore bounds denominator debt relative to
q_c and modulus growth relative to the incoming Gaussian supremum, independently
of q_c's absolute binary exponent. This does not change the global control p,
d, K or the ordinary-backend setup. Their actual descriptor domain, component
width parameter and long-record hypotheses must still be met. It does not
claim a unit-disk root entry for an arbitrary decoder packet.

At the completed child, the inherited exact C endpoint and PR4109's
completed-event grid theorem imply divisibility by `2^a`. Verify those low
bits before dropping them; verify high sign extension before returning W_c
bits. A nonzero dropped bit or missing sign extension rejects the invocation.
Projection is exact and does not introduce a rounding error or change the
represented Gaussian value. Wrappers are signed monomial permutations and
preserve the coarse grid; both signs therefore use this same promotion rule.

Only one child is active. Its exact return restores the coarse representation,
so the reserve is **a, not 224a**. The required signed guard width satisfies

```
W_req = W_c+2a+1 <= P+29+6(lambda-1)+4 B lambda.
```

This guard width is not permission to change the actual physical width.
The inherited Compact parameter G depends on the global p; merely proving
another width O(p) would not establish admission to that implementation.
Keep the already admitted parent's actual component Count unchanged:

```
C0 = 2^210000,     H = p+2 C0 d+3,     require H >= W_req.
```

Promotion writes a low zero block of length a, the W_c coarse bits, then
H-W_c-a sign bits. Projection checks all surplus high bits as well as the
a low bits. All callbacks execute at H, with the original global p,d,K,G,
compact fields and long-record descriptors. Thus the actual physical width,
Compact admission and coefficient-volume accounting remain the inherited
ones; their validity is not deduced from big-O notation.

Here is a sufficient explicit entry subdomain. If
`P<=p+4Bd+1`, `lambda<=d`, and d>=1, then

```
W_req <= p+(8B+6)d+24 < p+2C0d+3 = H.
```

Indeed `Gamma<2^2628`, `s<2^2648`, `B<2^100001`, and the exact integer
inequality `8B+26<2C0` implies the even integer `2C0-8B-6` is at
least 22, so `(2C0-8B-6)d>21`. The code checks that
constant inequality exactly. Inputs of source height at most 2Bd admit the
entry representation `h=2^(-p-2Bd)`, `P=p+4Bd+1`. The extra bit makes the coarse input bound strict even
when the source height bound is attained: `2^(2Bd)<2^(2Bd+1)`. This is
an explicit compatible entry subdomain. It does **not** prove that the actual
QQ16 F0/B1 producer supplies that height or that the selected parent already
has spare height for an inserted decoder.

Small numerical fixtures may choose H=W_req in their explicitly reduced
backend domain. They do not instantiate the production Compact or global
width parameters and must not be presented as production-width execution.

The outer root's normalized Hadamard/truncating interface is not used as a
C callback. The exact internal Machine entry is the relevant interface.

## Row stock and the actual admitted parent

The physical parent after its individually handled remainder has width
`73 lambda`, row count R and divisor `L=14336 Gamma`. It already carries
complete compact ranges, spectator ranges, spacing K and the source global
parameters. A rank-one child descriptor is

```
width' = lambda,       rows' = U=R/L,
after' = after+72 lambda K,
```

with all global parameters unchanged. These are literal `prepare_child`
assignments, not an inferred allocation from a logical array dimension.
Let `D0(e)=0` for e<73 and otherwise
`D0(e)=1+D0(48 floor(e/73))`. D0 is monotone by induction. Therefore

```
D0(lambda) <= D0(48lambda) = D0(73lambda)-1.
```

If the admitted parent has `L^D0(73lambda) | R`, then
`L^D0(lambda) | U`. Sequential calls reuse U; they do not multiply the
reservation by 224. The child capsule already includes the 72lambda K
spectator bits and complete compact fields. The minimal logical reference
volume `2^(73lambda)` is not its actual bit volume.

A standalone bank with only a power-of-two row count is not automatically an
admitted Machine input: L has a factor seven. This is a rejection control
against inventing row stock, not an obstruction to the source-bound parent.
Adding fresh rows, treating existing spectator axes as rows or padding a bare
packet requires its own complete semantic and physical bill. The primary
connection reuses the admitted parent's existing reservation.

## Charges, storage and comparable boundaries

The frozen PR4106 census is 224 rank-one children, 448 monomial wrappers,
352 full-cover maps, 1,820 unit ADDs, 896 quarter ADDs and 416 CLEARs. Its
scalar allowance is `8*1820+12*896+2*416=26144`. These are exact occurrence
counts. They are not physical times or global paid-profile coefficients.

Write `v_j` for the complete actual packet bit volume at callback j after
promotion; it includes rows, spectators, all coefficient fields and the actual H.
A complete symbolic physical bill is

```
sum(j=1..224) T_C(lambda,v_j;p,d,K,H,global descriptors)
 + 448 T_monomial + 352 T_cover
 + 1820 T_unit + 896 T_quarter + 416 T_clear
 + T_promote + T_project + T_external_continuation + T_retire.
```

Each term uses its matching widths, packets and chronology. T_C includes its
own internal parking, native work, copying, cleanup and protected return; these
must not be added a second time. External continuation/retirement names only
work outside that inherited callback. Unknown terms are not zero. Literal
ownership/layout evidence must decide which additional terms are needed.

Promotion reads the entire coarse packet and writes H bits per component,
including the two new blocks. Projection reads the entire wide result,
checks its low and high blocks and writes W_c bits per component. Each is
O(v_j), including rewinds and erased owned temporaries under a proper stream
implementation. These are extra paid passes. This ledger does not assert that
an unimplemented Python integer shift has that physical tariff.

An isolated wide backend can be reused sequentially while the caller's other
banks remain on separate protected storage. Its occupied/visited space is
`O_q(v_max)+F_q` under the inherited backend contract, plus the complete
coarse caller and its retained source/output copies. Promotion and projection
add O(v_max) space, not 224 simultaneous wide packets. The inherited
controller has `2q^2+100696823` fixed physical tapes plus eight caller ports;
this is not a six-tape implementation. Source-local logical private peak16
and the physical tape inventory measure different things. Erased work is
not a promise that a Python emulator releases backing allocation.

The decoder's owned output banks and private arrays also require an actual
outer lifetime contract. The 704 persistent F0 producer fields include dirty
helpers whose return obligations remain live. Their existence does not grant
224 free clean output banks. A fresh isolated output/work inventory may be a
fixed constant enlargement; its occupied volume, acquisition, clearing and
retirement must nevertheless be accounted for.

The physical controller stops at `e<73 or e^1000<d`. Direct Gaussian leaves
cost O(e v), and the weighted-tree argument sums those leaf costs with the
actual child volumes. For its unchanged selected recursion it uses
`tau=.99830289`, `sigma=.99833`, `beta=.001`, internal exponent
`.99832997289`, leaf exponent `.99833167` and reservation exponent `.998`,
all below `599/600`. These are inherited fixed-source exponents. An arbitrary
all-depth direct coordinate Gaussian implementation cannot be assigned this
sublinear recursive tariff: its prescribed work is linear in e per volume.
The unchanged admitted width H preserves the source volume and Compact
accounting. The condition H>=W_req must hold independently; a replacement
O(p) width alone would not establish this implication.

## What improvement is and is not established

PR4015 and PR4106 have the same 224 signed child occurrences, wrapper and map
counts and complete output/borrowed-state boundary. Use the same promoted
backend, admitted callback width H, coarse caller width and conversion protocol
for both. The prescribed
native/conversion bounds are equal. PR4106 removes exactly 100 whole-field
unit additions; at a fixed full bank of N complex coordinates this is
200N real-component additions. All other physical costs must be compared
using an actual compatible schedule; differing temporary addresses or
reordered callbacks are not assumed cost-free. The 800 logical allowance
advantage is a separate unit from this numerical count.

The complete selected moment is `sum n_r(r/73)^(1-a)/W` with its proved
coverage/usage coefficients. The 224 calls here contribute a local
`224(1/73)^(1-a)` before that coefficient. Refining them with an actual
recursive implementation does not create a negative global charge. No
selected idle work is certified removed by this adapter. The earlier
separate-consumer, common-frame and bridge investigations keep their scope
and credit; their missing continuation credits are not silently discharged.

The material enabling implication is narrower: an exact-grid callback can
admit the real recursive interior by explicit temporary precision promotion
and return exactly to the caller grid, with a common width and paid conversion
for the two recovery words. Complete decoder placement and the consumer's
budget are distinct remaining implications. Neither a new global profile nor
an improved selected kappa follows from this ledger.
