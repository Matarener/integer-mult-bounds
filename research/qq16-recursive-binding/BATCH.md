# Seven-field batching: a shallow escape and an all-depth stop test

## Claim and boundary

This alternative addresses the same actual `Machine.node` row-divisor obstacle
as the central padding audit. It does not replace a source-bound native supplier
with the coordinate Gaussian reference. The retained recovery word has 224
signed H1 events: 112 initial positive normalizations, 104 negative query
normalizations, and eight positive responses. Its individually charged signed
monomials must bring each event to the same canonical core coordinate rectangle
before any batching. Each real field retains its own charged maps and wrappers.

Suppose a pooled event has `Gamma * 2^s` rows, with integer `s >= 0`, and the
selected physical controller makes D successive recursive row divisions along
an actual path. Let

```
Gamma = 2^1296 O,   O = product(i=1..36)(2^(2i)-1),
L = 14336 Gamma = 7 * 2^1307 O.
```

Pooling b whole fields without padding gives exactly `b Gamma 2^s` rows. The
necessary and sufficient row-divisibility condition along this path is

```
L^D | b Gamma 2^s.
```

The smallest positive integral b satisfying that condition is

```
b_min(D,s) = 7^D O^(D-1) 2^max(0,1307D-1296-s).
```

This follows by cancelling the common Gamma and taking the remaining odd and
2-adic factors. It is an all-integer identity for every D >= 1, s >= 0; executable
samples are controls, not its proof. `D` counts actual recursive divisions,
including the controller's source cutoff. It is not tensor depth itself.

For D=1, seven fields suffice exactly when s>=11. For D>=2,
`b_min >= 49 O > 224`, regardless of s. Indeed O contains `(2^4-1)=15`, so already
`49 O >=735>224`; the exact two-level odd multiplier has 1338 bits. Thus **even
pooling all 224 retained H1 event fields cannot discharge a two-level recursive
row contract without padding or a changed source implementation**. This result
is stronger than the single-field rejection and independent of any liveness
restriction. Its excluded class is whole-field pooling at the fixed selected
Machine ABI, preserving the original row/spectator split and adding no rows.
It does not exclude repacking spectator dimensions, producer fusion, padding,
a different decomposition/controller, or changed recursive cutoffs.

The next section checks whether seven-field pooling at least has a genuine
first-level lifetime route. It does; therefore lack of seven logical hosts is
not the decisive all-depth obstruction.

## Why this does not establish a physical or precision saving

Concatenating rows is an algebraic direct sum only after the charged source
monomials put each real event in the same core representation. Distinct port
labels do not themselves establish common physical row layouts. The physical
controller still needs valid global descriptors, guard/compact fields, grid,
private state and exact gather/scatter ownership. Its continued row divisions
are the decisive arithmetic rejection above for D>=2.

A producer/recovery fusion that changes the number of rows or obtains a new
spectator reservation changes the boundary and must account for the producer's
live values, original ordered residual and final restoration. The host argument
here supplies no such fusion. Likewise, the changed interleaving and possible
new native summation patterns are outside #4109's frozen-word numeric claim.
For an isolated deterministic fixed-point core, commuting operations on distinct
fields preserves per-field inputs, but actual recursive errors and interiors
must be re-proved for the combined core. No precision allowance or kappa credit
is taken from this schedule.

capture recipes and distinct ports, all52 original paired-consumption blocks,
eight query accumulators, private-scope exclusion, all86 deferrable definitions,
and the six selected additional host leases. A direct run also rejected an early

and mutation controls. A source alteration that removes an acquisition or uses
a leased Z bank before restoration must be rejected.

This bounded alternative materially distinguishes a removable shallow lifetime
issue from the fixed-ABI all-depth stock obstruction. It supports continuing the
central padding/source-compatible representation route, rather than enlarging a
host census or building another query circuit around seven lanes.
