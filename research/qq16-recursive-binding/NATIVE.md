# Binding QQ16 lines to the physical recursive C machine

This is a source-relative construction contract. It uses the actual
`physical-complex-controller` descriptor, parking and return implementation,
not a coordinate Gaussian loop assigned the recursive price. Its retained
all-size refinement, selected native/common-label identities, chronological
hosting and ordinary B1/C0 backend remain hypotheses. No production O(73,2)
payload or GL64 factory has been executed for this contribution.

## Literal boundary and the three event variants

At frozen PR4106 event 4 the instruction is `line W0 0 +1`. Events 2 and 3
are `CLEAR W0 hole0` and `W0 += Y0`. The input is therefore an owned copy
of the current borrowed Y0 value, in physical frame F17 C_q^-1. The positive
line returns W0 in F17. Arbitrary original dirt in W0 has been removed by the
charged clear. There is no permission to write borrowed Y0.

The complete 224-event inventory has three classes:

* 112 positive initial normalizations on W0 through W111;
* 104 negative streamed query normalizations on Z10/Z11;
* eight positive response conversions on Z10.

All native calls are outside the scalar F/G private scopes. Their operand
values and correlations can be arbitrary within the caller's admitted entry
range and grid. The signed recipes inherited from the frozen native proof
use a right monomial, a positive rank-one C child and a left monomial; the
negative sign includes the necessary output XOR. That XOR is part of the
paid wrapper. The middle operator at tensor depth lambda is C^{tensor lambda}
on lambda selected directions, with identity on the other directions.
No inverse of a state-clearing producer is used.

## Actual physical caller, including its existing spectators

The physical selected controller has 73 active directions per local factor,
14,336 families and the actual orthogonal cover of cardinality Gamma. Its
group gather obtains complete current owner packets in the layout

```
[P][U][front][H][H][before][73 lambda K][after][H][back][r Gaussian fields].
```

Here K, H, the surrounding complete fields, r and the encoded global root
width d come from the already admitted physical parent. They are not inferred
from the logical reference size 2^{73 lambda}. `BankPackets.gather` preserves
the current bank, selects the source-bound family/cover keys and copies the
entire within-row packet. The complete replacement is committed only after
the local group returns.

In particular the existing active field already has the K spacing between
selected bits. Treating the logical size as the entire physical allocation
would erase real parent inputs and give an inapplicable padding obstruction.
Conversely an isolated minimal 73 lambda-bit reference cannot simply claim
these extra parent fields. The theorem below starts at the physical parent's
prepared packet boundary.

Write L=14336 Gamma and define the conservative source recursion depth

```
D0(e)=0                       if e<73,
D0(e)=1+D0(48 floor(e/73))     otherwise.
```

The physical root construction supplies row stock divisible by L^{D0(d)}
after its explicit reservation and less-than-two row padding. At subsequent
nodes the same invariant holds with their active width. This is an existing
paid root preparation; it is not rerun or treated as new free work here.

## Capsule inheritance theorem

Fix positive integer lambda, an admitted physical parent after remainder
processing with width e=73 lambda, root width d>=e and row count R divisible
by L^{D0(e)}. Keep its actual K, H, front/before/after/back fields, coefficient
count and common grid. At the local owner packet let U=R/L.

For any of the 224 rank-one events, the source `prepare_child(target,1)`
constructs the descriptor

```
child.width = lambda
child.rows  = U
child.after = parent.after + 72 lambda K
```

and copies every other descriptor unchanged. It preserves the complete packet
volume because

```
before + 73 lambda K + after
  = before + lambda K + (after + 72 lambda K).
```

There is no fresh copy of an absent spectator, no missing owner slice, and no
division by a logical payload size. The right native monomial has already
put the selected rank-one direction first; the left monomial restores its
source recipe after return.

The integer function D0 is nondecreasing. This follows by induction because
floor(e/73), multiplication by 48, and addition of one preserve order, while
the recursive argument is strictly smaller than e for e>=73. Therefore

```
D0(lambda) <= D0(48 lambda) = D0(73 lambda)-1.
```

Consequently L^{D0(lambda)} divides U. Every internal recursive division of
this child has sufficient exact stock. This proves the implication for all
positive lambda, rather than extrapolating from finite depths. The stopping
test `lambda<73 or lambda^1000<d` may terminate sooner; using D0 only overpays
stock. All 224 calls may reuse this descriptor promise sequentially: a call
returns the same row domain, so row stock is not consumed by the number of
calls. Batching seven live query values is unnecessary in this prepared ABI.

## Entry, return and the actual callable interfaces

There are two source-supported integration choices, with different allocation
obligations:

1. Register the recovery word in a new compiled local group. At a child
   instruction the existing `prepare_child` / `enter_child` path closes
   scalar, leaf and monomial scratch, parks the parent roles and their encoded
   continuation, and runs one active child. `return_node` restores the parent,
   checks the exact saved child instruction and replaces its target packet.
2. Supply a separately closed Machine with an owned scratch inventory and
   use `Machine.run(borrowed_payload, encoded_descriptors)`. This copies the
   input, preserves source/descriptors and returns a protected output. Its
   internal `root` flag means the entry of this C invocation. It is not the
   normalized Hadamard `root_layer` operation.

The second route cannot call `run` on an already active parent Machine. Its
additional engine and parking inventory, or a proved reuse protocol, must be
charged. The first route needs registration and storage for the recovery's
owned outputs and sixteen private banks; the retained selected binding has
704 slots and eight private banks and is not silently enlarged by this
theorem. Retained copied parent values, native scratch and protected output
must be disjoint from every live query/output bank until committed return.

The source child returns exact C^{tensor lambda}, with its complete packet
and descriptors restored and its owned work empty. It performs no completed
child rounding. Arbitrary correlations in the incoming packet are permitted
by the retained height argument. This exact return is why the coarse-grid
endpoint projection described in the integrated precision contract is legal;
the same statement would not hold for an arbitrary approximate callback.

Do not call the normalized outer root as a substitute. That root separately
executes S_D, C^{tensor D}, S_D and multiplication by ((1-i)/2)^D, followed by
truncation. Its endpoint is H0^{tensor D}, not the required C child.

## Precision and cost obligations carried into the integration

The retained source gives A(e)<=2 B e, with
`B=1041408 Gamma+2^100000`, for the coefficient-height excursion at width e.
The integrated feasibility ledger uses this actual recursive bound to protect
the coarse PR4109 interface, rather than replacing child interiors by pair
loops. Its common fine grid and signed width must cover both the division
reserve and magnitude reserve. Coarse endpoint projection must check discarded
low zeros and retained sign extension; it is an exact encoding conversion.
Conversion, movement, wrapper and scratch charges remain in that ledger.

The prepared child tariff is the retained source-relative recursive tariff
under its global p,d,K,H, long-record and ordinary-backend premises. The
descriptor theorem discharges stock, spacing inheritance and complete packet
shape at this boundary. It does not by itself prove the new complete supplier
moment, recovery invocation frequency, consumer usefulness or placement of
owned recovery outputs. Those are different obligations, not zero-cost terms.

The current selected compiled source does not contain the PR4106 recovery
word. It is an available backend for a prepared bridge, not evidence that a
selected outer caller has already invoked or paid for that bridge. The exact
F0/B1-to-recovery cut and its current-value/owner route still need the complete
caller connection before supplier admission.

## Evidence and limits

`construction.py` parses the authenticated physical source without importing
or executing it. It binds the concrete class constants, gather/capsule/return
methods and actual stock/padding mechanism. It classifies all 224 literal
events, checks the first owned-copy entry and exclusion from scalar-private
scopes, and tests descriptor equality at seven distinct depths/spacings.
These are descriptor arithmetic fixtures, not production-parameter payloads.
Controls reject a borrowed first target, a deleted child, insufficient parent
width, zero spacing and a changed source row-inheritance expression.

The monotonic-depth and packet-volume argument supplies the all-depth
quantifiers. Actual finite physical execution, when reported elsewhere in
this package, has its own reduced-geometry scope. Shared source conventions,
assisted review and retained all-size proof assumptions are disclosed; none
constitutes new independent human or formal-kernel acceptance.
