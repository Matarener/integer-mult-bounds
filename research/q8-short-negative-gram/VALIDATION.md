# Verification contract and limits

The scientific result is the uniform lower bound in PROOF.md. The finite
calculation exhausts all exact-length-three/five diagonal-one Gram matrices
and permitted ordered labels. RESULT.json records every coverage count and
SHA256 stream. Each stream contains the Gram rows, label mask, all eight
endpoint coefficient matrices and acceptance flag, encoded as compact JSON
plus newline. Booleans stay booleans. Every count is below 2^53.

The independent census imports no primary matrix, group or pruning code. It
enumerates every off-diagonal integer, multiplies by binary dot products,
computes rank from an explicit row span, and tries all 2^n label lists at
every spectral survivor. The primary uses subset-sum multiplication and
binary elimination, with proved label-rank/parity pruning. Both retain exact
integers and compare their full endpoint streams. No floating point or solver
answer participates in acceptance.

The generic-word controls compare every word through three calls, across
every admissible target-rank pair. Positive controls accept all eight direct
nine-call target lists. Their 72 one-call deletions are negative controls.
The faithful Hamilton action checks every basis column on three active and
two restored dirty roles. The expected negative action is central sign times
one positive action, separate from the three-call execution.

The optimized behavioral groups mutate the actual primary endpoint producer,
replace actual noncommutative multiplication with xor, corrupt the independent
action, and remove most of the real enumerator. Each check detects its fault.
They also reject invalid dimensions, Gram diagonals, labels, ranks and boolean
rank values, altered receipt content, and a real CLI output collision. A file
collision is rejected before scientific work and preserves the file bytes.

The registered environment is CPython 3.12 with warnings as errors and a fresh
private bytecode cache. Scientific commands also run from an actual committed
Git-free export. Final publication records exact argv, stdout, stderr, exits,
source hashes, immutable export manifest and before/after file identities.
Metadata/source-history checks are separate from scientific replay.

## Engineering decisions

Build the Lever shaped the contribution into two rerunnable complete censuses,
rather than a search log. Prove It Works required actual endpoint mutations,
positive fixtures and committed-source replay. Unslop kept the claim scoped to
the two computed lengths. The autonomous-run playbook stops after publication
and clean ownership release; it does not expand this into a seven-call search.

Power of Ten inspection covers the six Python modules and their direct entry
paths. All loops have finite bounds from calls<=9, census calls in `{3,5}`,
at most 2^20 matrices, 32 label lists and eight group coefficients. There is no
recursion, dynamic evaluation, generated code or background process. Every
scientific function stays below sixty physical lines. Explicit boundary
contracts and equality checks remain enabled under optimized Python. I/O and
subprocess failures propagate; the sole child command has a ten-second timeout.

Rule 3 deviation: Python and its standard library allocate during operation.
The scope is these bounded finite commands. Matrix rows have at most nine
bits, subset tables have at most 512 entries, explicit spans at most 32, and
the small enumeration list at most 64 matrices. The main censuses stream
candidates into SHA256 rather than retain a million matrices. This bounds
live scientific state independently of the full enumeration count. Python
allocator internals are uninspected. A fixed-memory native implementation
would be needed for direct compliance; it is not required by the mathematical
contract. Fixture counts, full replay and source inspection verify the caps.

Rule 9 deviation: unittest.mock dispatches among the explicitly named fault
targets during bounded behavioral tests only. Production calls are direct.
The test runner owns each patch context and restores it on every exit.
Strict scoped Ruff E4,E7,E9,F,B and warnings-as-errors cover the changed Python.
No repository-wide linter or unrelated historical suite is claimed.
