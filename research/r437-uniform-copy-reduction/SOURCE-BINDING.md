## The generated program must carry the current source

`children.extend` obtains the rank from the current source Specification,
derives rf, f or floor(f/2) from the encoded parent width, and appends

    (kind, current_code, rank, field, reverse, half),
    parent_size, child_size

to the source-bound program. It preserves the parent program and copies the
complete frozen history. `Callback.step` requires that the code is in the
Specification vocabulary, that the recorded rank equals that code's rank,
and that the exact size and depth relation holds. In the good branch the
new incoming unit is the parent's generated weight times the unit pivot;
`Page.child_weight` derives that value at the actual coordinate/prefix.

This is why an algebraic equality of the nine projectors does not authorize
replacing arbitrary source codes in a generated history. An actual integration

source-label translation that preserves every decoded coefficient, scope,
prefix ordinal and continuation. It must cover ancestor records, not only a
new root COPY label. The `source_audit.py` plan probe is separate from numerical callback execution.
