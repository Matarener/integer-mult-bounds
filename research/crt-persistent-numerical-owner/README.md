# Persistent numerical CRT ownership

The actual mixed-width RowEntry can now reuse one fixed bank of63 physical
backings across changes in its encoded precision guide. The adapter replaces
only physical role acquisition. Original transport, numerical arithmetic,
result semantics and successful retirement stay unchanged. Every LEFT
marker is reinstated with charged local operations; no old backing is
shrunk, replaced or silently cleared.

[PROOF.md](PROOF.md) derives each source role's extent, proves that longer
blank tails preserve delimiter-driven arithmetic, and bounds arbitrary
successful histories by the sum of rolewise maxima. Supplied initial blank
capacity is included. This is a new actual-owner reentry contract; the
general historical-maximum principle is credited to prior work.

[RESULT.json](RESULT.json) records actual P6→P15→P6 execution on identical
backings:536→1238→1238 retained cells. The large current-child case gives
lower11 and offsets(0,3). Port/Word/Arena constructors are sealed during
each call. A separate equal-precision witness has536 fresh cells per call
but537 retained across two calls, refuting maximum-of-standalone totals.
Controls cover missing marker setup, constructor bypass, premature reentry,
double close, omitted initial capacity and a stale suffix beyond a shrunken
current word. All borrowed words and complete owned tails are checked.

```sh
python3.12 -B scripts/research_package.py --package research/crt-persistent-numerical-owner
```

Both registered modes authenticate all input bytes and the typed receipt.
No h4 ROM or historical replay is required. This is a source-operation
theorem with finite corroboration, not a binary transition program, full
physical level, exceptional key, native/outer theorem or new kappa.
Canonical inputs and eight disjoint legal dirty words remain supplied.
Failed-initialization rollback and arbitrary dirty owned scratch are excluded.
