# Active-mode restoration at a native paid-query cut

This package certifies why a granted mode injection into the retained L240
query does not provide a clean extra observation while preserving the original
helper. It also proves a broader limitation for the same monotone full-frame
observer interface and records a conditional direct endpoint repair whose
physical payload transport remains open. **No new bound, supplier or legal
center replacement is claimed.**

## Result and evidence

The frozen source is the backward `F9-SOURCE-DAG-ALL8` program from
[filtered-native-kappa004](../filtered-native-kappa004/README.md), with its
`physical_add` tails omitted. The observer calculation evaluates native address
operators on their common fixed vector and retains all 632 arbitrary original
input amplitudes, including all 408 helpers. It is a scalar necessary interface,
not a complete phase-aware physical replay.

* **Granted L240 injection.** Immediately before source event 17155 (word event
  17978), grant an additive mode at L240's rank-8 frame 280, just before its
  rank-1 climb to full frame 1. The 4,868 distinct full-frame observations have
  rank 482 both before and after adjoining the injection-response column.
  Explicit rational witnesses check `Mz=v` and separate both the missing mode5
  and the original helper240 output from the changed observation span. This
  includes dirty-helper restoration; fitting only a desired main coefficient
  would miss the obstruction. See [l240-extra-column-gate.json](l240-extra-column-gate.json)
  and [the complete observation data](l240-full-observations.json.gz).
* **Monotone full-frame observer limitation.** The source has 482 persistent
  full-frame arrivals, no full-frame departures or new owned full-frame fields,
  and only invertible scalar updates within the full-frame subsystem. Its
  history is therefore spanned by its 482 final full rows. For the stated
  fixed-mode changes `F'=F+VR`, the eight missing R modes cannot become separate
  pure observations while preserving the original full targets. This is the
  exact interface in [full-sink-gate.json](full-sink-gate.json), not an exclusion
  of arbitrary active feedback or new physical observations.
* **Conditional direct repair.** Omitting the 48 helper-precompensation updates
  at word events 568–615 and granting `L240 -= C6`, where `C6=R5Y/4`, gives the
  scalar endpoint `X-AY-R5^T R5Y/4`, with Y and all helpers unchanged and owned
  scratch returned to zero. Here A is the retained center-free owner matrix.
  The literal ADD is **illegal**: C6 is at frame 0 while L240 is at frame 280.
  The checker rejects that operation under actual coframing. The result in
  [direct-l240-repair.json](direct-l240-repair.json) is conditional on supplying
  the required transported payload at frame 280, with its entire cost charged.

## Reproduce

From the repository root, using Python 3.12 and only its standard library:

```sh
python3 scripts/research_package.py --package research/active-mode-restoration --check-only
python3.12 scripts/research_package.py --package research/active-mode-restoration
```

The two registered commands run `verify.py` normally and with `-O`; each has a
120-second timeout. Direct replay is also available:

```sh
python3 -B research/active-mode-restoration/verify.py
python3 -O -B research/active-mode-restoration/verify.py
```

The verifier authenticates the unchanged predecessor archive and four member
hashes, materializes only those regular data members in a temporary directory,
and regenerates the three gates. It compares semantic evidence, excluding
elapsed time, and separately checks the saved witness pairings against every
observation. It imports no scientific source code from the archive. Controls
cover a corrupted witness, useful before/after side information, forbidden
full-frame lifecycle changes, incorrect compensation/sign, and the illegal
cross-frame ADD. No broad parameter search or heavy native suite is run.
