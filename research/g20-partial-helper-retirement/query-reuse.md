**Proof.** Run the raw physical provider. Clear an owned 112-field query bank T, copy the actual clean Y into it and compute

    T=Q^s Y=Q^s D y.

    QH=R h-RZy.

    H_1=QH+ZS=R h,

    X_1=X-WH_1=Dx-Ry,

using RW=WR. This is the unrestricted reference main endpoint. Finally perform the requested z += epsilon T, then clear all owned query/ordinary temporaries after their last reads. The destination update sees exactly the originally requested Q^s Y_std; it is not given S in place of T when those physical values differ.

There are 112 required query calls and eight mode calls, all rank one. No H8 repair is used. No original h is set to zero, identified with another input or discarded. H_1=Rh is an autonomous full Gaussian on each original mode input. The unchanged 400 helpers retain their exact independent original operators. The physical W/Z implementations and Q-square alias make every added operation explicit; no inverse code, odd division, D/W commutation or future helper value is used. ## Theorem 5. Ordinary reads may be deferred with explicit correction debt

Suppose an intermediate bank has the form v=v_std+B r, with r to become available later, and B an explicitly ordinary physical map. Let an intervening finite ordinary linear program act on this bank and other live banks, without changing the value needed to produce r. Then its full effect can be executed on the current values while maintaining an explicit ordinary coefficient map B_i for the r-debt of each live bank. Once r becomes available, subtract B_i r from every live bank. The resulting state equals execution of that same ordinary program on v_std.

**Proof.** Initially the debt is B on v and zero on the other banks. For an ordinary assignment w_i=sum_j A_ij w_j, update its stored coefficient by B_i=sum_j A_ij B_j. This is a fixed symbolic program of ordinary maps, not a numerical runtime inference. Linearity shows that the actual bank always equals the standard bank plus B_i r. At the completion point, the explicit subtractions remove exactly that term. Copies duplicate both value and debt; owned clears set both to zero. Dead versions need no correction. All actual readers and versions are listed in the finite program, so no observed intermediate value is silently ignored. QED.

For the actual raw provider's X, the initial debt is W r with r=Rh. Thus an ordinary bridge ADD reading X before a later helper repair is not automatically fatal: its descendants can carry their actual W-debt until that repair. This theorem does not declare a nonordinary Q/W conjugation free. ## Theorem 6. A constructive compiler for retired autonomous helper paths

Take the actual standardized neutral local provider, and choose an autonomous helper owner w outside the support of every input/output owner-mixing boundary map. Its input is therefore one actual physical source helper direction. Replace that one arbitrary original input by an owned field, debit its entire rank-k Gaussian target, and keep every other original input arbitrary. All initial dirty data in w are erased by a charged ordinary CLEAR.

Follow the literal versioned helper slot through its complete source path. A write into w from another live field is an incoming write. A read of w which can change any other live field, including a COPY or SWAP, is an outgoing read. Let A be the list of Gaussian requests on w strictly before its first incoming write, and B the list strictly after its last outgoing read. If there is no incoming write or no outgoing read, use the corresponding endpoint of its path; a request belonging to both lists is deleted only once. Delete precisely those requests, delete ordinary zero-prefix reads when desired, and after the last outgoing read clear w and omit every remaining operation whose only affected productive data are in w. Retain all other source requests and all other productive operations.

This is an explicit correct program for the same main operator and every other helper target, with w initialized and returned to zero. Its exact Gaussian paid reduction is the multiset A union B; the productive debit is exactly Hk.

**Proof.** At entry w is an owned zero. Before its first incoming write, every operation on it is a scalar map, a monomial, a Gaussian, a clear or a read of its zero value. Every such transform keeps it zero; every outgoing ADD/COPY contribution from that zero is zero. Delete its Gaussian calls, retain or remove those zero reads, and retag only the actual zero to the frame required at the first retained incoming write. This changes no other state.

After the last outgoing read, no remaining operation can carry information from w into another live field. Therefore clear w there and delete its later writes and Gaussian transforms; nothing in any other field changes. This suffix argument does not require the old suffix input to be zero, nor does it assume that the old final zero implies zero at an earlier time. Its correctness is dead-value elimination after the last actual observer. Whole-field SWAP and COPY events must be included when identifying that observer.

Between these two cuts, execute the exact retained word. The resulting other-field endpoints equal those of the reference word with this original input set to zero. The reference standardized main operator is independent of every autonomous helper input, and its other helper outputs each depend only on their own arbitrary original input. Therefore all those desired outputs are unchanged. The deleted field is now owned, receives its explicit entry erasure and final clear, and receives no productive credit. All other original fields remain arbitrary and are neither owned nor erased. Gaussian calls at the two cuts are exactly the stated deleted multiset. QED.

The actual source's 122-field helper basis is supported only on cold rank-nine owners. Thus each of its rank-four, rank-seven and rank-eight helper owners is outside that basis support. ## Theorem 7. Two-leg retirement has strictly positive concave gain

**Proof.** In the stated geometry, every Gaussian request lies before the first incoming contact or after the last outgoing contact.
