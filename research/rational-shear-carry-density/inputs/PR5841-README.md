# Complete G20 routes with fused q-adic carries

All 111 sparse port routes now have an exact low/high implementation at every
width, for both directions and both released bases. The construction combines
all elementary carries into one final dyadic translation per affected output
column. For the 7,548 actual source markers, the tree needs at most 28,492
translation sites instead of 74,460, a reduction of 61.7%. The scale-free basis
needs 28,492 instead of 53,448, a reduction of 46.7%. The linear words stay fixed.
These are carry-site counts. Their physical tariffs need not be equal, and this
is not a runtime or full supplier saving.

The proof gives a width-independent carry, its exact composition law, its
inverse, dyadic denominator and height bounds, and complete high-fiber
preservation. It includes canonical low-type commit. The stage-to-axis map uses
the source stage ordinal, not its numeric stage label. A full N=127f cover uses
127f^2 independent eight-entry row/lane blocks. Other columns, ancestor fields,
roles and unused descendant stock stay fixed. See [PROOF.md](PROOF.md).

The checker authenticates PR5820 head
`04b5db84b4b02bdc17e1c6287dfcf8b9c04199d4`, reconstructs each rational product,
checks the same line/complement interface and exact marker owners, and compares
22,200 complete full-width cases with a separate dense modular oracle and an
elementary carry interpreter. It checks 2,220 noncommuting rational cocycles,
3,100 exhaustive two-coordinate inputs, complete first/last-stage cover
fixtures, inverse restoration and six semantic rejection controls. The tested
moduli include a composite and an89-bit integer; the written identity has no
width cap. Every exact count and digest is in RESULT.json.

Run `python3 -B scripts/research_package.py --package research/g20-fused-qadic-carries`.
Python3.12 and the standard library suffice. The direct command is
`python3 -B research/g20-fused-qadic-carries/verify.py`.

Physical head placement, low-cache preparation and erasure, coefficient-specific
ROW/tape tariffs, padding, borrowed return, final compiler and compatible outer
admission remain open. The source native interface and all five framework
assumptions retain their status. No new kappa or selected-frontier change follows.
This package does not implement PR5836's physical unit-scale tariff or repeat
the current controller optimization.
