# Ten literal changed helper entrances

`kernel_entrances.py` constructs a local R429 FULL-box word with ten ordinary
helpers entering at their actual first rank-one frame E instead of ZERO.
The helpers remain arbitrary dirty streams. All429 helpers and111 sources
are restored exactly over the integers; every one of651 binary input columns
has the original clean target shear. Source and target native cuts are unchanged.

The selected helper IDs are242,467,462,469,463,464,367,401,444,470. Seven have
zero actual compensation columns. The other three share compensation columns
with233,360,385 respectively. These are columns of the actual semantic dirty
map, reconstructed from the literal initial compensation, rather than a
syntactic helper count.

For a duplicate pair(h,k), the two helpers reach a genuine common E before
the forward word. Apply k+=h there and k-=h at FULL after cleanup. The new
initial compensation is D*S modulo2, whose h column is zero. Consequently no
ZERO-frame operation reads the helper already supplied at E. No added
recursive query or private buffer is required. The literal saved word includes
all six basis ADDs and all advanced companion entrances.

The local histogram is exactly the frozen R429 FULL histogram minus10H1:
`{1:1396,2:1342,3:79,4:44,5:93,6:11,7:9}`, with mass5087. The helper residual
inventory is10 of width7 and419 of width8. For each actual root line E, the
receipt checks the complete16-by-16 rational ADDRESS identity
`D_FULL D_E^-1 = D_(E-perp)`. The paired owner wrapper must therefore be
keyed by(E,FULL).

This is a changed local boundary, not a completed supplier. An arbitrary
physical helper u may be interpreted as logical dirt h=D_E^-1u: no entrance
query is inherently required for this interpretation, because all public
helper dependence cancels. The owner must route the paired physical residual
D_FULL D_E^-1. Ten extra entrance queries are needed only when retaining the
old ZERO logical-dirt identification, which restores the old5097 mass. No
chronological owner allocation, complete outer moment, rounding theorem or
improved kappa is asserted.

```sh

python3 -O kernel_entrances.py
```
