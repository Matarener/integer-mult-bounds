# P104 whole-fiber coverage and helper-sharing gate

**Scoped result:** selecting partial sets of whole P104 row/column calls cannot
rescue PR3954's unchanged corrected profile. The exact touched-pair count is
`N=104(a+b)-ab`; the optimistic rank excess is
`264(a+b)-N=160(a+b)+ab>0` for every nonempty mask. Reducing the helper-owner
count does not alter this numerator while the named progress/endpoint
hypotheses remain valid. No new kappa, native supplier or frontier change.

There is also a separate endpoint obligation: the retained two-shear caller
has `104(a+b)-2ab` dangling pairs. Without a changed paid completion, the only
whole-call sets closed under its endpoint are empty or all208 calls. A smaller
rectangle is not the support of an unchanged104-port word.

The proof gives an exact four-corner test for asymmetric changed profiles.
It distinguishes a passing sparse relaxation from an actual closed caller:
with hypothetical excess100 per axis, one call on each axis has relaxed
excess-7 but206 unresolved endpoints, while the full closed caller has
excess9984. These hypothetical profiles are discrimination controls, not
constructed improvements. The all-correction-free closed value832 is only
conditional arithmetic, not a new private-COPY lifetime floor.

See [PROOF.md](PROOF.md) for the general incidence proof, source assumptions,
helper-potential cancellation, exact optimization criterion and stop decision.
[RESULT.json](RESULT.json) records the finite evidence. The conditional gate
explicitly grants full-array initial rank credits and leaves new physical
