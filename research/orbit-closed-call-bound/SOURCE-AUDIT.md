# Attribution and publication scope

The historical paired-bit C09 note supplies the root-chart census and the first-variation obstruction. Its original sources and receipt are retained unchanged and authenticated. The present package adds the matching three-call cyclic-port word per bank pair, the arbitrary restored dirty scalar-spectator extension, explicit regular-cover semantics and new independent finite checks. It does not turn local root geometry into a native caller construction.

The original root file is `research/e8-bit-carrier-skeleton/data/bit/bitE8-r865.json.gz` at scientific commit `20ecf2891d80b5acf18d980b2164fb44ea7faa90`. Only its root-line table is consumed. Its source package credits Dylan Crow / utcorvusvolat-dotcom's PR370, with Anthropic Claude assistance, and eumemic's retained carrier-skeleton work. The complete original notice and Apache-2.0 license are preserved. No circuit, hosting or frontier claim from the larger source package is freshly verified here.

The group-algebra normalization, rank and specialization methods have prior use in eumemic's [retained PR288 note](https://github.com/CrocSwap/integer-mult-bounds/blob/20ecf2891d80b5acf18d980b2164fb44ea7faa90/research/abelian-cayley-metric-scope/sources/pr288-README.md) and Ali Romman's [PR468](https://github.com/CrocSwap/integer-mult-bounds/blob/07a78bf335b0b5039a1fecd7cd74a0fe1d1605ea/research/bit-three-register-lower-bound/README.md). The latter concerns three registers and rational rank-one frames in a different abelian group algebra. Its large finite search is not rerun or invoked as a lemma here. These mechanisms are credited rather than claimed as new.

The current [fixed-support unary package / PR4023](https://github.com/CrocSwap/integer-mult-bounds/pull/4023) proves a `2n` optimum for a distinct order-four carrier and swap-algebra bridges, plus a narrower quartic result. The C09 model instead charges one simultaneous two-bank, three-port diagonal call. Neither alphabet reduction follows merely from the shared rank method. The separate cubic scalar-caller contribution concerns yet another ring and is excluded from this PR.
