# One frame relation cannot save paid rank over any coefficient field

**Scoped proof with an exact finite census; no new kappa.** Hanson Sun's
[`research/bit-one-relation-seed04`](../bit-one-relation-seed04/README.md)
proves that, with **F2** register coefficients and at most one rational frame
relation, the paid frames split into disjoint target sums, so
`sum_w rank C_w <= k`. Nick Petalas's
[HANDOFF](https://github.com/CrocSwap/integer-mult-bounds/discussions/1166#discussioncomment-19230525)
showed that two steps of that proof fail over F3. Its signed derivative breaks
the shared pattern, and a complementary pair of distinct projectors can sit on
the relation support. The handoff found no counterexample at W = 2, k <= 4.

This package proves the statement over **every coefficient field**, at every
register count W and every word length k. The proof replaces seed04's
binary graph classification (its steps 2 and 3) with three pair lemmas. They
show that a relation block is either one projector `N` with the all-plus
relation, as in seed04, or one complementary pair `N, N'` with
`N N' = N' N = 0` and `N + N'` a two-coordinate projector, which is new.
Every outside factor either commutes with the block or sits before or after it.

An exhaustive census over F3 and F5 agrees: no counterexample in
496,154 diagonal (word, relation) pairs, and each of them has the lemmas'
structure. That includes the W = 3, k = 5 and 6 range the handoff asked for.
In 49,110 of the 119,577 diagonal W = 3, k = 6 words, two distinct non-coordinate projectors appear
(complementary pairs), so the F2 proof's single-`N` step really does not apply to them.

Base: `a2b4b0395e293dded1cb17b4e78910b364af2343` (priority revision 8). Card
`bit-new-register-model`, drawn with seed `000882cc4a8ff64a03982134d465dc92`.

## Model

This is seed04's model, with the coefficient field changed. Let `K` be any field. Work in the group algebra `K[H]`,
where `H` is the additive group generated by nonzero rational rank-one frames
`A_1, ..., A_k` and `[A][B] = [A+B]`. There are `W >= 1` registers and paid factors

```
F_j = I + ([A_j] - 1) N_j,   N_j = x_j y_j^T,  x_j, y_j in K^W,  y_j^T x_j = 1.
```

These are all rank-one idempotents over `K`. Every formal coefficient must satisfy

```
F_1 F_2 ... F_k = diag([C_1], ..., [C_W]).                                (1)
```

**Theorem.** If `dim_Q span{A_1, ..., A_k} >= k - 1`, then there are pairwise
disjoint index sets `I_w` with `C_w = sum_{j in I_w} A_j`. Hence
`sum_w rank_Q C_w <= k`.

For `K = F2` this is seed04's theorem. Restored dirty registers (`C_w = 0`),
free invertible scalar basis changes over `K` (absorbed into the projectors) and
an output permutation are covered as in seed04.

## Proof

Write `P(t) = prod_j (I + (t_j - 1) N_j)` in `M_W(K[t_1^{±1}, ..., t_k^{±1}])`,
and `phi(t_j) = [A_j]`. The relation lattice `L = {n in Z^k : sum n_j A_j = 0}`
is saturated, so it is `0` or `Z r` for a primitive `r`. Then `H = Z^k / L`
is torsion-free, `K[H]` is a domain, and `ker phi = (t^r - 1)`.

**Step 1 (seed04's step 1; it holds over every field).** If `L = 0`, or some
`|r_j| >= 2`, distinct subsets of indices have distinct frame sums. Comparing
coefficients then makes `P(t)` diagonal, and `d/dt_j P(1) = N_j` is diagonal. A diagonal
rank-one idempotent is a coordinate projector `E_aa`. Diagonal factors commute,
so `C_w` is the sum of the frames with `N_j = E_ww`. Otherwise `r` has entries in `{-1, 0, 1}`.
Let `S = supp r` (so `|S| >= 2`, since the frames are nonzero), let
`S+` and `S-` be its sign classes, and let `g = t^{r+} - t^{r-}`, a unit multiple of `t^r - 1`.
Every off-diagonal entry of `P` is `g h_ab` for some Laurent polynomial `h_ab`. Since `g(1) = 0`
and `d/dt_j g(1) = r_j`, differentiating at `t = 1` gives

```
offdiag(N_j) = r_j M,   M_ab = h_ab(1).                                   (2)
```

Over F2 the sign disappears, which is seed04's shared pattern. For `j` outside `S`,
`N_j` is a coordinate projector. If `M = 0`, every factor is a coordinate projector and we are done as above.
From now on `M != 0`, so every `N_j` with `j in S` is a non-coordinate
projector. Rename `S+` and `S-` if needed so that `S+` is nonempty.

**Pair slices.** Let `i` come before `l` in the word, with both in `S`. Over the algebraic
closure, take the point where every other variable is `1` and `g = 0`: `t_i = t_l = z` when
`r_i = -r_l`, and `t_i = z`, `t_l = 1/z` when `r_i = r_l`. Points with `g = 0` satisfy `P = D`,
where `D = diag(t^(alpha_w))` lifts (1): equality (1) puts each `C_w` in `H`, so it is the image of a Laurent monomial. Hence `(I + (t_i - 1) N_i)(I + (t_l - 1) N_l)` is
diagonal for every such `z`, and so as a Laurent polynomial in `z`. Expanding, with `N_i N_l = (y_i^T x_l) x_i y_l^T`:

- `r_i = r_l`: `offdiag(N_i N_l) = offdiag(N_i) = offdiag(N_l)`;
- `r_i = -r_l`: `offdiag(N_i N_l) = 0`.

(Same sign: multiply by `z`; the off-diagonal part is
`(z-1)(z offdiag N_i - offdiag N_l) - (z-1)^2 offdiag(N_i N_l)`.
Opposite signs: it is `(z-1) offdiag(N_i + N_l) + (z-1)^2 offdiag(N_i N_l)`, and the first term is zero by (2).)

**Lemma 0.** If a rank-one matrix `u v^T` is nonzero and diagonal, then `u` and `v`
are multiples of one basis vector `e_p`. (Some `u_p v_p != 0`; then
`u_p v_q = 0` and `u_q v_p = 0` for `q != p`.)

**Lemma A (one projector per sign).** If `r_i = r_l`, then `N_i = N_l`.
Put `m = offdiag N_i = offdiag N_l` (nonzero) and `c = y_i^T x_l`. The equation `offdiag(c x_i y_l^T) = m`
forces `c != 0`. Let `E` be the set of off-diagonal positions where `m` is nonzero. For
`(a, b)` in `E`, `x_{i,a} y_{i,b} = x_{l,a} y_{l,b} = c x_{i,a} y_{l,b}`, so
`y_{i,b} = c y_{l,b}` and `x_{l,a} = c x_{i,a}`.
- If both `x_i` and `y_i` have at least two nonzero entries, the sources of
  `E` are exactly `supp x_i` and its targets are exactly `supp y_i`. There are at least two targets, so
  `N_l` is in the same case, with the same supports. Hence `x_l = c x_i` and
  `y_i = c y_l`, so `N_l = N_i`.
- Otherwise `N_i` is supported on one column `b` (`y_i ∝ e_b`) or on one row.
  Take the column case. `E` has the single target `b`, so `N_l` is supported on one
  column or on one row. In the column case it is column `b`, with the same
  off-diagonal entries and `(N_l)_bb = 1`, so `N_l = N_i`. In the row case `E` is
  a single position `(a, b)`. Then `{N_i, N_l} = {E_bb + mu E_ab, E_aa + mu E_ab}`, and
  the two orders give `N_i N_l = 0` or `N_i N_l = 2 mu E_ab`. Neither has off-diagonal
  part `mu E_ab`, a contradiction. The one-row case is the transpose.

**Lemma B (complementary pair).** If `r_i = -r_l`, then `N_i N_l = N_l N_i = 0`,
and `N_i + N_l` is a coordinate projector of rank two.
Assume `i` comes first (otherwise exchange the names). Then `N_i N_l = c x_i y_l^T` has zero off-diagonal part. If
it were nonzero, Lemma 0 would put `N_i` in a single row `p` and `N_l` in the
single column `p`. Their off-diagonal parts `m` and `-m` would then lie in disjoint
positions, so `m = 0`, a contradiction. So `N_i N_l = 0`. By (2), `D' = N_i + N_l` is diagonal,
and so is `D'^2 = D' + N_l N_i`. The same argument on `N_l N_i` gives `N_l N_i = 0`.
Thus `D'` is a diagonal idempotent of rank two, that is, `E_bb + E_cc` with `b != c`.

By Lemmas A and B, every factor in `S+` uses one projector `N`, and every factor
in `S-`, if any, uses one projector `N'`, with `N N' = N' N = 0` and `N + N' = E_bb + E_cc`.
All relation factors commute: `U_N(u) U_N(v) = U_N(uv)`, where `U_N(z) = I + (z-1) N`,
and `U_N(u) U_{N'}(v) = I + (u-1) N + (v-1) N'`.

**Lemma C (outside factors).** Fix one outside factor `E_aa` with frame `s`, and set every
other outside variable to `1`. This is a ring map, because `H` splits as `H_S ⊕ Z^(outside S)`.
Let `u` and `v` be the classes of the `S+` and `S-` frames that come before it, and
let `z = [sum_{S+} A_j] = [sum_{S-} A_j]`. (If `S-` is empty, then `v = 1` and `z` is the class of the `S` sum.) Put
`V = U_N(u) U_{N'}(v)`. The specialized word is

```
V (I + (s-1) E_aa) V^{-1} · Z,   Z = U_N(z) U_{N'}(z)  (Z = U_N(z) if S- is empty).
```

With all outside variables set to `1`, `Z` itself must be diagonal. If `S-` is empty, this gives
`(z-1) M = 0`, so `z = 1` and `r = 1_S` (seed04's all-plus relation). If `S-` is nonempty,
`Z = I + (z-1)(E_bb + E_cc)` is diagonal and invertible. In both cases, the coefficient of the free variable `s` shows that
`V E_aa V^{-1}` is diagonal. It is idempotent over a domain and has augmentation `E_aa`,
so it equals `E_aa`, and `V` commutes with `E_aa`. Off the diagonal,
`V - I = (u-1) N + (v-1) N'` has entries `(u - v) M` when `S-` is nonempty and `(u-1) M` otherwise.
So either `M` vanishes in row `a` and column `a`, and then `E_aa` commutes with every relation factor,
or `u = v` (respectively `u = 1`). In the latter case, the relation factors before
`E_aa` have a frame sum that is a multiple of `r`. Hence they are none of `S` or all of `S`.

**Conclusion.** Move every commuting outside factor out of the relation block. The block's product is
`I` in the all-plus case, or `I + (z-1)(E_bb + E_cc)` in the pair case. Assign `S+` to
register `b` and `S-` to register `c` in the pair case. Assign each outside factor to its coordinate. Every remaining factor
is diagonal, so `C_w` is the sum over a disjoint index set. Rank subadditivity
and `rank A_j = 1` give `sum rank C_w <= k`. ∎

The complementary pair is exactly Petalas's `N1 = [[2,2],[2,2]]`, `N2 = [[2,1],[1,2]]` over F3.
Over F2 and F4 it also covers the extension-field complementary pair of
[`research/bit-extension-one-relation-seed17`](../bit-extension-one-relation-seed17/README.md),
whose two roles are proved there separately. That package also prices `F_(2^e)` calls in binary calls;
this package does not touch that pricing.

## Evidence

[census.py](census.py) and [verify.py](verify.py) use only the standard library. They enumerate every
rank-one idempotent over `F_p`, every primitive relation `r in {-1,0,1}^k` with
`|supp r| >= 2` (one of `±r`), and every word. They compute the exact product in
`F_p[Z^k / Z r]`, collecting the multilinear coefficient of each subset under its class, and decide:
(a) diagonality with unit monomial diagonal; (b) disjoint assignment, trying both class representatives;
(c) the structure in Lemmas A–C. The pruned enumeration builds Step 1 in.
The unpruned cross-check runs over all words, checks Step 1 on every diagonal pair, and
compares the two diagonal sets exactly.

Lemmas A and B are also checked as finite pair statements. Every ordered pair of rank-one
idempotents with `offdiag N_l = ±offdiag N_i != 0` that passes the pair-slice condition has
the claimed structure. This is checked over F2 and F3 at W = 2, 3, 4, and over F5 and F7 at W = 2, 3.

The F3, W = 2 non-coordinate counts (20, 120, 480) match the handoff's counts.
Its totals (32, 208, 1,072) also count each coordinate-projector word once per
relation option. The W = 3, k = 3 unpruned cross-check (1,398 pairs, 147 s) was run locally
but is not registered. No row has a violation or a structure failure.
[CERTIFICATE.json](CERTIFICATE.json) records every row with a SHA-256 of its sorted pair list.

Controls: the complementary pair is diagonal under `r = (1,-1)` and rejected under `(1,1)`.
A shared `N` is diagonal under `(1,1)` and rejected under `(1,-1)`. Non-monomial and non-unit
diagonals are rejected. An overlapping assignment is rejected, and the alternative class representative is used.
Two different same-sign projectors are flagged.

Review: an OpenAI Codex read-only adversarial review of the proof and code found no gap (verdict "proof correct"). Its three wording notes are applied. This is not independent human review.

## Scope

The theorem is an optimistic paid-rank obstruction in seed04's abstract
model: one rational relation, an abelian address group, rank-one paid scalar
projectors over a field. Two or more relations, nonabelian addresses,
coefficient rings that are not fields (for example `Z/4`), higher-rank paid
projectors and free address changes are outside it. The finite census
corroborates the written proof; it is not the proof. No physical supplier,
pricing of non-binary scalar calls, compiler, precision or recursive-bill
obligation is addressed, and the selected bit profile and kappa are unchanged.

## Open next questions

1. **Two relations.** This is seed04's open question, now for every field.
   With nullity two, the pair slices give one constraint per pair of relation vectors.
   A first step is to classify the projector pools that satisfy Lemmas A and B for each relation separately.
2. **Coefficient rings that are not fields.** Lemma 0, Lemmas A and B and the form `x y^T` of a rank-one idempotent use a field (the idempotent-over-a-domain step needs only a domain).
   Over `Z/4` or `Z/2^e` an idempotent need not have the form `x y^T` with `y^T x = 1`.
   A first test is the census code with `p = 4` and the rank-one condition replaced by the free-rank-one
   definition. This matters only if a supplier uses such a ring.
3. **Formalization.** Lemmas 0, A and B are short finite statements about
   rank-one matrices and suit a proof assistant. The pair-slice step needs Laurent-polynomial evaluation.
