## 1. Causal deferred binding on the actual data module

**Theorem C1.** Let an exact finite linear program act on retained input x and helper inputs h1,...,hm. Suppose its retained endpoint is Ax, independent of every helper input. For helper i choose a cut immediately before its first outgoing read. Assume all its preceding operations are invertible unary transports and destination-only additions; no read of that helper affects any other field before the cut. Replace those preceding helper operations by an owned zero slot. At its cut assign any explicitly computed function of the current retained or previously bound fields, using an actual admitted ordinary same-frame operation. Retain its subsequent old operations. These changes may be made in chronological cut order and preserve the complete retained endpoint Ax.

Every helper target being retired is debited. Dirty entrance erasure, the assignment, known-zero header changes and final owned cleanup are positive paid operations. No helper output is claimed independent.

**Proof.** For one helper, while no outgoing read occurs, every other current field is independent of that helper's entrance. Its own old prefix has the form Lh+b, with L invertible. To obtain assigned cut value v, there exists the old entrance L^(-1)(v-b). This value is a correctness proof parameter, not an executed inverse. The actual new program writes v directly at the cut and then rejoins the old program on every current field for that old entrance. Since the old retained endpoint is independent of that entrance, it remains Ax.

For several helpers, a later unbound helper has no outgoing read into any earlier binding value: such a read would already be its first outgoing read. Thus the old retained prefix and each binding value are independent of all still-unbound entrances. Choose the counterfactual entrances successively in first-read order. Each choice changes no already matched retained prefix state. This proves the complete joint construction without solving an unproved simultaneous linear system. Later old suffix reads of already bound helpers remain present, so all their effects are retained. ∎

The claim is an exact identity of operators on payload functions. It is stronger than an equality for a sample input or a scalar bitmap. No runtime admissibility or guard estimate is inferred from the unexecuted counterfactual entrance; fresh runtime bounds must cover the actual assignments and retained suffix.

## 2. Binding through the literal old matcher

**Theorem C2.** Work in characteristic two. At a helper's first outgoing read, suppose its old instruction is y += Mh, where M is that instruction's actual admitted invertible ordinary matcher between the two whole physical field presentations. Reorder only other additions into y whose donors stay unchanged. Bind h := M^(-1)y using the literal inverse matcher, then retain y += Mh. The whole physical y is now zero. A following native query on y may be omitted, with its old output header acquired on the known whole-zero payload.

**Proof.** The binding uses a finite explicitly supplied ordinary map, namely the inverse of the old instruction's own matcher. Consequently the following old ADD gives y+MM^(-1)y=0 on every address and every column. The helper receives the former y information, so this is a transfer within the retained linear computation rather than erasure of an independent receiver input. Theorem C1 proves that the old retained endpoint still follows. The old helper target is lost and must be debited; the receiver's target remains because its eventual exact endpoint remains. The query omission acts on the whole zero function, not just on a selected coefficient or DATA slice. ∎

**Proof.** After the first swaps SOURCE is Πx+Jz and selected receiver is Dx. ## 4. Exact caller algebra for that changed provider

**Theorem C4.** Write T(B,C,K)(x,z,y)=(x,z+Bx,y+Cx+Kz). Two compatible chronological services satisfy

    T(B2,C2,K2)T(B1,C1,K1)
      =T(B1+B2,C1+C2+K2B1,K1+K2).

If actual supplied operators satisfy K2=-K1, their receiver-to-receiver blocks cancel, with remaining SOURCE coefficient C1+C2-K1B1. All original inputs remain independent.

**Proof.** Substitute z1=z+B1x and y1=y+C1x+K1z into the second service. The resulting ordinary receiver is y+(C1+C2+K2B1)x+(K1+K2)z. No factors are commuted. ∎

C3 is a constructive changed service, not a cheaper restoration of the original joined service. The Kz term must be retained in any actual caller. C4 does not assert K cancellation for the two different routed D25 stages. Their actual K operators contain their own E_t routes. No profitable compatible Gaussian caller or literal prefix deletion was established here.
