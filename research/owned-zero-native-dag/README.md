# Owned-zero native DAGs with destructive disposal

**Local, scoped negative result. No new supplier or kappa.** The explicit user
assignment asks for a new mechanism capable of exceeding kappa 0.002. This
experiment changes the scratch contract: use owned zero arrays, discard their
nonzero contents after their last use, and remove the selected bit word's D/C
phases. This is deliberately outside the clean-ancilla-return-to-zero model.
The selected record remains kappa **0.001672660197076918**.

## Three executable experiments

The input is eumemic's selected punctured E8 word with 111 ports and 439 helpers,
as retained by DreamingOfClouds' tuned supplier. Execute its literal A, scatter
and B. All 439 helper inputs are zero. Each owned helper is born at its first
used frame, for free; its eventual discard is also free. Scalar work, scratch
setup and erasure are omitted from the rejection budget. The nine retained
totals still pay their actual rank-seven COPY charges. Targets retain arbitrary
initial contents and finish at their prescribed hyperplanes.

| Source treatment | Forward rank mass | Optimistic complete bill at a=0 |
| --- | ---: | ---: |
| Copy every source into work at its initial line; preserve originals | 4551 | 639/512 |
| Fork a source only immediately before its first mutation | 4218 | 39/32 |
| Consume sources, then invert their complete code at the common FULL exit | 3894 | 5637/4736 |

Every variant has exact target content `y_t+x_t` on all 222 independent data
columns. The first two preserve original sources in separate registers; their
remaining movement to FULL is charged. A fork uses a zero work array at the
current source frame, so the original freezes there while the work version
continues. Three never-mutated sources need no lazy fork.

The third variant gives a small constructive algebraic observation: the raw
source block S is invertible over F2. All sources can therefore reach FULL and
be decoded together by scalar additions, without reconstructing any helper.
The verifier computes S inverse and checks all its source columns. An independent
replay with the pinned original interpreter confirms the full raw scalar map.
This is an optimistic representation-level construction, not new all-size/native
admission. In particular, a common local scalar frame does not prove a routed
global decoding interface. The code is large: `rank(S-I)=108`, so factoring this
specific source change through fewer than 108 scalar channels is impossible.

## The complete-cost rejection

Keep the pinned nine-stage, four-pair, 32-replica schedule, with m=64 and
W=28416. Extract its pure `recipe` function from the pinned source and reconstruct
every idle entrance and terminal catch-up. Because helpers are now owned scratch,
none is hosted in those idle useful-data arrays. Their full idle profile returns:

```
{7:21312, 14:14208, 28:14208, 42:14208}
```

Its rank mass is 1342656. Grant the four reverse calls only their mandatory
retained monotone data endpoint mass, `14*111` each; all reverse helper/copy work
is free. For a measured forward local mass L the necessary bill is at least

```
[5*32*L + 4*32*14*111 + 1342656] / [64*28416].
```

All three bills exceed one already at zero saving. Every retained positive
child rank is below m, so positive saving only raises its moment. The best
experiment loses by about 19.02%, before any of the omitted costs. This rejects
these three implementations in this schedule, even with a hypothetical ideal
reverse. It is not a lower bound for all owned-scratch programs.

This screen permits at most `L < 8658/5 = 1731.6` even to retain a positive
zero-saving deficit. The best L here is 3894. Another large optimization search
on this graph is not justified by the current budget. In particular, removing
all idle work would incorrectly make the best trial pass with bill 4281/9472;
the verifier retains that false-positive control.

## Open next questions

A different contract could carry encoded **borrowed** state between calls and
decode once at the controller's terminal boundary. This differs from discarding
owned scratch: it must preserve every useful idle input and avoid reintroducing
the missing restoration in a later call. This is a hypothesis, not a discovered
solution or a novelty claim. Source codes and global correction deferral already
have substantial predecessors.

The discriminating first step is one complete two-call program, with literal
physical input/output frames and owner maps, on arbitrary data and helper dirt.
Its boundary code must either cancel or have a priced terminal decoder. A proposed
small syndrome must pass the actual rank test, rather than treating the current
rank-108 source change as an eight-channel residual. The missing matched physical
consumer and favorable complete invoice block expansion. A changed owned-zero
graph would instead need to pass the 1731.6 mass screen before further synthesis.
