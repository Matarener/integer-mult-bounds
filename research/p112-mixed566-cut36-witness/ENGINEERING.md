# Engineering decisions and verification boundaries

The falsifiable predicate is a single literal common cut of size 36, residual support
ranks 5,6,6, and two independent codewords in the piece span. The primary
checker strengthens the last condition to exact intersection dimension 2.
The package is isolated; it changes no predecessor or shared verifier.

Build the Lever produced construct.py and the exact certificate checker.
Prove It Works required actual coefficient identities, separate reconstructed
geometry/constraints and accepting/rejecting CLI controls. Unslop shaped the
scope statements. No extra agent or thread was spawned. User authorization
covers the scoped Discussion posts, commit, fork push and contribution PR.

## Power of Ten inspection

1. Structured loops and exceptions only. There is no recursion in the new
   code. Source loading invokes only the fixed authenticated geometry API.
2. Root/coordinate loops are bounded by 120 roots and 8 coordinates. Binary
   elimination has at most 120 labels and 9 columns; rational elimination has
   at most 120 rows and 11 columns. The section search has at most 2667
   codimension-two spaces or 127 hyperplanes, with 27 labels per candidate.
   The independent inverse is 8 by 16 and constraint matrix has 73 rows and 8
   columns. Nine CLI mutants and two positive calls have 30-second timeouts.
   Each registered command has a 60-second timeout. JSON inputs are at most
   200000 bytes; geometry is at most 100000 bytes.
3. Python necessarily allocates arbitrary-precision objects and containers.
   Deviation for all four scripts: fixed steady-state allocation is not
   available in this runtime. Input byte/shape bounds, fixed matrix sizes,
   at most 512 binary-span elements and the finite search bounds constrain
   live memory. Temporary controls have scoped owners and are removed on
   success or failure. Follow-up: reconsider representation before increasing
   the dimension or admitting streamed/unbounded inputs.
4. Every new function is at most 60 formatted lines. Main certificate
   verification and schema parsing remain separate responsibilities.
5. Contracts remain enabled under -O. They check actual cut membership,
   binary ranks, source identity, field-independent coefficient equations
   and exact matrix dimensions. Failure controls exercise those conditions.
6. Scientific state is local. The source manifest and certificate are read
   only. Construct.py writes only to an explicitly requested external path.
   Control fixtures live in a scoped temporary directory. The session sets
   TMPDIR to its assigned external cache directory.
7. Source and witness boundaries validate byte limits and relevant schemas.
   Every replay subprocess checks its return status and has a timeout. The
   valid sign-gauge fixture confirms the verifier checks the mathematical
   predicate rather than requiring one literal list of signs.
8. Deviation at verify.py:model: compile/exec runs the exact SHA256-pinned
   source bytes to avoid stale .pyc substitution. Its one Ruff S102
   suppression is confined to this call. Altered source and source links
   are rejected before execution. The separate checker executes no imported
   geometry or primary code. Follow-up: replace executable geometry loading
   with an authenticated data-only interface if the canonical API supplies one.
9. Data access is shallow, with explicit dictionaries and fixed matrix
   shapes. There is no callback registry, dynamic plugin or indirect task
   dispatch. The authenticated module has one fixed API target, root_data.
10. CPython runs with -W error; normal and optimized replays exercise real
    scripts. Ruff check and format check cover the four new Python files.
    No repository-wide analyzer or historical suite was changed or rerun.
    Existing geometry source is preserved; the bounded API and positive
    fixture are inspected rather than rewriting its unrelated historical
    functions. Python managed allocations and the pinned-source execution
    are the explicit deviations above, not claims of strict low-level
    fixed-allocation compliance.
