# Verification and bounded implementation

Engineering-mode uses the investigation playbook, with the user's explicit
publication request authorizing the retained proof and replay package.
Build the Lever led to two deterministic complete enumerations. Prove It Works
led to actual receipt mutants, literal frame checks and committed source replay.
Unslop shaped the scope and claim wording. No child agent or thread was created.

All new code is confined to this package. Frozen geometry and predecessor
packages remain unchanged. The exact predicate is the four-piece theorem in
PROOF.md; the full caller is explicitly left open. Entry overlap covered 303
open PRs and 2,229 Discussion records with complete pagination, plus the
canonical handoff and prior campaign results. No exact small-piece or
root-support-rigidity match was found. This is bounded coverage, not proof of
novelty. The session decisions and transport logs live outside the checkout.

Power-of-Ten inspection covers common.py, verify.py, independent.py and
test_controls.py and the called root_data/chamber_receipt paths of authenticated
geometry.py. The geometry is preserved as a frozen source. No inherited heavy
flat_capacity entry point is invoked.

1. Control flow is iterative, with scoped temporary-directory cleanup and
   checked subprocess failure. No new recursion or background process exists.
2. All loops range over fixed finite domains. The two census limits are
   3,309,747/788,035 kernel spaces and 3,212,592/777,240 affine sections.
   Ambient dimension is at most nine. Root loops have at most 120 entries,
   generator loops eight, critical sets 1,260/336, and receipt mutants four.
   Each CLI control has a 120-second subprocess timeout.
3. Rule 3 deviation. CPython and Fraction allocate dynamically. This terminating
   standard-library program cannot prohibit runtime allocation. It streams one
   census section at a time. Tables have at most 512 integer masks or 256 root
   slots; a current affine span has at most 32 elements. Critical sets are
   bounded to 4,096 entries, source inputs to 100,000 bytes and JSON to 200,000.
   Control output is from a fixed local four-run verifier, not an external data
   stream. Verification includes both complete domains. If dimensions or inputs
   become configurable, introduce enforced budgets before expanding them.
4. New functions fit within sixty physical lines after normal formatting.
5. ValueError checks remain active under -O. Invariants include exact source
   inventory, root/label bijection, census totals, closure, literal frame partners,
   typed receipt equality and the strict slack contradiction.
6. Mutable state is local to a census or control. No shared checkout config,
   global Python cache, foreign source or selected record is changed.
7. Source and JSON boundaries reject malformed bytes, duplicate keys and links.
   Subprocess status and stderr are checked. Commands neither regenerate
   committed receipts nor silently accept a changed result.
8. Rule 8 deviation. common.model executes only SHA256-authenticated canonical
   geometry source bytes to avoid bytecode substitution. The target is a fixed
   three-file inventory and one named source. Altered and linked sources reject.
   Follow-up if the geometry contract changes: pin and review the replacement
   source before changing any digest or finite receipt.
9. Rule 9 deviation. The imported geometry exposes dot/canonical functions passed
   to a bounded reflection helper. These are fixed authenticated targets with
   process lifetime. No plugin dispatch or mutable registry exists. Both actual
   reflection paths and changed-source rejection are exercised.
10. Python warnings-as-errors, normal/optimized replay and Ruff diagnostics cover
    touched code. Exact tool versions and commands appear in CHECKS.json. No
    repository-wide diagnostics or historical heavy suites are required by this
    isolated package.

No performance or probabilistic evaluation improvement is claimed. The reported
counts are exact finite-domain cardinalities checked by two complete algorithms.
They are not timing benchmarks or a full multiplication proof.
