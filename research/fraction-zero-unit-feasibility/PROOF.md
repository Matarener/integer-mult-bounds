# Exact-value scope of the proposed shortcuts

This argument concerns the authenticated Fraction `error_trace` function and its standard exact-rational inputs. It does not change a native operator, admitted cost, precision theorem or complete supplier.

Assume both versions start an event with the same coefficient rows, scores, peaks, witness dictionaries, pairs and hash stream. Shared constants are ordinary immutable Fraction values 0,1,-1. Replacing repeated construction of those constants preserves exact values/types and does not share mutable row/score containers.

For an ADD/COPY coefficient update, let x be the destination coefficient, y the source coefficient and q the parsed exact scalar. The original computes x+q*y. If q=1, the derived expression is x+y; if q=-1, it is x+(-y); otherwise it retains x+q*y. All are exactly equal standard Fraction values. With d=abs(x+q*y)-abs(x), the original updates each weighted score s by s+d*a, and the unweighted score by s+d. If d=1, addition of a is equal; if d=-1, subtraction of a is equal; if d=0, leaving the score unchanged is equal; otherwise the original expression is retained. There is no floating arithmetic, truncation, reassociation across distinct coefficient contributions or integer-backend reuse.

The resulting coefficient is inserted or removed by the same zero predicate. The event order, rounded-site injections, prefix peak/tie rules, full witness copies, final scores/coefficients, Pareto rows and hash updates remain in their original order. Induction on the coefficient and event loops therefore preserves every returned value, including attaining witnesses and signed coefficient streams. Mutable output dictionaries/lists remain fresh. The scope excludes arbitrary user-defined numeric classes with observable operator side effects; standard Fraction arithmetic and the authenticated caller supply the declared domain.

Exact module/function source hashes and uniquely bound edits prevent transfer to a changed source. The unmodified callable must match a fresh compilation's recursive executable structure; only file/line metadata is ignored. The original callable is restored by a context manager even on exceptions. Tests reject both outer and nested live-code drift, and compare numeric types as well as values. The three declared malformed-input probes preserve the original exception type/message; no universal malformed-object API claim is made.

Finite evidence covers 241 programs/10,164 events, all six operations, zero/unit/general coefficients and weights, sign flips, cancellation and 16 failure/isolation controls. One full actual trace additionally checks every value/type and unchanged input on all 25,984 events/799 coordinates. This establishes source-bound exactness evidence. It does not fund a performance claim: the observed 0.237-second trace difference is insufficient headroom for the complete qualification target. The experiment stops before complete optimization construction.
