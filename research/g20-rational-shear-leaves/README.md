# Complete rational G20 shear leaves

All fourteen ADD coefficients in the released dense and sparse G20 catalogues
now have a literal coefficient producer linked to the original-owner affine
kernel and complete descriptor erasure. The class includes signed1/4,1/2,
3/2 and integers1 through4. Every odd positive Q is supported, including the
one-element ring. Program tables do not depend on Q or the payload.

The complete bound stays **1024V transitions and64V visited cells**, where
V=P Q^2 G S. It includes coefficient and zero-offset preparation, the physical
shear, original-owner installation, both descriptor erasures and every head
return. No host modular inverse, supplied coefficient or clean output owner
is free. General earlier-target routing is still outside this interface.

The arithmetic transducer is retained from JoyboyBrian's bit-low-carry-lowering.
The new work extends its fixed quarter-code envelope to the actual G20 class,
compiles its explicit-edge/five-symbol language into the existing local machine,
handles Q=1, and completes the producer/consumer link. DELTA.json lists every
change to the frozen transducer. See [PROOF.md](PROOF.md).

All366 complete physical leaves, 142,886 payload bits and84 full-bank inverse
round trips pass. Complete Q=125 pair fibers are executed for1/4 and3/2; their
large source spectator extents are not materialized. Nine controls reject bad
moduli, noncanonical input, rational-floor substitution, wrong sign, omitted
physical coefficient erasure and nonlocal motion. All42 fixed tables and the
complete typed receipt are checked.
