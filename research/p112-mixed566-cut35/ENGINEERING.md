## Power of Ten inspection

1. New functions use structured loops and exceptions, with no recursion. Every
   CLI failure propagates nonzero. Temporary control copies use context managers.
2. Bounds are the fixed120 roots, nine-bit labels, 256 coordinate vectors,
   97,155 five-spaces, 10,795 six-spaces per axis, 60*16*16 unions, 7,560 orbit
   nodes with eight neighbors, 35,960 four-root subsets and127 hyperplanes per
   axis. Source/JSON files have a200,000-byte boundary. Child controls each have
   a30-second timeout; registered commands each have a120-second timeout.
3. Python allocates dynamically. Live sets are bounded by these fixed domains.
   Controls copy only this package and its five explicit inputs and clean on
   every exit. The production checker does not allocate unbounded input state.
4. Every new function is under60 physical lines after formatting. Each computes
   one source, linear-algebra, census, transport, proof or CLI responsibility.
5. Executable require checks enforce the full census counts, model dimensions,
   source hashes, exact digests, transport completeness and strict proof gaps.
   They remain active under optimized Python. A cut36 rejection deliberately
   records the losing strict-E6 boundary, not theorem sharpness.
6. Each process owns its local sets. Only immutable constants are shared between
   scripts. No code modifies frozen sources, the selected record or Git refs.
7. Input shapes are validated at source/CLI boundaries. Subprocess controls check
   return codes, specific failure text and absence of a pass marker. Normal
   process and file errors propagate. Check scripts use only bounded local paths.
8. One exact hash-authenticated geometry source is compiled in memory rather
   than imported through possible stale bytecode. It is the sole dynamic source
   target. Local ordinary imports share only inspectable helpers.
9. No pointer arithmetic, callbacks, runtime registration or hidden dispatch is
   introduced. Python references and standard iteration are managed by Python.
10. Verification uses warnings as errors, normal and optimized interpreters,
    Ruff0.14.0 rules E,F,B,I,UP and formatting. Registered CI repeats the three
    Python commands. Ruff is local inspection, not a new global CI requirement.
