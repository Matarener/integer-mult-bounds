2026. No new kappa is certified.** This package closes the missing first
native interstage transition, extends its data gauges through the actual

nine-call replica** at the requested target. None of the emitted native
consumers meets that allowance. The selected frontier and every file from
the original attached repository are preserved.

## 3. Alternating signs expose 72 routed query channels

The fixed-sign extension leaves `T-2iS` invariant. Its extra-port record
image exposes only 64 directions across the bank schedule. The new native
variant instead uses

\[
Q_{\rm even}=[R,4I_8,8iI_8],\qquad
Q_{\rm odd}=[R,-4I_8,8iI_8].
\]

For every odd call, sign changes on the first eight extra coordinates in
both source and target banks conjugate the complete local word. This
retains the 5070 rank mass, adds no recursive children, and requires 64
additional real scalar primitives per odd call. The four changed calls
therefore add 256 real primitives per replica. Both emitted providers
and both orientations pass all 632 input columns. Forward and backward
scalar bills are 172314 and 181642; their checked local coefficient
prefix ceilings remain 124 and 128 bits. These local ceilings do not
admit the still-unlowered full consumer.

Write `S_b,T_b` for an extra-port **error image**, in the input-normalized
bank order `X0,Y0,X1,Y1,X2,Y2,X3,Y3`. Set

\[
E_b=-S_b/2+iT_b/4,\qquad O_b=S_b/2+iT_b/4.
\]

The even-stage records are recovered by

\[
\begin{aligned}
q_0&=E_{X0}+E_{Y0}-E_{Y1}+E_{Y2}-E_{Y3},\\
q_2&=-E_{Y0},\quad q_4=-E_{Y1},\quad
q_6=-E_{Y2},\quad q_8=-E_{Y3}.
\end{aligned}
\]

The odd-stage records are

\[
q_1=O_{X0}+O_{X1},\quad q_3=O_{X1}+O_{X2},\quad
q_5=O_{X2}+O_{X3},\quad q_7=O_{X3}.
\]

Apply the respective zero-port owner route to each recovered block. All
sixteen zero ports share that route within a stage, so the displayed
scalar left inverse extends to an exact operator-valued identity without
requiring the ordinary 112 port routes to agree. The coefficient matrix
has nine independent columns, each carrying eight query fields: 72
independent routed image channels in 128 extra outputs.

The word **error** matters. For arbitrary initial extra-port values, the
terminal extra data is not just a clean record of the changes. Reading
the terminal `S,T` as though they started at zero is not a consumer. The
following ordered inverse handles arbitrary initial values algebraically.

## 4. The residual inverse is a finite ordered expression

In the gauge where the ordinary nine-stage bridge computation has been
factored out, write the actual stage defects as

\[
E_j=I+U_jV_j,\qquad V_jU_j=-2I_8,\qquad
M=E_8\cdots E_0.
\]

Here `U_j` and `V_j` include the actual stage and port owner routes.
Collect them into the block column `U` and block row `V`, and define
`G_ij=V_i U_j`. Let `G_lower` and `G_upper` be its strictly lower and
strictly upper parts, respectively. Over the ring of routed operators,
with multiplication order preserved,

\[
M-I=U(I-G_{\rm lower})^{-1}V,
\]

and

\[
\boxed{M^{-1}=I+U(I-G_{\rm upper})^{-1}V.}
\]

Both triangular inverses are finite nilpotent sums. No dense inverse or
odd-denominator arithmetic is hidden in this identity. An algorithmic
form gathers the nine eight-field blocks `V_j z`, solves the upper
triangular system in descending stage order, and scatters `U_j q_j` to
every original and extra field. The arbitrary-dirty extra inputs are
then restored together with the ordinary data.

Conjugating by the physical native gauge `Gamma` makes the two outer
interfaces `V Gamma^-1` and `Gamma U`. Their composition cancels the
adjacent `Gamma^-1 Gamma` inside a Gram block. It does not permit moving
`Gamma` through an owner route, or treating either outer interface as a
free scalar addition. The emitted consumer IR records those interfaces
as explicit unresolved native obligations.

The active scalar specialization is separately checked on all 24 basis
directions per query mode, eight modes, and the 832 fixed kernel

where stages have identical cover routes. The arbitrary-route statement

The independent record reviewer also expands the complete 511-term free

The owned-query lifecycle has two checked options. The retained native

It is a stronger optional cleanup, not a requirement imposed on the

The finite temporary layout can reuse 72 of the existing 91 private

There is also a source-bound reason to reject a tempting 32+32 boundary

## 7. Why sixteen extra ports cannot simply be replaced by eight

The smaller geometry is attractive enough to test algebraically. In
the particular symmetric normalization used here, it has an exact
arithmetic obstruction.

Suppose a helper-only change of basis satisfies

\[
B\in\operatorname{GL}_{408}(\mathbb Z[1/2,i]),\qquad HB=[A,0],
\]

and retains the data block `J` in `D=I-[R,A]^T[R,A]/4`. Involutivity
requires `AA^T=-48I8`. The actual native helper matrix `H` has a
rank-eight minor whose determinant is 64. Therefore its rank remains
eight modulo 3, and the invertibility of both `B` and `B^-1` over the
Gaussian-dyadic ring preserves that rank.

The residue field is `F9=F3[i]`. Modulo 3, `AA^T=0`, so the rows of
`A` form an eight-dimensional totally isotropic subspace of a
nondegenerate bilinear space of dimension `k`. Thus `8 <= k-8`, giving
**k >= 16**. The sixteen-column factor `[4I,8iI]` attains the bound.
An independent modular interpreter checks the needed actual helper
columns from both native providers.

Over `Q(i)`, an eight-column factor does exist. Let `B8` be two copies
of the four-dimensional quaternion multiplication matrix for `1+i+j`;
then `B8 B8^T=3I`, and `A8=4i B8` has the required Gram matrix. Its
inverse is `-i B8^T/12`, which requires division by 3. The reflection
entries happen to be Gaussian dyadic, but the invertible helper
normalization and denormalization are not. The emitted matrix witness
therefore changes an arithmetic premise; it is not a native-word
admission. This minimum-sixteen result applies only to the specified
symmetric helper normalization, not arbitrary asymmetric dirty contracts.

## 8. What remains, in execution order

1. **Lower the physical query and image interfaces.** Start with the
   emitted `ALTERNATING-CONSUMER-IR.json.gz`, its actual routes, and the
   triangular Gram word. Construct literal native implementations of
   `V Gamma^-1` and `Gamma U`. Include arbitrary extra-port restoration
   and explicit owned-query lifecycle operations. A matrix identity or
   scalar bank rank is not a price certificate.
2. **Choose the geometry from the complete consumer bill.** The actual
   m73 construction needs an added tariff below about 5.99 H8. The
   stated m81 sixteen-port screen needs less than 68.68 H8. A rational
   eight-port route could investigate 69 H8, but must admit division by
   3 and survive the very small integer-packing margin.
3. **Combine the emitted data and slot schedules into one native
   chronological supplier.** The data-gauge checker and literal
   376-role helper allocator are compatible inputs, but their separate
   certificates are not a full native all-call compiler. Recheck changed
   consumer workspace, owner routing, restoration, and all output gauges
   in that same executable schedule.
4. **Close the full outer admission only after the finite bill fits.**
   Price every child, scalar operation, payload translation, address
   operation, and peak live field; propagate uniform precision and tape
   bounds; then rerun the exact outer engines with strict endpoint gaps.
   The retained outer engines already replay successfully. The missing
   finite supplier is what prevents a new endpoint from being submitted.

The owner-coupled dirty-core experiment is also retained as an alternative
source of factors. It replaces nine calls in one selected replica while
tracing its helpers through their actual later owner banks. Replicas 0,

order. This demonstrates actual inter-owner coupling; it does not prove
