# Literal transitions for the symmetric 128-port component

The first missing global obligation is now constructed. Both retained PR3734
providers admit an explicit forward/backward two-call transition on the existing
73-axis cover. It uses **32 additional rank-1 native children**, not a free
identification of the sixteen extra ports with ordinary norm-one ports. The
same construction extends through the actual nine-stage bridge schedule with
**256 additional rank-1 children**. Every extra port has a genuine FULL73
terminal gauge.

A second emitted variant alternates the signs of eight extra coordinates.
It changes the query-record directions while keeping the native geometry and
recursive profile fixed. Its additional bill is **64 real scalar primitives
per changed call**, with no new recursive children.

This package does **not** establish a new kappa. The emitted controller still
carries an ordered, routed data residual. A separate exact witness shows that
the existing scalar bridge pattern does not cancel it. The productive denominator
1024 below is therefore a candidate denominator conditional on decoding that
residual, not an already admitted multiplication supplier.

## 2. A virtual normal makes the zero-port transition possible

Give every extra port the **virtual** unit vector \(r=e_0\). This changes no
local label: the extra label remains zero and its local entrance remains I.
The virtual normal only specifies a paid interstage native operation and an
owner chart.

Let

\[
 A_j=C_{e_0}C_{e_1}\cdots C_{e_{8+8j}}.
\]

After a local call at stage \(j\), both zero-port banks have gauge \(A_j\).
Immediately before the next active local call at stage \(j+1\), apply

\[
 C_{e_0}^{-1}
\]

to both zero-port banks of that call. The resulting gauge contains only
\(8(j+1)\) exterior directions. The ordinary owner permutation that fixes
\(e_0\) and exchanges \(e_1,\ldots,e_8\) with the next eight-axis block
moves this gauge to the common local exterior. The new local zero-port
entrance is consequently I tensored with that exterior, as its actual program
requires.

The extra-port chart uses standard coordinate axes, so its affine entrance
and exit translations are zero. The existing 112 ports retain the authenticated
phase translations and owner routes. The checker compares the complete
quadratic phase polynomial over all 73 Boolean characters, including its
constant Gaussian phase; it is not a phase-modulo-global-scalar test.

The native inverse line is an actual rank-1 recipe. Its left monomial adapter
has the translation \(e_0\), and its right adapter is identity. Both signed
recipes are checked on all 512 Gaussian basis columns in the native 9-axis
space, with exact FULL commutation and effective phase/direction mutations.

bridges**. Zero-port banks therefore have matching FULL-prefix gauges whenever
the original controller applies a bridge. Applying a line early to the wrong

## 5. An exact counterexample to free constant-D cleanup

There is a tempting algebraic shortcut. If the three defects of an F-B-F block
were the same involution, its remaining code could be placed in the FULL bank
and removed by scalar operations. The actual owner routes do not satisfy that
premise.

`residual_witness.py` checks a particularly transparent actual-route example.
Choose extra source port 112, corresponding to the first S coordinate. Then

\[
 (D_1D_0)_{112,112}
 =\sum_{j\in\operatorname{supp}(R_0)}
   P_{\rho_{\mathrm{zero}}\rho_j}-55I.
\]

There are exactly 56 original ports in this support. Each contributes coefficient
one; every displayed owner map is checked to be nonidentity as an actual
73-dimensional orthogonal matrix.

For input equal to a delta function at the identity cover class on source port
112, the output coefficient at the identity class is consequently **−55**, while
an ordinary decoded output requires **1**. This is a difference of −56, with no
floating-point approximation or assumed route independence.

The same example survives the complete ordinary nine-stage bridge pattern.
After the first two calls X0 is zero. The next forward call leaves Y0 unchanged;
the two bridges to pair 1 cancel their writes because they see the same Y0.
All later pairs receive zero. The final signed exchange still carries the
\(D_1D_0\) error. This is a scoped counterexample to that proposed free consumer,
not a lower bound on all possible consumers.

## 6. A useful state invariant and its native alternation

Write the sixteen source extras as \((S,T)\). The reflection changes them by

\[
 S'=S-q,\qquad T'=T-2i q.
\]

For the original fixed-sign word, every component of \(T-2iS\) is invariant under D. The check verifies all
eight invariants against the actual reconstructed matrix. Because S and T use
the same virtual route, the invariants persist under each routed fixed-sign \(D_j\).

This leaves genuine structure to exploit: an eventual consumer should use the
carried zero-port state and the FULL banks, and should track the dirty initial
state explicitly. The invariant alone does not prove that the final S values
contain all stage queries or that their data scatters can be implemented at no
native cost. Their scatter maps depend on the actual stage and port.

The fixed invariant also limits which distinct stage records the extra state
can carry. The follow-on experiment therefore changes the odd stages to

\[
 Q_{\rm even}=[R,4I,8iI],\qquad
 Q_{\rm odd}=[R,-4I,8iI].
\]

Let P change the signs of the eight S coordinates and act as identity elsewhere.
Then \(D_{\rm odd}=PDP\). The actual alternate local program is obtained by
conjugating the complete original word with \(\operatorname{diag}(P,P)\):
sixteen sign changes at the two bank entrances and sixteen at their exits.
All affected entrance coordinates have literal I gauge; all affected exits
have literal FULL gauge. The original 112-port data block and the 376 restored
arbitrary helper roles are unchanged.

`alternating_sign.py` emits `evidence/ALTERNATING-PROGRAMS-base.json.gz` and
`ALTERNATING-PROGRAMS-extra.json.gz`. It freshly checks both complete
orientations on all 632 independent columns, their literal frames, their
recursive profiles, and their scalar invoices and prefix bounds. The exact
added charge is 32 Gaussian sign macros, or 64 real primitives per call.
Using the alternate at stages 1, 3, 5 and 7 adds 256 real primitives per replica.
There are no new owner routes or native children.

On an odd-stage routed query the changes become

\[
 \Delta S=+q,\qquad\Delta T=-2i q,
\]

whereas on an even stage they are \((-q,-2i q)\). This realizes two different
record directions natively. The sibling `../helper-consumer` package investigates
their complete record inversion and the dirty initial state; that record algebra
does not automatically provide a native operation that restores the non-FULL
data bank.
