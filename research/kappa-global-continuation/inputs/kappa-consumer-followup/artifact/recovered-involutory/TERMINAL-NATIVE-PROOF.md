## Terminal convention

Use the state **after the final signed exchange**. In this convention the four
X banks have gauge FULL C_q^-1 and the four Y banks have gauge FULL. Before
that exchange the names are reversed, and the bank factors are conjugated by
the signed exchange S. Mixing those conventions would give the wrong decoder.

The normalized residual is

\[
M=E_8E_7\cdots E_0,\qquad
E_j=P_j^{-1}C_jP_j,\qquad C_j^2=I.
\]

Here P_j contains the entire ordinary bank prefix before stage j and the
actual per-port stage route. The checker reads the original nine-stage recipe
through the source-bound `check_controller.py` comparison. The local right
factor is

\[
C_j=I+e_xe_x^T\otimes(G-I)\quad\text{at a forward stage},
\]

\[
C_j=I+(e_x+e_y)e_y^T\otimes(G-I)
\quad\text{at a backward stage}.
\]

The finite prefix is emitted as all 112 portwise ADDs for each ordinary
operation, then inverted in reverse order. A separate parser checks the
resulting exact eight-bank matrix and both inverse orders. The selected pair's
two banks are routed explicitly before C_j and unrouted afterward. Stage zero
uses the identity route.

The source code G=I+AR has RA=-2I. The eight serial queries therefore do not
disturb later queries. In the backward right factor each query is scattered
with A into both X and Y; in the forward factor it is scattered only into X.
The emitted right-factor programs square to the identity on all 632 columns,
and their private query field returns to zero. They touch no arbitrary helper.

\[

\[
