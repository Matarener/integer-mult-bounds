## Exact new mechanism

Let `J=I-KR`, let `M=RK`, and suppose a dyadic right inverse P satisfies `RP=I`.
Without any scalar or commutativity assumption on M, define

```
A=P(M-2I)-K,   G=I+AR.
RA=-2I,       G^2=I,       JG-I=P(M-2I)R.
```

Indeed `RA=M-2I-M=-2I`, so the square of G is I. Also
`JG-I=(A-K-KRA)R=(A+K)R=P(M-2I)R`. All multiplication orders are explicit.
Thus sparse rows of P give sparse target repair without requiring an inverse
of M or of J. For the actual E8 source, M=14I and A=12P-K. This replaces the
order-six source code in Ali Romman's PR1862 with an involution. It is a changed
representation contract rather than a different packing of the old word.

The complete local content maps are

`B_G(x,y)=(x-y,Gy)`, `F_G(x,y)=(Gx,y+Gx)`.

For one fixed chart `F_G B_G F_G=(-Gy,x)`. The extra output code is real work:
fixed-chart algebra alone does not make the actual controller a signed swap.
The involution also gives up sparse query hosting: `RG=-R`; `LG=R` would force
`L=-R`. The predecessor's selected-coordinate query reader cannot be inherited.

## Actual routes and terminal cost, rather than a common-code surrogate

The actual nine-call controller has nine routed stage codes. Data owner classes
use `d*rho(stage,port)` in the73-bit orthogonal cover. `bridge.py` gives112
independent physical cover-support witnesses for each of stage pairs0/1,1/2,2/3.
They cannot be repaired by native phase changes alone. A common physical code
with eight row-supported repairs at each adjacent stage is impossible: the union
of the two repair supports must cover all112 differing routed J rows.

The full terminal analysis is stronger. `trace_rank.py` reconstructs the exact
selected nine-call recipe, derives its nine rank-eight bank factors, and checks
all36 pairs of actual routes. For each pair the112 relative right factors are
distinct. TRACE-PROOF.md uses the complete regular cover, not a single-owner
sample, and derives

`rank(M_actual-I) >= (279/4) |cover| payload_dimension`.

The precise inherited native premise is that each routed code is a port-diagonal
**unitary** conjugate carrying its actual rho route in the controller's normalized
logical coordinates. All native within-class unitary phases are allowed. The
cross-projection trace is4/7 per cover payload; exact separate bank metrics give
query and image rank bounds567/8, and a unitriangular ordered-product middle
factor gives the279/4 defect bound. Initial/output native conjugations preserve
this rank. Full details and limits are in TRACE-PROOF.md.

Consequently, a linear repair observing at most63 full query fields per cover
and no other source-dependent state is impossible. The suggested seven-bank
56-field repair is excluded on the actual noncommuting routes. **Only under the
proposed one-H8-per-full-field tariff**, its bill is at least558 rank mass versus
504 saved across nine calls, a gap at least54. Integer fields require70, costing
560. This is not a universal native tariff bound: typed address subspaces,
retained source state or a changed operator graph are different contracts.

Flattening every output Y hole to FULL does not fix the problem for one H1 per
port. It leaves the initial X factor C_q^-1. Paying both directions cancels the
ordinary raw deficit even when all centers are removed. Likewise bundling two
existing banks provides one bank-tag bit, not the f independent bits required
for an additional tensor direction at arbitrary recursion width f.
