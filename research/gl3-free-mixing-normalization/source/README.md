# One dirty-register GL3 target has minimum nine paid calls

For `A=(1,4,3)`, `B=(2,4,3)` and `I=(1,2,4)` in row-mask notation,
the target `diag([A],[B],[I])` has minimum nine paid calls in the exact
three-register model `M3(F2[GL3(F2)])`. The third input is arbitrary and must
be restored exactly.

This is a finite, certificate-backed negative result. The seven- and
eight-call CNFs have RUP proofs accepted by the separate DRAT-trim checker;
every paid factor is an involution, so padding with cancelling pairs excludes
all shorter lengths. The known direct-nine construction supplies the upper
bound and passes exact replay on all 504 regular basis inputs.

The connection from the checked CNFs to the mathematical model rests on the
[encoding argument](ENCODING_AUDIT.md), reproducible generator and tests.
There has been no independent human review or proof-assistant verification.
This result concerns one fixed target; it provides no new kappa, selected
frontier, general integer-multiplication bound, or physical implementation.

## Model and completeness

Each position chooses one of six coordinate-CNOT address labels `g` and one
of all 28 binary rank-one idempotents `N=uv^T`, `v^T u=1`.
The allowed factor is `I+N([g]+[I])`: 168 choices at every position.
Free scalar `GL3(F2)` mixing is normalized into these projectors.

The CNF constrains all nine matrix entries over the full 168-dimensional
group algebra, including all dirty-input dependencies and the restored
third diagonal. Natural 3-by-3 matrix equality would be insufficient; a known
alias is rejected by the full formal checker.

There are no bridge, label-order, target-conjugacy or symmetry restrictions.
The only pruning fixes coefficients outside the proved support intersection
`B_t intersect B_(n-t) T_c` to zero. Every transition equation is retained.
The forward/backward support argument, Boolean gate equivalences,
free-mixing normalization and pair-padding argument are in
[ENCODING_AUDIT.md](ENCODING_AUDIT.md).

## Reproduce

Python 3.10+ suffices for integrity, exact witness replay and CNF regeneration.
Run from this package directory:

```sh
python -B verify.py
python -B exact_checker.py DIRECT_NINE.json
```

The default verifier does not run a solver or silently equate a stored log
with a fresh proof check. For actual independent proof replay, build the
included checker and run:

```sh
cc -std=c99 -O2 -Dgetc_unlocked=getc third_party/drat-trim/drat-trim.c -o third_party/drat-trim/drat-trim
python -B verify.py --proofs --checker third_party/drat-trim/drat-trim
```

On Windows use GCC and an `.exe` output name. Proof replay has a 600-second
checker limit per instance, needs about 110 MB temporary disk space, and
retains checker logs under `.verification-work/`. The local original checks
used about 55 MB and 98 MB sampled checker RSS.

To reproduce the encoding controls and optionally regenerate proofs in a
fresh `reproduction/` directory:

```sh
python -m pip install -r requirements.txt
python -c "from pathlib import Path; Path('reproduction').mkdir(exist_ok=True)"
python -B controls.py --output reproduction/original-controls.json
python -B cnf_controls.py --z3 /path/to/z3 --out reproduction/cnf-controls
python -B cnf_model.py --length 8 --out reproduction/length8
python -B pysat_run.py --cnf reproduction/length8/instance.cnf --selectors reproduction/length8/SELECTORS.json --out reproduction/length8-glucose4 --python /path/to/python --checker third_party/drat-trim/drat-trim --seconds 600 --checker-seconds 300
```

Use the Python interpreter with the pinned dependencies installed. Repeat
the last two commands with length 7 and fresh output directories to regenerate
that certificate. The last command runs the bounded proof-generation wrapper. A fresh
proof may differ in bytes; acceptance requires an actual checker success.
The committed certificates can be checked without installing a SAT solver.
The original 15 control groups and four CNF control groups are recorded in
`controls/`; their scope is detailed in the encoding argument.

## Trust and open next questions

The external C proof checker validates CNF unsatisfiability, not the custom
generator's mathematical equivalence. The SMT and direct-CNF implementations
use different representations but were prepared within the same task and
share conceptual assumptions; the CNF generator also imports arithmetic
from the exact witness checker. Neither is independent human review.

1. **Independently review model equivalence and support pruning.** This is the
   main remaining trust obligation. Start with the transition and support
   arguments, regenerate the CNFs and replay the proofs on another platform.
2. **Assess whether another target warrants a separate pilot.** One target
   demonstrates a feasible certificate-producing approach, not the remaining
   family's answer. First check current coordination and model equivalences;
   broader search requires a new scoped claim and resource assessment.
