# One owned field remains necessary under rational overwrites

## Contract

This is a scoped algebraic proof. Work over the commutative rational group
algebra

`B = Q[q,j_1,...,j_(s-1)] / (q^4-1, j_1^2-1,...,j_(s-1)^2-1)`,

where `s>=1`. Put `J_0=q^2` and `J_k=j_k` for `k>=1`. The ordinary subalgebra
`A` is generated by the `J_k`. Its elements do not distinguish `q=1` from
`q=-1` when the spectator involutions have the same values. These are the
formal faithful-sector interfaces of the cited Boolean-sector family.

For every `a in F2^s`, let

`E_a = 2^(-s) product_k (1 + (-1)^(a_k) J_k)`.

There are `r>=1` blocks, each containing `2^s` independent data fields. The
desired data map multiplies field `a` in every block by

`F_a = 1 + q E_a/2`.

Any finite number of borrowed fields is allowed, with independent arbitrary
initial values and exact restoration. Every data field must produce its own
specified output independently of those borrowed values. An owned field has
arbitrary initial data and must finish zero. The question is whether a program
can have zero owned fields.

Grant the following enlarged instruction alphabet:

- Any square matrix with entries in `A` on all current fields, for free.
  This includes arbitrary rational scalar overwrites, dense ordinary mixing, shifts and
  CLEAR. The maps need not be assumed invertible in advance.
- Multiplication of one field by `q` or `q^-1`, with any finite number of calls.

All instructions are `B`-linear. The program is a fixed finite word on these
fields. It has no data-dependent branches, nonlinear operations, discarded outputs or other
`q`-dependent ordinary gates. Dynamically borrowed fields can be included from
the start as unused fields, because their values are arbitrary and restored.

## The new lower bound

**Theorem.** No word in this enlarged alphabet realizes the target with zero
owned fields. Consequently the exact minimum owned-field count is one,
using the cited one-field construction for the upper bound.

**Proof.** Fix the spectators to `j_k=1` and evaluate at `q=1` and `q=-1`.
Write these rational algebra homomorphisms as `chi_+` and `chi_-`. Both send
every `J_k` to `1`, so they agree on every ordinary coefficient in `A`.

Suppose there are `N=r 2^s+b` fields, including `b` borrowed fields and no
owned fields. Every instruction therefore gives two square rational matrices.
For an ordinary instruction these matrices are identical, so their
determinants agree. A query has determinant `1` at `chi_+` and `-1` at
`chi_-`. Its inverse has the same two determinants. Multiplicativity gives
the invariant

`det M_+ = (-1)^t det M_-`,

where `t` is the total number of query and inverse-query instructions.
This equality holds even if an ordinary gate is singular.

Exactly `E_0` evaluates to `1`; all other `E_a` evaluate to `0`. Each target
block thus has determinant `3/2` at `chi_+` and `1/2` at `chi_-`. Restoration
of borrowed fields contributes an identity block, while independence of the
data outputs removes off-diagonal borrowed-to-data terms. The target is
exactly `diag(F_data,I_b)`. It follows that

`det M_+ / det M_- = 3^r`.

Both determinants are nonzero. Since `r>=1`, this ratio is neither `1` nor
`-1`, contradicting the invariant. This proves the lower bound for every
finite number of restored borrowed fields and every finite word length.

For the upper bound, PR #5658 constructs an ordinary involutive route that
collects `sum_a E_a x_a` at role zero. In each block it clears one owned field,
copies that role to it, queries it, adds half its value to the role, and clears
it again. Applying the ordinary route again gives precisely the required
`F_a` outputs. One owned field is reused across all blocks. That published
construction is a cited upper bound, not a result audited in this package.
Its dyadic alphabet is contained in the enlarged alphabet. Hence the lower
and upper bounds match. QED.

## What changed from the predecessor

Ali Romman's PR #5658, section 5, proves the workspace lower bound when scalar
overwrites are restricted to dyadic units. Its rank-loss argument reduces
modulo three. Allowing `SCALE 3/2` defeats that invertibility premise, as the
source explicitly notes. Our argument works in characteristic zero and
compares two characters that every ordinary instruction shares. It covers
all rational scalar overwrites and, more strongly, arbitrary ordinary linear
mixing. It does not extend the predecessor's sharp `r+1` CLEAR bound to this
larger alphabet.

The invariant is a classical determinant argument. The new contribution is
its application to the explicitly open scalar-overwrite interface and the
resulting sharp workspace theorem, produced by Nick Petalas.

## Scope controls and limitations

A primitive overwrite by `1+q/2` distinguishes the two characters and directly
evades the hypothesis. It is outside the ordinary algebra. If borrowed outputs
may change, a reciprocal factor on a borrowed field can cancel the determinant
ratio, so the displayed obstruction also disappears. Neither control supplies
a legal implementation in the stated model. No characteristic-two or
nonlinear/adaptive claim follows from this proof.

The formal algebra and the finite linear instruction interface are explicit
premises. No claim is made that every possible native implementation factors
through this algebra, or that every physical caller has the exact restoration
contract. The theorem concerns temporary field count. Precision, tape cost,
ordinary operation count, a complete supplier, the selected conditional kappa
and the five framework assumptions remain outside its conclusion.

## Finite corroboration

The standalone checker expands the projectors literally at every paired
character through six axes. It checks the target ratio through sixteen blocks
and both query parity choices. Every two-by-two ordinary matrix over a fixed
eight-element rational alphabet is checked against an independent permutation
determinant, including singular maps and both query locations. Seeded longer
words exercise rational nonunit scales, row mixing, swaps and queries,
checking the invariant at every cut. Explicit changed-model and rank-loss
controls mark the theorem boundary. These are finite checks of the argument's
algebra, not a finite search offered as a universal proof.
