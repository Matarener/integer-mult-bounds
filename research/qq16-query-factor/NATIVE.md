# Native adapter obligation for the emitted query-factor word

The emitted word is a logical full-cover correction, not yet a native word.
This audit binds the missing adapter to its literal first query gate and
prices one explicitly stated normalization route. It changes the next
construction decision: compiling `add_view` as a raw owner map followed by
an ADD is invalid; globally normalizing every Y field is already too costly
under the stated comparable native tariff. A query-specific compensated
sequence or producer fusion remains open.

## Same logical gate, exact native transport

At the pair boundary write `T_X(d)=F17(d)` and
`T_Y,p(d)=F17(d) C_(d q_p)^-1`. The candidate chooses `F17(d)` for all
owned query carriers. Its gate

```
target(d) += c source(d g)
```

acts on logical coefficients. A native implementation must instead insert

```
T_target D_g T_source^-1
  = [T_target (D_g T_source^-1 D_g^-1)] D_g.
```

The bracketed phase has polynomial
`psi(w)=phi_target(w)-phi_source(g^T w)` modulo four. A physical affine map
can additionally supply an even linear term `2 delta dot w`; it cannot
supply an arbitrary missing quadratic phase. The route order is the actual
right-owner order in the emitted word. All route matrices are independently
reconstructed from the pinned DATA-PHASES chart swaps, including `rho2 rho1`.
No native map is silently identified with its owner matrix alone.

The literal first ADD is event 32, `q0 += Y0` through `rho1_0`. At owner I
and payload character `e0`, the routed source has phase zero and the owned
F17 target requires phase one. Thus raw map-plus-ADD writes coefficient one
where the required native representation has coefficient i. An affine
payload translation changes the exponent by zero or two and cannot repair
this discrepancy. At the constant character both phases are zero, which
explains why payload-constant logical replay does not test this premise.
The required phase's polarization rank is one. For every positive tensor
length the same witness can occupy one payload layer, with the constant
character in all other layers. Spectator contents are unchanged. Thus this
is not a rejection confined to a chosen finite tensor length.

For a polynomial `psi`, define its binary polarization by

```
B_psi(u,v) = (psi(u XOR v)-psi(u)-psi(v))/2 mod 2.
```

A line term `c parity(a dot w)` contributes `(c mod 2) a a^T`.
The independent checker computes this matrix exactly on all 73 axes.
The literal candidate's per-ADD rank histogram is 2,240 at rank zero,
1,632 at rank one, 1,824 at rank sixteen, and 416 at rank seventeen.
The first future-owner example is event 608, `q16 += Y76` through
`rho2_76`, and has rank seventeen. This is an exact phase requirement of
that gate with the declared F17 carriers. These ranks are **not native-call
charges**, and their sum is **not a lower bound on a fused implementation**.
Other carrier choices, shared transformations, changing query bases and
producer fusion can change the gatewise requirements.

As a separate signed control, the actual port-zero line has q=11. At
character e0, `Y0 += X0` requires inverse C_q transport: raw X has phase i,
required Y has phase one, inverse C_q repairs it, and positive C_q produces
minus one. All 16,384 columns of the packet's 32 signed selected-port line
recipes are checked directly as Gaussian integer kernels. Their scale is
that of `2 C_q^(+/-1)`; the native child contract supplies the normalization.
The packet provides these recipes for sixteen selected ports. It does not
provide signed recipes for the remaining 96 ordinary ports; absence here
is not a mathematical impossibility or a proof that no recipe exists.

## Stop test for one generic implementation route

Specify the route before pricing it:

1. Apply positive C_q to every one of the 112 current Y fields to enter F17.
2. Implement the query-factor correction in F17 with whatever further owner
   transport and query workspace it requires.
3. Apply inverse C_q to every one of the 112 final Y fields to restore their
   required external frames.

The two frame sweeps alone contain 224 rank-one children and 448 native
wrappers. This is a count of this explicit route, not a universal minimum.
We optimistically grant the missing ordinary-port signed recipes at one
rank-one child each. Query operations and all other nonnegative costs are
also granted zero solely for the following rejection screen.

Under the explicit common-interface tariff

```
C_r(lambda)=c (r lambda)^(1-a), c>0, lambda>0, 0<=a<=1,
```

we have `C8/C1=8^(1-a)<=8`. The selected pair's sixteen removed rank-eight
centres therefore fund at most 128 C1, while the QQ16 pair's 32 introduced
lines plus these 224 normalizers already cost 256 C1. The saving is at most
`-128 C1` even before the literal scalar increase 28,616, query work,
wrappers, physical owner transport, storage, restoration, movement,
precision and control. Even the 112-entry normalization sweep plus the
32 QQ lines exceeds the complete optimistic credit by 16 C1.

This is a precise rejection **under the stated comparable tariff**, whose
application to the actual recursive supplier has not been established by
this package. It is not an arbitrary physical-cost conclusion, an
all-repair lower bound, or a kappa result. It uses neither the proposed
PR3976 incidence nor a 553 allowance. The sixteen centre deletions are
credited once. If wrappers are already included in the chosen child tariff,
they must not be charged again.

## What would reopen a paid implementation

The promising next object is a compiled query-specific word that shares
phase work or changes the producer and query carriers jointly, rather than
normalizing every current Y field separately. It must discharge the
per-gate phase obligations by an actual compensated sequence, preserve both
bridge legs and every borrowed field, and return all owned scratch to its
specified state. Its finite native kernels, exclusive scratch lease,
physical access, finite precision and true recursive incidence remain
unproved here. The logical word's final CLEARs alone do not prove those
native interiors or their restoration.

This audit used OpenAI Codex assistance and shared the frozen source data
and declared interface with the construction worker. It imports no primary
implementation. It is an independent finite phase calculation, not an
independent human review or formal-kernel proof.
