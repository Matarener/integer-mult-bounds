# Paid query-factor repair: cost and restoration contract

This note concerns a new correction after the actual QQ16 F0/B1 pair,
with both current X/Y outputs required to match the selected pair before
its next bridge. The pair-1 bridge inputs must remain unchanged. A
correction to an earlier input, a decoder output held elsewhere, or a
constant-owner identity does not by itself meet this endpoint contract.

## What the existing obstructions cover

PR4003 (`309189077d0f760248bbdaadab42ecbff4f3ea2d`) concerns the different
full-recovery prefix boundary. Its residual is
`Q2(X_T) - M21 Q1(Y)`, where the T-port X term is indispensable.
The exact 104-branch bound applies to parallel sums of constant rational
8-by-8 channel matrices times one shared owner permutation per branch.
It is not a native-call, scalar-operation, movement or storage lower bound.
Sequential reuse, different native kernels and other alphabets require
separate accounting.

PR4030 (`12df564caa8918453de658fe49601de6a9227017`, proof Git blob
`3ed514dee41b4ab79d459927c4816750cb58ab9a`) fixes those 104 owner routes,
the F16 output query frame and separate normalization of each branch. It
allows arbitrary common input quadratic frames, including plane mixing,
and prescribes the optimistic rank-k phase-normalizer tariff `k^(1-a)`.
For positive integer lambda and `0 <= a <= 10/13`, its sharp formal
normalization-only envelope is `104 lambda^(1-a)`. Every nonzero common
polar perturbation costs more in that class. It explicitly grants other
nonnegative obligations free only for that lower-bound screen.

Neither result automatically applies to a changed producer-pair factor.
A claimed application must identify the same operator, owner decomposition,
input/output frames, separately normalized branch contract and tariff.
Changing one of those hypotheses is a new construction obligation, not a
contradiction of either predecessor. Conversely, a rank-eight formal query
factor does not supply a paid native implementation.

## Baseline credit is granted once

Relative to the two selected source words, the QQ16 pair proposes replacing
sixteen rank-eight centre calls by thirty-two rank-one line calls. Its
literal scalar allowance increases by 28,616 real primitives. It also
introduces 528 explicit owner maps and 64 native line wrapper maps.
The native call count increases by 16 while the sum of child ranks falls
by 96. Neither count alone specifies a recursive tariff.

Only after endpoint compatibility and comparable tariffs are established
may a complete positive saving be screened by

```
16 C8 > 32 C1 + 28,616 S
        + repair + conversion + retention + restoration
        + allocation + movement + precision + control.
```

C8/C1 denote common-unit tariffs for the removed and introduced children;
S denotes the scalar real-primitive tariff. Wrappers must be included
exactly once in child tariffs or priced separately. Explicit owner maps
require a tariff too. No numerical cap is substituted for the unknown
right-hand terms. Any repair invoice is added to this same baseline:
the sixteen removed centres cannot be credited a second time.

If a production recursive model establishes moment weights for exactly
these calls and supplies actual replacement incidence, its moment change
can then be evaluated. The incumbent fixed-usage moment is not imposed on
a different unproved incidence. The PR3976 proposed invocation fraction
and 553 allowance are not available budget. No current kappa or global
multiplication bound follows from this local screen.

## Required query and workspace contract

The repair must read queries of the *current* QQ16 outputs, or explicitly
retain earlier queries through a paid lifetime. Reusing the same symbol
for an original query and a newly measured current query does not prove
their equality. Forming, routing, normalizing and consuming each query
must be listed in its word.

At the pair boundary the selected and QQ16 local words return their
borrowed helpers and clear their private streams. Those eight private
streams do not constitute free persistent query storage across native
calls. A borrowed arbitrary helper cannot be cleared to initialize a
clean query. Dirty borrowing needs a reversible protocol and its exact
restoration. Owned scratch needs allocation, live-range and terminal
contracts. The #4015 decoder's 224 owned outputs are not automatically
available source fields or scratch.

Any final receipt must distinguish: exact operator equality, native frame
and owner legality, literal local counts, scratch ownership/restoration,
physical movement, recursive precision, and actual outer incidence.
Unknown terms remain unknown, even when the finite factor identity passes.

## Conditional screen for the generic common-frame construction

The source bindings distinguish a model assumption from the finite arithmetic.
The gauge44 canonical word lists eight centre frames, each with eight axes.
Each of the sixteen removed calls binds to an actual rank-eight Clifford
child between frame zero and that centre frame, in the listed direction. The QQ16 line recipes use the
normalized rank-one Cq convention in the pinned bridge operator review.
Thus the relevant rank indices are those of the actual phase children,
not the rank of a data-map discrepancy.

Suppose these actual calls have comparable lifted native-moment tariffs
`C_r(lambda)=K(lambda)*(r*lambda)^(1-a)`, with `K(lambda)>0` and `0<=a<=1`.
Then `C8/C1=8^(1-a)<=8`. All unchanged native children cancel in the
same-boundary comparison. The sixteen removed H8 calls therefore credit
at most 128 H1 units, while QQ16 already adds 32 H1 units. There is at most
96 H1 units left for **all** repair native work, even if every other cost
is granted free.

The explicit generic construction which promotes every one of the 112 Y
hole fields to the common F17 frame already uses 112 H1 calls on ingress.
Its native moment is therefore at least 16 H1 units above the selected
pair before query formation or output restoration. Promoting and restoring
all 112 fields uses 224 H1 calls, giving an excess of at least 128 H1 units.
These differences are derived from the literal port and source-child
counts. They do not require the proposed PR3976 invocation fraction:
under the stated tariff they hold pointwise at each lambda, so any positive
incidence of this replacement preserves the excess.

The rank tariff and its production recursive lift correspondence remain
explicit premises. This is a rejection of that generic normalization
route in that native-moment model. It is not an arbitrary physical-cost
bound, a bound on every realization of the query factor, or a claim that
104 normalizers from PR4030 apply to this new repair.

## Literal candidate arithmetic and owned lifetimes

The current candidate word contains 6,216 events: 6,112 logical routed
ADDs and 104 CLEARs. Its coefficients occur as 1,760 signed units,
4,320 signed quarters and 32 signed eleven-quarters. Under the stated
scalar compiler this costs 66,832 real primitives, including all CLEARs.
Together with the unrepaired QQ16 pair's scalar increment, this is
95,448 additional scalar primitives before native conversion, physical
address work or precision costs. This is a literal arithmetic allowance,
not a complete executable native cost.

There are 4,736 nonidentity-owner routed reads and 1,376 identity-owner
reads, using 329 distinct owner matrices. These counts are not numbers
of physical map calls. An `add_view` describes a logical source view;
its paid realization must supply legal source and target frames, payload
translations, source preservation, and access/movement costs.

Five eight-field query records use 32 owned fields because the n and c
records explicitly reuse the same eight slots after CLEAR. One additional
owned field carries selected-output deltas, giving 33 declared owned
cover fields. The independent audit checks initialization before use,
CLEAR confined to declared owned fields, zero terminal values, no
borrowed-helper or pair-1 access, and no writes to ordinary current X.
The 33-field requirement is an allocation contract; this audit does not
find those fields in the selected physical stock or price their lifetime.

An independent one-source owner-ring check also tests the critical query
availability premise. It replays the literal F0 word and B1 prefix for
arbitrary owner-dependent X at port 0 and constant payload, reconstructs
all 112 stage-1 owner maps directly from the phase source, and verifies
`f=ell0,T P1,T (R1 Y_current)`. Replacing that expression by the current
query `a=R1 Y_current` fails. This check imports no primary verifier; its
scope is this critical availability identity, not a second full-column
factor proof or a native implementation of query acquisition.

The generic normalization screen grants correctness and all additional
conversions free when rejecting that route under its stated native tariff.
It does not claim that all 112 ingress calls are unavoidable for every
repair, or that the remaining routed ADDs are already legal native gates.
