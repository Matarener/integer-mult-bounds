# Validation and scope

The mathematical claim is the written uniform half-call rank bound in PROOF.md
and its computer-assisted exact nine-call consequence. The replay checks the
proof's algebra and its finite premise, rather than inferring a uniform theorem
from random words.

## Scientific checks

- All 64 Q8 products respect the explicit quotient map. All 125 basis triples
  satisfy associativity. Negative i/j images have the stated central coefficient.
- All 530 diagonal-one Gram/label words through three calls and 480 fixed-seed
  words at lengths four through nine match the chronological coefficient against
  full formal Hamilton action. Binary products and ranks have separate dot-product
  and span implementations. Every sampled zero obstruction satisfies the rank bound.
- All eight ordered direct nine-call target lists pass. Five physical roles
  retain two arbitrary dirty spectators. All 72 one-call deletions fail. The
  faithful regular action checks all 320 input-group columns across those targets.
- Only the inherited three-role exclusion through seven calls and its positive
  query are replayed. The unchanged PR3471 implementation and a new independent
  Hamilton implementation agree on both entire 91,955-state balls. Both complete
  5,241,435-candidate queries have zero hits for both negative shapes. The original
  positive query has nonzero hits. No unrelated four-role census is rerun.

The native build enables C++20, O3, Wall, Wextra, Wpedantic, Werror, Wconversion
and Wshadow. Python runs with warnings as errors and the controls also run under
optimization. This is exact binary/group arithmetic, with no floating point,
probabilistic exclusion or solver dependency. The fixed seed only chooses
additional generic identity checks; it does not drive the complete finite query.

quotient multiplication, corrupt the Hamilton j action, falsify rank, and change
the actual retained native update on owned temporary byte copies. Each fails its
observable source/identity/finite check. Invalid labels, booleans, dimensions and

receipt after complete scientific replay. The real CLI refuses an existing output
receipt before computation and preserves its bytes. Required controls use normal
exceptions and unittest checks, so Python optimization cannot disable them.

## Engineering constraints

Build the Lever determined the retained reproducible verifier and independent
finite query. Prove It Works determined full candidate membership replay and
actual native mutation rather than a result-only comparison. Separate Before
Serializing Shared State determined the private package, external run directory,
exclusive worker lock and short shared Git/reservation locks.

All new functions are below sixty physical lines. There is no recursion. Primary
call inputs are capped at twelve; exhaustive Gram controls stop at three and
sampled words at nine. The independent finite engine has exactly three roles,
fifty-six factors and three ball levels. A ball has at most
`1+56+56^2+56^3=178809` states before any measured deduplication. The full query
has at most `178809*57` candidate occurrences and two membership targets. Rank
spans have at most 512 members in the generic controls. Physical controls have
five roles and nine calls. Native compilation and execution have 120/180-second
timeouts; the registered scientific/control commands have 600/120-second caps.
Every subprocess exit is checked. Temporary resources use context-managed
lifetimes, including failure paths. No interpreter/source mode is changed.

Power of Ten rule 3 deviation applies to the new Python verifier/oracle and the
retained standard-library/native search. Python and hash sets allocate during
work, so fixed-pool allocation would require replacing the managed runtime and
search implementation. The finite bounds above limit live states, width and
process count; the retained native role/depth checks remain active. Repeatable
success and the actual mutation/CLI failure controls exercise cleanup. A future
expanded domain must supply a new capacity bound before it is admitted.

Rules 8/9 deviations apply to unittest.mock's three bounded module-function
substitutions and two constant substitutions, restored by context managers, and
the native driver's one textual include/main rename. The include preserves exact
frozen source while exposing the two explicit scoped queries. It introduces no
runtime target choice or new symbol lookup. The native producer mutation uses
owned exclusive regular byte copies and the same strict compiler settings.

The CLI validates receipt collisions before work. Source files are trusted,
committed package inputs; source hashes authenticate their exact bytes. Metadata
validation, publication-byte/source-history checking and Git-free scientific and
control runs are separate required checks. A passing transport/hash check alone
is not mathematical acceptance.
