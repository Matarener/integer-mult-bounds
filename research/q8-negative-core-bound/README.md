# Negative Q8 endpoints have a half-call scalar core

For a word of n positive i/j rank-one Q8 calls ending in negative generators
zi/zj and restored identities, its simultaneous scalar core has at most
floor(n/2) roles. This written all-finite-workspace theorem follows from a
sign-sensitive degree-two coefficient. The call Gram matrix obeys
`A(I+H)A=0` with H strictly triangular.

For exactly three negative targets, a hypothetical word below nine calls
must have seven calls and exactly three core roles. The retained PR3471
three-role exclusion then proves the exact minimum is nine, even with any
finite restored dirty workspace. This closes the seven-call question in
PR3517/PR3525. The direct construction attains nine.

writable directory. The verifier creates and removes its own native executable
and ball dumps there. From the repository root:

```sh
python3.12 -Werror -B scripts/research_package.py --package research/q8-negative-core-bound
python3.12 -B scripts/check_research_commit.py --package research/q8-negative-core-bound --check-source-history
```

The following actual scientific/control commands also run in a Git-free source
export with no dependency installation:

```sh
python3.12 -I -Werror -B research/q8-negative-core-bound/verify.py
python3.12 -I -O -Werror -B research/q8-negative-core-bound/test_package.py
```
