# Shorter G20 words across independent operations

The exact PR5807 word loses another **75 ADDs per call**, or **1,350 over
18 calls**. Its local ADD count falls11,579 to11,504. The positive scalar
majorant falls2,653,582 to2,625,858; both need22 bits. All2,846 paid queries,
48 owned fields, public endpoints and exact queried values are unchanged.
The full emitted word is in WORD.json.gz.

A simple commuting-cancellation screen saved only two ADDs. The complete
construction instead uses dependency projections and exact four-role
synthesis. It makes68 strict replacements in five rounds, then reaches a
fixed point for the declared scan. The retained finite-context primitive
count falls952838305581 to952838302881 under the same two-primitive ADD
charge. The old global event-index and compiler hashes are not recompiled.

## Dependency projection

Start from each ADD and grow its interacting role set. A gate that touches
the set must be included. When a new role enters, close the entire earlier
interval again. Stop at a fifth role, a native/reset event on an active role,
or a different active scalar frame. Operations on disjoint roles can stay
in the interval. Project all included ADDs to their two-to-four active roles.

The frozen PR5793 engine gives the exact shortest word for that matrix on
arbitrary dirty role inputs. Its complete GL(2,2), GL(3,2), GL(4,2) distance
certificates have6,168 and20,160 states. The source checker independently
executes the replacement on all2^n Boolean assignments. Every skipped event
is disjoint from the active roles, so the selected word can move to the
front of its interval without changing the computation. The new word uses
the same scalar frame and introduces no field.

A second pass uses A A=I and A B A=B C for elementary transvections when
exactly one of the two directed incidences is shared. It can cross gates
that commute with A and native/reset events on disjoint operands. Reverse
transvections are excluded. Each three-role identity gets a complete truth
table check. Alternate both passes until neither finds an improvement.
The descent is finite because every rewrite removes an ADD. The fixed point
is for this precise closure/scan grammar, not every four-role subset or a
global minimum circuit.

## Exact native boundary

Commuting scalar work can change an unrelated field's intermediate snapshot
at a native event. A whole-array hash at every event would reject valid
commutation. Instead, this verifier compares the operation descriptor and
complete RAW value of the actual queried or reset field at every non-ADD
event. Those observations agree exactly, in order, with the frozen source.
This includes every Q, ZERO_Q, INIT and ERASE. The admitted native maps and
phases are therefore used on the same values. No sampled-zero argument is
used; all685 independent input axes are encoded in the exact binary rows.

Complete forward and reverse checks also prove every final public and dirty
owned endpoint. Actual frame checks run on the emitted word. The paid
profile and owned reserve remain fixed, and the positive scalar majorant
is recomputed. Controls reject crossing a dependent native query and a
changed query owner. The source native proof, full caller and primitive
tariffs remain dependencies; they are not newly admitted by this package.

## Reproduction and limits

```sh
python3.12 -B scripts/research_package.py --package research/g20-trace-resynthesis
```

Python3.12 and its standard library suffice. The registered normal and
optimized commands authenticate source and tool bytes, rebuild all edits
and the word, and compare complete receipts. EDITS.json gives each current
interval, selected instructions and replacement. The direct verifier is
Git-free. Frozen predecessor bytes are unchanged.

This is a constructive finite-cost improvement. It does not improve the
recursive paid profile, supply a physical ROW/tape implementation, or prove
a new kappa. All five framework assumptions and the selected frontier remain.
The complete source's global event ledger must be rebuilt before a new
compiler artifact can use the shorter local word.

## Open next questions

Can dependent query payloads in an actual source query block share a native
call? Start from the emitted word and its exact RAW rows. A useful result
must emit both reversible pre/post basis changes and legal zero-frame moves,
then prove all arbitrary-input endpoints and charge each new operation.
The dependency-free scalar scan here does not answer that question.
