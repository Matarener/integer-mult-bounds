# A sharp fifth-root threshold for two tensor tests

This scoped analytical proof gives the exact dimension-independent recovery
error for unitary charts whose tensor squares and cubes are both within
operator-norm error epsilon of a reference. It was produced by Nick Petalas.

Set a=arcsin(epsilon/2) and epsilon_*=sqrt((5-sqrt(5))/2). For any
unitaries A,B of the same positive finite dimension,

    max(||A^(tensor 2)-B^(tensor 2)||,
        ||A^(tensor 3)-B^(tensor 3)||) <= epsilon

implies the sharp bound

    ||A-B|| <= 2 sin(a/3)           for epsilon < epsilon_*,
              2 sin(pi/3 + a/3)    for epsilon >= epsilon_*.

Every value is attained by scalar phases. At equality epsilon=epsilon_*,
the phase exp(4pi i/5) gives error sqrt((5+sqrt(5))/2). The small-error
branch has left limit 2 sin(pi/15), so the sharp envelope jumps at this
threshold. [PROOF.md](PROOF.md) proves all dimensions and all epsilon in
[0,2]. The exact threshold and jump witness are checked in Q(sqrt(5)).

This answers a quantitative version of the finite-width phase boundary
raised in unpaidmoon's [PR #5837](https://github.com/CrocSwap/integer-mult-bounds/pull/5837).
It is an original repository application of elementary spectral theory
and trigonometry, with no general literature-priority claim. It does not
audit the predecessor's scalar lift or selected MOVE coverage.

## Limits and relation to current work

The hypotheses require one fixed pair of exact unitary charts, honest
operator norms, and absolute phase. They do not cover projective comparisons,
nonunitary maps or independently perturbed tensor factors. Approximate finite
tests alone do not bound every later tensor width by the same small error.

## Implementation limits

The fixed verifier uses no recursion, subprocess, network or dynamic code.
Rational phases use numerators -24..24 and denominators 1..24; there are
at most 1,177 phase fixtures before deduplication. Bisections take 88 or
96 steps, and reject declared precision outside 16..128. Matrix dimensions
never exceed eight. Every loop has a fixed finite fixture or collection
bound, and functions stay below 60 lines. Explicit guards remain enabled
under optimization. Warning-strict normal and optimized Python are the
interpreted-code diagnostics. CPython/Fraction dynamic allocation is a
Power of Ten deviation; fixed input and matrix bounds constrain live memory.
The receipt writer owns one exclusive-create file and closes it on every exit.
