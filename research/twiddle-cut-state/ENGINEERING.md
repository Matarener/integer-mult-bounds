# Engineering decisions and limits

The measurable predicate is equality of the exact number of complete suffix functions with the closed formula at every fixture, plus literal modular-sum equality and intended optimized CLI rejections. The universal statement is the separate written proof.

Build the Lever changed the deliverable from a hand-counted example into a rerunnable residual-function and interval verifier. Prove It Works requires actual final committed bytes, registered CPython 3.12 and Git-free scientific/control replay. Separate Before Serializing Shared State gives this worker its own package, branch, outputs and process-held ownership locks, with short shared Git/reservation locks. No extra threads or subagents are used.

Power of Ten review covers states.py, checks.py, verify.py and test_controls.py.

1. Control flow has no recursion or call cycles. Exceptions propagate to CLI failure. The control fixture uses scoped cleanup and restores each injected mutation before proceeding.
2. Formula loops have at most 257 terms. Integers have at most 513 significant bits from d,h<=256. Physical fixtures use ell<=6, at most three axes, at most twelve address bits and at most 4096 address evaluations per case. Interval fixtures have h<=7, active<=12, at most 128 allowed terms and at most 256 residues. Wide cases have d<=64,h<=256. At most eight failing CLI probes and one valid probe each have a 90-second timeout; registered jobs have a 120-second limit.
3. Python allocates integers, sets, tuples and subprocess buffers during operation. This is a managed-runtime deviation, not fixed-capacity steady-state allocation. Bounds above cap the largest full truth-vector collection at 4096 entries per fixture, plus 600 compact report rows. Input source files are individually capped at 256 KiB. The verifier is not a production tape program. Follow-up is a separately bounded physical producer with its own capacity proof.
4. Each authored function is below sixty physical lines. Functions separate formula, physical oracle, interval oracle, CLI/source boundaries and owned-copy controls.
5. Contracts use ValueError rather than Python assert, so optimized execution preserves them. They check actual formula/physical/interval equality, source bytes, malformed domains, output receipt and intended fault diagnostics. Removing these checks changes observed CLI success.
6. Formula state is local. The only module state is immutable package paths and one authenticated imported layout module. The controls own every byte in their private fixture and restore mutations before its scoped deletion.
7. Byte-copy writes, subprocess exit codes, arguments, timeouts and hashes are checked. A failed final probe fails the whole control command. Diagnostic output is retained on unexpected failure.
8. Authenticated source loading uses compile/exec for one exact, hash-checked canonical circuit.py, avoiding bytecode-cache reads. This deviates from the metaprogramming restriction to execute a retained independent oracle outside Git without cache substitution. Its three fixed input paths, source-size bound, SHA256 equality and source-presence/corruption controls constrain it. Follow-up is a dedicated frozen data-only layout fixture if the source oracle contract changes.
9. Ordinary Python dispatch and iterators are runtime mechanisms. Calls are direct within the four authored files, except the one fixed authenticated named_slots target. This deviation has one bounded external target, immutable for a replay. No callback chains, hidden registry or production pointer claim is introduced.
10. Validation uses CPython 3.12 with -Werror, normal and optimized science, actual optimized subprocess controls, scoped Ruff E4/E7/E9/F, AST function-size inspection, repository metadata/pins, committed bytes/source history and Git whitespace checks. The registered hook repeats science and controls. It does not run Ruff or prove the theorem on hosted CI; maximum compiler diagnostics and a static Python type proof are not supplied.

The framework/library implementations of Python arithmetic, hashing, dataclasses, tempfile and subprocess are trusted runtime dependencies, not formally analyzed memory-allocation or timing primitives. The bounds are resource/admission checks for a finite verifier, not a physical supplier invoice.

No complete caller costs are inferred. The result supplies an information lower bound, not an upper-cost implementation. Descriptor construction, transition encoding, address production, dirty-state/restoration, signed packet/layer composition and complete supplier/outer contracts remain unknown here. This is one bounded obstruction result, not an expansion into another dependent construction round.
