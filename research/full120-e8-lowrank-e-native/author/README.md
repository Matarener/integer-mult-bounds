## Reproduce

Use Python3.10 or newer and the standard library only. All runtime inputs
are local to this package. From this directory run:

```
python3 -I -B e_adapter.py
python3 -I -B owned_e.py
python3 -I -B n3.py
python3 -I -B backward512.py
python3 -I -B checkpoint120.py --mode base120
python3 -I -B checkpoint120.py --mode root512
python3 -I -B modes120.py
python3 -I -B macros120.py
python3 -I -B precision120.py
```

Repeat with `-O` to verify that no scientific check relies on Python
assertions. The default commands compare exact recomputation with retained
receipts and do not rewrite science. `replay.py --write` runs both modes and
records command/output hashes in `REPLAY.json`; it writes transient logs to
a new directory outside the packet. `FILES.sha256` seals the payload.
