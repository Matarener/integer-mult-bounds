# Helper feedback after 112 early native queries

This construction permits helper-to-helper feedback after the original complex
FULL has exposed 112 early common-Q responses. It updates each helper argument,
its held raw query result, and its normalized observation before the native word
resumes. All eight original center calls remain. No extra Gaussian call is
needed for a feedback shear.

This is a forward interface, not a complete caller or a kappa improvement.
After feedback, helper outputs are Gaussian transforms of changed independent
coordinates. They are not yet autonomous Gaussian jobs on the original inputs.
A caller must remove or consume that code and pay for the full construction.

[PROOF.md](PROOF.md) gives the exact contract and the ordered patch.
[RESULT.json](RESULT.json) records the source-bound replay and seven rejected
mutations. [SOURCES.json](SOURCES.json) pins every imported source and the
historical catalogue and selected record. All live source files are already
on canonical main; no pending Git object or network is required for replay.

## Result and local bill

For distinct selected coordinates h and k, the interface implements
`xi_k <- xi_k + Q xi_h`. It supports a finite sequence of these shears,
including reuse of a prior source or destination. The preserved invariant is
`w_j=K_j xi_j`, `raw_j=E_j K_j xi_j`, `obs_j=Q xi_j`.
Each shear uses two COPY, three ADD, three monomial field maps and three CLEAR,
with one reused owned scratch field. These are counted operations, not free
machine work. The proof applies to every allowed positive fiber width under
the inherited native and Clifford lifting conventions.

The source and charged helper-return completion have paid profile
`{1:2207,2:412,3:510,4:127,5:66,8:8}`. The 358 cold outputs are full H9 transforms
of the feedback coordinates; the 50 other helper jobs retain profile
`{4:2,7:7,8:41}`. All 408 helper directions remain independent, and none is erased.
Their original target rank mass and the paid rank mass both rise by 136 during
completion. The completion alone is a strict concave-moment loss; the saved
invoice preflight checks this before any feedback and does not claim a caller.

The hoisted bank uses 224 added owned fields, 224 COPY, 448 CLEAR and 112
whole-field/chart swaps. Its fixed basis work is 6,420 ADD and 408 SCALE, with
at most 400 monomial field maps including completion wrappers. A nonempty
feedback sequence adds one owned scratch field and the per-shear work above.
The native word and its original owned center field remain additional.
The five-shear receipt checks all 632 original and 226 arbitrary owned inputs.

## Reproduce

Python 3.12 or later and the standard library suffice. From the repository root:

```sh
python3 -B scripts/research_package.py --package research/original-helper-query-feedback
python3 -I -O -B research/original-helper-query-feedback/verify.py
```

Expected token: `PASS_UNCODED_FORWARD_EARLY_QUERY_FEEDBACK`.
The default verifier is read-only. `--emit` writes `RESULT.json` for authors.
It authenticates live bytes before importing source, ignores bytecode caches,
and compiles the inherited scientific modules with assertions active in both
wrapper modes. The registered runner also gives each command a private cache.
[VALIDATION.md](VALIDATION.md) records actual execution and omitted checks.

The replay includes the original native word, all eight centers, all 358 first
departures, all 112 replacements, the empty-sequence control, five overlapping
feedback shears, all helper returns, all owned clears, 112 physical query
identities and 32 charged completion identities. It rejects a stale raw result,
a stale observation, a missing Q factor, wrong chart transport, dirty scratch,
live scratch at exit, and an omitted completion.

The predecessor physical adapters and all-width native implementation remain
inherited. No backward interface, flat physical compiler, uniform precision
bill, full caller, supplier admission or selected cold replay is supplied.

## Open next questions

A useful next step is one complete caller with a terminal decoder for the
Q-dependent helper code and a complete paid/target invoice. A separate backward
interface needs its own source chronology and exact phases. Only after caller
closure can its ordinary work, storage and precision be priced. The exact
questions, first steps and blockers are in [TASK.json](TASK.json).
