# Native transport and the helper-300 successor boundary

**A scoped construction and cost decision; no improved κ.** A successor born at
helper 300's first line frame gives an exact 21-input local replacement with the
same **38 H1** invoice. It restores the independent value at the local cut,
however, and does not yet establish a productive split of the original helper.
We identify the missing input/output boundary equation and test two ways of
supplying it. Neither gives a funded selected-source replacement.

This is the explicitly assigned continuation after the eight- and twenty-field
fixed-boundary floors. It changes the transport or productive-input premise,
rather than enlarging the old monotone census. Scientific sources come from main
`32890bc5de034ab8fc93ac88ead7279a6a416d04`, priority revision 7; the selected
conditional κ remains `605457647/200000000000`.

## Results

- **Native transport:** an exact rank-zero warp between the source lines
  `<273>` and `<324>` changes the logical operator. Preserving the value instead
  needs a rank-two transform. An explicit one-way correction attains **one H2**
  plus two monomial adapters, with full tableau and absolute phase checked.
  A two-input argument rules out creating an isolated clean cancellation
  contact using only free monomial adapters on distinct frames.
- **Plane-frame successor:** the declared helper-300 handoff at frame 430 is
  impossible under monotone scalar transport. Its arbitrary input must reach
  outputs 299 and 301 at frame 419, which does not contain its birth plane.
- **Line-frame successor:** birth and retirement at frame 21 admit a literal
  local construction at **38 H1**. Retiring the old helper at plane 430 instead
  duplicates a paid ascent and costs **39 H1**. The checker verifies every
  coefficient of the 21-input endpoint identity.
- **Actual source boundary:** the cut value is the original helper plus 16
  original main-input terms. The original helper input also has nonzero
  coefficients in 11 other roles, including external role 505 at frame zero.
  Thus a local rename does not establish the required full-source endpoint.
  Input rebasing is a legitimate possibility. A specified same-label exit shear
  has sixteen rank-seven coefficients; it is neither free nor a certificate of
  the actual inverse through the main transform. The admitted output decoder
  and caller remain unconstructed.
- **Exact budget:** the maximal retained-endpoint regrouping allowance is
  `0.07703787664069600…` per LOCAL. Even granting the largest single rank-nine
  productive split adds only `0.01861244404255384…`. One extra H1 per LOCAL
  loses. One H2 charged only once globally exceeds all eighteen combined
  allowances. A once-global H1 is **not** excluded by this optimistic arithmetic.

The line-frame construction is an instance of the entrance-pure successor pattern
already identified in [GamingPuzzled's PR5472](https://github.com/CrocSwap/integer-mult-bounds/pull/5472),
head `ce96fe9747ea0643bd8c30d448c1ba8e2b30ac30`. Its novelty is not claimed here.
Our contribution is the named source interface, exact native repair, and complete
conditional cost comparison. That pending PR's gadget and whole-word screens
are neither copied nor rerun as evidence for this package.

## Proof and reproduction

Read [NATIVE.md](NATIVE.md) for the operator obstruction and exact correction,
[BOUNDARY.md](BOUNDARY.md) for the nominated local identity and source coupling,
and [BUDGET.md](BUDGET.md) for the signed invoice and directed rational bounds.
The pricing exponent is `t = 1 - 605457649/200000000000`, using the selected
supplier's tested saving rather than substituting its final κ.

From the repository root with Python 3.12 and no third-party dependencies:

```sh
python3.12 -B scripts/research_package.py --package research/helper-transport-contract
```

The three separately authored checks are also portable to a source export:

```sh
python3.12 -I -B research/helper-transport-contract/verify.py --repo .
python3.12 -I -B research/helper-transport-contract/check_split_boundary.py --repo .
python3.12 -I -B research/helper-transport-contract/verify_budget.py --repo .
```

Repeat with `-O` for the optimized controls. Source pins are checked before
imports; all new proof checks use explicit exceptions. The registered runner
isolates Python's bytecode cache. Direct replay should likewise use a clean
export or an empty `-X pycache_prefix` directory. Imported historical compiler
assertions are not a substitute for the explicit rank, tableau, phase and
endpoint comparisons in these checks.

These checks do not replay the complete native provider, physical compiler,
owned relations or selected caller. There is no new full multiplication theorem,
general Clifford floor, or impossibility result for coordinated changed words.
Neither a mixed cut value nor a failed isolated decoder excludes a different
input/output basis with a proved admission contract.

On CPython 3.12.14 / macOS arm64, all six registered commands pass. Normal and
optimized JSON outputs also agree in a read-only source export with Git absent
from PATH. All exported payloads remain byte-identical. Three changed-provider
controls fail at source authentication, and an altered compiler is rejected
before import. The scientific checks include six boundary mutations, four
accounting mutations, and phase/wrong-repair controls in both native fixtures.
Committed-byte, source-history and official export-integrity checks pass.

## Open next questions

1. **Can a coordinated producer and decoder realize the line-frame split using
   existing paid work?** First supply exact entrance and exit maps satisfying
   `E_out W_new E_in = D_new` for the complete independent target operator,
   including the external role 505 and every arbitrary successor column.
   A local rename alone does not supply those maps. An extra paid job needs
   compensating savings beyond a single productive split.
2. **Can one transport genuinely be shared across the eighteen LOCALs?** The
   optimistic allowance can pay one global H1 arithmetically. First identify the
   actual common boundary and independent information carried; a single-field
   price does not certify transport of eighteen unrelated fields.

The bounded session stops at these discriminating results. A further construction
round needs one explicit passing source/cost contract; a larger fixed-word census
or a new unpriced consumer is not the next step. Structured questions and the
