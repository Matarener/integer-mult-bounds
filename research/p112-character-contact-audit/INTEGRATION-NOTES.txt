Source/receipt binding integration; not another all-phase oracle

The verifier authenticates the immutable PR4204 geometry container, final
independent phase checker and receipt, and separately frozen free-group
oracle and receipt. No primary or predecessor checker is imported or run.
The primary code/receipt were updated to their final17:10:20 freeze before
the successful binding replay; the initial earlier-code pin correctly
rejected the changed bytes. Registered defaults use PHASE-RESULT.json,
independent_oracle.py, ORACLE-RESULT.json and the source export filename.

Independent bounded checks read every ordered plus-one recipe in the
provided5824-edge geometry and its exact operation skeleton. The source
case counts are104/2912/2808 at contact ranks1/2/3. Native occurrence counts,
signed ADD counts, typed field/role order, per-edge histograms and rank
masses match source metadata and primary aggregate totals. All8880 phase
descriptor records have checked alphabet/digest-name/schema, symmetric
binary polar, Z4 diagonal/linear compatibility and binary rank. Rank is
computed with set-span growth, rather than the primary pivot algorithm.
The union of serialized phase IDs/native phase hashes is independently
counted, with the unused auxiliary identity distinguished.

This does not reconstruct8880 complete character phase arrays again.
It compares inventory length to the primary's reconstructed-record count;
that matching count does not promote this metadata check into an independent
phase reconstruction. The total edge/character/sign/raw-column counts are
arithmetic bindings of the source domain to the authenticated primary
receipt. Primary cache sizes and actual all-character values remain primary
replay evidence. Four stored primary mutation witnesses are metadata-checked,
not independently reevaluated against the full phase arrays here.

Copied corruption controls reject a changed primary aggregate, reordered
typed operation, wrong polar rank, and changed immutable source checksum.
Normal and strict optimized executions produce identical output receipts;
default invocations write no files. Package-root and explicit file overrides
serve portable staging; no private paths enter the receipt.

Universal versus finite boundary: the free-group oracle and written proof
establish the abstract noncommuting dirty-helper identity under invertible
frame maps and central sign+/-1, with P=Q needed in the direct case. The
primary phase checker separately binds the provided finite source frames,
Z4 phases, recipe order and all raw columns/characters. This integration
only connects their authenticated bytes and finite metadata. A source
physical_helper_return flag is metadata, not execution of a native ABI.

No original P112 port reconstruction, full source caller/circuit, native
compiler, B4/DP, tape invoice, precision/supplier/outer multiplication theorem
or new kappa is claimed. Rank/polar data alone cannot prove complete complex
phases, as the universal and primary phase controls explicitly demonstrate.
