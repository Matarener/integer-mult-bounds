## Power of Ten inspection

1. All production traversals are iterative. The fixed 1,080-line D7 orbit and
   30,240-pair orbit have explicit bounds and fail on early termination or excess.
   Helpers have direct calls and structured exceptions; no recursion exists.
2. At most 1,200 lines, 120 roots, 240 signed roots, 8 reflections, 28 minors,
   757 root pencils with at most three non-a members and 360 retained candidates
   enter the production geometry. The fifth pass has at most 432,000 line tests.
   The independent incidence DP uses 15 small-union sizes, at most 112 positions,
   161 budgets and at most nine transitions. CLI controls have 60-second timeouts.
3. Rule 3 deviation. Python/Fraction and container operations allocate during the
   checks. Exact arithmetic and the Python runtime prevent a no-allocation steady
   phase. The finite domains above bound live collections; JSON and source files
   are capped at 512 KiB. The largest persistent orbit has 30,240 pairs. No solver,
   network or subprocess is used in either mathematical enumeration. Follow up
   only if a future larger domain requires a separately budgeted implementation.
4. Each mathematical helper has one responsibility. Function lengths are inspected
   after formatting. The single CLI-control method owns its temporary directory,
   copies and subprocess checks and is kept cohesive rather than split into
   forwarding wrappers.
5. All proof gates use explicit exceptions, including under Python -O. The eight
   test groups exercise success, changed source, linked source, changed inherited
   proof, false receipt and boundary failures. No acceptance depends on assert.
6. Candidate sets, counters and input authority are local. Sources are read only.
   Only an explicit --write command replaces RESULT.json. Normal replay compares
   it and writes no package output. Temporary fixtures have scoped cleanup.
7. Every child return status and rejection diagnostic is checked. Missing files,
   wrong hashes, duplicate JSON keys, wrong inventories and failed orbit bounds
   propagate failures. Partial computation is never accepted as a negative result.
8. Rule 8 deviation. The primary compiles exactly one fixed pinned geometry file
   after checking its SHA256 and refusing linked path components. This avoids
   bytecode-cache substitution and executes the authenticated bytes. The S102
   suppression is confined to that call. There is no input-selected code path.
   The separate reconstruction imports no geometry code. Follow up if the upstream
   geometry acquires a data-only API; migrate then without changing the model.
9. Data access is shallow and calls are explicit. Rule 9 deviation. unittest
   performs standard bounded test-method dispatch over eight fixed groups. Its
   runner owns test lifetime; subprocesses are waited on with timeout. No runtime
   registration is used in mathematical code.
10. The registered validation runs Python with warnings as errors. Ruff checks and
    formatting cover all new Python. No repository-wide diagnostics are weakened.
    Rule 10 deviation. Python supplies no compiler-enforced static ownership or
    capacity proof. Exact finite bounds, explicit invariants and both production
    enumerations compensate within this standard-library package. Human and
    proof-kernel review remain open.
