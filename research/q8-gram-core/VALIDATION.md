# Verification contract

The executable cap is sixteen roles and sixteen calls. All loops range
over those bounded dimensions, eight group elements, or explicitly finite
fixture families. The circuit has a 200,000-node capacity and refuses
oversized inputs. No solver is part of registered replay. The CLI refuses
existing output files and caps requested solver timeouts at 600 seconds.

The replay independently checks full arbitrary dirty-input columns using
integer Hamilton multiplication and a regular Q8 action. It verifies the
quotient intertwines each ordered call and every coefficient of the whole
word. Every binary Gram matrix with diagonal one through three calls and
every i/j labeling is reconstructed. An independent enumeration of binary
eigenspaces at 1,zi,zj checks the endpoint criterion. An explicit row-span
enumeration checks the symbolic rank circuit for every binary matrix
through dimension three. Direct nine-call three-negative fixtures include
restored spectators. RESULT.json records the actual coverage counts.

Behavioral tests inject real core-producer, group-multiplication, independent
action and symbolic-endpoint faults. They also exercise invalid idempotents,
labels, dimensions, target counts, span membership, output collisions and
positive/negative short endpoint controls. Normal and optimized Python use
ordinary exceptions, so optimization does not remove scientific checks.

The generated SMT-LIB uses only fixed-width Boolean/bit-vector operations.
The concrete evaluator and exported syntax share a bounded operation list.
Finite evaluator agreement checks the equations, but is not an independent
SMT parser proof. External parser checks and bounded solver attempts are
separate session evidence; the seven-call export hashes are in RESULT.json.
The rank circuit performs Gaussian insertion with conditional pivots and
counts occupied pivots. No determinant approximation or floating point is
used. Every scientific integer in the receipt is small enough for exact
JSON transport; raw committed bytes and SHA256 remain authoritative.

## Power of Ten decisions

The code uses structured iteration and no recursive call path. Functions
stay within sixty physical lines. Boundary validation limits matrix shape,
row bits, gate labels, vectors and idempotence. Explicit postconditions check
rank factorization, Gram roundtrips, quotient equations and formal endpoints.
State belongs to one bounded word or circuit; replay has no shared writer.
File and write errors propagate. Source receipts bind all scientific code,
proof and retained predecessor bytes. No dynamic code evaluation or code
generation that is later imported occurs. SMT text is an exported artifact.

Rule 3 has a managed-Python deviation in all scientific modules. Python
allocates immutable integers, tuples and strings during bounded operations.
Live matrices have at most 256 entries, all ring coefficients fit eight bits,
and live circuits have at most 200,000 nodes. The finite verifier processes
one word or one matrix candidate at a time. Export text is bounded by that
node cap. Runtime/library allocation internals are not inspected. A native
fixed-capacity implementation would be a separate task if memory becomes
a measured limitation; no fixed-allocation claim is made here.

Rule 9 has a unittest-only dispatch deviation. Scoped mock boundaries
inject faults in named producer/arithmetic functions and restore them at
context exit. Production paths use direct module calls. Rule 10 uses
warnings-as-errors execution and scoped Ruff lint. No repository-wide type
or CI configuration is changed. The rank/eigenspace domains and direct
fixtures compensate for the absence of a proof assistant; they do not
substitute for independent human or proof-kernel review.

The selected full cold replay, Lean, physical caller, larger native census
and a solved seven-call exclusion are unrun or unclaimed. No changed
selected source is used. The original failed sparse baseline attempt and
both solver timeouts are preserved separately from corrected checks in
the session receipts.
