## Exact construction interface

An eligible incoming helper `h` is not touched by A, the zero-frame precondition,
the compensation, or the initial twisted corrections. It is not written before
its first B producer. Thus it carries its independent arbitrary input throughout
the proposed release interval.

Let `P` be the original B prefix immediately before that producer, and put

\[
 c=P e_h-e_h.
\]

Deleting every earlier read of `h` changes this prefix to
`P - c e_h^T`. All other input columns agree exactly. The suffix interpreter
computes operator-valued columns in the free algebra generated by the literal
warp events. A forward warp multiplies a column term on the left; pulling a
suffix backward multiplies on the right. Adjacent inverse symbols cancel, but
no extra commutation is assumed.

The protected projection contains all 112 Y ports and all 91 helpers whose
native endpoints are proper hyperplanes. At a proposed cut, the solver finds
dyadic releases `w = sum_r a_r e_r` satisfying

\[
 \pi S_{\mathrm{cut}}w=\pi S_{\mathrm{producer}}c.
\]

The literal new gates are `r += a_r h`. Since no other register feeds `h` before
the producer, the suffix column for a donor `r != h` is unchanged when the early
reads of `h` are deleted. The displayed equation therefore proves that all
protected outputs agree on the affected input column. Every other input column
already agrees.

The search constrains each release frame to contain the donor's current frame
and to be contained in its next native frame. It replays the complete monotone
frame chronology after mutation. This interval is essential: requiring donors
already to be at the release frame misses the known helper 544 positive control.

Two gate-deletion modes are explicit. The default replaces an old read by an
identity scale on its recipient, preserving that recipient's native climbs.
`--drop-reads` deletes it literally and shifts every affected warp index. A
geometry-only shadow omits the deleted contacts when ordering candidate donors;
this shadow is never emitted as a native word. Every accepted candidate's actual
frame bill is recomputed from its emitted word.
