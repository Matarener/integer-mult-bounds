## What was independently checked

### The specified 4^9 binary controls

The reviewer reconstructs the nine stages and all bridges directly from the
actual retained controller template. It applies the forward and backward
two-bank maps as row operations on eight-by-eight matrices, then visits all
262144 choices of the two per-stage bits: pre-Y D and post-X D.

This is a direct chronological enumeration using unbounded Python integers;
it imports none of the producer search's matrix or inverse functions and
does not use its meet-in-the-middle algorithm. The D=+1 control gives the
expected block signed exchange. No D=-1 choice gives that same exchange.
The result agrees with `control-search/CONTROLS.json`.

This excludes exactly the named controls for the retained common-involution
recipe. It does not exclude more general scalar controls, changes to the
bridge word, or other native interfaces.

### Protected release algebra and the five emitted HPE candidates

Source inspection confirms the order in `projected_release.py`:

* Backward suffix propagation appends native owner words on the right.
* Forward prefix propagation prepends them on the left.
* The target concatenates suffix then prefix, canceling only adjacent
  inverse symbols.
* The released helper is untouched by A and the initial corrections and
  is unchanged before its first B write. Retiming those reads therefore
  changes only that initial helper's column.

The review independently propagates that complete affected column through
B, the restore word, and the full cleanup word. It checks both the original
and each emitted candidate. The original column is restored exactly. Every
candidate restores the helper itself and has zero difference on all Y and
hyperplane-ended helper outputs, as well as all owned query buffers. The
remaining errors are recorded explicitly as FULL-bank dirt rows.

This verifies the protected algebra for the emitted hits. It does not turn
them into complete native consumers: an HPE helper cannot simply be read
at FULL for free, and the error still needs a compatible native repair.
The source discovery scan was interrupted; five hits are not a complete
classification of possible retimings. The per-helper search also deliberately
stops after finding a candidate.

The receipt pins the new generators, emitted candidate payloads, retained

### All 31 combined subsets, including shared donor 616

The final extension examines every nonempty subset of the five stated
retiming generators. The reviewer independently rebuilds the combined B word
and its shifted warp positions from each original provider source and the
published specifications; it imports none of `combine_releases.py`'s
composition code. It reconstructs **62 provider words** and checks their
canonical payload hashes against the combined census.

For every rebuilt word, the bound shared frame compiler recounts its actual
native path and helper width inventory. Both providers are explicitly checked
against the same census profile. This includes the nonadditive shared-donor
616 climbs when helpers 484 and 584 occur together. For every selected helper
in every subset and provider, independent ordered free-word propagation
checks its complete affected column: **160 columns** in total. The h556
extra-provider column is included. The expected two-donor dirt remains;
no complete native repair is asserted.

The reviewer binds each combined profile and both provider payloads to
`JOINT-PROFILE-SCREEN.json`. Starting from the retained positive baseline,
it independently composes each complete profile from the local tariff and
the reported joint owner-bin stock. In a bin with old remainder r and joint
selected-helper multiplicity k, the price contribution changes once from
r to r+k. The total multiplicity must be 3240 times the number of selected
helpers; all complete profiles preserve the full raw invoice.

All **31 exact target moments**, their differences from the actual baseline,
and their rational root brackets are verified with the authenticated
arithmetic engine. Every subset is strictly worse than the baseline and
fails the retained target even granting free completion. Physical owner-bin
stocks come from the separately authenticated joint census; the review does
not independently reload and replay each FILL row.

This closes the question of whether these five particular generators become
profitable merely by combining them and sharing their named donors. It does
not exclude other retiming generators, a change to the producer word, or a
different physical allocation.
