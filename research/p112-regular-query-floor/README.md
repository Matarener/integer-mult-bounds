# A sharp reader floor for projectively TU query dictionaries

Every exact finite recoding of a selected set of alternating Gram-I plane
indicators retains at least its original actual-reader bill if its complete
query coefficient matrix is a nonzero diagonal row and column scaling of an
integer totally unimodular matrix. The statement holds over every coefficient
field, for arbitrary target and query counts and arbitrary readers on all ports.
It applies to any finite even binary-orthonormal partition. The original terms
attain equality. On Tekalign's retained PR3370 P112 fixture, the whole-K floor
is 224. This is a scoped negative theorem and does not improve kappa.

The new implication in [PROOF.md](PROOF.md) transfers each active reader's
target-axis span request to F2 without enlarging any source or reader support.
The expanded identity then forces the tariff. Graph-difference and network
query dictionaries are included, even with arbitrary nonzero diagonal
rescalings. "Projectively TU" here always refers to the fixed target axes;
an unrestricted change of basis is outside the stated contract.

PR3463 covers arbitrary pair-span directions. PR3475 covers one literal
seven-ray triple dictionary with triple-span readers. This result covers
arbitrary target counts in a structural dictionary class, and permits global
readers that cancel outside the target support. Its determinant-two boundary
is outside the transfer theorem and remains covered only where a separate
argument applies. [COMPARISONS.json](COMPARISONS.json) records exact inspected
source heads, blobs, hashes, attribution and overlap distinctions. PR2111's earlier TU-signing lemma constrains the binary pairing matrix, while
this result constrains the target-query coefficient matrix. An eight-label
Gram-I4 example with a Fano contraction separates those hypotheses. These public
comparison proofs are not executable dependencies or publication-ancestry pins.

uses permutation determinants, integer-minor span and exhaustive XOR supports.
It reproduces the entire ordered span digest and every minor histogram.

Three exact literal P112 examples have nonzero diagonal row/column scalings,
rational readers outside the four target supports and genuine nonaxis target
representations. Each original and transferred binary operator agrees at all
12,544 entries; both implementations recompute every per-term actual-reader
bill. Each original example has 910 nonzero reader entries outside its targets,
whose contributions cancel. Both implementations check the expanded I224
identity at all 50,176 entries. The original 32 terms attain total tariff 224.

The three pair-sum columns on a triangle have determinant -2 and express an
axis with half-integral coefficients over Q. They cannot express that axis in
F2. This is an explicit failure of support transfer, not a cheaper decoder.
Behavioral controls reject that transfer, an omitted actual reader, invalid
capacities/field requests and six real optimized CLI corruptions, then verify
a restored positive replay. Contracts remain enabled under Python optimization.

## Limits and family decision

Narrow this search to changed contracts. A projectively TU query dictionary
inside the target span cannot save the stated additive support tariff. Any
next construction first needs an exact cheaper literal factorization outside
that class. No further dictionary census or native construction is reserved.

Arbitrary nonregular dictionaries, external query dimensions and shared
nonadditive native work are excluded. Query acquisition, scalar coefficients,
frames, dirty restoration, ownership, hosting, stock, precision, all-size
compiler obligations, complete suppliers and outer transfer remain separate.
The selected conditional kappa remains 0.001672660197076918. Independent human
and formal proof-kernel review are unclaimed. No Lean, Docker, hosted CI or
full selected cold replay was run.

## Engineering constraints

The new code is source-closed, uses exact arithmetic, has no recursion or
background process, and keeps functions below 60 physical lines. Finite
controls use at most four target axes, ten query columns, 112 scalar ports and
224 expanded coordinates. The theorem is not limited to those finite controls.
All verification contracts use explicit exceptions and survive optimization.
Ruff 0.17.1 checks E,F,I,B,UP,SIM,RUF,C4,PIE,PERF,PTH,RET with target py312;
the same settings and formatting were run before publication without suppression.

Python's managed allocation is a Power of Ten rule-3 deviation. Reads are
capped at 1 MiB, primary receipt/fixture reads at 32 KiB, exact solves at 4 by
11 entries and minors at 4 by 4. The largest explicit binary matrix is 224 by
224; at most 4,096 support decisions and 1,024 XOR images are live per example.
Python and standard-library allocation cannot be disabled. A production caller
would require a fixed-buffer backend; none is claimed here. The test harness
copies at most 32 package entries plus the declared bounded input, runs each
subprocess synchronously with a 30-second timeout and removes its private
directory on every exit. There is no persistent research process.

The duplicate-key callback, fixed-file runpy test import and unittest dispatch
are rule-8/9 deviations. Their targets are fixed, source-authenticated local
code or standard-library test machinery with synchronous lifetimes. No plugin
or arbitrary code name is accepted. Direct calls replace them in a future
production backend; a full test-framework rewrite is outside this bounded
scientific package. Shared runner/export code remains unchanged.
