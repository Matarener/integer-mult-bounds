# Validation

CPython 3.12 on Windows; Python standard library only. `python3 -I -O -B research/borrowed-rankone/verify.py` authenticates the two source inputs, derives four real scalar windows and both orientations, checks 160 independent symbolic local columns including arbitrary dirty entry and exterior, and checks all emitted instructions with the retained source scalar pricing function. Every selected instruction must be ADD or legal SCALE using only original X/Y roles; there is no scratch, CLEAR, COPY or recursive opcode.

The four selected source programs contain two nontrivial borrowed-input adapters and two transpose-dual borrowed-target adapters. The verifier rejects missing input uncomputation, omitted dirty-target subtraction, false rank-one decompositions, illegal odd-denominator normalization, non-dyadic input and shifted source selectors. It also checks 339 borrowed programs from 100 deterministic small rank-one matrices, exercising all legal pivot candidates with exact endpoint and price checks. Exact feasible flow certificates are rechecked for the inherited gauge fallback on every actual source block.

Registered replay, committed-byte transport checks, Git-free export replay and publisher preflight are performed for the release. No Linux execution is available; portability follows standard-library implementation choices but is not an observed Linux test. No global rewritten multiplication, norm/precision or κ audit is claimed. The optional source-history traversal is not used in the shallow checkout; explicit source pins and committed bytes are checked directly.
