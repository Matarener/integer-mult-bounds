Capture dirt and the inherited complete-stream interface

This note responds to Sagar Thakrar's PR3700, open question 1, at head
aa0bd9fbc8700506b1fafcc55bca9bd32aced7d9. It states the exact interface used
by this conditional finite certificate; it does not prove a new all-size
physical implementation of that interface.

The selected #589 captures are already dirty: the nine retained totals carry
42,44,46,63,66,46,43,62,59 helper columns at COPY. In the helper464 edit,
the captures originally called h477 and h478 replace the deleted helper464
column with helper340's column, keeping their clean rows and 46/43 dirt
counts. The helper470 edit drops its dirt column at the capture originally
called h475. The public independent audit derives these facts from the word;
this package's full-basis audits check the resulting word and all COPY windows.

The inherited interface required here is universal in the complete current
stream: for a fixed legal frame/window, COPY applies one paid linear transform
to an arbitrary stream and private-stream discard retains its complete linear
cost. It is not an interface restricted to a prescribed named subset of dirty
helper labels. A fixed linear transform/discard law valid on every independent
input basis column is valid on every linear combination of SOURCE, TARGET and
helper contents. Changing which such columns occur in a total therefore does
not change this interface's width, frame, private lifetime or paid rank. The
record replay checks all 659 input columns in both orientations and closes
every COPY window while restoring the original helper contents. No dirty
column is projected away to obtain the reported identity or price.

This observation explains why the stated arbitrary-stream interface suffices
for the changed capture contents. It does not establish that an implementation
having a weaker, label-specific contract realizes that interface. The selected
all-size/common-label SOURCE/compiler/field/cover and correlated-hosting
realization obligations remain explicit and conditional. In particular, this
note does not erase arbitrary original/helper dirt for free, reschedule a
SOURCE query, narrow a retained private stream, or prove a new whole exponent.
