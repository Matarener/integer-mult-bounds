```sh
python3.12 -Werror -B scripts/research_package.py --package research/t16-three-helper-cycle
```

To retain every generated artifact, use a fresh external directory:

```sh
python3.12 -Werror -B research/t16-three-helper-cycle/verify.py --work /absolute/fresh/output
python3.12 -Werror -B research/t16-three-helper-cycle/test_verify.py
python3.12 -O -Werror -B research/t16-three-helper-cycle/test_verify.py
```
