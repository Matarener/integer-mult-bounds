# Square-zero is necessary for the borrowed-space shear tariff

**Scoped proof with exact finite census; no new κ.**

Ali Romman's [PR #5640](https://github.com/CrocSwap/integer-mult-bounds/pull/5640)
(`research/borrowed-space-shear-tariff`) proves that a square-zero update
`diag(I+N, I_q)` of rank r costs exactly `2 ceil(r/q) + 2` cross-bank shears
with q arbitrary dirty borrowed coordinates. Its lower bound holds for every
endpoint `diag(T, I_q)`, but its attaining word needs `N^2 = 0`. This package
answers what happens for a general endpoint.

**Theorem.** Over any field K, for any n, q >= 1 and any n by n matrix T, if a
word in the PR #5640 alphabet implements `diag(T, I_q)` using at most two
gathers, or at most two scatters, then `(T - I)^2 = 0`.

**Corollary.** If `(T - I)^2 != 0` and `r = rank(T - I)`, every implementing
word has at least `max(ceil(r/q)+1, 3)` gathers and as many scatters, so at
least

    max(2 ceil(r/q) + 2, 6) shears.

When `r <= q` the PR #5640 count of four shears cannot be attained by any
non-square-zero T. The extra cost is exactly two shears in every domain
enumerated below.

**Finite census (exact minima).** A breadth-first search over the whole group
generated by the alphabet gives the exact minimum for every reachable endpoint
in six domains. Every one equals

    tariff(T) = 2 ceil(r/q) + 2            if (T - I)^2 = 0,
    tariff(T) = max(2 ceil(r/q) + 2, 6)     otherwise.

| field | n | q | group order | square-zero endpoints | non-square-zero endpoints |
|---|---|---|---:|---:|---:|
| F2 | 2 | 1 | 168 | 3 (min 4) | 2 (min 6) |
| F2 | 2 | 2 | 20,160 | 3 (min 4) | 2 (min 6) |
| F2 | 3 | 1 | 20,160 | 21 (min 4) | 98 (min 6), 48 (min 8) |
| F3 | 2 | 1 | 5,616 | 8 (min 4) | 15 (min 6) |
| F5 | 2 | 1 | 372,000 | 24 (min 4) | 95 (min 6) |
| F2 | 3 | 2 | 9,999,360 | 21 (min 4) | 98 (min 6), 48 (min 6) |

The last row comes from the opt-in NumPy script; the others come from the
registered standard-library verifier. Each reachable set is all of `SL(n, F_p)`.
The F2, n=q=2 row is the smallest case where the square-zero formula fails: its
two non-square-zero endpoints have `r = 2 = q`, so the rank bound allows 4, but
6 are needed. On F2, n=3, q=2 the rank-3 endpoints meet the rank bound 6 exactly.
So the 6-shear floor and the rank bound both bind there, at different endpoints.

## Proof

Write the current state as `x = X x0 + Y z0`, `z = C x0 + D z0`, starting from
`(X,Y,C,D) = (I,0,0,I)`. A gather `G(A)` sets `C += A X`, `D += A Y`. A scatter
`S(B)` sets `X += B C`, `Y += B D`. The endpoint requires `X = T`, `Y = 0`,
`C = 0`, `D = I`.

Adjacent gates of one kind merge (`G(A)G(A') = G(A+A')`). So every word with at
most two gathers is `S(B0) G(A1) S(B1) G(A2) S(B2)`, with some matrices
possibly zero. Its states are, in order:

    S(B0): X = I,           Y = B0
    G(A1): C = A1,          D = I + A1 B0
    S(B1): X = I + B1 A1,   Y = B0 + B1 (I + A1 B0)
    G(A2): C = A1 + A2 (I + B1 A1)
           D = I + A1 B0 + A2 Y
    S(B2): X = I + B1 A1 + B2 C,  Y = Y + B2 D.

The endpoint gives `C = 0` after `G(A2)`, so `A1 = -A2 (I + B1 A1)` and the
final data block is `T = I + B1 A1`. Expand `A2 Y` with `C = 0`:

    A2 Y = A2 (I + B1 A1) B0 + A2 B1 = -A1 B0 + A2 B1,

so `D = I` forces `A2 B1 = 0`. Multiply `A1 = -A2 (I + B1 A1)` on the right by
B1: `A1 B1 = -A2 B1 - (A2 B1) A1 B1 = 0`. Hence

    (T - I)^2 = B1 (A1 B1) A1 = 0.

The final `Y = 0` only fixes B2 and adds no constraint. For words with at most
two scatters, use the PR #5640 transpose-reversal. Transposing the complete
matrix product and reversing its order gives a word for `diag(T^T, I_q)` with
gathers and scatters exchanged. Then `(T^T - I)^2 = ((T - I)^2)^T = 0`.

The corollary combines this with the PR #5640 bound `k, l >= ceil(r/q)+1`.
The argument uses the restoration of arbitrary dirty borrowed inputs (`D = I`).

## Evidence and reproduction

From the repository root, with CPython 3.12 and only the standard library:

```sh
python3.12 -B scripts/research_package.py --package research/borrowed-shear-general-endpoint
python3.12 -I -W error -B research/borrowed-shear-general-endpoint/verify.py
python3.12 -I -O -W error -B research/borrowed-shear-general-endpoint/verify.py
```

The verifier prints a JSON `RESULT` payload and `PASS_BORROWED_SHEAR_GENERAL_ENDPOINT`;
it takes about 21 seconds locally. For each of the five standard-library domains it:

- enumerates the full group by breadth-first search, so each distance is an
  exact minimum over all words;
- checks every endpoint `diag(T, I_q)` against the tariff above;
- replays one shortest witness word per endpoint as a literal (n+q)-square
  matrix product and checks it equals `diag(T, I_q)`, including the dirty
  borrowed columns;
- checks that every shortest non-square-zero witness has at least three
  gathers and three scatters, as the theorem requires.

Controls: the square-zero-only formula `2 ceil(r/q)+2` is refuted on exactly the
two F2, n=q=2 non-square-zero endpoints, and a witness with one corrupted
coefficient fails to replay. All checks are explicit and survive `-O`.

The F2, n=3, q=2 row needs NumPy and about 70 seconds and 40 MB of distance table.
It is not registered in VERIFY.json:

```sh
python3.12 -B -I research/borrowed-shear-general-endpoint/extended_census.py
```

It passed locally with NumPy 2.5.4 (`PASS_EXTENDED_CENSUS`, group order 9,999,360,
168 endpoints, 0 mismatches). That row is local evidence only; CI does not run it.

## Limits

The theorem is a written proof checked by its author only; human and formal
proof-kernel review are unclaimed. The census covers only the six listed
domains. **No general upper bound is proved for non-square-zero T.** Whether
`max(2 ceil(r/q)+2, 6)` is attainable for every T over every field is open.
The clean-borrowed-coordinate variant, coefficient costs, precision and the
translation-kernel extension of PR #5640 are not treated. This is a side
result in the same alphabet. It changes no κ, selected frontier, physical
supplier or caller bill.

## Open next questions

- **Is `max(2 ceil(r/q)+2, 6)` always attainable?** It is exact in every
  enumerated domain. A proof would complete the tariff for general endpoints
  in this alphabet. First step: build a six-shear word `GSGSGS` for an
  arbitrary `T` in `SL(n, K)` when `q >= n`. Then try to splice it with the
  grouped PR #5640 word for larger r. Blocker: the PR #5640 cross-products
  `L_i V_j = 0` fail for non-square-zero factors, so a new invariant is needed.
- **Which endpoints are reachable at all?** Each shear has determinant one, so
  `det T = 1` is necessary. Each census domain reaches all of `SL(n, F_p)`. A
  general proof for every field and every q is not supplied here.
- **Does the clean-borrowed tariff `2 ceil(r/q)+1` show the same square-zero
  gap?** The transpose argument is unavailable there, as PR #5640 notes. The
  one-sided gather argument above may still apply.
