# Early helper queries for the retained forward BIT source

This package proves a finite source interface. It exposes two original helper
queries at each of 111 ports before the retained forward word starts. It adds
no native child and binds the responses and outputs to all 111 actual port
routes. The complete kappa calculation does not improve: no profitable caller
or full ordinary-work tariff is supplied.

Read [the proof](PROOF.md) and [the exact result](RESULT.json). The source pins
are in [SOURCES.json](SOURCES.json). The publication base is
`32890bc5de034ab8fc93ac88ead7279a6a416d04`. The source was studied at
`1ec1119972c9aefe42525172d07b332fcff81cb4`; all four live inputs have the same
bytes at both commits. The selected record in the package metadata is only
historical provenance. No selected record or frozen predecessor is changed.

## What the interface gives

All 439 helper first-query rows equal their independent entrance inputs.
Of these first queries, 286 have rank one. Each port has at least two. Select
the two earliest at every port to obtain the direct 222-query interface.

For each selected helper, keep an owned copy of the raw first query and an
owned observation. Run the original source. At its original first-query cut,
swap the whole helper and raw fields, including their frame tags. Clear the
owned duplicate. Every original source column and subsequent scalar event
then has the original value and frame.

The actual port route rho fixes the port projector P and sends the local
rank-eight projector to P plus the fresh seven-plane B. Input, observation,
and output routes therefore give the response Q xi and final job Q D_B xi.
The proof checks the 15-by-15 head matrices and their 30-by-30 native address
matrices. It uses the retained fixed common-cover route contract.

| Interface | Early queries | Owned COPY | Owned CLEAR | Whole-field SWAP | Extra owned fields | Additional maps |
| --- | ---: | ---: | ---: | ---: | ---: | --- |
| Direct local ports | 222 | 444 | 888 | 222 | 444 | None |
| Direct ports at a fresh global stage | 222 | 444 | 888 | 222 | 444 | 666 fixed cover routes |
| Optional common-axis local variant | 286 | 572 | 1,144 | 286 | 572 | 843 nonidentity head chart maps |

These are different variants. The 286-query counts must not replace the
222-query counts. The optional common-axis row is a local interface; its 843
maps do not pay the 222-query fresh-stage routes.

The unchanged paid profile is

    1323 H1 + 1342 H2 + 79 H3 + 44 H4 + 102 H5 + 11 H6 + 19 H7.

Without feedback, all 439 helper targets remain H8. The package also checks
111 disjoint pre-source feedback pairs. In BIT, Q squared is I, so the held
input, response, and raw field can all receive the exact paired update. The
source then returns a coupled helper block. A caller must decode that full
block before it can claim the original independent target list.

The reverse source has main-input contamination in all 439 first helper rows.
This package does not expose a reverse cold-helper bank. Swapping the two main
roles gives the opposite main shear with the same forward source.

## Reproduce

Use Python 3.12. The verifier uses only the standard library.

```sh
python3 -B research/bit-early-helper-queries/verify.py
python3 -O -B research/bit-early-helper-queries/verify.py
python3 -B scripts/research_package.py --package research/bit-early-helper-queries --check-only
python3 -B scripts/research_package.py --package research/bit-early-helper-queries
```

Expected verifier output:

```text
PASS_BIT_EARLY_HELPER_QUERIES queries=222 routes=111 source_controls=4 owned_controls=5 new_kappa=false
```

The complete replay checks 661 persistent input columns and 445 owned input
columns for the direct interface. It also checks the 286-cut variant, all
nine original COPY lifetimes, all 111 native routes, and the changed helper
arguments. Normal and optimized runs must give the same exact result.

The verifier rejects a byte mutation in each declared source, a wrong held
input, a wrong frame-tag swap, a dirty owned input, an uncleared raw field,
and an uncleared observation. It does not rerun a discovery search.

The direct verifier also works in the committed package export without Git.
The registered metadata checks use Git to resolve provenance. No native
payload, full GL cover, uniform compiler, ordinary precision or outer
multiplication assembly is executed by this package.
