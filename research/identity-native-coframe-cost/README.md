# Cost of identity-native coframe specialization

Dugongue PR5665 gives a valid way to replace logical native generators by identity and implement exact transports between chosen Clifford coframes. This package settles its local paid-versus-helper comparison: for every admitted coframe choice and every `0<t<=1`,

`paid_moment - changed_helper_moment >= 232*8^t > 0`.

The 224 main fields each require endpoint grade eight. Eight centre transports each have grade eight. Each of the 408 independent helpers must pay at least its actual two-sided endpoint grade along its own persistent transport path. Thus its new productive grade cannot finance those main and centre costs. The local paid moment is at least about **50.54%** above the helper moment whenever that moment is nonzero. The exact ratio bound is `1+232/459`.

This is a cost obstruction for the proposed comparison. It does not dispute the coframe construction's operator identity. A larger caller would still have to fund the explicit main/centre residual and all other work. A whole caller that itself satisfies the identity-native transport contract has `paid_moment>=productive_moment`; arbitrary existing callers have not been placed in that class here. No new kappa or universal multiplication lower bound is claimed.

The theorem permits arbitrary Clifford coframes, all helper target changes and every moment exponent in the interval. It is stronger than a search over partial Fourier subsets. The source is checked in both complete directions. Neither identity specialization contains a whole-zero original or centre query that could be omitted. Changes to the scalar word, retired targets, nonidentity native generators or an explicitly proved free zero-header transition require a different analysis. The active P104 late-binding and native-gauge investigations are outside this result.
