factor by two pure-bank U9 gathers. It preserves the complete operator,
lowers its private rank mass from 13,872 to 13,744, and fits into the inherited
compensation chronology with arbitrary source, target and helper inputs.
The complete local change is
`DeltaH={8:4336,9:32,16:-2160,17:-32}`, including all extra source visits.

## Construction and scope

For each of sixteen coordinate groups, replace `g` by the pure-bank feature
`f` satisfying `8f=2g+sum(h)+2t`. The inverse is
`g=4f-sum(h)/2-t`. Transforming the scatter rows contragrediently preserves
`K=B A^T/8192`. Pure sources visit their own U9 and then FULL; the remaining
800 centres keep their FULL gathers. The complete K word replaces the old
outer source-to-FULL and target-cap phases in the compensation schema.

Ordinary helpers return to the same **logical** value at FULL. Their physical
output is **Fd**, not the physical entrance vector d. Copied private totals
and their erasure are a separately paid interface premise. The finite native
recipes establish exact phases under that premise; they do not implement
private erasure or a physical restoration wrapper.

## Reproduction and source binding

From the repository root, with Python 3.12 and NumPy 2.3.5:

```sh
python3.12 -B scripts/research_package.py --package research/h6-u9-asymmetric-compensation
```

[VERIFY.json](VERIFY.json) registers six mathematical stages and normal/`-O`
portability controls. The native stage regenerates recipes and chain/defect
checks; the separate frozen replay never calls the lowerer. Regeneration is
compared with the committed artifacts without writing them. Every mathematical
receipt field and the exact serialized recipe bytes are compared.

For a standalone source export, run each listed command with `{package}`
replaced by this directory and `{python}` by the pinned interpreter. No Git,
network access, original workstation paths or external source trees are needed
by these commands. Repository metadata provenance checking separately needs
the source history.

[FROZEN-SHA256.json](FROZEN-SHA256.json) authenticates the unmodified original
sources, receipts and minimum upstream dependency closure. The explicit
[adaptations](ADAPTATIONS.json) change only source acquisition, paths and
read-only output comparison in memory. Nested imports execute authenticated
source bytes directly, bypassing `.pyc` caches. Frozen modules are compiled
with `optimize=0` to retain their original assertions even under an `-O`
caller; outer verifier checks use explicit exceptions. Runtime duration,
runtime version observations and the caller optimization flag are the only
excluded receipt observations, in the specifically listed receipts.

Frozen reports retain historical local-only status and earlier open gates.
The current claim is this README and PROOF.md. In particular, PRECISION.json
sharpens RESULT.json's earlier conservative denominator bounds, and the
