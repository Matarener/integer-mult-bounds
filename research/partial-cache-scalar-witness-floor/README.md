# Best scalar witness for the partial-cache observer: floor sqrt(7/92)

**Scoped exact finite certificate. No new κ.** This sharpens the
`1/sqrt(19)` error floor of Ali Romman's
[PR #5537](https://github.com/CrocSwap/integer-mult-bounds/pull/5537)
(`research/partial-cache-minimax-floor`) to `sqrt(7/92) ≈ 0.27584`, and proves
that `7/92` is the exact optimum over every scalar witness. The previous value
`1/sqrt(19) ≈ 0.22942` used one fixed kernel vector.

## Result

Use the observation channel of JoyboyBrian's
[PR #5498](https://github.com/CrocSwap/integer-mult-bounds/pull/5498): every
full-nine-axis-frame value of the raw PR5402 backward word, plus the eight
endpoint partial caches. Use #5537's physical input norm and the eight-mode
physical target `T`. A *scalar witness* is a displacement `k ⊗ v`: rational
scalars `k` on the 632 original roles times one arbitrary field value `v`,
with zero on the nine owned inputs.

1. The scalar witnesses whose free-word coefficients vanish on every observed
   row form a rational space of dimension **150**. The 4,858 distinct
   (row, free word) forms have rank 482 on the 632 roles.
2. Over that space,

       max ||T J(k⊗v)||^2 / ||J(k⊗v)||^2 = 7/92,

   and the optimum is isotropic: the 8x8 matrix `C^T G^-1 C` equals
   `(7/92) I`. Here `G` is the physical Gram matrix of a kernel basis and `C`
   is its target matrix.
3. For each of the eight modes there is an integer witness attaining `7/92`
   whose target lies only in that mode. The mode-1 witness has 156 raw roles:
   56 X roles at ±13, 56 Y roles at ±1 and 44 helpers. Its physical image has
   113 nonzero roles, and `||T J||^2 / ||J||^2 = 784/10304 = 7/92`.

PR #5537's argument is unchanged: the antipodal pair `±J(k⊗v)` has identical
observations at every positive width. So every decoder, including nonlinear
ones using the complete supplied history, has uniform error at least
`sqrt(7/92)` on the physical unit ball. A randomized decoder has worst-case
expected squared error at least `7/92`. The old witness of #5498 is in the same
kernel and gives exactly #5537's `1/19`. The verifier checks this as a control.

### Why 7/92 is optimal among scalar witnesses

Write a witness as `k = B c` for the kernel basis `B`. The target is `C^T c` and
the physical squared norm is `c^T G c`, with `G` positive definite. Every
Gauss-Jordan pivot of `G` is checked positive. For any unit `u` in R^8,
Cauchy-Schwarz in the `G` inner product gives

    (u^T C^T c)^2 <= (u^T C^T G^-1 C u)(c^T G c) = (7/92)(c^T G c).

Taking the supremum over `u` gives `||C^T c||^2 <= (7/92) c^T G c`. The
verifier checks `G X = C` and `C^T X = (7/92) I` exactly, and checks that the
explicit witnesses `B X e_a` attain the bound.

## Scope and limits

- **Claim type:** an exact finite certificate (rational linear algebra on the
  pinned word) plus the short Cauchy-Schwarz argument above. The all-width
  transfer is #5498's coefficientwise free-word argument. It applies unchanged
  because every scalar witness in the kernel is coefficientwise zero.
- **Not the full norm.** This is the optimum over the scalar class `k ⊗ v` only.
  It is a lower bound on `||T restricted to ker O||`, #5537's Open next
  question 2. Operator-valued kernel elements, such as width-dependent or
  role-dependent maps of `v`, are not covered. The exact norm may be larger.
- **Inherited premises.** These are cited, not re-proved: the free-word
  grammar of #5498 and its replay of the PR5402 word; the PR5402 target
  formula `b_k = (1/2) K_m,k^-1 R sum_j M_kj y_j`; the unitary wrappers,
  frames, `2Km` mode entrances and helper basis `L` of PR5402, as used by #5537
  for its physical norm; and the all-width physical realization of these maps.
- **Free-word grammar.** Constraints are taken coefficientwise in reduced free
  words, as in #5498. Extra operator relations among actual monomial matrices
  could enlarge the true kernel. That would only raise the floor further.
- No supplier admission, paid-call bound, κ change or complete multiplication
  theorem follows.

## Controls

The verifier must reject or detect each of the following:

- One perturbed coordinate of the optimal witness must leave the kernel.
- Dropping the eight endpoint caches enlarges the kernel to dimension 158. The
  diagonal optimum then reaches `105/8`, so the caches carry real information.
- The raw (non-physical) norm gives `7/204` for the same witness. The helper
  basis and mode entrance normalization therefore matter.
- Every input byte is checked against `SOURCES.json` before the PR5498 replay
  module is imported. The emitted receipt must equal `RESULT.json`, which was
  generated by `verify.py --emit`.

## Reproduce

From the repository root, with CPython 3.12 (about 25 s per run):

```sh
python3.12 -I -W error -B research/partial-cache-scalar-witness-floor/verify.py
python3.12 -I -W error -B -O research/partial-cache-scalar-witness-floor/verify.py
python3.12 -B scripts/research_package.py --package research/partial-cache-scalar-witness-floor
```

A sparse checkout must include `research/partial-cache-history-observer`,
`research/native-rank8-helper-provider`, `research/coded-native-caller`,
`research/kappa-round3-warp-20261022` and `research/partial-cache-minimax-floor`.

## Open next questions

1. **What is the full norm of T on ker O?** This scalar optimum is a lower
   bound only. First step: allow role-dependent unitary or monomial
   coefficients on `v` at width one, and test whether the kernel strictly
   grows past the 150-dimensional scalar space. The blocker is an all-width
   argument for non-scalar kernel elements.
2. **Why is the optimum isotropic?** `C^T G^-1 C = (7/92) I` for all eight
   modes. A symmetry of the PR5402 mode boundaries may explain it and give a
   closed-form witness. First step: compare the eight integer witnesses under
   the provider's mode permutation.
3. **Can one retained observation lower the floor?** #5537 asks whether one
   extra observation separates `J(V)`. With the 150-dimensional kernel in hand,
   the useful test is how much one versioned partial-history row lowers the
   `7/92` optimum. Physical availability and retention of that row remain
   unpriced.
