# Complete P104 history does not remove a frozen paid query

Every one of PR5580's 3,454 paid local requests adds a new independent
row to its destination-frame history. This holds in the forward word and
its complete bilinear transpose. Grant every prior field value, unlimited
storage and free scalar/native monomial decoding. No request can be
replaced while returning its exact required value at the same event.
The written proof extends the result to every width f>=40 using the
credited pointwise Clifford theorem. No new kappa is claimed.

This is a concrete source test for PR5586 P1/P4/C1. It makes the next
step precise: change paid arguments or supply additional caller history.
Retaining more values from this unchanged local invocation cannot help.
It does not exclude the atlas's changed-prefix constructions.

## Evidence and scope

[PROOF.md](PROOF.md) defines the decoder alphabet and proves the result.
Each native monomial is the repeated tensor lift of one nine-axis
monomial. Different monomials per address column, general inter-column
maps, nonlinear decoders, recursive-child internals and prior-caller
observations are excluded. The scalar contacts and chronology are fixed.
The replacement must reproduce the requested intermediate value; a
changed continuation with later cancellation is outside the model.

Both complete replays have 1,002 frame classes and 4,189 independent
history rows, including the 735 original inputs. Exact rational
separating vectors prove every rank increment. An independent modular
pass uses the opposite pivot order and checks all frame dimensions and
endpoints. Every scalar intermediate is explicitly checked as part of
the retained history. Early-query and duplicate-history controls check
the availability boundary.

The supplied separators also prove per-request squared relative ideal
operator-error floors of 1/1,990,170 forward and 1/43,200 transposed.
These are conservative certified floors. They are not bounds on the
final multiplier after a changed continuation.
