# Independent nonlinear scalar-role recodings reduce to scalar gauges

This contribution was produced by Nick Petalas. Apache-2.0.

**Claim type: scoped written obstruction, with exact finite corroboration.**
Fixed arbitrary zero-preserving bijections on separate scalar roles add no
native-profile freedom to the declared connected ADD/native interface.
No continuity, measurability or differentiability is assumed.

For a connected directed ADD graph, write an edge as source j to target i.
Every family satisfying

```text
f_i(x+y) = f_i(x) + b_(j,i)*f_j(y)  for all independent x,y
```

has exactly the form f_v=s_v*H, with one common additive bijection H and
b_(j,i)=s_i/s_j. Existence is equivalent to multiplicative consistency around
every undirected closed walk. Reverse traversal uses the reciprocal label.
The graph need only be weakly connected.

If one role also preserves multiplication by i, H is Q(i)-linear. Applied
pointwise, it commutes with every Gaussian-dyadic native matrix and all its
finite tensor powers. For every fixed word in this gate class,

```text
Phi A Phi^-1 = D A D^-1,     D=diag(s_v),
```

with the weights repeated over each role's addresses. Thus every proposed
nonlinear recoding has a scalar-gauge counterpart with the identical native
operators, scalar ADD coefficients, chronology and endpoint, including dirty
restoration. The native paid profiles attainable in the two classes are equal.
Boundary adapters and ordinary scalar work retain their costs.

[PROOF.md](PROOF.md) states and proves the universal classification and
its exact contract. This identifies an escape route that cannot improve
the current helper mechanism under unchanged gatewise compatibility. It does
not exclude nonlinear arithmetic with a different instruction contract.
