# A paid query closes the bridge boundary, but repays the saving

PR3963 identified the missing current-Y contribution at the actual ordinary
bridge after F0/B1 and pair-1 idle preparation. This package augments PR3952's
96 earlier y1_U outputs with the eight current query components. It gives a
literal, legal local consumer of that 104-field boundary and verifies the
complete composition on arbitrary routed arrays.

The serial composition costs **208 H1, 416 wrappers, 400 cover maps and 15,040
scalar primitive allowance**, with 120 owned full-cover workspace fields and
eight owner-private fields. Borrowed current Y is unchanged; the mutable
other-pair target receives the exact bridge subtraction; all workspace returns
zero/identity. No early retention is needed.

The result is a scoped stop for this repair. Algebraic/native fusion cancels
the newly added query subtraction and reconstruction and yields the existing
96 source bridge ADDs. The augmented interface closes the information gap,
but no source bridge operation disappears. Under the same common-label
native entry premise, direct subtraction costs 768 scalar allowance. If all
120 extra fields remain allocated, their paid cleanup raises that to 1,008;
this exact external-state variant is also checked.

[PROOF.md](PROOF.md) gives the arbitrary-array equations, source event3,
complete ownership/frame/cleanup contract, invoices and obligation ledger.
This is not an admitted complete QQ16 substitution, a global cost rejection,
or a claim that eight new physical families are necessary. Source placement,
movement, storage, rounded precision, coverage and recursive admission remain
open. The existing centre removal is not credited again.
