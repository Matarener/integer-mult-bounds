# Verification and engineering decisions

The changed behavior is one physical boundary. An explicitly configured encoded
plan uses `floor(p^(1/40))` in every dependent reservation/guard field. Complete
MSB-first signed packets enter and leave the existing LSB-first root through
value-preserving per-component reversal. All predecessor files in `retained/`
are unchanged and authenticated. ROOT-PLAN.patch displays the exact plan delta,
including removal of one unused local assignment diagnosed by Ruff.

The Build the Lever principle led to the executable adapter, exact receipt and
source-closed replay. Prove It Works led to execution on the actual retained
Tape, Count, RootPlan, GridBoundary and RootLayer classes. No other worker,
external reviewer or formal proof-kernel validation is claimed.

## Checks

- Exhaust all 508 signed values at widths 2 through 8, with signed endpoints,
  two complex records, inverse conversion and preservation of the original.
- Execute seven encoded plans, including both sides of `2^40`, and a nonzero
  recursion-depth case at `2^280` with the actual T74 row divisor. Compare all
  relevant fields against separate integer inequalities/formulas.
- Reject malformed, short and long packets and reuse the same bridge afterwards.
- Run four complete roots through OuterLayer against the separate rational
  Walsh oracle, including zero/one selected axis, nonzero spectator fields,
  multiple rows and coefficient fields. Check borrowed packet/descriptors and
  closed owned state.
- Reject a short joined packet and then execute a valid retry through the same
  wrapper. Four optimized CLI mutants change reverse scanning, restore the old
  dimension law, omit the exit bridge or omit the entrance bridge. Each fails
  at its named semantic assertion.
- Validate metadata/pins, Ruff E4/E7/E9/F diagnostics and formatting of new code,
  compile the seven new/derived Python files, then compare committed bytes and
  declared source history. Run the committed Git-free export with unchanged
  hashes. The final report records exact commands and final-head receipts.

An early malformed-packet run exposed an output-marker cleanup ordering error.
The correction rewinds before erasing the marker. Initial import-path and
TemporaryDirectory cleanup diagnostics, the failing cleanup runs and subsequent
passing receipts are retained in the session evidence. They are not presented
as passing final-head replays.

## Power of Ten scope

All new execution paths use structured exits and no recursion. Packet loops
have bounds `2N` and w from validated encoded counts. The source staging loop
has exactly 74 rows. Test domains are explicit finite tuples/ranges; mutation
execution has four cases and a 300-second timeout per child. Counter cleanup,
input rewind, partial-output erasure and reuse are exercised. The source loader
has contained paths and exact size/hash checks. Subprocess status, stderr,
timeout and exact receipt are checked. New functions stay at or below 60 lines.
Assertions remain active as explicit ValueError contracts under Python -O.
No positive-rank child, new native opcode or arithmetic rounding is introduced.

The following inherited/platform deviations remain bounded here.

Rule 3, fixed capacity. CPython objects and Tape cell arrays allocate dynamically.
The new physical inventory is fixed at 26 tapes, each call has exactly V output
bits and at most w buffered component bits, and encoded counters use logarithmic
space. The scope is one synchronous boundary invocation, with no concurrent
writer or queue. The physical pools have capacity eight; the signed-word
receipt observes peak bridge leases of five. All owned leases close on failure
and success. Host cell capacity reclamation is unclaimed. A native runtime
port must preserve these explicit physical bounds.

Rule 4, one-page functions. The source-sensitive derived RootPlan.compute is
98 lines and otherwise retains the original exact planning program. Splitting
that inherited expression/lifetime block would enlarge the correctness audit
without advancing this boundary. Its only changed expression supplies the fixed
exponent. The exact three-hunk patch, field oracle and rejection controls bound
this exception. A future upstream RootPlan refactor must replay all reservation
and cleanup obligations, rather than copy a partial expression subset.

Rules 8 and 9, retained source loading. The frozen cohort uses explicit
module construction and dynamic imports to join its authenticated legacy
archives. RETENTION.json closes every runtime byte, prepare.py checks the 74
rows, and the four known private loader directories are explicitly cleaned.
Root injection is a bounded existing interface; the production root keeps its
native/hosting responsibility. This package adds no loader registry or native
factory. Cold export verifies availability without a Git object cache.

Rule 10, diagnostics. E402 is excluded because the retained cohort must activate
before importing the physical classes, and standalone isolated scripts explicitly
select their source directories. Ruff E4/E7/E9/F remains enabled, including F841.
The original formatting of outer_root_plan.py is retained so its three hunks
remain reviewable. Other new files use Ruff formatting. Frozen predecessor code
is not reformatted. Python 3.12 and optimized Python replays run with warnings
as errors. No project-wide lint or historical/full selected replay is implied.
