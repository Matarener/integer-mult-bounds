# The actual outer dimension and signed component boundary

## Statement and inherited premises

Fix the retained T74 construction, ordinary exponent
`tau=99830289/100000000`, complete positive-child histogram, native identities,
whole-owner hosting, exact coefficient-height induction and complete root
return contracts of Jose Manuel's PR3477. These are conditional premises here.
This package does not independently validate the production native payload.

The following boundary implication holds. Replace the retained encoded plan's
fixed dimension law by `d=floor(p^(1/40))`, keep `K=floor(d^(1/500))`, and supply
any `D<=d` selected positions `rho+jK`, with `0<=rho<K`, complete preceding and
following fields, an `O(p)`-bit address/descriptor and the retained long-record
range `r=2^Theta(p/d)`. For sufficiently large p the same physical root
reservation, guard, recursion and normalization argument is applicable. Its
conditional cost is

    O(V d^tau (log(2d))^tau) = O(V d^0.998305).

Here V is the entire serialized payload, including all spectators. The fixed
constants in the long-record and descriptor conditions are chosen before inputs.
For p below the effective cutoff, elementary kernels cover the bounded range.
This does not assert that the full T74 production implementation has been run.

Compose this explicitly planned root with `WordOrderBridge` before and after
it. On signed two's-complement components of width `w=p+2`, real before
imaginary and increasing coefficient order, `OuterLayer` returns the same
normalized tensor endpoint and final truncation in the outer caller's
most-significant-bit-first representation. It preserves its borrowed packet
and encoded descriptors. The two bridges add O(V) work, O(V) occupied/visited
storage and a fixed 26 tape roles. They add no recursive child or rounding.

This fills the two specific dimension/format obligations named in PR3477's
handoff to PR2298. It is a conditional interface result. It does not establish
a new integer exponent, supplier admission or a selected-frontier change.

## A parameter change in the actual encoded plan

`outer_root_plan.py` is the retained `root_plan.py` with the three hunks in
`ROOT-PLAN.patch`. The constructor validates one fixed rational exponent;
`compute` passes it to the unchanged encoded `floor_power` implementation.
The default stays `(997,1000)`. The outer wrapper requires an explicit
`(1,40)` plan. Merely passing a smaller D to an old plan is insufficient.

The plan computes its own d, K, G, H, recursion depth, q0, qF, qB, Q0, delta,
working component width, whole-packet cardinality, root stock and padding from
this d. No old-d reservation survives. In particular the root uses the actual
T74 divisor `L=66304*|O(73,2)|`, rather than the preceding R480 divisor.
There are no changes to the role schema or to complete spectator extents.
The physical root already accepts its plan as a constructor parameter.
PR3477's T74 root retains that parameter and the same root/grid methods.
`OuterLayer` takes an explicitly constructed root at this existing interface.

The encoded arithmetic remains exact. `floor_power(p,1,40)` returns the unique
integer d with `d^40<=p<(d+1)^40`. Changing the fixed numerator/denominator
changes only fixed arithmetic constants. It introduces no floating evaluation,
input advice, scalar approximation or host-decoded precision into the plan.
The concrete oracle tests the exact boundary on both sides of `p=2^40`.
It also checks a nonzero-depth plan at `p=2^280` against the actual T74 divisor.

## Why the dimension extension preserves the root argument

Put epsilon=1/40 and c=1/500. The strict powers needed at this boundary are

    1-epsilon(1+c)=19499/20000,
    1-epsilon=39/40,
    epsilon*c=1/20000.

Thus `dK<=p^(epsilon(1+c))=o(p)`, the guard `C0*d` is o(p), and
`K/log p` tends to infinity. With `G=4*ceil(log2 p)+6` and `H=dG`,
`H/(dK)=G/K` tends to zero. The depth is O(log d), so q0 is O(log d)
for the same fixed divisor L. The other reservations are
`qF=ceil(2H/K)` and `qB=ceil(H/K)`. Therefore Q0 is o(d).
In the actual outer calls D=d-1, the reserved core is eventually nonempty.
For smaller D the existing direct branch remains available.

When the fast branch is taken, `D>Q0` and `D<=d` give the same `K>3G`
guard used in PR3477. Eventually `3H<dK<p`. The unchanged numerical guard
has width `p+2C0*d+3=O(p)` and uses one exact grid throughout the root.
The final signed truncation is the same operation and has the same error.
The precision is not recomputed from the number of selected axes alone.

The native and child programs depend on the selected dimension e, frames,
packet layout and root d, not on a separate hard-coded epsilon. The child
size remains `r*floor(e/73)<=48*floor(e/73)<e`; the stopping rule remains
`e<73` or `e^1000<d`. Under the stated T74 premises, the same strict moment
at sigma=.9983 yields internal exponent tau with `(log p)^tau`, leaf
exponent `.9983017`, and reservation exponent `.998`. For fixed positive
epsilon, `log p=O(log(2d))`. These exponents and the complete histogram
are unchanged. Each remains strictly below .998305 after absorption.
The larger long-record power `p/d=Theta(p^(39/40))` still pays every fixed
polynomial setup/descriptor cost. This checks the exact three places where
lowering epsilon enters the retained proof; no runtime constant is inferred
from a fixed prefix reserve.

This argument retains all native, hosting, ordinary and all-size premises.
It is not an independent replay or formal verification of those premises.

## The complete signed tape adapter

For a width-w component let x_j be its bit of weight `2^j`, with x_(w-1)
the two's-complement sign. The outer encoding is
`x_(w-1),...,x_0`; the root encoding is `x_0,...,x_(w-1)`.
The bridge copies precisely w bits to one owned tape buffer, then scans that
buffer backwards while appending to its output. It clears the buffer before
the next component. Its component countdown is twice the complete Gaussian
cardinality, not the cardinality of one selected fibre.

Consequently each component represents the same signed integer before and
after conversion. Component boundaries, real/imaginary order, coefficient
order, row order and every address field stay fixed. The map is an involution
on all complete bit packets, with arbitrary correlations or dirty values.
It does not change the physical tensor axes. Applying the inverse map after
the root therefore gives the same componentwise normalized endpoint in the
outer representation, including the retained truncation toward zero.

For N Gaussian values the packet has `V=2Nw` bits. Each component entails a
forward buffer pass, backward output pass and clearing pass, all O(w). The
retained encoded Counter uses amortized ripple movement. Initializing its
width counters costs O(log w) per component and its complete component
countdown costs O(N+log N). These fit O(V) for w>=2. Borrowed source rewind,
return rewind and failure clearing are linear in the visited packet.
The buffer occupies O(w) cells, counters use O(log N+log w), and the complete
output occupies V cells. A fixed eight-role scratch pool and one output per
bridge, plus the eight-role wrapper pool, give 26 added tape roles.
The host Tape model can retain historical list capacity; this is an
occupied/visited tape bound, not a claim of host-memory reclamation.

The bridge validates signed width, positive encoded cardinality, each bit and
the final blank. Truncation, extra bits and an internal nonbit all fail before
a result is returned. Owned buffers and counters close on every exit, input
heads rewind, and failed output is erased. An initial implementation erased
the output marker before rewinding; the malformed-input control exposed that
cleanup defect. The published ordering rewinds before erasing the marker.

`OuterLayer` plans once to obtain the actual width and complete cardinality,
copies these two encoded counts, clears planning scratch, converts, invokes
the root, then converts the returned packet. It releases its intermediate
packets and counts on success or failure. Root invocation owns its existing
cleanup contract. The caller must consume each output before reuse.
Its extra fixed-degree encoded planning cost is paid by the long record.

## Consequence for the outer caller and stopping point

The source-bound outer parameters are exactly PR2298's epsilon=1/40 and
c=1/500. Its narrowest charged saving is still
`epsilon*c*(1-tau)=169711/2000000000000`. The new layer exponent and linear
format passes do not remove this exact-K transposition cost. This package
makes no stronger integer-kappa substitution. It also does not repeat the
released wider-K/weaker-outer optimization in Discussion2291.

The remaining review is the complete production T74 refinement and inherited
ordinary/native/hosting contracts, followed by the actual outer integration,
its analytic and numerical obligations and end-to-end execution. The finite
checks here use a reduced binding and guard. They verify the boundary itself;
they do not execute O73/GL64-scale native objects or the production guard-sized
payload. Independent human and formal proof-kernel review are unclaimed.
