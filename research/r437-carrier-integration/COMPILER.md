# Fresh compiler and request boundary

The input is the exact #4067 carrier word and reconstructed chunked template,
combined with the exact 63 owner rewrites retained from Rohan Arun's #3959.
The old C arm uses ai-nanachi's #3647 OQ4 word with those same owner rewrites.
The #3959 complex-side headline is not imported: its subsequent retraction does
not establish or refute this separately checked BIT owner component.

`compiler.load('C'|'D', q)` returns the actual canonical catalogue's source
objects and a replica-indexed topology. The canonical `Catalogue`, `Base`,
`Chart`, `Request`, and `Specifications` algorithms are retained. An exact
source-text adapter substitutes the literal 659-role R437 input and fresh
profile for the older canonical construction. The old frozen request digest
is intentionally removed from the builder: the new ordered digest is an output
reconstructed by the independent comparison checker, not a reused acceptance
constant. The unchanged C arm reproduces #4010's ordered request digest.

The 63 owner assignments are applied by the retained `compile_owners`, including
its actual chronological untouched-pair windows, absolute destination family,
whole-eight-coordinate support, compact occupied prefixes and exact-once helper
checks. Every physical stage/replica then gets its literal MOVE/COPY identifiers;
IDLE requests use `idle_identifiers(child, replica)`. No replica-blind IDLE API
is provided. Old prototype positions cannot serve as physical request codes.

Both C and D contain 903,456 requests: 836,928 MOVE, 2,592 COPY and 63,936 IDLE.
Their 1,235 chart labels coincide, but their interned base objects number 541 and 542 and their
ordered source records differ. At q=3 both require 6,512 code bits. More
generally the two `LowCodes` constructors have the same `(q,64,903456)` arguments,
so their integer limits and widths are equal at every common fixed q. The
five-bit expansion relative to the replica-factorized predecessor is already
present in C. The incremental D-minus-C field-width charge is zero; this says
nothing about the cost of rebuilding different code values, programs or
histories, which must still be included at their actual consumer boundaries.

The forward SOURCE87 MOVE from frame189 to509 is now event22397/request1676
at stage0/replica0, versus event22689/request1755 in C. The reverse counterpart
is event4737/request94518 at stage1/replica0, versus event4442/request94439.
The rank-two projector is the same, but the chronological key and source
context are different. The actual changed input before this earlier MOVE
must be acquired before it executes; compiling its later projector does not
supply that earlier dirty read. Regenerated D changes preceding ADD consumers,
so unchanged projector or COPY SOURCE rows are never used to assert equality
of full dirty state.

Source handles carry a version, a digest of the exact word/template/pooled
owners/moves and fixed code context, an integer code, and a literal request key
including replica. `resolve_handle` also requires the exact Specifications
catalogue object. The tests reject baseline handles in D, wrong replica keys,
legacy replica-blind lookup, legacy IDLE enumeration, mismatched Specifications,
cross-prime contexts, untyped integer handles and native COPY attempts.
Raw fields remain integers internally: the physical caller must resolve the
handle against the designated source context before encoding those fields.

`compiler_checks.py` checks every request's key, caller position, owner/source
chart and exactly-once IDLE identity. It reconstructs every chart independently
from geometry and checks dyadic entries and a dyadic-unit determinant, plus
every same-family owner-pair distinguishing witness. For every fresh local
base it verifies exact rational idempotence and rank, then verifies the degree-eight characteristic polynomial
`det(tI-P)=t^(8-r)(t-1)^r` at nine exact points. Reducing this
identity at any odd prime preserves its eigenvalue multiplicities; idempotence
makes P diagonalizable because zero and one remain distinct. Hence its rank
and the chart invertibility survive every odd prime. Coordinate IDLE projectors have an
explicit independent-axis witness. This supplies algebraic premises to the
separate numerical admission argument; it does not alone establish runtime
history distribution or physical gather correctness.

The exact native and common `Specifications` for the changed SOURCE87 request
in each orientation are instantiated at q=3 with identity low header. This
finite source-compilation test does not enumerate GL64, execute the whole
production residual or replace an all-size primitive/refinement premise.
