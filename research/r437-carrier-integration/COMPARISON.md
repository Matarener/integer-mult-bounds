# Separately written literal comparison

`independent.py` imports no primary integration builder, old carrier builder,
pooled compiler, catalogue, or physical implementation. It reads shared frozen
mathematical inputs and independently interprets them. This is assisted checking
of common sources, not independent human acceptance or a formal-kernel proof.

The source pins are #4067 at `a95f11c52e3ca1e4c5171b3c20d8f4b0815aee2e`,
#3647 at `a24f9ff95c12fd0b6792e3f710569237efd72db2`, #3959 at
`babd2e36471422cd3e97f912a5cf2846da52a222`, and #4010 at
`92daee4bf12255efe4ae0102eeb5f72794bf9c57`. The receipt authenticates its
literal word, old template, proposal and candidate byte inputs. Every candidate

input is modified. Source-history verification is a separate package check.

## What is checked

The checker uses Fraction row elimination for all 636 rationally closed frames,
and reconstructs both local chronological streams from the four word sections.
It verifies literal stream equality with each authenticated template. A separate
GF(2) interpreter tracks all 659 independent initial columns through forward and
reverse operations, including protected private COPY and ERASE. It checks full
terminal restoration, all SOURCE write observations, and COPY SOURCE rows/frames.
This symbolic scalar check does not itself prove physical native transport.

The new rank-two SOURCE87 MOVE is at forward event 22397 (new B69), from frame 189
to frame 509. The old MOVE was at event 22689 (old B283). Thus a source plan first
available at the old event cannot supply the earlier acquisition. There are 966
SOURCE-write observations in either orientation; all agree. Exactly one complete
COPY DIRTY row differs: forward ordinal 7 and reverse ordinal 1 (zero-based).
All nine SOURCE rows and frame observations agree. The changed D has 55 rows.

Chronological idle windows are derived from the outer schedule. All 63 proposed
owner changes must match their exact old owner. Absolute families, lifetime,
whole eight-coordinate support, disjoint occupancy and compact remaining
suffixes are checked with bitsets. Every one of 288 calls and 125,856 helper-owner
occurrences is covered; each IDLE suffix is enumerated once per replica/family.

A separate request serializer computes local residual projectors by a rational
Gram-matrix inverse, rather than importing the catalogue's Gram-Schmidt code.
It derives owner charts, local and idle base hashes, native request fields,
ordered request hashes and full GL64 source-code widths. Both C and D are checked
under the retained replica request-record schema. The stronger carrier handle
schema is an integration-builder responsibility.

## Four-way result and limits

All four variants have 903,456 requests and rank mass 1,808,352. A/B use the original
OQ4 owners; C/D use the actual 63 pooled moves. The pooled incremental difference
D-C is exactly `{1:+288,2:-576,3:+288}`. The owner and IDLE-record digests remain
equal across the local word replacement. The fresh native request digest must
change because request positions and bases change. Equal request cardinality
alone does not authenticate old handles.

For any real exponent `0<a<1`, strict concavity of `x^(1-a)` gives
`1 + 3^(1-a) - 2*2^(1-a) < 0`. Therefore this rank-profile difference improves
that component of the common recursive moment at every such exponent. This
comparison neither prices additional precision/stock nor establishes a complete
caller gain. No endpoint root is recomputed here.

Controls replace new D with old D (rejected by the arbitrary-DIRTY identity),
move an owner to the wrong absolute pair (rejected), and duplicate an owner
rewrite (rejected). Handle, prime, Specifications, numerical and physical
controls belong to their respective integration checks.

## Hosted slot implication (inverse-coordinate convention)

For physical family `f`, let `F_f` be its retained invertible ambient family
chart: the literal eight-dimensional family chart in the first eight
coordinates, identity elsewhere. For slot `s`, let `P_s` be the actual column
permutation in `Catalogue.chart_matrix`, and `E` the inclusion of the first
eight coordinates. Put

`J_s = F_f P_s E`, and `L_s = E^T P_s^(-1) F_f^(-1)`.

The canonical implementation uses the family chart when the slot touches the
first eight axes and identity otherwise. These branches give this same `J_s`:
when all slot axes lie outside the first eight, `F_f` is identity on their
span. The checker derives the literal permutation images, rather than assuming
an ordering of the slot set.

Consequently `L_s J_s = I_8`. For two distinct slots in one family,
`L_s J_t = 0`, because their permutation images are disjoint coordinate sets.
The checker establishes disjointness globally for each absolute family,
including the different IDLE domains. The remaining IDLE coordinates are the
exact complement. No orthonormality assumption is required for this argument.
The 111 family matrices and their inverses are authenticated and checked over
rationals; all their denominators are powers of two, so these injection
identities also hold over every odd-prime local ring. This statement does not
remove the separate prime-admission guards on local residuals.

For a local linear operator `P` on the eight-dimensional slot, its transported
operator is `J_s P L_s`. It acts on that slot as `P` and annihilates every other
slot. Distinct-slot transported operators therefore compose independently.
Any local complete-word linear identity holds on the direct sum for arbitrary
initial slot coordinates, while the complement is fixed. The local checks
include all 659 input columns, not just clean helpers, and preserve every SOURCE
write observation. Thus, **conditional on the caller implementing the literal
transported primitive and each chronological acquisition**, the carrier's
full arbitrary-DIRTY word identity survives the 63 pooled owner changes. This
closes the slot-aliasing implication; it does not discharge physical transport,
rounding, bad-event probability or resource budgets.

The changed full COPY capture is retained verbatim in the receipt as old/new
bit rows and their explicit dirty-role difference. Its SOURCE projection is
unchanged, but an implementation using the old complete COPY operator would
require an additional argument and cannot be accepted by this comparison.
