# Verification scope and code constraints

The new geometric result is a written universal proof. The finite programs
check its examples, the zero-space calculation and implementation failures.
They do not turn a dimension cap into a universal theorem. Both implementations
are separately written here; independent human review is unclaimed.

The registered commands use CPython 3.12, isolated mode, optimized mode,
warnings as errors and no bytecode writes. Mathematical contracts use explicit
ValueError checks, so optimization does not disable them. The two inherited
classification commands regenerate the complete incidence coverage and field
certificates on pinned canonical bytes. Their historical notices remain intact.

## Inspection against the ten code constraints

1. The new code has no recursion or call cycles. Structured exceptions propagate
   failure. TemporaryDirectory owns the control export and cleans it on exit.
2. Fixture counts are at most 12, group counts at most 3, group sizes at most 6,
   ambient labels eight bits, target ports at most 9. Each scientific assignment
   loop has at most 3^9=19683 iterations; each reader lookup has at most 2^9=512
   entries. Rank width is at most 32; the actual raw source has at most 18 ports.
   Common-space enumeration has at most 2^6=64 vectors. Seven fault subprocesses
   have individual 60-second timeouts. The registered wrapper bounds each
   complete command at 120 seconds. These are executable capacities, not theorem
   restrictions.
3. CPython and its containers allocate during execution. This is a managed
   runtime deviation from allocation-free steady operation. The finite bounds
   above cap live state; there is no worker queue or persistent service. Each lookup bundle has at
   most 2048 integer ranks. Constructing the next
   bundle can briefly retain two bundles. Source files are at
   most 1 MiB and the control inventory at most 48 files. Runtime allocator
   internals are not instrumented. A future larger-domain implementation must
   choose new explicit capacities before accepting larger inputs.
4. Every new function fits the roughly 60-line ceiling after formatting.
   The exact AST length inspection is retained with session verification.
5. Contracts check Gram-I, common span, target disjointness, rank ranges,
   annihilator cardinality, direct-sum rank/cardinality, exact complete bills,
   operator entries, receipts, source bytes and copy ownership. Controls exercise
   malformed geometry, wrong supports, false receipts and source drift.
6. State is local to one fixture or one external temporary copy. New source
   writes occur only in the control copy. Canonical inputs remain unchanged.
7. Fault subprocess return codes are explicitly checked; both success and
   failure outputs are inspected. Byte-copy write length, ownership, regular
   file type, link count, distinct device/inode identity and bytes are checked.
   File writes in fault setup either complete or raise; no partial receipt is
   accepted. The control script calls a fixed interpreter and an owned copied
   script with no shell.
8. There is no generated or evaluated code. Fault controls replace a bounded
   literal in an owned copied verifier and run that inspectable program.
9. Call targets are explicit. Collection traversal is bounded. No plugin
   dispatch, callbacks, pointer operations or ambient mutable registry is used.
10. The new Python files pass Ruff 0.17.1 E,F,I,B,UP,C4,PIE,RUF,PERF,PLW and
    PLR0911/0912/0913/0915 checks, Ruff formatting and Python warnings-as-errors.
    An exploratory Ruff ALL run also reported annotation/docstring/package and
    copyright-style rules, numeric-constant style, trailing commas, CLI print
    calls, boolean-position style and the fixed subprocess security warning.
    The applicable correctness findings were fixed. The project uses standalone
    untyped research scripts; those additional style policies were not adopted.
    No code-level diagnostic suppression was added. Future repository-wide
    typing or packaging policy should migrate these scripts consistently.

Source closure includes the actual inherited proofs and all runtime files of
the registered classifier. The exact pending PR3538 proof bytes are local;
its foreign origin is an origin receipt, not a required Git-history pin. All
canonical SOURCES.files pins are ancestors of the new publication. Required
metadata, committed-byte/history and Git-free replay are separate gates.

The selected full cold replay, Lean, Docker, hosted CI, native supplier
admission and a multiplication theorem audit are outside this contribution.
No timing or performance claim is made. The exploratory random search and its
corrected packed-rank bug are excluded from scientific acceptance.
