# Retuned ordinary backend in the retained T74 layer

**Conditional layer transfer, not a new integer-multiplication exponent.**
The ordinary theorem in Jose Manuel's [PR3562](https://github.com/CrocSwap/integer-mult-bounds/pull/3562)
uses `c=1/577`, hence `tau=332353/332929`. That is below the complete
T74 moment threshold. The `sigma<tau` summation in the earlier physical
layer cannot simply receive this new value.

This package supplies the missing `tau<sigma` stopped-tree argument and an
opt-in production constructor using the same authenticated physical cohort.
It retains the entire positive child histogram, exponent-1000 stopping,
`d=floor(p^.997)`, root reservations, numerical banks and original stock
contract. With `sigma=.998271`, the conditional layer exponent is
`alpha=.998273`, improving the earlier layer saving from `.001695` to
`.001727`. Shared defaults and selected-frontier files are unchanged.

[PROOF.md](PROOF.md) states the all-size implication and retained hypotheses.
The new exponent is for the normalized complex layer on its stated domain;
it does not automatically transfer to the smaller dimension plan or complete
outer integer-multiplication invoice.

## Evidence and scope

- Both retained exact interval engines enclose the **full** moment in
  `[999999903535664027556833879161,
  999999903535664027556833879162]/10^30 < 1`.
  At the ordinary exponent the moment exceeds one. One extra rank-one
  child also breaks the chosen moment; no additional child is free.
- The stopped-leaf exponent is `.998272729`, with exact final margin
  `271/10^9`. Internal and reservation logarithms have positive power margins.
  A separately enumerated rational toy tree checks the reversed-inequality
  failure, strict stopping at equality and the paid leaf invoice. It is a
  generic proof control, not a T74 payload test.
- `factory.py` binds the retuned profile to the retained ordinary constructor
  and T74 root. Constructor-contract checks and explicitly reduced execution
  are distinguished from an actual production GL64/T74 execution. The reduced
  roots check the installed native object and root returns; the receipt reports
  ordinary-call counts separately, so installation is not confused with
  execution of the selected ordinary branch. The observed ordinary `run`
  counts are `[0,0]`; these small root fixtures do not exercise that branch.
- The pending PR3562 theorem and interface are retained **verbatim**, with
  original attribution, commit, Git blobs and SHA256 in
  [inputs/ORIGIN.json](inputs/ORIGIN.json). No PR3562 runtime namespace is mixed
  into the T74 cohort. `backend_identity.py` rechecks every one of the 35
  files in PR3562's exact backend manifest against the retained nested T74
  archive closure. The unchanged live T74 binding receives a private module
  name because the native catalogue also has a distinct `binding` module.
  Its all-size ordinary proof is an inherited conditional
  premise; this package does not independently reprove it.

## Reproduce

From a full checkout with Python 3.12:

```sh
python3.12 -B scripts/research_package.py --package research/t74-retuned-ordinary-layer --check-only
python3.12 -B scripts/research_package.py --package research/t74-retuned-ordinary-layer
```

The registered commands deliberately use optimized Python with warnings as
errors. All checks use explicit failures rather than disabled assertions.
A Git-free committed package export can run the two `verify.py --suite`
commands directly; no separately fetched PR head is needed. The package runner
provides a fresh bytecode namespace; use a fresh `-X pycache_prefix=...` for
direct replay if preexisting bytecode might exist.
