# Actual caller cost and numerical ledger

This is a local implementation ledger for the selected first F0/B1 connection.
It does not infer runtime improvement from two upper bounds. Numerical and
arithmetic quantities below are distinct from tape actions and physical tapes.
Source authentication and the actual producer/continuation trace are performed
by the integrated verifier before these independent counting functions run.

## One external boundary

Compare the original source interval from the selected producer entry through
its next required two-leg bridge with the installed route at exactly those
same immutable caller ports. This local boundary does not hide implementation
changes after the bridge: the installed root uses an external child adapter at
**every** root child, including retained source instructions later in the root.
The complete root extension of the bill is recorded below. Retained scalar,
owner-exit and bridge instructions may be paired only after their actual state,
head, descriptor and operation traces are proved to agree. Equal mathematical
outputs or equal child ranks do not justify physical cost cancellation.

In particular, the original and installed child protocols differ; the original
parks the parent while the installed implementation retains it beside a separate
engine. Their costs and C execution contexts remain separate. The proved finite
internal-role permutation justifies the later publication comparison between
the **fixed-copy and adopted versions of this same installed protocol**. It does
not establish original-versus-installed child trace equivalence.

The proposed route replaces the named sixteen rank-eight centre children in
the producer by its thirty-two rank-one children, applies the frozen 4106
recovery, reconstructs current data using the actual G unit shears, returns all 112 Y
ports through their required negative line, and performs 224 fixed-port
copybacks before the actual continuation. The central source trace must bind
those sixteen centre occurrences and thirty-two replacements. A scalar query
that is no longer live is not an available input to this bill.

count: each pass has complete input/output, descriptor and cleanup charges.
An implementation which uses a different exact transducer must price that
transducer. Borrowed copying, logical COPY and transfer-to-fixed-port have

Let v=P*U*row_bits be one owner packet, V=Gamma*v be one complete family field,
and B=14336V the original parent bank. The assembled decoder bank is S=448V.
Every emitted producer group scans B; every emitted decoder group scans S.
Nonleader map visits still execute finite cycle-control work:528Gamma producer
visits and352Gamma decoder visits. Include that fixed source-control invoice
even when a nonleader emits no payload group.
The service's P-dependent assembly reads224 borrowed family fields and writes
their224 copies plus224 new zero fields. It retains that S-bit source while
its Machine creates its own current and replacement banks and protected return.
Extraction checks every borrowed return bit, copies224 owned return fields and
erases both the assembly bank and protected result. Its encoded rows are
448GammaU; constructing that Count and all setup/retirement work is paid.

For the assembly/extraction loops themselves, a conservative additional bound
is

    4096*(S + 448P*(bE+1) + bP + D_service + 1),

where bE=bitlength(Gamma U row_bits), bP=bitlength(P), and D_service is the
initial service/owned-output backing discarded by those loops. This counts
all per-prefix segment counters, source/output rewinds, input comparison,
zero initialization, copies and final bank/result erasure. Use the same
amortized Count countdown bound as LIFECYCLE.md:64*(n+b+1) actions for a
canonical b-bit counter decremented n times, including setup and closure.
There are448P segment counters in assembly and448P in extraction, with total
counter decrements2S and a fixed number of scans/moves/writes per bit; factor4096
dominates these explicit terms. Construction of the field-prefix Count,
outer encoded setup and the service Machine's own execution are outside this
bound and remain separately charged. This is an upper bound on the implemented
loops, not an asymptotic assumption that input-sized metadata is free.

After extraction, the lifecycle mechanism pays224 fixed-destination transfers.
For equal V-bit old/new fields the retained literal transfer costs16V+17 cell
actions, followed by full-parent-bank scatter/commit/release. Its constructive
storage bound and P-dependent counter costs are given in LIFECYCLE.md; those
bounds do not include the additional assembly/extraction bound above or the
service-Machine execution. The private zero-generation and lease
checks remain charged, including initially longer dirty backing.

The integrated driver selects **whole-bank adoption** after that common
scatter. Public input and output ports remain fixed. Only the internal current
role exchanges with the completed replacement, and the roles, parked-role and
Parking bindings are all updated as proved and checked in LIFECYCLE.md. This
is a new adaptation of #3380's ownership idea to the actual source machinery;
its different22V+13 result is not imported.

The adoption bill includes the full binary scan, origin checks and paid old

scatter work is identical. Release and the later source continuation have
matching cell-action traces under the proved finite internal-role permutation;
all relevant bindings are updated and public ports remain fixed. Consequently
this is a constructive difference of two matched executions:

    T_install_adopt = T_install_fixed - (11B+4) + c_R,

where c_R is the additional fixed finite-role selector/control cost if the
machine model prices it separately. In the tape-action model the saving is
exactly11B+4; with additional control it improves that local bill precisely
when c_R<11B+4. This is not subtraction of unrelated upper bounds. Charge it
once at the reached global installation fence; B already includes Gamma, so
multiplying the saving by Gamma again is incorrect. Across multiple reached
installations sum their distinct B_u terms and their control charges.

The adopted publication reduces an expense of this new installed connection.
It removes no additional original QQ16 arithmetic or native interval and does
not alter the isolated native-component screen or selected kappa. The fixed-copy
publication remains an executable matched alternative. Physical tape inventory
and the conservative high-water bound are unchanged; internal backing changes
owner, and erasure does not imply allocation reclamation.

Three distinct Machine inventories can be simultaneously required: the modified
producer parent, the decoder service, and the original recursive C child
engine shared sequentially by the two callers under a proved closed protocol.
The parent remains suspended while the service runs; the child engine is never
re-entered. Their Ordinary backends are distinct. A conservative total bound
is3I+2^20 fixed physical roles, where I=2q^2+100696823 is the inherited original
Machine bound and the remaining compiler/acquisition/service roles must be
listed below that reserve. Relative to an already paid original parent, the
increment is at most2I+2^20. This is a sufficient inventory, not a minimal count.
The decoder's extra eight private slots are outweighed by its256 fewer packet
slots; numerical engine inventories retain their inherited upper bounds.
High-water backing is additional to tape count: in particular, assembly and
protected return each have448V bits, and parent/native suspended state remains
live. Erasure is not release of the emulator's historical allocation.

## Complete child protocols and the extended root bill

`ProducerMachine.enter_child` overrides every root child instruction. It also
serves every decoder-service child. The original source executes its recursive
children in the same Machine with parent parking; the installed caller invokes
a distinct original `Machine.run`. The original implementation continues to
handle that separate engine's recursive descendants, so this installation does
not recursively apply the modified producer at every node.

The authenticated `ProducerBinding.root_child_census()` enumerates all482 source
events, every compiled local child and all idle remainders, and checks the actual
dispatcher at every idle rank. `root_protocol_invoice` independently binds its
histograms and boundary partitions. Counts below multiply Gamma:

| Root interval | Original child calls | Installed root child calls | Additional service calls |
| --- | ---: | ---: | ---: |
| Entry through original source bridge6 | 17,565 | 17,581 | 336 |
| Later source events7 through481 | 493,097 | 493,097 | 0 |
| Complete root | 510,662 | 510,678 | 336 |

The original whole-root rank histogram is
`{1:349604,2:60192,3:62585,4:20448,5:11808,7:7,8:1152,48:4866}`.
The installed root adds32 rank-one occurrences and removes16 rank-eight
occurrences; all other multiplicities agree. Thus **511,014 Gamma external
original-Machine runs** occur across root and service, including
**510,646 Gamma retained root occurrences with changed protocols**. Of those,
17,549 Gamma are before the local exit and493,097 Gamma are after it. The
unchanged later rank histogram is
`{1:337544,2:58102,3:60330,4:19738,5:11398,7:7,8:1112,48:4866}`.
These are invocation frequencies, not an equality of payloads or physical bills.

For each original root occurrence j, define the following disjoint operation
sums at its actual geometry, descriptor lengths, dirty backing and live state:

- P_b(j): original `prepare_child` arithmetic, payload and fourteen descriptor
  copies into the capsule, encoded header construction and temporary closure.
- E_b(j): entry boundary/origin checks, `Parking.park` of every live parked role,
  capsule-to-active transfers and child control setup.
- C_emb(j): actual original child node/body and descendants in the embedded,
  nonroot execution context, stopping before its final parent return.
- R_b(j): child-current to protected-output transfer, child-active-role cleanup,
  `Parking.restore`, header read/clear, parent group reconstruction, output to
  parent target transfer and bank/head/control reconnection.

For an installed root or service occurrence k, define:

- P_i(k): its actual `prepare_child` work and capsule/header construction. Even
  shared source code can have different encoded event-index lengths; no equality
  of P_b and P_i is silently assumed.
- A_i(k): boundary, header and child-instruction checks and finite descriptor
  views at external entry.
- Run_C_ext(k): the **complete** separate original `Machine.run`: borrowed
  payload/descriptor copying, node setup, actual C body and descendants, root
  protected return and engine closure. Its own recursive parking, native and
  ordinary work is included once here.
- Z_i(k): protected output to parent target transfer, marker erasure, capsule and
  header cleanup, and parent PC update.

Write F_b=P_b+E_b+C_emb+R_b and F_i=P_i+A_i+Run_C_ext+Z_i. C_emb and Run_C_ext
are intentionally different terms. The latter includes input copying and a
root-return path absent from the former; their C bodies execute with different
parent/stack/root contexts. A source-relative context/trace argument could
justify cancelling a precisely delimited subtrace, but matching ranks and
semantic endpoints do not supply that argument. Do not charge the complete
Run_C_ext and then add its input copying, native parking or root cleanup again.

Let N_b and N_i be the actual root costs excluding child preparations, entries,
bodies and returns: root input/descriptors/setup, all nonchild arithmetic,
monomials, exchanges, bank gather/scatter/commit, owner/event control and final
root output/cleanup. N_i includes the additional fence predicate at **every**
root `finish_group`, not just at the installation. Let T_s include the entire
service and fence: encoded preparation and assembly, the service Machine's
nonchild setup/input/output and bank operations, its336 Gamma F_i terms,
extraction, fixed copybacks, adopted publication and disposal. The earlier
assembly bound is only one component of T_s.

At either the local prefix boundary or the complete root boundary, a measured
compatible comparison is exactly

    T_b = N_b + sum(original root occurrences j) F_b(j)
    T_i = N_i + sum(installed root occurrences k) F_i(k) + T_s.

The full-root version includes the493,097 Gamma later externalized calls and
all later control costs. The local prefix is not a claim that later adapter
expenses vanish. Fixed root ports and completed state refinement allow the
external boundary to be matched; they alone establish no inequality of T_i
and T_b. Every term is an operation sum of the actual implementation, not a
subtracted unrelated upper bound.

Pair the retained source occurrences using their literal source positions,
not merely their ranks. Define their possibly signed protocol/context credit

    C_ret = sum(retained j) [F_b(j) - F_i(j)].

For the complete root, an improvement is equivalent to

    C_ret > (N_i-N_b) + T_s
              + sum(32 Gamma new producer lines) F_i
              - sum(16 Gamma removed centres) F_b.

This identity retains all C-body/context differences and every new expense.
C_ret has prefix and later parts; both remain unevaluated. If only upper
bounds are available, the expression is an admission target, not a proved
saving. The original parent parking serializes its live bank and additional
roles; avoiding it can provide real credit. It must not be set to zero or
assumed smaller than the added native component. The next discriminating
experiment is paired metering/proof of the original embedded and external
protocols with actual bank geometry and dirty backing, including descendant
context and cleanup, followed by comparison against the new full-bank scans.
This may change affordability even while the native-component screen fails.

## Isolated native-component charge screen

For the stated mechanism the newly introduced rank-one occurrences are
32+224+112=368, versus sixteen rank-eight occurrences removed. With identical
packet volumes and the same homogeneous child charge at exponent
0<=alpha<=1, the ratio of introduced to removed charge is

    368 / (16 * 8^(1-alpha)) = 23 / 8^(1-alpha) >= 23/8.

The normalized difference is
`(368-16*8^(1-alpha))*73^(alpha-1)>0`. Its width-linear endpoint already adds
240 lambda units; its alpha=1 ratio is 23. This rejects an improvement of
that *specified native-charge budget* before considering the additional
positive scalar/map/copy work. It is not a runtime lower bound, a lower bound
on all current-value reconstructions or a contradiction of a sharper physical
implementation. The hypotheses include equal actual packet volume and the
same tariff. A coordinated route that removes different source work, fuses
native operations with a proved endpoint, or changes a consumer can escape
this screen and needs a new comparison.

A stronger restricted decision screen does not depend on this particular
current reconstruction. Any route retaining the full D224 and the same
producer32, while adding only nonnegative further native charge and removing
only those sixteen H8, already introduces256 C1. Even a hypothetical free
native reconnection leaves at least128 C1 of width-linear charge deficit.
Consequently optimizing only the post-D repair cannot improve this isolated
native-component tariff. This does **not** reject affordability of the complete
installed connection or of every full-D mechanism: C_ret above can supply
compensating physical credit from avoided parent parking. Changing recovery,
proving native cancellation or removing more source work can improve the native
component, while a different caller protocol can improve the total bill.
No ordering between those unlike costs has been proved here.

The local 800-allowance improvement from 4015 to 4106 survives its matched
word comparison but cannot pay this native-charge deficit by a change of
units. This route is an enabling installation candidate whose total affordability
remains unresolved by the unevaluated protocol/context and scan balance; it is
not an established affordable supplier or a new selected recursion. The precise recursive
frequency must be given before charging any whole-tree budget; one installed
first F0 cut proves no all-node substitution theorem.

## Row stock and actual physical volume

The actual controller uses `L=14336 Gamma` and gathers complete per-family,
per-cover packets. Let `U=R/L`. The physical Gaussian count of a gathered
packet is

    prefixes * U * 2^(front+3*compact_bits+before+73*lambda*K+after+back)
      * coefficients.

Twice this number times actual component width H_b is its payload bit volume.
Changing the child active width to lambda and appending 72 lambda K to
`after` preserves that entire volume; spectators are never collapsed.
The parent must already satisfy its actual row-stock predicate. The root
planner's paid padding and final zero-row removal are inherited, not newly
supplied by the decoder. The encoded compiler's validation of U and the
D0 child divisor makes that dependency explicit. It does not authorize using
logical `2^(73 lambda)` as the physical packet size.

## A source-grid admission certificate

Keep the four widths distinct: logical coarse W_c, native reserve a,
physical coefficient width H_b and address guard H_g. The inherited physical
root has

    Delta = 2^210000 d, q_s = 2^(-p-Delta), H_b = p+2Delta+3,
    G = 4 ceil(log2 p)+6, H_g = dG.

The actual component Count, spacing, Compact guards, root p and root d are
unchanged. `compact_bits` is an address descriptor and is not H_b.

A safe sufficient local argument starts at an unchanged source entry whose
inherited height is at most h0=2Bd, where
`B=1041408 Gamma+2^100000`. It bounds every component by `2^h0` and places
it on grid `2^(-p-h0)`. Such an entry hypothesis includes arbitrary correlated
and dirty live families; it does not assume their numerical values vanish.
It has to be justified at the actual chosen entry by the inherited source
execution. A completed-output norm bound cannot replace it.

Charge the *changed* producer in full after that entry. Let g_P and d_P be
its conservative modulus-growth and denominator-debt exponents, derived from
its complete physical instruction word. `literal_height` charges every dyadic
scalar occurrence, including the Horner scratch numerator before division,
and every completed native rank r by r lambda. Unit-phase monomials preserve
modulus and grid. One unfinished rank-r child has a separate native interior
reserve at most `2Br lambda`; it is not charged r lambda until completion.
This deliberately generous bound avoids borrowing the unchanged original
producer's height theorem for a changed circuit.

For t=lambda-1, 4109 bounds the complete decoder's interpreted scalar values
by an additional `19+3t` growth bits and `9+3t` denominator bits. Its largest
unfinished native callback requires reserve a<=2B lambda plus the Gaussian
modulus headroom bit; subsequent exact returns reuse that reserve.

The actual source continuation is G(x,y)=(-y,x+y), conditional on the
source lift, owner-routing and endpoint-frame proof supplied by the semantic
module. On recovered owned banks Z=x,W=y, execute W+=Z and then Z-=W.
The first operation has magnitude at most2M, and the second's conservative
prefix bound is3M<4M; its endpoint is exactly -y. The bound is valid for
arbitrary correlated nonconstant payloads. No extra denominator bit or
private query is introduced. A centre-free J map is not substituted for the
actual G endpoint.

After the final signed C lambda tensor and the two actual bridge legs with
coefficient c, completed bounds are

    growth <= h0+g_P+19+3t+2+lambda+ceil(log2(1+|c|)),
    debt   <= h0+d_P+9+3t+lambda.

Use the maximum of these and the unfinished-producer/decoder/final-native
bounds in `fixed_grid_admission`. Requiring growth and debt at most Delta
makes all interpreted coefficients exact integers on q_s and fits H_b:
their encoded magnitude is at most `2^(p+Delta+growth)`, strictly below the
signed H_b limit `2^(p+2Delta+2)`. Thus a correctly implemented full-width
route can keep the source's actual grid and width throughout. This is a
conditional admission calculation; payload execution and the absence of
premature arithmetic rounding must still be checked in the actual lowering.

For the complete producer interval, the verifier sums the actual scalar
literal height and native rank mass across both changed cores, all outer macro
bodies and the three retained intervening source groups. Each owner-family
traversal is bijective, so a maximum-norm bound charges each group body once
per scalar field, rather than multiplying numerical growth by Gamma. Map-cycle
operations are exact signed permutations and do not grow coefficients. This
whole-interval source argument is necessary: the65536-PC bound of one group
alone does not bound all the producer barriers.

The authenticated46-body compilation gives the explicit conservative values

    g_P = 230124 + 27834 lambda,
    d_P =  84422 + 27834 lambda,

with maximum local child rank8. These sums include the three unchanged
intervening source cores; they are not estimates from scalar-event counts.
The rank48 bound below is retained as a sufficient upper domain. Source event5
(the pair-1 idle preparation) remains unchanged after service return and before
the bridge. Its untouched families retain the original source height bound;
that reuse of the numerical bound relies on helper/end-state preservation
proved by the composed source connection. It does not cancel event5's changed
physical child entry/return protocol.

`uniform_interval_domain` validates each constituent source word and checks
that the measured aggregate constant and lambda slope are both below2^22.
Therefore g_P,d_P<2^22(lambda+1). With d>=73lambda and |c|<=1, every completed
and unfinished bound above is strictly below

    (4B+2^24)d < 2^210000 d = Delta.

The first inequality uses the producer interior bound
`2Bd+96B lambda+1`, plus the generous literal word allowance; the other
stages are smaller. The last integer inequality is checked exactly. The
written inequalities establish the all-lambda claim; evaluating a few lambda
values is only a control. In particular this is a one-cut sufficient bound,
not a proof that inserting this work at every recursive node preserves the
original all-depth height or time recurrence.

The primary implementation retains q_s and H_b throughout, using this new
admission proof and exact physical scalar/native execution. It does not require
a coarse down-projection between children. #4129 supplies the inherited exact
C interior/refinement and return reasoning; its coarse-format bridge remains
a separately available protocol. If that protocol is used instead, it must
pay those conversions and verify low-zero/sign-extension conditions. Taking
W_c=H_b in that contract is invalid because it violates
`H_b>=W_c+2a+1`. No integer calculation in this ledger is an encoded compiler.
The chosen physical implementation and its numeric certificate must agree.

#4114 gives a useful regression against a smaller unjustified premise: its
L359 dirty ray reaches 128T in data and68T in a helper before exact return.
The completed-output norm58 is therefore not an interior range certificate.
That scalar projection alone is not an arbitrary-payload operator norm.

## Reuse decisions in this ledger

- **#3055: reuse unchanged.** The actual 4129 controller already inherits
  physical Compact and its ordinary/native premises. Its root proof derives
  K>3G and the repair inequality, and retains long-record setup conditions.
  This installation claims no new Compact implementation or saving.
- **#3619: adapt only with a new endpoint/layout proof and cost.** The physical
  support router permutes address coordinates in complete opaque-record
  rectangles. That can implement appropriate coordinate permutations, but it
  is not a generic Gaussian-frame transform. Its faster tariff additionally
  requires cp<=n<=C0p, support k<=2p^(997/1000) and log2(R+1)<=A0p. Outside
  that domain retain its literal/unabsorbed invoice. No such tariff is
  credited automatically to the 352 maps above.
- **#4114: regression evidence only.** Retain its dirty-ray warning and exact
  witness scope; do not turn it into a new uniform height theorem.
