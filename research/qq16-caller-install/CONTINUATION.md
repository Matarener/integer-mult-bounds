## Explicit new word

The decoder returns owned Z_p=F17 x_p and W_p=F17 y_p. For each port execute

    W_p += Z_p;
    Z_p -= W_p;
    W_p <- C_(d q_p)^-1 W_p.

The second ADD reads the updated W. The first two operations share exactly
one frame, so their required native transport is identity. They give
Z=-F17 y and W=F17(x+y). The final negative line produces the required
selected Y frame and value. F17 and the line commute because both are
convolutions. Each negative line uses #4129's actual recipe with translation
q fused in the left wrapper; replacing it by the positive line is invalid.

The word is emitted for all 112 ports: 224 signed unit ADDs, 112 negative
rank-one native children and 224 native wrappers. There are no additional
quarter operations, owner maps, or private fields in this reconstruction.
Its input and output fields are the already-owned decoder outputs. The
backend and wrapper engine inventories remain separately closed and paid.
The scalar operations and native lines operate on complete current packets;
a host-language numeric oracle does not implement them.

A discarded preliminary route used four J/J^-1 applications and then a
one-accumulator J shear. Besides extra work, it targeted the centre-free
endpoint rather than the selected pair. The current word uses neither
that endpoint substitution nor the odd division in J^-1.

QQ16 mechanisms. A complete installed version can still be a substantial
enabling contract, but it cannot claim an improved supplier or exponent.
