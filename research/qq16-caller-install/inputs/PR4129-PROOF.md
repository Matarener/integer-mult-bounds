# A paid recursive native bridge for QQ16 recovery

## Claim and significance

This contribution gives an implemented, reusable bridge from the frozen PR4106
native interface to the **actual** retained physical complex `Machine`.
It replaces an unspecified native rounding/interior premise with an exact
source-relative contract on a prepared physical packet. It does not install
QQ16 in the selected global schedule or establish an affordable whole supplier.

The result meets outcome B of the assignment: an implementation contract for a
previously unsupported stage, with executable paid conversion and return. A
coordinate Gaussian loop, a width estimate alone, or the descriptor arithmetic
alone would not supply this implication. The production backend's mathematical
refinement and native/ordinary/hosting assumptions remain inherited, rather
than newly accepted or formally proved here. Its production O73/GL64 payload
is not executed by this package.

We use separate names for quantities that the source overloads. `H_g=dG` is the
source's address guard field. `H_b=p+2C0 d+3` is its stored real-component width,
where `C0=2^210000`. The dyadic value `h` below is a quantum, not either width.
`T_lambda` denotes the exact positive C tensor backend. `D_4106` denotes the
recovery word; it is not an inverse of a private-clearing transition and is
not identified with the selected physical provider G or the QQ16 provider Q.

## 3. Actual recursive interior height and promotion

The retained whole-array height theorem permits arbitrary correlations and
incoming heights. Put s=1041408Gamma, E=2^100000 and B=s+E. It proves

```
A(e)<=8e at a direct leaf,
A(e)<=A(48 floor(e/73))+s floor(e/73)+E internally,

```

Height bounds the whole Gaussian supremum and denominator debt, not a single
path without its sums. The numerical instructions are homogeneous dyadic
linear operations or CLEAR-to-zero. No nonzero numerical constant is injected.
The ideal endpoint is proved before the finite-grid simulation. Therefore the
height induction can be rescaled to any dyadic input quantum without changing
the physical global parameters or finite control. Temporary bit-interchange
strings are interpreted as coefficients only after their exact primitive return.

PR4109 supplies q_c=h2^(-9-3t), W_c=P+28+6t at every interpreted caller cut,
including completed signed native events, for the unchanged word. It covers
components, while the backend height uses complex modulus. Choose

```
a=8lambda at an admitted direct leaf, otherwise a=2Blambda;
q_w=q_c2^-a;
W_req=W_c+2a+1.
```

A coarse complex value has modulus<2^W_c q_c. The recursive height excursion
has modulus<2^(W_c+a)q_c, and denominators refine by at most a bits. In q_w
integer units its components are therefore integral and strictly below
2^(W_c+2a)=2^(W_req-1). The additional signed bit is essential to this inference.
The primitive's finite carry is covered by its own physical transducer contract;
it is not falsely counted as a stored Gaussian numerator.

Keep the actual admitted backend width H_b unchanged and require
`H_b>=W_req`. Promote each little-endian signed coarse integer by writing a

## 5. Implement and pay the encoding protocol

`bridge.py` executes the lift and projection with the actual source Tape API:
reads, writes and unit moves only. Payload bits never enter an unbounded host
integer. The immutable pattern uses three finite symbols disjoint from the
source bit/marker alphabet. Unary width/reserve/high descriptors are paid
inputs; `unary_from_count` constructs them with the actual encoded Count
countdown and its amortized ripple protocol. Descriptor arithmetic computing
a and the surplus remains a separately charged encoded setup step.

The pattern has a LOW cells, W_c COPY cells and b=H_b-W_c-a HIGH cells. Its
setup checks b>=a+1 without decoding a variable length. A scan emits/validates
one component, rewinds the pattern and repeats; a finite parity flag requires
complete real/imaginary pairs. Only the last sign bit is retained in finite
control. Setup failure erases a partial pattern and returns borrowed descriptor
heads. Runtime failure erases partial output and returns source/pattern heads.
A protected output must be consumed before reuse. Closing erases the pattern.

For m real/imaginary components, each pattern traversal is H_b unit positions.
Promotion traverses mW_c source cells; projection traverses mH_b source cells.
Outputs, complete rewinds, protected-return erasures and pattern retirement are
linear in these extents. A conservative finite-state bound for the conversion
body, including setup/close, is

```
64 [m H_b+H_b+W_c+a+b+1] literal cell actions.
```

This bound grants unused slack for complete return copies/erasures. The actual
Count-to-unary setup and its input/counter/output tape meters are recorded
separately; binary countdown amortization gives O(H_b+log H_b). Charge the
encoded parameter arithmetic as T_descriptor. In particular the Python fixture
loader is not claimed to be the physical descriptor compiler. Combined with
the metered body, this is a constructive O(mH_b+H_b) conversion bound plus that
explicit setup. Extra wide packets/protected outputs are included in occupied
space and erasure charges, rather than treated as free pointer swaps.

The callback uses one complete source Machine inventory I=2q_*^2+100696823
and a separate external monomial/ordinary inventory, bounded above by another
complete I. The source constructor requires a fresh private ordinary engine;
sharing the active engine was rejected during integration. Reserve at most256
new metadata/stream tape roles per each of the224 fixed occurrences, plus32
fixed bridge/control roles. This exceeds the two83-field wrapper layouts,
encoded parameters, unary descriptors/countdowns, patterns, coarse/wide ports
and fixed setup temporaries in the specified protocol. Thus a conservative
owned inventory bound is `2I+2^20`, excluding the enclosing caller's inventory.
It is deliberately generous. No tape is allocated per component by the bridge;
backend recursive depth uses its inherited fixed inventory/physical stack.
Only one callback's wide occupied packet is live. The whole caller, retained
copies and protected outputs are also charged. Erased work does not promise
that a Python list releases historical capacity.
