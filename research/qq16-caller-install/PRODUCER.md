## Literal operator lowering

A `cover_sweep` or `private_sweep` becomes a single global event with a complete
cover loop. Each group selects actual data families 0–223 at the current owner.
Scalar instructions lower to the actual full scalar engine; only private C
roles can be cleared/copied. A private sweep retains its complete body inside
one gathered group. The next global event starts only after every owner has
completed and scattered. Consequently private fields never cross a cover
barrier. Native lines conjugate the actual rank-one child by the two retained
native recipes and by the owner's `g^-1`/`g` views. This implements the actual
owner-dependent line, not a constant-payload substitute.

For a map with matrix `A` and translation `delta`, the required action is

`out(d,z_1,...,z_lambda) = in(d A,z_1 xor d delta,...,z_lambda xor d delta)`.

Right multiplication by `A` partitions the finite orthogonal group into cycles
of equal length `k=ord(A)`. The binding visits every rank but emits a group only
at the least rank in its cycle. At that leader it selects all k actual owner
packets in cyclic order. Adjacent plain swaps rotate their contents to the left.
A representation conversion is essential: the certificate stores **columns**
of A, whereas `OrthogonalCover.unrank` returns **rows** of d. The implementation
transposes the stored A once, uses row-matrix multiplication for d A, and uses
row-dot-vector action for d delta. Treating source owner rows as columns would
reverse the product/order and apply an incorrect translation at nonsymmetric
owners.
A source exchange implements `(x,y) -> (y,-x)`; a subsequent `scale(-1)` on its
second output converts it to a plain swap. Then, for output owner `d`, an actual
identity-matrix monomial translates every active column by `d delta`. Scattering
the gathered packets restores each result to its immutable physical owner.
Outer prefixes, unused rows, coefficients and spectator fields follow the
existing BankPackets/MonomialPackets contracts and are not removed.

The 528 literal maps have orders `{2:464,5:24,6:12,12:20,17:4,20:4}`. Thus at
most 20 packet slots suffice, within the admitted 704. All translation vectors
are nonzero. Every group code is below the source 65536-PC limit. These are
fixed supplier control alphabets; no numerical payload or variable Count is
decoded to obtain the cycle. Production execution would still pay every bank
scan; the finite group algorithm is not an efficiency claim.

This resolves a specific dispatcher issue: a payload monomial inside one
704-owner gather cannot change cover owner. The new cycle dispatch changes the
actual selected bank keys and retains the full-cover barrier order.

## Original child endpoint and suspended parent

Running the changed binding recursively without further proof would silently
change every child supplier. `machine_class` therefore supplies a narrow
`ProducerMachine` adaptation. At `prepare_child` it uses the source-created
capsule and source header, verifies the exact target/rank/program counter, then
calls a distinct closed **original-binding Machine**. It consumes that result
into the designated parent packet, erases the capsule and header, and resumes
at the source's next PC. The parent is not re-entered; its group, other packets
and private fields remain protected while the separate engine executes.
All original child recursion, parking and restoration remain within that
original engine. The complete bill includes both engine inventories and
simultaneously occupied parent/capsule/child backing.

The optional `at_fence` hook runs only once after the final B group has closed,
with the parent scratch scope suspended. Before and after the hook, all actual
parent primitive engines must be closed. Its callback must separately prove
recovery, owner reconnection, leases and eventual retirement. A hook's presence
is not evidence that those duties have been discharged.

## Executable evidence and limits

`producer-fixture.py` runs the actual Tape, Count, BankPackets, scalar,
MonomialPackets, Ordinary and Machine code on a two-dimensional complete cover,
with two outer prefixes, nonconstant owner-dependent signed complex values,
and an untouched second family. It separately exercises an original-child
return through the new controller. Independent expected arrays are test oracles,
not claimed input loaders. Omitted exchanges, omitted translation and omitted
sign correction each reject. A second actual fixture uses the full six-owner
O(3,2) cover and a nonsymmetric order-three map on 192 complex values. An
independent dense row-matrix oracle checks its owner product and address action;
transposed map-record and transposed owner-translation controls both reject.
An additional O(3,2) fixture applies both signed native lines through the
actual original rank-one child, conjugated by every owner, on 192 nonconstant
complex values across two prefixes. Its independent dense row-dot-vector
oracle computes the direction `d e0`; reversing the `g^-1`/`g` conjugation
rejects at the nonsymmetric owners. These calls exercise the actual native
leaf endpoint, not a recursive non-leaf production payload.
These executions preserve borrowed payloads and
encoded descriptors and close the parent/child engines.

The reduced fixture does not execute a selected O(73,2) payload, all 224
recovery outputs, or the entire integrated QQ16 continuation. Production
applicability requires the central packet/range/lifecycle admissions and the
source-relative all-depth primitive and clean-core contracts. A module-level
scalar oracle does not by itself check physical composition.

`integrated-fixture.py` additionally runs one continuous reduced physical
caller. Its producer applies opposite signed actual C lines to two fields,

and both signed bridge instructions before returning. An independent exact

prefixes, four families and two cover owners. A second generation uses different
nonconstant input on the same parent, original-child and service engines and
the same installation, checking reuse after publication and retirement.
The fixture also attaches the producer to an actual reduced `RootLayer`,
preserving its public roles and plan and rejecting an active root or a wrong
inherited child, as well as each changed dimension, rank, family-count or cover
geometry. It then exercises the installed kernel directly; it does not
claim execution of `RootLayer.run` or its full outer protocol.
Wrong producer sign, early fence
and output/acquired-field alias each reject. This is a reduced composition test
of the real implementation, with explicitly test-only initial arrays and
