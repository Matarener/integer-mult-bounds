PROOF.md is an author-written universal argument. RESULT.json records
finite correctness corroboration. Neither passing replay nor publication
claims independent human or formal proof-kernel acceptance. The selected
full cold replay, Lean, Docker, hosted completion, ten-call existence or
exclusion, physical caller and complete supplier are unrun.

The changed code is entirely inside this package. The registered CPython
3.12 commands use -Werror and optimized behavioral controls. The separate

reuse the multiplication table, group-algebra update or chronology code.
All 64 group products are compared. Generic fixtures use fixed seed 1904;
both label orientations and noncommutative orders are included. Direct

rank premise; no finite fixture count is the proof of the theorem.

## Power of Ten inspection and bounds

1. The scientific/control call graph has no recursion. Exceptions unwind
   context-managed files, temporary directories and checked subprocesses.
2. Internal role capacity is 8, paid-word capacity 24 and label capacity 2.
   Group bytes have 256 possibilities, and every product has 64 bit pairs.
   The basis lookup is bounded by 256 combinations of 8 masks. Rank rows
   have at most 24 bits and elimination at most 25 steps per row. Generic
   replay has 390 words, maximum 5 roles and 12 calls. Direct fixtures have
   at most 8 roles and 18 calls. Count controls cap t at 32 and each count
   at 3t. CLI count helpers validate t <= 1,000,000 and counts <= 3,000,000;
   this implementation bound does not limit the mathematical theorem.
   Control subprocesses have 30-second timeouts. Each registered command
   also has a 30-second timeout, including inherited process-group cleanup.
3. Managed-runtime allocation is the explicit deviation below. All code
   collection growth has a fixed domain and no research search queue.
4. Functions remain below 60 physical lines in normal formatting.
5. Executable require contracts enforce identities, source bytes, capacity,
   exact domains and output exclusivity with -O enabled. No scientific
   correctness decision depends on assert.
6. Scientific data are local immutable tuples or owned temporary matrices.
   Constants are fixed; mocks exist only inside scoped control contexts.
   No scientific command mutates frozen inputs or any shared Git state.
7. Boundary validation rejects bool-as-integer, bad labels/idempotents,
   capacity excess and invalid output reuse. Subprocess exit codes and
   fault diagnostics are checked. Buffered byte writes either finish or
   raise; their byte identity is checked by the export/control contracts.
8. No eval, source generation, decorators or runtime registration appears.
   Import path setup supports isolated Git-free execution of this one
   package. The authenticated sources bound all imported local modules.
9. Direct module calls have explicit fixed targets. unittest.mock.patch
   is confined to behavioral controls and restored by context managers.
10. Use CPython -Werror and scoped Ruff E/F/B/UP diagnostics. No diagnostic
    suppression is introduced. Strict diagnostics on unrelated historical
    sources and a repository-wide type migration are outside this package.

Rule 3, fixed capacity. Python 3.12 requires allocations during arithmetic,
imports, JSON, pathlib and subprocess setup. The deviation covers only
this bounded verifier/control process. Input capacities above bound live
scientific matrices to 8x8 bytes and chronological matrices to 24 rows of
24 bits, plus fixed small fixture collections. Managed integer/object and
library allocator internals are not measured. Compensating controls are
entry capacities, sequential replay, no child research process, explicit
subprocess timeouts and temporary-resource cleanup. The registered and
optimized commands exercise valid/max fixture and invalid capacities.
A native fixed-buffer rewrite is the follow-up if this verifier becomes
a long-lived or untrusted-input service.

Rules 8 and 9, imports and control dispatch. Isolated execution needs four
explicit sibling modules and unittest.mock's temporary target dispatch.
The scope is this package only. RESULT.json authenticates scientific
runtime source bytes, the source-corruption control rejects changes,
and actual arithmetic/action/chronology faults are rejected independently.
No production plugin registry or dynamic target selection is added.
A move into a stable repository Python package would remove sys.path
setup; a new runtime mechanism must add its own source closure and tests.

Rule 3, temporary control export. Each copied payload is checked as an
owned regular non-symlink source and written exclusively to a distinct
inode. Bytes and owner are checked. No metadata or mode is copied, and
no chmod is used. TemporaryDirectory owns and removes only that control
copy. Scientific source inputs and interpreters are read-only. Full
publication export receipts separately measure every payload before and
after execution and retain those measurements before deleting scratch.
