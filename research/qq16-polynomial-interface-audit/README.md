# Independent QQ16 numerical-interface certificate

**Independent verification of PR3303; no new kappa or supplier.** The literal
full-cover F0 then B_1_2 arithmetic reference admits PR3303's stated sufficient
component format at every integer tensor depth `lambda >= 1`:

```text
quantum      h * 2^(-71 - 19*(lambda-1))
signed width P + 215 + 38*(lambda-1)
```

All 704 persistent input fields have real/imaginary components in `h Z`, with
magnitude strictly below `2^P h`; `h` is a positive binary quantum and `P >= 0`
is integral. Eight owned private fields enter zero. Native, bridge, endpoint
and full-cover semantics remain inherited premises. This is a numerical
execution contract, including native interiors, rather than a literal
common-coordinate borrowed-helper restoration theorem.

## New evidence

PR3303's separate numeric interpreter shares its source loader and event
expander. This package reads authenticated raw packet/archive data itself,
expands the two programs independently, validates each used owner inverse and
nine-axis monomial, and executes a new polynomial/max-plus analysis. It imports
no predecessor executable. The existing PR3303 receipt is comparison data.

The new interpreter preserves rational polynomials in `z=2^(lambda-1)` rather
than a magnitude and one exponent. Grid bounds retain maxima of affine lines
in `lambda-1`. It covers all **53,118 events**, **270,288 primitive observations**,
**3,498 distinct nine-axis monomials** and **512 owner maps**, with the complete
712-field F0 state carried into B1. [PROOF.md](PROOF.md) supplies the all-depth
argument; [RESULT.json](RESULT.json) retains exact independent trace, source
address, state, inverse, polynomial and counter receipts. The numerical bounds
and counter totals agree.

PR3303's displayed second Gaussian output has an extra quarter-turn relative
to its pinned native C: the source gives `(s-i*d)/2`, while its proof text
writes `(d+i*s)/2`. The latter equals i times the former. This changes the
operator but preserves component-grid and magnitude bounds, so the numerical
theorem and invoice are unaffected. This package states the source formula
and checks sign-sensitive delta fixtures; it leaves the predecessor unchanged.

The derived numeric reference invoice is

```text
(372322 + 110760*lambda) * N + 12 W-bit word operations per owner,
2112*N conceptual cover-component transfers,
1426*N + 12 numeric storage words,       N = 2^(73*lambda).
```

The 12 densities in `numeric_units_per_N` are calibrated at lambda=1. The three
native arithmetic/copy densities scale with `N*lambda`; other numeric densities
scale with N. Cover-component transfers are separately priced. Remaining
counters count literal calls/labels. The invoice includes constant-product partials, shifts,
sign changes, scalar updates, Gaussian interiors and final reusable-scratch
clearing. It is not a physical or recursive tariff.

## Reproduce

From a checkout containing this package and its five declared inputs, using
standard-library CPython 3.12:

```sh
python3.12 -I -Werror -B scripts/research_package.py \
  --package research/qq16-polynomial-interface-audit
```

Expected: `PASS_QQ16_POLYNOMIAL_INTERFACE_AUDIT`, eleven passing behavioral groups,
and `PASS_REGISTERED_RESEARCH_PACKAGE`. Direct `verify.py` and `test_verify.py`
also work in a regular-file Git-free export. Replay is read-only;
`verify.py --write PATH` creates an absent receipt only.

both signs, small tensor layers, a cross-numerator overflow witness despite
fitting endpoints, negative dyadic products, grid dominance, actual carried

## Scope and complete-bill boundary

The selected kappa remains `0.001672660197076918`. No full payload of dimension
`2^(73*lambda)` is allocated or executed, no minimum-width claim is made, and
these upper-envelope extrema are not actual reachable-component lower bounds.
The inherited native functional identities are not reproved by checking
monomial and owner-map bijections. There is no human or proof-kernel review.

An admitted input grid/range, physical source access, ownership and routing,
address/sign/control work, code/storage initialization, exact borrowed-state
representation, recursive child tariffs and F17 consumption remain separate
obligations. Unknown costs are not zero. In particular a zero arithmetic
defect on the stated lattice does not supply an affordable caller or remove
its restoration bill. Family decision: complete this independent check and
stop; no downstream optimization campaign follows from this receipt alone.
