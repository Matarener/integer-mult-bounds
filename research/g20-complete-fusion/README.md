## Reproduce

Python 3.12 and the standard library suffice. This registered command
runs both normal and optimized replay:

```sh
python3.12 -B scripts/research_package.py --package research/g20-complete-fusion
```

For a Git-free package copy, run `python3.12 -I -B verify.py`. Every proof
record is rebuilt in a fresh temporary directory. Exact stream bytes and
decoded payloads must match; only CPU time and gzip container metadata
are ignored. Source and package files must stay unchanged. Expected output:

```text
PASS_COMPLETE_G20_FUSION_ORDINARY_003488579527
PASS_REGISTERED_RESEARCH_PACKAGE research/g20-complete-fusion outcome=completed
```

The separate adjoint, stream, interval, and block checks are a second
implementation by the same author and AI assistant. They are not
independent scientific acceptance. The retained native/all-width, ROW,
compiler, precision, tape, and analytic contracts remain assumptions.
The finite uniform program and decimal eventual threshold are not
materialized. Full historical suites and formal-kernel proofs are not
part of this replay.
