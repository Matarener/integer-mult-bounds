# Verification boundary and implementation decisions

The mathematical claim is the written uniform workspace reduction and its two
unit-price corollaries in PROOF.md. The executable evidence corroborates the
linear algebra and replays its finite exclusion dependencies. No sampled
identity replaces coefficientwise equality.

## Checks

The direct verifier uses exact F2 vectors and all eight formal coefficients.
It checks 5,333 fixed short words, the 487 diagonal monomial endpoints among
them, and five fixtures through twelve roles. Both reductions are forced on
every larger fixture. Every original scalar column satisfies the appropriate
image-inclusion or quotient intertwining equation. The first-order identity,
trace parity, reduced rank-one idempotence, endpoint and role bound are checked
with explicit exceptions, including under optimized Python.

Direct words are checked at widths 2,3,4,8,12 for every fitting ordered active
pair/triple. Every single-call omission must change the full endpoint.
RESULT.json records exact counts. Counts describe finite coverage and operation
bills; no runtime speedup or statistical performance claim is made.

The retained PR3471 native source compiles with C++20, optimization and
`-Wall -Wextra -Wconversion -Wsign-conversion -Wshadow -Wpedantic -Werror`.
Its original complete query rows and ball hashes must match the retained
receipt exactly. The independent Hamilton/full-convolution implementation
checks all 64 products, 8,502 native probe matrices, both complete four-role
depth-two balls and both pair meet queries. The complete triple membership
stream has one implementation after these checks. An independent second full
stream is unclaimed. The unchanged executable also runs its three other
original cases; these do not enlarge the new theorem's target families.

Four behavioral groups reject actual production quotient/dot-product faults,
a compiled native paid-action mutation, changed noncommuting order, omitted
restoration, an altered dirty spectator, invalid vector/label/type/role/call
inputs, source drift and receipt overwrite. A preliminary test expected the
idempotence failure after a dot-product mutation; the actual implementation
rejected earlier at quotient-basis construction. The diagnostic is retained
in the session evidence and the final control checks that earlier failure.
No scientific acceptance condition changed.

Reproduction commands are in README.md and VERIFY.json. The package is opt-in
and changes no shared tooling. SOURCE/retention validation, the registered
Python 3.12 replay, optimized controls, Ruff E/F/B/UP/SIM and formatting,
exact committed bytes/source history, transport integrity and actual Git-free
committed-source replay are the publication gates. Their precise outcomes and
commands are recorded in the final session report.

## Power of Ten inspections

New functions stay below sixty physical lines. There is no recursion, network
access, dynamic evaluation, unbounded search, detached process or shared mutable
scientific state. Local basis pivots, vectors and factors have one owner.
Subprocess results propagate, and compiler/search calls have 120/300 second
timeouts. Temporary directories have scoped cleanup. Overwrite refusal happens
before computation. All meaningful mathematical checks remain active with -O.

The managed Python runtime allocates objects during exact arithmetic and
set construction. This is a rule-3 deviation, limited by twelve original roles,
48 calls per reduction input, at most twelve basis vectors, the fixed 5,333-word
corroboration domain and two 42,041-state independent balls. Each matrix has at
most 144 eight-bit coefficients. Native steady-state allocation is retained
unchanged from PR3471: stored balls contain at most 91,955 states and streamed
candidates are not retained. Standard-library table, set, JSON and subprocess
internals allocate and are not fully audited here. These are bounds on live
collections, not measured byte limits or a replacement for a hard memory quota.
Follow-up would require a packed fixed-capacity implementation before exposing
an unrestricted-input service; no such service is introduced.

The inherited native factor sets use a standard unordered-set hash callback,
and unittest uses bounded framework dispatch and explicit monkeypatches.
These are rule-8/9 deviations with visible fixed targets. Native hashing does
not decide mathematical equality, which compares every state word. Test
mutations restore scope on exit. No production plugin or runtime registry is
introduced. A fixed-capacity native replacement would retain the same equality
and mutation controls.

The generic repository replay runner and exporter are unchanged infrastructure.
Their dependency/import behavior is covered by repository checks, not a claim
of a new whole-runner audit. New direct verifiers use source files and support
-I; shared publication helpers use ordinary import mode as documented.

## Remaining obligations

five-role exclusion, nonuniform-price optimum, physical caller/consumer bill,
all-size supplier admission and multiplication theorem are unrun or outside
scope. Retained predecessor attribution and immutable bytes are preserved.
