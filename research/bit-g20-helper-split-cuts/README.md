# All common-frame G20 helper split cuts

The P104 helper-split mechanism has no direct unchanged-word application
at any cut of this G20 BIT source. The exact result covers all 427 retained
helpers, all four equal-endpoint groups, every proper nested cut frame,
arbitrary common-frame binary bases and all existing owned buffers.
It also covers scalar extensions in characteristic two and the algebraic
bilinear transpose. [PROOF.md](PROOF.md) states the necessary pairing test.

The source is PR5512 at main 5e0052ca0aa3036a3afa8b0438927377c8d97d53.
[Discussion5607](https://github.com/CrocSwap/integer-mult-bounds/discussions/5607)
records the scope. The selected frontier is unchanged. No new kappa is claimed.

Run `python3.12 -B scripts/research_package.py --package research/bit-g20-helper-split-cuts`.
Python 3.12 and the standard library suffice. The verifier covers all
22534 cuts of 22533 events, binds rational physical frames, checks each
kernel pairing and a separate rank-product identity, and compares complete
forward and reverse traversal coverage. The exact 660-column RAW/DIRTY
endpoint and positive/negative controls are checked. Input hashes refer
to unchanged source bytes; FRAMES.json is stored in a gzip wrapper to
preserve its source line endings. Normal and optimized runs are registered.

The source native-frame induction is a credited premise. This package
does not rerun the complete physical caller, finite compiler, outer proof,
formal kernel or full-history ancestry. Its all-cut rank result is author
checked; an independent reviewer has not accepted it.
