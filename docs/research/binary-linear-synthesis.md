# Construct a cheapest complete binary linear word

Use this tool for at most four arbitrary binary roles with a specified XOR and
SWAP alphabet. Each allowed gate has a positive integer cost. The target is the
complete output matrix, including all roles that must return their input.
No register is assumed to start at zero.

```json
{"schema":"binary-linear-synthesis/v1","width":2,"target":[2,1],"gates":[
 {"op":"xor","src":0,"dst":1,"cost":1},
 {"op":"xor","src":1,"dst":0,"cost":1},
 {"op":"swap","src":0,"dst":1,"cost":7}
]}
```

```sh
python3 -B scripts/synthesize_binary_linear.py problem.json > certificate.json
python3 -B scripts/synthesize_binary_linear.py problem.json --check certificate.json
```

Each target row is an integer bit mask: bit j is the coefficient of input j.
The example swaps the two arbitrary inputs at cost 3 with XORs instead of the
cost-7 SWAP. Word entries are indices in the declared gate list. Gate prices
must include their stated local work; the tool does not infer physical prices.

The producer runs Dijkstra's algorithm over the subgroup generated by the
allowed gates. It exports a potential for every reached matrix. The checker
requires closure under every allowed gate and the inequality
p(next)<=p(current)+gate_cost, with p(identity)=0. This bounds every possible
word from below. The returned word attains the target potential. A separate
literal bit interpreter checks it on every possible input. If the closed set
omits the target, the requested endpoint is unreachable in this alphabet.

The full four-role XOR group has 20160 elements. The tool checks that boundary;
it does not restrict the word length to an arbitrary search radius. Positive
costs ensure an optimal word has no repeated state. Singular targets are
unreachable because every allowed gate is invertible. Empty alphabets are
supported. Limits: four roles, 18 distinct gates, gate costs in 1..10^9 and
4 MiB JSON input or saved certificate.

## Open next questions

Use the emitted word as a small source-bound linear replacement. Recheck the
complete caller endpoint, aliases, native phases, operator semantics and the
full bill. This model does not include clean scratch, COPY/CLEAR, frame changes,
recursive calls or rounding. Minimum scalar gate cost alone does not raise
kappa or establish a native tensor identity.
